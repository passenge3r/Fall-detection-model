# PreVFall 留出测试案例集

所有案例均采用严格受试者独立模型：视频中的受试者编号与测试fold一致，该受试者未参与对应模型训练和阈值选择。黄色倒计时/官方标签只用于画面展示，不进入模型。

## 预测成功

### 1. Subject 1：三个时距全部命中

- 视频：`success_subject1_fdfsm1.mp4`
- 官方事件：眩晕后向前跌倒，侧视角。
- 中风险首次出现：跌倒前2.00秒。
- 高风险首次出现：跌倒前0.93秒。
- 严格判定：1秒、2秒、3秒均命中。

### 2. Subject 4：三个时距命中，但存在过早预警

- 视频：`success_subject4_fdssm4.mp4`
- 官方事件：眩晕后侧向跌倒，侧视角。
- 严格判定：1秒、2秒、3秒均命中。
- 局限：模型在规定时距之前已经触发部分风险，说明其对该动作较敏感；可以算召回成功，但不是理想校准案例。

## 预测失败

### 3. Subject 5：错过1秒和2秒时距

- 视频：`failure_missed_subject5_fwsfm5.mp4`
- 官方事件：无力后侧向跌倒，正视角。
- 严格判定：3秒低风险命中；2秒中风险和1秒高风险均未在各自规定窗口内命中。
- 失败类型：风险升级不稳定/临近跌倒时置信度回落。

### 4. Subject 6：非跌倒误报

- 视频：`failure_false_alarm_subject6_cgsm6.mp4`
- 官方标签：无跌倒。
- 模型输出：触发高风险。
- 失败类型：将异常姿态或动作变化误判为即将跌倒。

## 使用建议

现场展示时应先播放两个成功案例，再主动展示漏报和误报案例，最后说明当前方案通过连续窗口确认、9折投票、姿态质量门控以及后续真实场景阈值校准降低误报。不要只播放成功案例并宣称已经能够无人值守部署。
