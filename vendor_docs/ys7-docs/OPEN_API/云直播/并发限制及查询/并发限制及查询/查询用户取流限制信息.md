## 查询用户取流限制信息

- 接口功能

   查询用户设置的取流并发限制信息

- 请求地址

`https://open.ys7.com/api/v3/mall/online/user/limit/live`

- 请求方式

`GET`

- 子账户token请求所需最小权限

`仅支持E套餐未欠费的主账号token调用`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | liveType | String | 取流类型，入参为:VTDU或者RTMP。轻应用jsdecode和私有流选择VTDU；HLS、RTMP、FLV选择RTMP | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/mall/online/user/limit/live?liveType=VTDU' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{"meta":{"code":0,"message":"string"},"data":[[]]}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应状态信息 |
| -code | Int | 响应码 |
| -message | String | 响应描述 |
| data | Array<Object> | 响应体 |
| -limitType | Int | 限制类型，0:按通道限制，1:按用户限制 |
| -liveType | String | 取流类型，VTDU或者RTMP |
| -limitNumber | Int | 限制并发数 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 无效参数 |  |
| 500 | 操作失败 |  |
