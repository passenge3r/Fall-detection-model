# 查询直播流推流记录列表

---

## 接口URL

GET /api/service/media/streammanage/stream/record/list

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放API访问令牌 |  |

### query

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| streamId | long | Y | 直播流ID |  |
| startTime | string | Y | 开始时间，默认为30天以前 |  |
| endTime | string | Y | 结束时间，默认为当前时间 |  |
| pageStart | int | Y | 页码，默认0 |  |
| pageSize | int | Y | 页大小，默认50，最大100 |  |

## 响应

```
{
    "data": {
        "recordList": [
            {
                "client": "127.0.0.1:8080", //客户端标识
                "startTime": "2024-12-11 12:00:00", //直播流推流记录开始时间
                "endTime": "2024-12-11 12:00:00" //直播流推流记录的结束时间
            }
        ]
    },
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {
            "total": 7,
            "pageSize": 100,
            "pageStart": 1,
            "hasMore": true
        }
    }
}
```

### 错误码

| 状态码 | 错误码 | 错误信息 | 解决方案 |
| --- | --- | --- | --- |
| 400 | 10001 | streamId为空 |  |
| 400 | 10001 | streamId格式错误 |  |
| 400 | 10001 | startTime格式错误 |  |
| 400 | 10001 | endTime格式错误 |  |
| 400 | 10001 | startTime必须在30天内 |  |
| 400 | 10001 | endTime必须在30天内 |  |
| 400 | 10001 | endTime必须大于startTime |  |
| 400 | 10001 | startTime不能大于当前时间 |  |
| 400 | 10001 | endTime不能大于当前时间 |  |
| 400 | 10001 | pageStart格式错误 |  |
| 400 | 10001 | pageSize格式错误 |  |
| 400 | 10001 | pageStart不能小于0 |  |
| 400 | 10001 | pageSize不能小于1 |  |
| 400 | 10001 | pageSize不能大于100 |  |
| 404 | 404 | streamId不存在 |  |
| 500 | 50000 | 服务异常 |  |
