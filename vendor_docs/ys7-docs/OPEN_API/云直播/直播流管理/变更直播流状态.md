# 变更直播流状态

---

## 接口URL

PUT /api/service/media/streammanage/stream/status

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放API访问令牌 |  |

### query

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| streamId | string | Y | 直播流ID |  |
| status | int | Y | 状态：0-禁用，1-启用 |  |

## 响应

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```
