## 查询直播流列表（GET）

- 接口功能

   查询直播流列表

- 请求地址

`https://open.ys7.com/api/service/media/streammanage/stream/list`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| header | deviceSerial | string | 设备序列号，只作为筛选条件 | N |
| body | streamId | string | 流ID | N |
| body | pageStart | int | 页码，默认0 | N |
| body | pageSize | int | 页大小，默认50，最大100 | N |
| body | accessType | int | 接入类型：1-设备接入，2-rtmp接入 | N |
| body | status | int | 流状态：0-已禁用，1-已启用 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/media/streammanage/stream/list' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: DEVICE_SERIAL' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'streamId=value' \
--data-urlencode 'pageStart=value' \
--data-urlencode 'pageSize=value' \
--data-urlencode 'accessType=value' \
--data-urlencode 'status=value'
```
