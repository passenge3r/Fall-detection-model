# 删除直播流

---

## 接口URL

DELETE /api/service/media/streammanage/stream

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放平台用户的accessToken |  |

### query

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| streamId | string | Y | 直播流ID |  |

## 响应

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

### 错误码

| 状态码 | 错误码 | 错误信息 | 解决方案 |
| --- | --- | --- | --- |
| 400 | 10001 | streamId为空 |  |
| 400 | 10001 | streamId格式错误 |  |
| 404 | 404 | streamId不存在 |  |
| 500 | 50000 | 系统异常 |  |
