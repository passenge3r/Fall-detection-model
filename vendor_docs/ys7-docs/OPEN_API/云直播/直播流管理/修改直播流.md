# 修改直播流

---

## 接口URL

PUT /api/service/media/streammanage/stream

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放API访问令牌 |  |

### query

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| streamId | string | Y | 直播流ID |  |
| startTime | string | Y | 开始时间，时间格式：yyyy-MM-dd HH:mm:ss，开始时间和结束时间跨度最多720天 |  |
| endTime | string | Y | 结束时间，时间格式：yyyy-MM-dd HH:mm:ss，开始时间和结束时间跨度最多720天，结束时间不能小于等于当前时间 |  |

## 响应

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

### 错误码

| 状态码 | 错误码 | 错误信息 | 解决方案 |
| --- | --- | --- | --- |
| 400 | 10001 | streamId为空 |  |
| 400 | 10001 | streamId格式错误 |  |
| 400 | 10001 | startTime为空 |  |
| 400 | 10001 | endTime为空 |  |
| 400 | 10001 | startTime格式错误 |  |
| 400 | 10001 | endTime格式错误 |  |
| 400 | 10001 | startTime和endTime跨度最多为7天 |  |
| 400 | 10001 | endTime必须大于当前时间 |  |
| 400 | 10001 | endTime必须大于startTime |  |
| 404 | 404 | streamId不存在 |  |
| 500 | 50000 | 系统异常 |  |
