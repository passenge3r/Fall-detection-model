## 获取直播流播放地址（GET）

- 接口功能

   获取直播流播放地址

- 请求地址

`https://open.ys7.com/api/service/media/streammanage/stream/address`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| body | streamId | long | 直播流ID | Y |
| body | protocol | int | 流播放协议，1-hls、2-rtmp、3-flv | Y |
| body | quality | int | 视频清晰度，1-高清（主码流，默认）、2-流畅（子码流）。 rtmp直推流该字段不生效 | N |
| body | supportH265 | int | 是否支持H265编码，0-不支持（默认），1-支持。 rtmp直推流该字段不生效 | N |
| body | mute | int | 是否静音，0-不静音（默认），1-静音。 rtmp直推流该字段不生效 | N |
| body | type | int | 类型：1-播放地址（默认），2-推流地址（rtmp接入直播流生效） | N |
| body | expireTime | int | 过期时间，rtmp接入直播流生效，单位秒，默认为730天，最大为730天 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/media/streammanage/stream/address' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'streamId=value' \
--data-urlencode 'protocol=value' \
--data-urlencode 'quality=value' \
--data-urlencode 'supportH265=value' \
--data-urlencode 'mute=value' \
--data-urlencode 'type=value' \
--data-urlencode 'expireTime=value'
```

- 返回数据

```
{
    "data": {
        "address": "rtmp://rtmp02open.ys7.com:1935/v3/openlive/FR1229491_1_1?sid=787305182210818048&mute=1&t=f0f054233a252a1f32af13a1a59a95f302c613df84aef2459aeb5da2f38c3fc8&ev=100&supportH265=1"
    },
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

| --- | --- | --- |
