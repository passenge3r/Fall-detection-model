## 设备本地录像统一查询接口

- 接口功能

   设备本地录像统一查询接口

- 请求地址

`https://open.ys7.com/api/v3/device/local/video/unify/query`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放平台令牌，支持托管、子账号、设备小权限token，权限为Replay | Y |
| Header | deviceSerial | String | 设备序列号 | Y |
| Header | localIndex | String | 通道号 | N |
| Query | recordType | Int | 录像类型 1:定时录像 2:事件录像 3:智能-车 4:智能-人形 5:自动浓缩录像，不填默认查询所有类型 | N |
| Query | startTime | String | 起始时间，时间格式为:1731988238，开始结束时间必须在同一天，开始时间不能大于结束时间 | Y |
| Query | endTime | String | 结束时间，时间格式为:1732007943，开始结束时间必须在同一天，开始时间不能大于结束时间 | Y |
| Query | isQueryByNvr | Int | 是否反查NVR录像，0-不反查(默认)，1-反查NVR | N |
| Query | location | Int | 录像检索位置：1-本地录像检索(默认)，2-CVR中心录像检索 | N |
| Query | pageSize | Int | 分页的页面大小，默认50，最大500 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/local/video/unify/query?startTime=1731988238&endTime=1732007943' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: J79401957' \
--header 'localIndex: 1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "records": [
            {
                "startTime": 1731945592,
                "endTime": 1731949200,
                "type": "ALARM",
                "size": ""
            }
        ],
        "fromNvr": true,
        "deviceSerial": "J79401957",
        "localIndex": "1",
        "hasMore": true,
        "nextFileTime": 1732007943
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 业务数据 |
| data.records | Array | 录像记录列表 |
| data.records[].startTime | Long | 录像开始时间 |
| data.records[].endTime | Long | 录像结束时间 |
| data.records[].type | String | 录像类型 |
| data.records[].size | String | 录像文件大小，单位：字节 |
| data.fromNvr | Boolean | 该录像文件是否来自关联的NVR |
| data.deviceSerial | String | fromNvr为true则返回关联NVR设备序列号，否则返回入参填的设备序列号 |
| data.localIndex | String | fromNvr为true则返回关联NVR设备通道号，否则返回入参填的设备通道号 |
| data.hasMore | Boolean | 是否存在更多录像文件 |
| data.nextFileTime | Long | hasMore为true时，该参数值为下一个录像文件的开始时间，可作为下一页录像文件查询的开始时间 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 请求参数有误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
| 10031 | 账号无权限访问该设备 | 账号无权限访问该设备 |
| 20001 | 通道不存在 | 通道不存在 |
| 20002 | 设备不存在 | 设备不存在 |
| 20006 | 网络异常 | 网络异常 |
| 20007 | 设备不在线 | 设备不在线 |
| 20008 | 设备响应超时 | 设备响应超时 |
| 20015 | 设备不支持 | 设备不支持该录像类型 |
| 50000 | 服务异常 | 服务异常 |
