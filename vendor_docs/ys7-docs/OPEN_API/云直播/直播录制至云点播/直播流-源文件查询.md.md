## 直播流-源文件查询

- 接口功能

   直播流-源文件查询。不支持子账号。流相关文件存储在存储引擎中，如果文件在存储引擎过期或删除，则返回的fileNodeId无法获取到具体的文件地址

- 请求地址

`https://open.ys7.com/api/service/media/streammanage/stream/file/info`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| body | streamId | String | 流id | Y |
| body | fileType | Int | 文件类型：1录像 2截图 | Y |
| body | queryDate | String | 录像时间，格式'2025-07-28'（fileType=1时必传） | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/media/streammanage/stream/file/info' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'streamId=787305182210818048' \
--data-urlencode 'fileType=1' \
--data-urlencode 'queryDate=2025-07-28'
```

- 返回数据

```
{
    "data": {
        "streamId": "787305182210818048",
        "fileType": 1,
        "fileInfo": [
            {
                "fileNodeId": "2W1QQ",
                "createTime": "1753267106000",
                "updateTime": "1753267106000"
            }
        ]
    },
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| data | Object | 返回数据 |
| data.streamId | String | 系统自动生成的32位字符串，直播流的唯一标识 |
| data.fileType | Int | 文件类型：1录像 2截图 |
| data.fileInfo | Array | 文件信息列表 |
| data.fileInfo[].fileNodeId | String | 文件节点ID |
| data.fileInfo[].createTime | String | 创建时间，13位时间戳 |
| data.fileInfo[].updateTime | String | 更新时间，13位时间戳 |
| meta.code | Int | 状态码，200表示成功 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数不合法 |
| 404 | 资源不存在 | 请求的资源不存在 |
| 20003 | 直播流不存在 | 指定的直播流不存在 |
