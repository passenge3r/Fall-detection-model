## 直播流-云点播文件获取

- 接口功能

   查询流-云点播录像文件。依赖底层存储引擎，如果选定时间段的文件过期或被删除，将无法查到具体文件信息

- 请求地址

`https://open.ys7.com/api/service/media/streammanage/stream/index/file`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| body | streamId | String | 流id | Y |
| body | startTime | String | 开始时间，格式'2025-07-28 12:12:12'，开始时间和结束时间间隔不能超过一天 | Y |
| body | stopTime | String | 停止时间，格式'2025-07-28 13:12:12' | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/media/streammanage/stream/index/file' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'streamId=787305182210818048' \
--data-urlencode 'startTime=2025-07-28 12:12:12' \
--data-urlencode 'stopTime=2025-07-28 13:12:12'
```

- 返回数据

```
{
    "data": {
        "streamId": "787305182210818048",
        "fileInfo": {
            "fileNodeId": "2W1QQ",
            "fileUrl": "https://cloud-oss-ez/124.m3u8"
        }
    },
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| data | Object | 返回数据 |
| data.streamId | String | 系统自动生成的32位字符串，直播流的唯一标识 |
| data.fileInfo | Object | 文件信息 |
| data.fileInfo.fileNodeId | String | 文件节点ID |
| data.fileInfo.fileUrl | String | 文件地址 |
| meta.code | Int | 状态码，200表示成功 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 404 | 资源不存在 | 请求的资源不存在 |
| 20003 | 直播流不存在 | 指定的直播流不存在 |
| 20004 | 直播流录像格式不符 | 直播流的录像格式不符合要求 |
| 20005 | 直播流文件未找到 | 指定时间段内未找到直播流文件 |
