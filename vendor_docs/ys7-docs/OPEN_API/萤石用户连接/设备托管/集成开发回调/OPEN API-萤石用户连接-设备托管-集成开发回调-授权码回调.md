## 授权码回调

- 接口功能说明 开发者需要在控制台中填写回调地址,地址协议形式为 HTTPS/HTTP,同时整个请求地址由开发者自定义.开放平台会通过开发者的回调地址,将授权码以参数形式给到开发者,参数名为 auth\_code.开发者只需要通过 auth\_code 来获取需要的授权信息.

1. 在授权过程中开放平台会将 auth\_code 以及 traceability 给开发者，traceability为1到7位数字, auth\_code 有效时长为 10 分钟
2. 开发者拿到 auth\_code,通过 auth\_code 和开发者的 access\_token 请求到开放平台获取授权信息接口
3. 开发者可以通过在自己的托管中间页链接上加入自定义traceability的数字内容,来标记对应的业务内容（例如托管用户的标记）,在回调地址中可以获取由开放平台透传的traceability值,通过开发者自己的映射来达到区分业务的目标。
4. 收到授权信息后,返回给开放平台服务成功,返回其他字符则会接口调用失败.

- 请求地址 Url:{callBackAddress}?auth\_code=value&traceability=01234567
- 请求方式 Get 返回信息 { "code": "200" }

注：返回上述信息,则开放平台认为开发者信息获取成功.返回其他任何信息,均认为失败
