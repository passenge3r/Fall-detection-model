## B1账户单设备托管解绑

- 接口功能

   B1账户单设备托管解绑。当前将设备归属账号简称为账号B1，将被托管账号称为账号B2。目前该接口需平台人员在后台开通，且仅对付费客户开放，若账号为免费账号则无法使用该服务。若需开通请联系将申请发送至"open-team@ezvizlife.com"邮箱，我们会有专人对接处理。

- 请求地址

`https://open.ys7.com/api/v3/lapp/trust/sign/resource/relieve`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | B1账号萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号 | Y |
| Header | localIndex | String | 设备的局部资源标识（通道解绑时，必传） | N |
| Body | appKey | String | B2账号的appKey | Y |
| Body | state | String | 状态 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/lapp/trust/sign/resource/relieve' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: D81172392' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'appKey=6a822843d98c4fc8a36007e2e1c97183' \
--data-urlencode 'state=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": true
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| -code | Int | 服务响应状态码，参见响应码解释 |
| -message | String | 服务响应状态描述 |
| data | Boolean | 操作是否成功 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 参数错误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
| 50000 | 服务异常 | 服务异常 |
