BtoB托管服务

**服务介绍：**

萤石开放平台开发者搭建的平台服务已经深入各行各业，出于“空间有效利用”和“项目成本管控”的考虑，单个摄像头设备可能会有被使用到多个行业平台的诉求。需要将其他开发者账号（账号体系涵盖开放平台账号/云眸账号/云曜账号等）下面的设备托管至自己账号下方，此时BtoB设备托管产品服务便满足了多方行业客户对于多级设备权限管控的需求。
（目前B2B托管服务需平台人员在后台开通，且仅对付费客户开放，若账号为免费账号则无法使用该服务。若需开通请联系将申请发送至“open-team@ezvizlife.com”邮箱，我们会有专人对接处理）

**简单步骤：**

当前将设备归属账号简称为账号B1，将被托管账号称为账号B2

| 步骤 | 步骤功能 | 接口名称 | 操作 |
| --- | --- | --- | --- |
| 步骤1 | B2通过账号密钥授权码，提供给B1，代表B2愿意让B1进行授权托管操作。 | B账户托管申请生成授权码 | [查看详情](https://open.ys7.com/help/1890) |
| 步骤2 | B1通过密钥和B2给的授权码，进行可托管关系确认绑定 | B账户托管用户授权 | [查看详情](https://open.ys7.com/help/1891) |
| 步骤3 | B1通过查看账号下的设备列表，查看到哪些设备未被托管，哪些已托管，可以筛选出未托管的设备列表 | B账户托管查询资源列表 | [查看详情](https://open.ys7.com/help/1892) |
| 步骤4 | B1操作单设备托管接口，将某台设备托管给B2 | B账户单设备托管授权 | [查看详情](https://open.ys7.com/help/1893) |
| 步骤5 | B1若希望解除托管，则基于解绑接口进行解绑 | B账户单设备托管解绑 | [查看详情](https://open.ys7.com/help/1894) |
