## B1账户托管查询资源列表

- 接口功能

   B1账户托管查询资源列表。当前将设备归属账号简称为账号B1，将被托管账号称为账号B2。目前该接口需平台人员在后台开通，且仅对付费客户开放，若账号为免费账号则无法使用该服务。若需开通请联系将申请发送至"open-team@ezvizlife.com"邮箱，我们会有专人对接处理。

- 请求地址

`https://open.ys7.com/api/v3/lapp/trust/sign/resource/list`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 账号B1萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号 | N |
| Body | sign | String | 授权码 | Y |
| Body | authorizeType | String | 托管类型，authorize:查询已托管 | N |
| Body | pageStart | Int | 分页起始位置，默认0 | N |
| Body | pageSize | Int | 分页大小，默认10，最大20 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/lapp/trust/sign/resource/list' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'sign=6a822843d98c4fc8a36007e2e1c97183' \
--data-urlencode 'authorizeType=authorize' \
--data-urlencode 'pageStart=0' \
--data-urlencode 'pageSize=10'
```
