## B2账户托管申请生成授权码

- 接口功能

   B2账户托管申请生成授权码。当前将设备归属账号简称为账号B1，将被托管账号称为账号B2。目前该接口需平台人员在后台开通，且仅对付费客户开放，若账号为免费账号则无法使用该服务。若需开通请联系将申请发送至"open-team@ezvizlife.com"邮箱，我们会有专人对接处理。

- 请求地址

`https://open.ys7.com/api/v3/lapp/trust/sign/apply`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | B2账号的萤石开放API访问令牌 | Y |
| Body | appKey | String | B1账号的appKey | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/lapp/trust/sign/apply' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'appKey=6a822843d98c4fc8a36007e2e1c97183'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": {
        "sign": "6a822843d98c4fc8a36007e2e1c97183#f65ee5ff5db8457c9650634a12c7e053#d7a4e8f92de44cdbbc94a332cea6ecc1",
        "appKey": "6a822843d98c4fc8a36007e2e1c97183"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| -code | Int | 服务响应状态码，参见响应码解释 |
| -message | String | 服务响应状态描述 |
| data | Object | 响应数据 |
| -sign | String | 授权码 |
| -appKey | String | 开发者B用户的应用key |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 参数错误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
| 10015 | 授权地址不存在 | 授权地址不存在 |
| 10005 | appKey异常 | appKey异常 |
