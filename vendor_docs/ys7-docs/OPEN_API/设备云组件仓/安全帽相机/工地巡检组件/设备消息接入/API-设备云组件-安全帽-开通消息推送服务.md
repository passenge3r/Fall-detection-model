## 开通消息推送服务

开通消息推送服务可前往：萤石开放平台控制台-产品中心-消息推送.

![](https://resource.eziot.com/group2/M00/00/A2/CtwQFmSb1guAFZKyAAKMxuneEok939.png)

a) 消息类型：

- 报警消息：包含人体感应事件、紧急遥控按钮事件、移动侦测报警、婴儿啼哭等多种报警类型。
- 上下线消息：设备上线与下线消息。
- ISAPI上行消息：针对此设备包含

b) webhook回调地址

c) 签名密钥（可选）

d) 推送失败最大充实次数（可选，取值范围1~3）

e) 回调失败通知邮箱、短信通知手机号（可选）
