## 设置窗帘行程校准

- 接口功能

   设置窗帘行程校准。功能描述：设置窗帘行程校准；是否支持托管：是；是否支持子帐号：是；需要权限：DevCtrl；资源类型：dev。

- 请求地址

`https://open.ys7.com/api/v3/device/curtain/correct`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/curtain/correct' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: {deviceSerial}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 元数据 |
| meta.code | Integer | 业务状态码 |
| meta.message | String | 业务信息 |
| meta.moreInfo | Object | 额外信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 参数错误 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |
| 50000 | 服务异常 | 服务异常 |
| 20007 | 设备不在线 | 设备不在线 |
| 20002 | 设备不存在 | 设备不存在 |
