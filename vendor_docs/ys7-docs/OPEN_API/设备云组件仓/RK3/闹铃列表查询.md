---

## 闹铃列表查询

- 接口功能

   用于查询RK3设备上生活提醒闹钟信息列表，其它设备不保障可用。

   托管和子账户token请求所需最小权限 "Permission":"GET" "Resource":"dev:序列号"

- 请求地址

`https://open.ys7.com/api/v3/device/life/remind/clock/list`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl -X GET 'https://open.ys7.com/api/v3/device/life/remind/clock/list?deviceSerial=BDXXXXX' \
-H 'accessToken: at.xxxxx'
```

- 返回数据

```
{
  "meta": {
    "code": 200,
    "message": "操作成功",
    "moreInfo": null
  },
  "data": [
    {
      "clockId": "lbYf7492",
      "timeHour": 8,
      "timeMin": 30,
      "tag": "闹钟",
      "enable": 1,
      "once": 0,
      "year": 0,
      "month": 0,
      "day": 0,
      "weekdays": [1, 2, 3, 4, 5],
      "content": "工作日闹铃",
      "faceId": "",
      "name": ""
    }
  ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 状态码，参考下方返回码。**优先判断该错误码，返回200即表示成功**。 |
| meta.message | String | 状态描述 |
| meta.moreInfo | String | 更多信息 |
| data[].clockId | String | 新建闹钟ID |
| data[].timeHour | Int | 小时 |
| data[].timeMin | Int | 分钟 |
| data[].tag | String | 闹铃名称 |
| data[].enable | Int | 0-禁用 1-启用 |
| data[].once | Int | 0-重复 1-单次 |
| data[].year | Int | 年份 |
| data[].month | Int | 月份 |
| data[].day | Int | 日期 |
| data[].weekdays | Array | 生效星期列表 |
| data[].content | String | 提醒内容 |
| data[].faceId | String | 提醒人脸对象ID |
| data[].name | String | 提醒对象名称 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 检查请求参数 |
| 10002 | accessToken异常或过期 | 重新获取token |
| 10005 | 无权限操作 | 检查账号权限 |
| 20001 | 设备不存在 | 检查设备序列号 |
| 20002 | 设备不属于该用户 | 确认设备归属 |
| 20007 | 设备不在线 | 确认设备在线状态 |
