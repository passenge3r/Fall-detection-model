# 删除闹铃

> 删除RK3设备上的闹铃

> 更新时间: 2026-06-11T14:52:12.000+08:00

> 文档ID: 5220 | 来源树: OPEN_API

---

## 删除闹铃

- 接口功能

   删除RK3设备上已创建的生活提醒闹钟，其它设备不保障可用。

   托管和子账户token请求所需最小权限 "Permission":"CONFIG" "Resource":"dev:序列号"

- 请求地址

`https://open.ys7.com/api/v3/device/life/remind/clock`

- 请求方式

`DELETE`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| body | (body) | Array<String> | 闹钟ID列表，数量≤10 | Y |

- 请求示例

```
curl -X DELETE 'https://open.ys7.com/api/v3/device/life/remind/clock' \
-H 'accessToken: at.xxxxx' \
-H 'deviceSerial: BDXXXXX' \
-H 'Content-Type: application/json' \
-d '["lbYf7492","zKUo9392"]'
```

- 返回数据

```
{
  "meta": {
    "code": 200,
    "message": "操作成功",
    "moreInfo": null
  },
  "data": null
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 状态码，参考下方返回码。**优先判断该错误码，返回200即表示成功**。 |
| meta.message | String | 状态描述 |
| meta.moreInfo | String | 更多信息 |
| data | Object | null（删除成功无返回数据） |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 检查请求参数 |
| 10002 | accessToken异常或过期 | 重新获取token |
| 10005 | 无权限操作 | 检查账号权限 |
| 20001 | 设备不存在 | 检查设备序列号 |
| 20002 | 设备不属于该用户 | 确认设备归属 |
| 20007 | 设备不在线 | 确认设备在线状态 |
