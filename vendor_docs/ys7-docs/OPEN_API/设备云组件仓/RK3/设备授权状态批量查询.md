## 设备授权状态批量查询

- 接口功能

   查询用户名下的多个RK3设备的授权状态，其它设备不保障可用。能力集校验：否；是否支持托管：否；是否支持子账户：是（子账号请求所需最小权限：操作权限为"GET"，资源类型为 DEVICE）。

- 请求地址

`https://open.ys7.com/api/v3/device/authorize/list`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌，参考"获取AccessToken"接口获取 | Y |
| header | Content-Type | String | 请求内容类型，固定值：application/json | Y |
| body | deviceSerials | Array<String> | 设备序列号集合，整个请求体即为该数组（不可重复，数量≤10） | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/authorize/list' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '["BD1231873","BD1231874"]'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": [
        {
            "deviceSerial": "BD1231873",
            "status": 1
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 状态码，参考下方返回码 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 扩展信息，无内容时为 null |
| data | Array<Object> | 设备授权状态结果集 |
| data[].deviceSerial | String | 设备序列号 |
| data[].status | Int | 授权状态：1-已授权，0-未授权 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请检查请求参数是否正确 |
| 10002 | accessToken过期或异常 | 请重新获取accessToken |
| 10005 | 无权限操作 | 请检查账号权限 |
| 20001 | 设备不存在 | 请检查设备序列号是否正确 |
| 20002 | 设备不属于该用户 | 请确认设备归属 |
| 20007 | 设备不在线 | 请确认设备处于在线状态 |
