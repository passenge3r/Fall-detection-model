## 闹铃提醒记录查询

- 接口功能

   用于查询RK3设备上已执行的闹铃提醒记录以及未来待执行的闹铃，其它设备不保障可用。能力集校验：否；是否支持托管：是；是否支持子账户：是（托管和子账号请求所需最小权限：操作权限为"GET"，资源类型为 DEVICE）。

- 请求地址

`https://open.ys7.com/api/v3/device/life/remind/clock/schedule/record`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌，参考"获取AccessToken"接口获取 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| body | date | String | 查询日期，格式：yyyy-MM-dd | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/life/remind/clock/schedule/record' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: BDXXXXXXX' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'date=2026-05-11'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": [
        {
            "name": "闹钟",
            "configId": "QjFz7293",
            "remindTime": "2026-05-11 19:51:00",
            "type": 1,
            "memberId": "d04684eb9e794eebad5b1c79d21c48b6",
            "memberName": "张三",
            "status": 2,
            "mark": "",
            "clock": {
                "clockType": "date",
                "clockPeriod": "2026-5-11"
            }
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 状态码，参考下方返回码 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 扩展信息，无内容时为 null |
| data | Array<Object> | 闹铃提醒记录列表 |
| data[].name | String | 提醒名称 |
| data[].configId | String | 配置ID（闹钟配置ID） |
| data[].remindTime | String | 提醒时间，格式：yyyy-MM-dd HH:mm:ss |
| data[].type | Int | 类型，1-闹钟 |
| data[].memberId | String | 成员ID（人脸对象ID） |
| data[].memberName | String | 成员名称 |
| data[].status | Int | 状态：0-未完成，1-待办，2-完成 |
| data[].mark | String | 备注 |
| data[].clock | Object | 闹钟扩展信息（type=1时有值） |
| data[].clock.clockType | String | 提醒类型 |
| data[].clock.clockPeriod | String | 提醒周期 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请检查请求参数是否正确 |
| 10002 | accessToken过期或异常 | 请重新获取accessToken |
| 10005 | 无权限操作 | 请检查账号权限 |
| 20001 | 设备不存在 | 请检查设备序列号是否正确 |
| 20002 | 设备不属于该用户 | 请确认设备归属 |
| 20007 | 设备不在线 | 请确认设备处于在线状态 |
