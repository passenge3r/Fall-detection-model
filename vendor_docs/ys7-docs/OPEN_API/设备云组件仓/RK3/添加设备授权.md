> 为RK3设备添加授权，使用开放平台设备添加接口后，需要调用此接口给设备授权，萤石APP添加无需调用

## 添加设备授权

- 接口功能

   用于给RK3设备授权。使用开放平台设备添加接口或者控制台上进行设备绑定后，如果想要使用设备上的闹铃功能，需要调用此接口，其它设备不保障可用。能力集校验：否；是否支持托管：否；是否支持子账户：是（子账号请求所需最小权限：操作权限为"CONFIG"，资源类型为 DEVICE）。

- 请求地址

`https://open.ys7.com/api/v3/device/authorize/add`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌，参考"获取AccessToken"接口获取 | Y |
| header | Content-Type | String | 请求内容类型，固定值：application/x-www-form-urlencoded | Y |
| body | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/authorize/add' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'deviceSerial=BDXXXXXXX'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": null
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 状态码，参考下方返回码 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 扩展信息，无内容时为 null |
| data | Object | 业务数据，本接口固定为 null |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请检查请求参数是否正确 |
| 10002 | accessToken过期或异常 | 请重新获取accessToken |
| 10005 | 无权限操作 | 请检查账号权限 |
| 20001 | 设备不存在 | 请检查设备序列号是否正确 |
| 20002 | 设备不属于该用户 | 请确认设备归属 |
| 20007 | 设备不在线 | 请确认设备处于在线状态 |
