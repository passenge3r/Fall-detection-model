> 更新时间: 2026-06-11T14:52:20.000+08:00

> 文档ID: 5218 | 来源树: OPEN_API

---

## 添加闹铃

- 接口功能

   用于RK3设备添加生活提醒闹钟，支持重复闹铃和单次闹铃，其它设备不保障可用。

   托管和子账户token请求所需最小权限 "Permission":"CONFIG" "Resource":"dev:序列号"

- 请求地址

`https://open.ys7.com/api/v3/device/life/remind/clock`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| body | timeHour | Int | 小时 0-23 | Y |
| body | timeMin | Int | 分钟 0-59 | Y |
| body | once | Int | 0-重复(默认) 1-单次 | N |
| body | year | Int | 年份，不小于当前年，不超过9999 | N |
| body | month | Int | 月份 1-12 | N |
| body | day | Int | 日期，按月份校验 | N |
| body | weekdays | Array<Int> | 生效星期 0(周日)~6(周六)，不可重复。单次只能1个且匹配日期 | Y |
| body | content | String | 提醒内容，最长20字符 | N |
| body | tag | String | 闹铃名称，最长50字符，不传默认"闹钟" | N |
| body | faceId | String | 提醒人脸对象ID（与name同时填写或同时为空） | N |
| body | name | String | 提醒对象名称（与faceId同时填写或同时为空） | N |

- 请求示例

```
curl -X POST 'https://open.ys7.com/api/v3/device/life/remind/clock' \
-H 'accessToken: at.xxxxx' \
-H 'deviceSerial: BDXXXXX' \
-H 'Content-Type: application/json' \
-d '{"timeHour":8,"timeMin":30,"once":0,"weekdays":[1,2,3,4,5],"content":"工作日闹铃"}'
```

- 返回数据

```
{
  "meta": {
    "code": 200,
    "message": "操作成功",
    "moreInfo": null
  },
  "data": {
    "clockId": "lbYf7492"
  }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 状态码，参考下方返回码。**优先判断该错误码，返回200即表示成功**。 |
| meta.message | String | 状态描述 |
| meta.moreInfo | String | 更多信息 |
| data.clockId | String | 新建闹钟ID |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 检查请求参数 |
| 10002 | accessToken异常或过期 | 重新获取token |
| 10005 | 无权限操作 | 检查账号权限 |
| 20001 | 设备不存在 | 检查设备序列号 |
| 20002 | 设备不属于该用户 | 确认设备归属 |
| 20007 | 设备不在线 | 确认设备在线状态 |
