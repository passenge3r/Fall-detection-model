# 每日呼吸率统计-根据日期统计当天每10分钟呼吸率

> 更新时间: 2026-06-25T20:31:13.000+08:00

> 文档ID: 1836 | 来源树: OPEN_API

---

## 每日呼吸率统计-根据日期统计当天每10分钟呼吸率

- 接口功能

   根据日期统计当天每10分钟呼吸率统计每日呼吸率

- 请求地址

`https://open.ys7.com/api/service/sleepDetector/v3/third/forward/huayi/analysis/v1/devices/deviceIdPlaceholder/average/breaths`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| query | deviceId | String | 设备ID | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/sleepDetector/v3/third/forward/huayi/analysis/v1/devices/deviceIdPlaceholder/average/breaths?deviceId=xxx' \
--header 'accessToken: at.xxxxx'
```

- 返回字段

| avg | Float | 呼吸率平均值 |
| max | Int | 呼吸率最大值 |
| min | Int | 呼吸率最小值 |
| minuteList | Array<Object> | 呼吸率统计数据集 |
| -avg | Float | 呼吸率平均值 |
| -ts | String | 时间戳 |
| riskRank | String | 睡眠呼吸风险评估等级：FREE=无风险；LOW=低风险；MIDDLE=中风险；HIGH=高风险。可用值:FREE,HIGH,LOW,MIDDLE,UNKNOWN |
| sleepDatetime | String | 每日睡眠开始时间戳 |
| wakeupDatetime | String | 每日睡眠结束时间戳 |
