## 平台用户设备绑定

- 接口功能

   平台用户设备绑定。

- 请求地址

`https://open.ys7.com/api/service/sleepDetector/v3/third/huayi/device/bound`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 用户访问令牌 | Y |
| Query | deviceCode | String | 设备code | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/sleepDetector/v3/third/huayi/device/bound?deviceCode=ABC123' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "data": "1691721801237917698",
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| data | String | 绑定成功后生成的deviceId |
| meta | Object | 响应元信息 |
| -code | Int | 响应码 |
| -message | String | 响应信息 |
| -moreInfo | Object | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
| 400 | 参数错误 | 参数错误 |
