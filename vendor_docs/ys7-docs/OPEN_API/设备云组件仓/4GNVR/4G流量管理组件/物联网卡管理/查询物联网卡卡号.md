# 查询物联网卡卡号

## 查询物联网卡卡号

- 接口功能

   查询设备的物联网卡卡号

- 请求地址

`https://open.ys7.com/api/service/devicekit/simcard/device/nbCardId`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/devicekit/simcard/device/nbCardId' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: xxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": {
        "nbCardId": "898604A0102170147344"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应状态信息 |
| -code | Int | 错误码 |
| -message | String | 错误描述 |
| data | Object | 响应数据 |
| -nbCardId | String | 物联网卡卡号（部分海康设备支持） |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 参数错误 |  |
| 20018 | 该用户不拥有该设备 |  |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
