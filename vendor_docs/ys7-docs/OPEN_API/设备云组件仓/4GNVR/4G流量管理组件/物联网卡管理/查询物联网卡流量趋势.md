## 查询物联网卡流量趋势

- 接口功能

   获取查询月份内日期对应的物联网卡消耗流量

- 请求地址

`https://open.ys7.com/api/service/devicekit/simcard/statistic/trafficTrend`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| query | queryMonth | String | 查询月份，例：2023-01 | Y |
| query | nbCardId | String | 物联网卡卡号，部分物联网卡和设备关系不存在，补充查询条件 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/devicekit/simcard/statistic/trafficTrend?queryMonth=2023-01' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: xxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": [
        {
            "date": "2023-04-17",
            "usedVolume": 152135
        },
        {
            "date": "2023-04-18",
            "usedVolume": 122135
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应状态信息 |
| -code | Int | 错误码 |
| -message | String | 错误描述 |
| data | Array<Object> | 流量趋势数据 |
| -date | String | 日期 |
| -usedVolume | Int | 物联网卡消耗流量（字节） |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 参数错误 |  |
| 20018 | 该用户不拥有该设备 |  |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
