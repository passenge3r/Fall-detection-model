## 物联网卡添加

- 接口功能

   添加物联网卡

- 请求地址

`https://open.ys7.com/api/service/devicekit/simcard/add`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| body | nbCardIds | String | 物联卡卡号，例：111,112,113 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/devicekit/simcard/add' \
--header 'accessToken: at.xxxxx' \
--data-raw 'nbCardIds=111,112,113'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应状态信息 |
| -code | Int | 错误码 |
| -message | String | 错误描述 |
| data | Object | 响应数据 |
| -successList | Array<Object> | 添加成功卡号 |
| --icc | String | 卡号 |
| --success | Boolean | 是否添加成功 |
| --errCode | Int | 错误码 |
| --errMessage | String | 错误描述 |
| -failedResults | Array<Object> | 添加失败结果 |
| --icc | String | 卡号 |
| --success | Boolean | 是否添加成功 |
| --errCode | Int | 错误码。70000101:已输入过相同卡号；70000102:请输入正确的卡号，电信19位，移动20位；70000103:本账号已添加过该卡；70000104:该卡已加入流量池；70000105:该卡非萤石卡；70000404:分配流量池错误；70000106:该卡非萤石卡；70000107:本流量池已添加过该卡；70000108:该卡已加入其他流量池 |
