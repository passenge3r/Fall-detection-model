## 物联网卡删除

- 接口功能

   删除物联网卡

- 请求地址

`https://open.ys7.com/api/service/devicekit/simcard/delete`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| body | nbCardIds | String | 物联卡卡号，例：111,112,113 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/devicekit/simcard/delete' \
--header 'accessToken: at.xxxxx' \
--data-raw 'nbCardIds=111,112,113'
```
