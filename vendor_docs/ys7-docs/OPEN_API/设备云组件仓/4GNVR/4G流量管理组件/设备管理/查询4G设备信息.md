## 查询4G设备信息

- 接口功能

   获取4G设备信息，包括设备名称、设备在线状态、设备添加时间、设备离线时间、物联网卡号、物联网卡可用流量及有效期等信息

- 请求地址

`https://open.ys7.com/api/service/devicekit/simcard/device/info`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| query | nbCardId | String | 物联网卡卡号，部分物联网卡和设备关系不存在，补充查询条件 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/devicekit/simcard/device/info' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: xxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": {
        "deviceSerial": "K90134622",
        "deviceName": "停车砖设备",
        "status": 1,
        "addTime": "2023-03-10 21:07:10",
        "offlineTime": "2023-03-15 00:02:37",
        "nbCardId": "8986112129908240071",
        "remainingTrafficVolume": 24576.03,
        "expireTime": "2023-03-15 00:02:37"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应状态信息 |
| -code | Int | 错误码 |
| -message | String | 错误描述 |
| data | Object | 响应数据 |
| -deviceSerial | String | 设备序列号 |
| -deviceName | String | 设备名称 |
| -status | Int | 设备在线状态，0:不在线，1:在线 |
| -addTime | String | 设备添加时间 |
| -offlineTime | String | 设备离线时间 |
| -nbCardId | String | 物联网卡号 |
| -remainingTrafficVolume | Number | 物联网卡可用流量（MB） |
| -expireTime | String | 物联网卡有效期 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 参数错误 |  |
| 20018 | 该用户不拥有该设备 |  |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
