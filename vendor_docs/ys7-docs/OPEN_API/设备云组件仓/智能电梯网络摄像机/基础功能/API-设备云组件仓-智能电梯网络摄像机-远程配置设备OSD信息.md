# 远程配置设备OSD信息（POST）

- 进入开放平台控制台-我的资源-设备列表中，搜索指定设备，点击在线配置即可打开设备配置页面（目前还仅支持基础配置，电梯物联配置需在本地进行。）

![](https://resource.eziot.com/group2/M00/00/A5/CtwQF2S_e5WAHqFaAAClMkhibok791.png)

- 在图像-OSD设置中除了名称、日期、星期外还可以最多叠加4个自定义字符，可按照实际项目要求进行字符叠加。

![](https://resource.eziot.com/group2/M00/00/A5/CtwQFmS_e52AZCaGAAOL2NEPRBE544.png)
