# 开通消息推送服务

> 设备消息接入服务介绍：您仅需要提供一个推送地址，就可以收到消息进行解析。为了保障服务质量，每条消息推送请求设置的超时时间为2秒，处理超时后，认为该条消息发送失败，如果配置了重试机制，将会使用重试机制重试发送，达到最大重试次数依旧失败后，将丢弃消息不再进行推送。建议您接收推送消息后快速写入自己的消息队列中，提高消息接收能力。开通成功后即可获取消息，进行解析使用。

- 请确保您的账号已开通消息推送服务，并且还有消息推送资源剩余。首次开通有免费推送量赠送哦！

开通消息推送服务可前往：[萤石开放平台控制台-产品中心-消息推送](https://open.ys7.com/console/messagePush.html)。

- 上下线消息：设备上线与下线消息。
