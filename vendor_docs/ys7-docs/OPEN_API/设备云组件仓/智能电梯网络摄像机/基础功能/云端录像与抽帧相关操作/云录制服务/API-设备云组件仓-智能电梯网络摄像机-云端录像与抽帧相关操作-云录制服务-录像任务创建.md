# 录像任务创建

## 回放录制

- 接口URL

https://open.ys7.com/api/open/cloud/v1/rec/video/save

- 接口描述

创建回放录制任务，将现有的云存储视频存储至云端。支持转码或不转码。（设备本地录制信息不支持进行云录制传输至云端）

- 详细说明

<https://open.ys7.com/help/368#video_recorded-api1>

## 实时录制

- 接口URL

https://open.ys7.com/api/open/cloud/v1/preview/save

- 接口描述

创建实时录制任务，将进行中画面录制到云端。支持转码或不转码。（设备本地录制信息不支持进行云录制传输至云端）

- 详细说明

<https://open.ys7.com/help/368#video_recorded-api2>
