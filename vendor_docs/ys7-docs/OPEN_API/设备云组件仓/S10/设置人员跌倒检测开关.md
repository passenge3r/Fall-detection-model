## 设置人员跌倒检测开关

- 接口功能

   根据设备序列号、通道号、资源类别、领域标识和属性标识，设置设备的人员跌倒检测开关状态。

- 请求地址

`https://open.ys7.com/api/v3/device/otap/prop`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号,存在英文字母的设备序列号，字母需为大写 | Y |
| header | localIndex | Integer | 资源序号 | Y |
| header | resourceCategory | String | 资源类别，如global、Video等 | Y |
| header | domainIdentifier | String | 功能点领域，表示属性所属领域 | Y |
| header | propIdentifier | String | 功能点标识，表示具体的属性标识符 | Y |
| header | Content-Type | String | 请求体内容类型 | Y |
| body | enabled | Boolean | 是否启用该属性 | Y |

- 请求示例

```
curl -X PUT 'https://open.ys7.com/api/v3/device/otap/prop' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: XXX' \
--header 'localIndex: 1' \
--header 'resourceCategory: Video' \
--header 'domainIdentifier: PeopleFallingDownDetection' \
--header 'propIdentifier: PeopleFallingDownDetectionRule' \
--header 'Content-Type: application/json' \
--data '{"enabled": true}'
```

- 返回数据

```
{
  "meta": {
    "code": 200,
    "message": "操作成功",
    "moreInfo": null
  },
  "data": null
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 返回数据，设置成功时为空 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 请求参数异常 | 参数为空或格式不正确，Body不能为空 |
| 10002 | accessToken过期或异常 | 重新获取accessToken |
| 10031 | 子账户或萤石用户没有权限 | 请确认当前账户拥有该设备的配置权限 |
| 20007 | 设备不在线 | 请确认设备已上线后重试 |
| 20018 | 该用户不拥有该设备 | 请检查设备序列号是否正确，确认该设备属于当前用户 |
| 50000 | 服务异常 | 请稍后重试或联系技术支持 |
| 70018 | 资源不存在 | 请检查通道号（localIndex）是否正确，确认该通道资源存在 |
