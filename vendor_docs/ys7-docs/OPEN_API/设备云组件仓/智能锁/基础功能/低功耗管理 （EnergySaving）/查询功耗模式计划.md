## 查询功耗模式计划

- 接口功能

   查询功耗模式计划（EnergyModePlan），本文档仅适用于设备型号Y3000FVX，其余型号不保证可用。

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/Video/1/EnergySaving/EnergyModePlan`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/json | Y |
| header | accessToken | String | 用户访问令牌 | Y |
| path | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/Video/1/EnergySaving/EnergyModePlan' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "成功",
        "moreInfo": {
            "deviceMeta": {
                "code": "0x00000000",
                "errorMsg": "Succeeded."
            }
        }
    },
    "data": {
        "plan": [
            {
                "name": "undefined",
                "repeatPeriod": [
                    2
                ],
                "action": [
                    {
                        "actionType": "model/attribute/set/EnergySaving/EnergyModeCfg",
                        "startValue": "perf"
                    }
                ],
                "startTime": "00:00:00",
                "sustain": 0,
                "enabled": false
            }
        ]
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码，参见响应码解释 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |
| data | Object | 业务参数 |
| data.plan | Array | 计划列表 |
| data.plan.name | String | 计划名称 |
| data.plan.repeatPeriod | Array | 重复周期 |
| data.plan.action | Array | 计划操作内容 |
| data.plan.action.actionType | String | 执行动作URI |
| data.plan.action.startValue | String | 功耗类型，枚举值[perf-性能模式；saving-省电模式；super-saving-超级省电模式；non-sleep-不休眠模式；normal-常规模式；user-用户模式] |
| data.plan.startTime | String | 触发时间 |
| data.plan.sustain | Int | 持续时间 |
| data.plan.enabled | Boolean | 使能开关 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数错误 |
| 20007 | 设备不在线 | 设备不在线 |
| 20002 | 设备不存在 | 设备不存在 |
