## 查询超脑设备信息

- 接口功能

   查询超脑设备信息，包括设备名称、在离线状态、添加和离线时间、所属区域id、接入和支持通道数。

- 请求地址

`https://open.ys7.com/api/service/devicekit/deepinmind/device/info`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/devicekit/deepinmind/device/info' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K90132222'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": {
        "deviceSerial": "K90132222",
        "deviceName": "超脑设备",
        "status": 1,
        "addTime": "2023-03-10 21:07:10",
        "offlineTime": "2023-03-15 00:02:37",
        "districtId": "",
        "channelNum": 10,
		"supportChannelNum": 32
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| meta.code | Int | 错误码 |
| meta.message | String | 错误描述 |
| data | Object | 业务数据 |
| data.deviceSerial | String | 设备序列号 |
| data.deviceName | String | 设备名称 |
| data.status | Int | 在离线状态 |
| data.addTime | String | 添加时间 |
| data.offlineTime | String | 离线时间 |
| data.districtId | String | 区域id |
| data.channelNum | Int | 接入通道数 |
| data.supportChannelNum | Int | 支持通道数 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 请求参数异常 |  |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
| 404 | 资源不存在 |  |
