## 查询超脑设备算法

- 接口功能

   查询超脑设备引擎编号、模型描述信息、模型ID、引擎状态信息和模型包名。

- 请求地址

`https://open.ys7.com/api/service/devicekit/deepinmind/device/algorithm`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/devicekit/deepinmind/device/algorithm' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K90132222'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| meta.code | Int | 错误码 |
| meta.message | String | 错误描述 |
| data.LoadingInfoList | Array | 引擎状态信息列表 |
| data.LoadingInfoList[].engine | Int | 引擎编号 |
| data.LoadingInfoList[].description | Array | 模型描述信息 |
| data.LoadingInfoList[].MPID | String | 模型包ID |
| data.LoadingInfoList[].status | Int | 引擎状态信息。0-模型包尚未加载，1-模型包加载&运行良好，2-模型包运行异常，3-模型解密失败，10-引擎初始化中，11-引擎异常，12-当前引擎用作人脸智能使用，13-安全帽检测，14-烟雾检测，15-周界防范，16-人员管理，17-行为分析，18-混合模式，19-占用 |
| data.LoadingInfoList[].MPName | String | 模型包名 |
