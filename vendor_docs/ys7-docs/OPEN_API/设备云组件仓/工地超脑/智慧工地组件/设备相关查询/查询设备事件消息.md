## 查询设备事件消息

- 接口功能

   查询设备事件消息，查询某一设备消息的上报时间、事件类型及消息体，可以按消息类型以及时间进行查找。

- 请求地址

`https://open.ys7.com/api/service/devicekit/common/device/event`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | N |
| body | eventType | String | 消息类型 | N |
| body | queryDate | String | 查询日期 | Y |
| body | pageStart | Int | 分页页数，从0开始 | Y |
| body | pageSize | Int | 分页大小 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/devicekit/common/device/event' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: L32461399'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| meta.code | Int | 错误码 |
| meta.message | String | 错误描述 |
| data | Array | 事件消息列表 |
| data[].deviceSerial | String | 设备序列号 |
| data[].channelNo | Int | 通道号 |
| data[].districtId | String | 区域id |
| data[].eventType | String | 事件类型。烟火检测事件:smokeAndFireDetection；烟雾检测事件:smokeDetection；火点检测事件:fireDetection；渣土车检测:slagTruckDetection；AI图片任务检测事件:AIOP\_Picture；AI视频任务检测事件:AIOP\_Video |
| data[].eventBody | String | 消息体 |
| data[].reportTime | String | 上报时间 |
