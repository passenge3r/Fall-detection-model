## 消息统计（按时间、区域、设备）

- 接口功能

   按时间、区域、设备对不同类型事件进行统计。

- 请求地址

`https://open.ys7.com/api/service/devicekit/deepinmind/event/stats/by/device`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| query | districtId | String | 区域id | Y |
| query | queryDate | String | 查询日期，格式：yyyy-MM-dd | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/devicekit/deepinmind/event/stats/by/device?districtId=xxx&queryDate=2023-07-05' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: L32461399'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": [{
        "eventType": "1313dasd",
        "count": "21",
    }]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| meta.code | Int | 错误码 |
| meta.message | String | 错误描述 |
| data | Array | 统计数据列表 |
| data[].eventType | String | 事件类型 |
| data[].count | Int | 事件数量 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 请求参数异常 |  |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
| 404 | 资源不存在 |  |
