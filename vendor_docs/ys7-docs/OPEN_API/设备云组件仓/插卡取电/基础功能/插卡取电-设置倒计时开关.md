## 插卡取电-设置倒计时开关

- 接口功能

   设置倒计时开关（PowerSwitchCountdown）。

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/Switch/1/PowerMgr/PowerSwitchCountdown`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/json | Y |
| header | accessToken | String | 用户访问令牌 | Y |
| path | deviceSerial | String | 设备序列号 | Y |
| body | enable | Boolean | 倒计时使能启用（true）/取消（false） | Y |
| body | timeRemaining | Integer | 倒计时时间（秒）。范围[15,86340] | Y |
| body | switch | Integer | 倒计时结束后动作开（true）/关（false）。范围[0,2147483647] | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/Switch/1/PowerMgr/PowerSwitchCountdown' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{
	"enable":true,
	"timeRemaining":15,
	"switch":0
}'
```

- 返回数据

```
{
 "meta": {
    "code": 200,
    "message": "成功",
    "moreInfo": {
      "deviceMeta": {
        "code": "0x00000000",
        "errorMsg": "Succeeded."
      }
    }
  }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Integer | 服务响应状态码。参见响应码解释。 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 成功 | 操作成功 |
