# 插卡取电-设置开关定时计划

## 插卡取电-设置开关定时计划

- 接口功能

   设置开关定时计划（PowerSwitchTimePlan）。

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/Switch/1/PowerMgr/PowerSwitchTimePlan`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/json | Y |
| header | accessToken | String | 用户访问令牌 | Y |
| path | deviceSerial | String | 设备序列号 | Y |
| body | plan | Array | 计划列表。范围[0,8] | Y |
| body | plan[].name | String | 计划名称。范围[0,32] | N |
| body | plan[].repeatPeriod | Array | 重复周期，为空，执行一次。范围[0,16] | Y |
| body | plan[].action | Array | 计划操作内容。范围[1,8] | Y |
| body | plan[].startTime | String | 触发时间。范围[1,] | Y |
| body | plan[].sustain | Integer | 持续时间。范围[0,1440] | Y |
| body | plan[].enabled | Boolean | 使能开关 | Y |
| body | plan[].action[].actionType | String | 执行动作URI。范围[1,2556] | Y |
| body | plan[].action[].endValue | String | 执行动作的identifier的值(根据具体协议定制，类型)。范围[0,128] | N |
| body | plan[].action[].startValue | String | 执行动作的identifier的值(根据具体协议定制，类型)。范围[0,128] | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/Switch/1/PowerMgr/PowerSwitchTimePlan' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{
	"plan":[
		[
			{
				"name":"undefined",
				"repeatPeriod":[
					[
						1
					]
				],
				"action":[
					[
						{
							"actionType":"undefined",
							"endValue":"",
							"startValue":""
						}
					]
				],
				"startTime":"00:00:00",
				"sustain":0,
				"enabled":false
			}
		]
	]
}'
```

- 返回数据

```
{
 "meta": {
    "code": 200,
    "message": "成功",
    "moreInfo": {
      "deviceMeta": {
        "code": "0x00000000",
        "errorMsg": "Succeeded."
      }
    }
  }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Integer | 服务响应状态码。参见响应码解释。 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 成功 | 操作成功 |
