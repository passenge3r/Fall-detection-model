# 设置温度告警阈值

---

## 设置温度告警阈值

- 接口功能

设置温度告警阈值

- 请求地址

`https://open.ys7.com/api/v3/device/otap/prop`

- 请求方式

`PUT`

- 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| accessToken | String | Y | header | 用户访问令牌 |
| deviceSerial | String | Y | header | 设备序列号 |
| localIndex | String | Y | header | 资源描述，描述资源类型下的序号，如：0 |
| resourceCategory | String | Y | header | 资源种类，描述资源的类型，如：global |
| domainIdentifier | String | Y | header | 功能点领域，填写报备时的属性所在领域，如：Humiture |
| propIdentifier | String | Y | header | 功能点标识，填写报备时的属性标识符，如：TemperatureAlarmThreshold |
| maxTemperature | Number | N | body | 最大温度，范围[-100.0,1000.0] |
| unit | String | N | body | 温度单位，范围[celsius,fahrenheit] |
| minTemperature | Number | N | body | 最小温度，范围[-100.0,1000.0] |
| enabled | Boolean | Y | body | 告警使能 |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/otap/prop' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: xxxxxx' \
--header 'localIndex: 0' \
--header 'resourceCategory: global' \
--header 'domainIdentifier: Humiture' \
--header 'propIdentifier: TemperatureAlarmThreshold' \
--header 'Content-Type: application/json' \
--data-raw '{"maxTemperature":50.0,"unit":"celsius","minTemperature":0.0,"enabled":true}'
```

- 返回数据

```
{
  "meta": {
    "code": 200,
    "message": "成功",
    "moreInfo": {
      "deviceMeta": {
        "code": "0x00000000",
        "errorMsg": "Succeeded."
      }
    }
  }
}
```

- 返回字段

| 字段名称 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Integer | 服务响应状态码，参见响应码解释 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 成功 | 请求成功 |
