## 跳绳-查询倒计时

- 接口功能

查询倒计时。

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/0/LightCtrl/CountdownCfg`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/json | Y |
| header | accessToken | String | 用户访问令牌，accessToken获取方法见 https://open.ys7.com/help/81 | Y |
| path | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/otap/prop/xxxxx/global/0/LightCtrl/CountdownCfg' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "成功",
        "moreInfo": {
            "deviceMeta": {
                "code": "0x00000000",
                "errorMsg": "Succeeded."
            }
        }
    },
    "data": {
        "enable": true,
        "timeRemaining": 60,
        "reportTimestamp": 1860425061,
        "switch": true
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码。参见响应码解释。 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |
| data | Object | 业务参数，详细说明见下表 |
| data.enable | Boolean | 倒计时使能启用（true）/取消（false） |
| data.timeRemaining | Int | 倒计时时间（秒），范围[60,86340] |
| data.reportTimestamp | Float | 上报时间（毫秒） |
| data.switch | Boolean | 倒计时结束开（true）/关（false） |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 成功 | 请求成功 |
