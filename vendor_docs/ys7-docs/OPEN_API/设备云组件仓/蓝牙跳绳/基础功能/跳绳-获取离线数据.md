## 跳绳-获取离线数据

- 接口功能

获取离线数据。

- 请求地址

`https://open.ys7.com/api/v3/otap/action/{deviceSerial}/global/0/OfflineData/GetOfflineData`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/json | N |
| header | accessToken | String | 用户访问令牌，accessToken获取方法见 https://open.ys7.com/help/81 | N |
| path | deviceSerial | String | 设备序列号 | N |
| body | pages | Int | 第几页数据,从0开始 | N |
| body | pageSize | Int | 当前页数据个数 | N |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/otap/action/xxxxx/global/0/OfflineData/GetOfflineData' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{
    "pages": 1,
    "pageSize": 10
}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "成功",
        "moreInfo": {
            "deviceMeta": {
                "code": "0x00000000",
                "errorMsg": "Succeeded."
            }
        }
    },
    "data": {
        "code": 0
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码。参见响应码解释。 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |
| data | Object | 业务参数，详细说明见下表 |
| data.code | Int | 操作返回值，0为成功 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 成功 | 请求成功 |
