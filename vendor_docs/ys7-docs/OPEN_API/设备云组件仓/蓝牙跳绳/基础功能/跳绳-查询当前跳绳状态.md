## 跳绳-查询当前跳绳状态

- 接口功能

查询当前跳绳状态。

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/0/JumpRopeDetection/JumpRopeStatus`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/json | Y |
| header | accessToken | String | 用户访问令牌，accessToken获取方法见 https://open.ys7.com/help/81 | Y |
| path | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/otap/prop/xxxxx/global/0/JumpRopeDetection/JumpRopeStatus' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "成功",
        "moreInfo": {
            "deviceMeta": {
                "code": "0x00000000",
                "errorMsg": "Succeeded."
            }
        }
    },
    "data": {
        "mode": "",
        "jumping": true,
        "count": 93406,
        "calorie": 96305,
        "time": 2563,
        "speed": 56
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码。参见响应码解释。 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |
| data | Object | 业务参数，详细说明见下表 |
| data.mode | String | 模式，范围[free,count,time,physicalTest]。free-自由跳；count-计数跳；time-定时跳；physicalTest-体测 |
| data.jumping | Boolean | true:正在跳绳，false:停止跳绳 |
| data.count | Int | 计数，范围[0,100000] |
| data.calorie | Int | 卡路里，范围[0,100000] |
| data.time | Int | 时间，范围[0,7200] |
| data.speed | Int | 跳绳速度，范围[0,100] |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 成功 | 请求成功 |
