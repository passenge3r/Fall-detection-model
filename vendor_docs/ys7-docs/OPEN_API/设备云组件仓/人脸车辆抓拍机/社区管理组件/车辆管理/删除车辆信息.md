## 删除车辆信息

- 接口功能

   删除车辆信息

- 请求地址

`https://open.ys7.com/api/service/devicekit/aicamera/vehicle/delete`

- 请求方式

`DELETE`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| body | communityId | String | 车辆所属小区id | Y |
| body | plateNumber | String | 车牌号 | Y |

- 请求示例

```
curl --location --request DELETE 'https://open.ys7.com/api/service/devicekit/aicamera/vehicle/delete' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'communityId=a213c23065544d24ae0d795e041233d5' \
--data-urlencode 'plateNumber=浙A·00008'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    },
    "data": true
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码。参见响应码解释 |
| meta.message | String | 服务响应状态描述 |
| data | String | 服务响应 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 请求参数异常 |  |
| 49999 | 数据异常 |  |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
