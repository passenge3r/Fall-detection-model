## 修改车辆信息

- 接口功能

   修改车辆信息，可修改车辆的车牌号、车牌颜色、车辆类型、车身颜色、车辆品牌、车辆标签以及所属小区的信息

- 请求地址

`https://open.ys7.com/api/service/devicekit/aicamera/vehicle/update`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| body | plateNumber | String | 车牌号 | Y |
| body | plateColor | String | 车牌颜色 | N |
| body | vehicleType | String | 车辆类型 | N |
| body | vehicleColor | String | 车身颜色 | Y |
| body | vehicleLogo | String | 车辆品牌 | Y |
| body | vehicleLabel | String | 车辆标签 | Y |
| body | communityId | String | 车辆所属小区id | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/service/devicekit/aicamera/vehicle/update' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'plateNumber=浙A·00008' \
--data-urlencode 'plateColor=蓝色' \
--data-urlencode 'vehicleType=奥迪' \
--data-urlencode 'vehicleColor=黑色' \
--data-urlencode 'vehicleLogo=A6' \
--data-urlencode 'vehicleLabel=标签' \
--data-urlencode 'communityId=21befc41c31f4811ac8cf297d1b7618f'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码。参见响应码解释 |
| meta.message | String | 服务响应状态描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 10001 | 请求参数异常 |  |
| 49999 | 数据异常 |  |
| 50000 | 服务器异常 | 可提交工单解决相关问题 |
