## 分页查询报警信息

- 接口功能

   分页查询报警信息

- 请求地址

`https://open.ys7.com/api/service/devicekit/aicamera/statistics/alarm`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| query | deviceSerial | String | 设备序列号 | Y |
| query | communityId | String | 小区id | Y |
| query | startTime | String | 开始时间，yyyy-MM-dd HH:mm:ss | Y |
| query | endTime | String | 结束时间，yyyy-MM-dd HH:mm:ss | Y |
| query | eventType | String | fielddetection：区域入侵 linedetection：越界侦测 | Y |
| query | pageFrom | Int | 分页起始offset，从0开始 | N |
| query | pageSize | Int | 分页大小，默认为100，最大为1000 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/devicekit/aicamera/statistics/alarm?accessToken=at.xxxxx&deviceSerial=L19165790&communityId=a213c23065544d24ae0d795e041233d5&startTime=2023-05-09+10%3A00%3A00&endTime=2023-05-09+12%3A00%3A00&eventType=fielddetection&pageFrom=0&pageSize=100'
```
