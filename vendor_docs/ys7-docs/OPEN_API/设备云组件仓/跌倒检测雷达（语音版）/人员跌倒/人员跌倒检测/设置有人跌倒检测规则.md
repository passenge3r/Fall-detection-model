# 设置有人跌倒检测规则

## 设置有人跌倒检测规则

- 接口功能

设置人员跌倒检测规则参数

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/["0"]/PeopleFallingDownDetection/PeopleFallingDownDetectionRule`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| path | deviceSerial | String | 设备序列号 | Y |
| body | sensitivity | Float | 人体检测灵敏度阈值，范围[0.0,100.0] | N |
| body | triggerTime | Int | 事件触发时间，范围[0,255]，当人员倒地时间超过该配置时间时则触发人员跌倒事件上报 | N |
| body | region | Array | 指定跌倒事件的检测区域，坐标数组 | Y |
| body | region[][].XPosition | Float | X坐标实际位置信息，范围[-100.0,100.0] | Y |
| body | region[][].YPosition | Float | Y坐标实际位置信息，范围[-100.0,100.0] | Y |
| body | enabled | Boolean | 是否启用检测 | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/["0"]/PeopleFallingDownDetection/PeopleFallingDownDetectionRule' \
--header 'Content-Type: application/json' \
--header 'accessToken: at.xxxxx' \
--data-raw '{
  "sensitivity": 65.0,
  "triggerTime": 0,
  "region": [
    [
      {
        "XPosition": 10.0,
        "YPosition": 10.0
      }
    ]
  ],
  "enabled": false
}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "成功",
        "moreInfo": {
            "deviceMeta": {
                "code": "0x00000000",
                "errorMsg": "Succeeded."
            }
        }
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码，参见响应码解释 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 请求参数错误 | 参数错误 |
| 10002 | accessToken异常或过期 | 令牌失效 |
| 49999 | 数据异常 | 服务器异常 |
