## 设置滞留时长

- 接口功能

设置滞留时长

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/["0"]/stay/stayTime`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | Content-Type | String | application/json | Y |
| Header | accessToken | String | 用户访问令牌 | Y |
| Path | deviceSerial | String | 设备序列号 | Y |
| Body | data | Int | 滞留时长，可选值：20-20分钟，30-30分钟，40-40分钟，50-50分钟，60-1小时，120-2小时 | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/["0"]/stay/stayTime' \
--header 'Content-Type: application/json' \
--header 'accessToken: at.xxxxx' \
--data '30'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "成功",
        "moreInfo": {
            "deviceMeta": {
                "code": "0x00000000",
                "errorMsg": "Succeeded."
            }
        }
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码，参见响应码解释 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 请求参数有误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
