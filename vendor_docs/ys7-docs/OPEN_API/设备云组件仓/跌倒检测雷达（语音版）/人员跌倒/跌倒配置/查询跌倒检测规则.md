## 查询跌倒检测规则

- 接口功能

查询跌倒检测规则参数

- 请求地址

`https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/["0"]/FallingDownDetection/FallingDownDetectionRule`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| path | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/otap/prop/{deviceSerial}/global/["0"]/FallingDownDetection/FallingDownDetectionRule' \
--header 'Content-Type: application/json' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "成功",
        "moreInfo": {
            "deviceMeta": {
                "code": "0x00000000",
                "errorMsg": "Succeeded."
            }
        }
    },
    "data": {
        "leftDistance1": 77,
        "leftDistance2": 65,
        "backDistance1": 65,
        "frontDistance2": 63,
        "backDistance2": 31,
        "triggerTime": 0,
        "rightDistance1": 197,
        "rightDistance2": 74,
        "frontDistance1": 200
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码，参见响应码解释 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| meta.moreInfo.deviceMeta.code | String | 设备响应状态码 |
| meta.moreInfo.deviceMeta.errorMsg | String | 设备响应状态描述 |
| data | Object | 业务参数 |
| data.leftDistance1 | Int | 左侧存在检测距离，范围[0,200] |
| data.leftDistance2 | Int | 左侧跌倒检测距离，范围[0,100] |
| data.backDistance1 | Int | 后方存在检测距离，范围[0,200] |
| data.frontDistance2 | Int | 前方跌倒检测距离，范围[0,100] |
| data.backDistance2 | Int | 后方跌倒检测距离，范围[0,100] |
| data.triggerTime | Int | 事件触发时间，范围[0,255] |
| data.rightDistance1 | Int | 右侧存在检测距离，范围[0,200] |
| data.rightDistance2 | Int | 右侧跌倒检测距离，范围[0,100] |
| data.frontDistance1 | Int | 前方存在检测距离，范围[0,200] |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 请求参数错误 | 参数错误 |
| 10002 | accessToken异常或过期 | 令牌失效 |
| 49999 | 数据异常 | 服务器异常 |
