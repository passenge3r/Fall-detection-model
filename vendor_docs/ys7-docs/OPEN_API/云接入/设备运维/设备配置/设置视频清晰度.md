# 设置视频清晰度（POST）

> 设置视频清晰度，向设备下发指令修改设备通道的清晰度设置
> 是否支持托管/子账号: 支持托管及子账号，权限为Config，设备通道级鉴权

---

## 接口URL

https://open.ys7.com/api/v3/device/setVideoLevel

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| localIndex | string | Y | 设备通道号 |  |
| accessToken | string | Y | 萤石开放API访问令牌 |  |
| deviceSerial | string | Y | 设备序列号 |  |

### body

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| videoLevel | int | Y | 设备视频清晰度等级 0-流畅,1-均衡,2-高清,3-超清,4-极清,5-3K,6-4K |  |

### 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/setVideoLevel' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--header 'accessToken: at.47g4c0k4aokhhyg02lwnsvcud7ci7o5m-2kses2xtgo-0fzuqbp-tdddnlrp5' \
--header 'deviceSerial: BG9859941' \
--header 'localIndex: 1' \
--data-urlencode 'videoLevel=4'
```
