## 设备视频预览参数设置

- 接口功能

   设备视频参数设置

   是否支持托管及子账号：支持，权限为Config

- 请求地址

`https://open.ys7.com/api/lapp/device/video/encode/set`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| body | accessToken | String | 访问令牌 | Y |
| body | streamTypeIn | String | 视频码流 1:主码流, 2子码流 | Y |
| body | resolution | String | 视频分辨率 0:DCIF 1:CIF 2:QCIF 3:4CIF 4:2CIF 6:QVGA（320x240） 16:VGA 17:UXGA 18:SVGA 19:HD720p 20:hd900 21:XVGA 27:1080P 56:2304\*1296 | Y |
| body | videoFrameRate | String | 视频帧率0:全帧率 1:1/16 2:1/8 3:1/4 4:1/2 5:1 6:2 7:4 8:6 9:8 10:10 11:12 12:16 13:20 14:15 15:18 16:22 | Y |
| body | intervalFrameI | String | I帧间隔,默认100 | N |
| body | streamType | String | 视频流声音设置,1-有声音 | N |
| body | videoBitRate | String | 码率上限0-32K 1-48k 2-64K 3-80K 4-96K 5-128K 6-160k 7-192K 8-224K 9-256K 10-320K 11-384K 12-448K 13-512K 14-640K 15-768K 16-896K 17-1024K 18-1280K 19-1536K 20-1792K 21-2048K 22-自定义, 默认13 | N |
| body | bitRateType | String | 码率类型 0:变码率 1:定码率 默认1 | N |
| body | picQuality | String | 图像质量 0:最高 1:较高 2:中等 3:低 4:较低 5:最低 默认2 | N |
| body | encodeType | String | 编码类型 1:H264, 2:H265 默认1 | N |
| body | encodeComplex | String | 编码复杂度 默认1,0-低，1-中，2-高 默认1 | N |
| body | deviceSerial | String | 设备序列号 | Y |
| body | channelNo | String | 设备通道号, 默认为1 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/device/video/encode/set' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'deviceSerial=BG9859941' \
--data-urlencode 'channelNo=1' \
--data-urlencode 'streamTypeIn=1' \
--data-urlencode 'resolution=19' \
--data-urlencode 'videoFrameRate=0' \
--data-urlencode 'intervalFrameI=100' \
--data-urlencode 'videoBitRate=13' \
--data-urlencode 'picQuality=2' \
--data-urlencode 'encodeType=1' \
--data-urlencode 'encodeComplex=1'
```

- 返回数据

```
{
    "msg": "操作成功!",
    "code": "200"
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| msg | String | 响应提示信息 |
| code | String | 响应code |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | HTTP状态码:200 |
| 20002 | 设备不存在 | HTTP状态码:200 |
| 20007 | 设备不在线 | HTTP状态码:200 |
| 20008 | 设备响应超时 | HTTP状态码:200 |
| 50000 | 服务器异常 | HTTP状态码:200 |
| 10002 | accessToken过期或异常 | HTTP状态码:200 |
| 10001 | 无效参数 | HTTP状态码:200 |
| 20018 | 该用户不拥有该设备 | HTTP状态码:200 |
| 10031 | 子账号或开发者用户无权限 | HTTP状态码:200 |
