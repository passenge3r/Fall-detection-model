## 设备存储介质格式化

- 接口功能

   根据设备序列号和存储介质编号格式化指定编号的设备存储空间

- 请求地址

`https://open.ys7.com/api/v3/device/format/disk`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Body | deviceSerial | String | 设备序列号 | Y |
| Body | diskIndex | String | 存储介质编号 | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/format/disk' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'deviceSerial=BG9859941' \
--data-urlencode 'diskIndex=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功!",
        "moreInfo": null
    },
    "data": null
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应结果 |
| -code | Int | 响应状态码 |
| -message | String | 响应状态码描述 |
| -moreInfo | Object | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10002 | accessToken过期或异常 | token无效，请重新获取 |
| 10031 | 子账号或开发者用户无权限 | 无操作权限 |
| 20002 | 设备不存在 | 设备未注册或已注销 |
| 20007 | 设备不在线 | 设备离线 |
| 20011 | 设备不支持或者设备异常 | 设备不支持该操作 |
| 20014 | 设备序列不正确 | 序列号格式错误 |
| 20016 | 当前设备正在格式化 | 请勿重复操作 |
| 20018 | 该用户不拥有该设备 | 无设备权限 |
| 60058 | 设备存在高风险需要确权 | 需要二次验证 |
