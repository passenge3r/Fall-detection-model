## 查询人形检测区域

- 接口功能

   查询人形检测区域

- 请求地址

`https://open.ys7.com/api/v3/device/motion/detect/get`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | channelNo | String | 通道号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/motion/detect/get' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K69690868' \
--header 'channelNo: 1'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功",
    "data": {
        "deviceSerial": "K69690868",
        "channelNo": 1,
        "rows": 10,
        "columns": 10,
        "area": [0, 1, 2, 3]
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码，200表示操作成功 |
| msg | String | 返回消息 |
| data | Object | 返回数据对象 |
| data.deviceSerial | String | 设备序列号 |
| data.channelNo | Int | 通道号 |
| data.rows | Int | 配置区域划分行数，平分探测距离 |
| data.columns | Int | 配置区域划分列数，平分探测角度 |
| data.area | Array[Int] | 区域设置，如表顺序排列，每个值按位取值 例 [1,2,4,8,6] 则选中区域为序号 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数错误 |
| 10002 | accessToken过期或异常 | 令牌失效，需重新获取 |
| 20002 | 设备不存在 | 设备不存在 |
| 20007 | 设备不在线 | 设备离线 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |
| 20032 | 该用户下通道不存在 | 通道号不存在 |
| 60020 | 设备不支持该信令 | 设备不支持该信令 |
