## 设置补光灯开关

- 接口功能

   设置补光灯开关

- 请求地址

`https://open.ys7.com/api/v3/device/fillLight/switch/set`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| body | deviceSerial | String | 设备序列号 | Y |
| body | enable | Int | 状态：0-关闭，1-开启；默认为0 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/fillLight/switch/set' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'deviceSerial=C57256745' \
--data-urlencode 'enable=1'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功!"
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 业务码 |
| msg | String | 描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
