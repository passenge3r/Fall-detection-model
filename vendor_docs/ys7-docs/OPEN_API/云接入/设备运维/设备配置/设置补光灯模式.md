## 设置补光灯模式

- 接口功能

   设置补光灯模式

- 请求地址

`https://open.ys7.com/api/v3/device/fillLight/mode`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| body | deviceSerial | String | 设备序列号 | Y |
| body | mode | Int | 黑白夜视模式:0；全彩夜视模式:1；智能夜视:2；人形检测全彩模式:3；默认为0 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/fillLight/mode' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'deviceSerial=C57256745' \
--data-urlencode 'mode=1'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功!"
}
```
