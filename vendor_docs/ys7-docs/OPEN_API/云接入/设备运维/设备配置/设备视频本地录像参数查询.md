## 设备视频本地录像参数查询

- 接口功能

   查询设备设置的本地录像视频相关参数。支持托管及子账号，通道级，校验权限为Get。

- 请求地址

`https://open.ys7.com/api/v3/device/video/encode/get`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号 | Y |
| Header | localIndex | Integer | 设备通道号（默认1） | N |
| Query | streamType | Integer | 视频码流 1-主码流，2-子码流（默认1） | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/video/encode/get?streamType=1' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: {deviceSerial}' \
--header 'localIndex: 1'
```

```
        "resolution": "19",

    }

```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 元数据 |
| meta.code | Integer | 业务状态码 |
| meta.message | String | 业务信息 |
| meta.moreInfo | Object | 额外信息 |
| data | Object | 业务参数，详细说明见下表 |
| data.encodeType | String | 编码类型 |
| data.streamTypeIn | String | 视频码流 |
| data.resolution | String | 视频分辨率 |
| data.videoFrameRate | String | 视频帧率 |
| data.videoBitRate | String | 码率上限 |
| data.intervalFrameI | String | I帧间隔，单位：秒 |
| data.streamType | String | 视频流声音类型 |
| data.bitRateType | String | 码率类型 |
| data.picQuality | String | 图像质量 |
| data.encodeComplex | String | 编码复杂度 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 参数错误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
| 20002 | 设备不存在 | 设备不存在 |
| 20007 | 设备不在线 | 设备不在线 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |

| videoFrameRate | 视频帧率 0-全帧率 1-1/16 2-1/8 3-1/4 4-1/2 5-1 6-2 7-4 8-6 9-8 10-10 11-12 12-16 13-20 14-15 15-18 16-22 |
| videoBitRate | 码率上限 0-32K 1-48k 2-64K 3-80K 4-96K 5-128K 6-160k 7-192K 8-224K 9-256K 10-320K 11-384K 12-448K 13-512K 14-640K 15-768K 16-896K 17-1024K 18-1280K 19-1536K 20-1792K 21-2048K 22-自定义 |
| intervalFrameI | I帧间隔，单位：秒 |
