## 查询图像风格

- 接口功能

   查询图像风格

- 请求地址

`https://open.ys7.com/api/v3/device/display/mode/get`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/display/mode/get' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K69690868'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功",
    "data": {
        "valueInfo": {
            "mode": 1
        }
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码，200表示操作成功 |
| msg | String | 返回消息 |
| data | Object | 返回数据对象 |
| data.valueInfo | Object | 状态对象 |
| data.valueInfo.mode | String | 图像风格，1-标准，2-写实，3-艳丽 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
