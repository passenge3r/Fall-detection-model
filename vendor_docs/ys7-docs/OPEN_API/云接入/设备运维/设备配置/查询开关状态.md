## 查询开关状态

- 接口功能

   查询开关状态，用于查询灯光提醒开关状态。

- 请求地址

`https://open.ys7.com/api/v3/device/switchStatus/get`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | channelNo | String | 通道号 | Y |
| query | type | String | 301-灯光闪烁开关/移动侦测灯光联动,305-灯光联动开关/PIR灯光联动 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/switchStatus/get?type=301' \
--header 'deviceSerial: K69690868' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "msg": "操作成功",
    "code": "200",
    "data": {
        "subSerial": "K69690868",
        "type": 301,
        "enable": false
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| subSerial | String | 设备序列号 |
| type | Int | 开关类型，301-灯光闪烁开关/移动侦测灯光联动，305-灯光联动开关/PIR灯光联动 |
| enable | Boolean | 状态，true-开启，false-关闭 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
