## 查询设备图像参数

- 接口功能

   查询设备图像参数，托管/子账号：支持，权限类型：设备级GET权限，该接口需要设备支持能力集：support\_image\_param

- 请求地址

`https://open.ys7.com/api/v3/device/video/image/params`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/video/image/params?deviceSerial=' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "brightness": 50,
        "contrast": 50,
        "saturatio": 50,
        "sharpness": 50,
        "gammaCorrection": 5,
        "gain": 50,
        "imageStyle": "standard"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码，参见错误码解释 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |
| data | Object | 响应数据 |
| data.brightness | Int | 亮度，范围0-100 |
| data.contrast | Int | 对比度，范围0-100 |
| data.saturatio | Int | 饱和度，范围0-100 |
| data.sharpness | Int | 锐度，范围0-100 |
| data.gammaCorrection | Int | 伽马矫正，范围0-9 |
| data.gain | Int | 增益，范围0-100 |
| data.imageStyle | String | 图像风格，[standard-标准；soft-柔和；gorgeous-艳丽；manual-手动] |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数错误 |
| 10031 | 账号无权限访问此设备 | 账号无权限访问此设备 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |
| 500 | 服务器异常 | 服务器异常 |
| 20002 | 设备不存在 | 设备不存在 |
| 20015 | 设备不支持 | 设备不支持 |
