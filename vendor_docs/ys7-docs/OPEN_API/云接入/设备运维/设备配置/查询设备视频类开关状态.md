## 查询设备视频类开关状态

- 接口功能

   查询设备视频类开关状态，支持托管及子账号，校验权限为Get，设备级鉴权。隐私遮蔽开关状态查询需要设备支持support\_privacy能力集，休眠开关状态查询需要设备支持support\_low\_power能力集，人脸识别开锁开关查询需要设备支持support\_lock\_face\_key能力集，特写追踪开关查询需要设备支持support\_feature\_track能力集，视频水印是否展示logo开关状态查询需要设备支持support\_logo\_switch能力集。

- 请求地址

`https://open.ys7.com/api/v3/device/video/switch/status`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| query | type | Int | 开关类型，7-隐私遮蔽，21-休眠，455-人脸识别开锁，701-特写追踪，702-视频水印是否展示LOGO | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/video/switch/status?type=7' \\
--header 'accessToken: at.xxxxx' \\
--header 'deviceSerial: L89032MK'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    },
    "data": {
        "deviceSerial": "L89032MK",
        "type": 7,
        "enable": 1
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 返回数据 |
| data.deviceSerial | String | 设备序列号 |
| data.type | Int | 开关类型，7-隐私遮蔽，21-休眠，455-人脸识别开锁，701-特写追踪，702-视频水印是否展示LOGO |
| data.enable | Int | 设备开关状态，0-关闭，1-开启 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数不合法 |
| 10002 | accessToken过期或异常 | 令牌失效，请重新获取 |
| 10031 | 账号无权限访问此设备 | 权限不足 |
| 429 | 请求过于频繁 | 请降低请求频率 |
| 20002 | 设备不存在 | 设备未注册 |
| 60020 | 设备不支持该指令 | 设备不支持此操作 |
