## 设备主动防御

- 接口功能

   操作设备开启/关闭设备主动防御，需要设备支持**support\_active\_defense**能力集。支持托管及子账号，设备级，校验权限为Config

- 请求地址

`https://open.ys7.com/api/v3/device/defence`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| body | status | Int | 状态：1-消除报警，2-触发报警 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/defence' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'deviceSerial=C57256745' \
--data-urlencode 'status=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "Operation succeeded",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元数据 |
| meta.code | Int | 业务码 |
| meta.message | String | 描述 |
| meta.moreInfo | String | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 20014 | 设备序列号不正确 | 设备序列号不正确 |
| 10031 | 子账号或开发者用户无权限 | 子账号或开发者用户无权限 |
| 20007 | 设备不在线 | 设备不在线 |
| 20008 | 设备响应超时 | 设备响应超时 |
| 60012 | 未知错误 | 未知错误 |
| 10001 | 参数错误 | status只能为1或2，deviceSerial不能为空 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
