## 音频编码格式切换

- 接口功能

   音频编码格式切换。是否支持托管：支持，权限为Config。设备通道级鉴权，需要校验的能力集：support\_audio\_encode\_types。

- 请求地址

`https://open.ys7.com/api/v3/device/audio/encodeType`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | accessToken | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | localIndex | String | 资源（通道）号，非必选，默认为1 | N |
| body | encodeType | String | 音频编码格式 AAC，示例：G711a | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/audio/encodeType' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: xxxxx' \
--header 'localIndex: 1' \
--header 'Content-Type: application/json' \
--data-raw '{"encodeType":"G711a"}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    }
}
```
