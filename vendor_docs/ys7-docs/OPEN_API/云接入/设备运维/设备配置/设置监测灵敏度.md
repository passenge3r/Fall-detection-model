## 设置监测灵敏度

- 接口功能

   设置灵敏度信息（只用于支持检测灵敏度设置的设备，需要设备支持能力集：support\_sensibility\_adjust=1）

- 请求地址

`https://open.ys7.com/api/v3/device/detect/config/set`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/x-www-form-urlencoded | Y |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | channelNo | String | 通道号 | Y |
| body | type | String | 检测类型，3-PIR检测灵敏度，4-人形检测灵敏度 | Y |
| body | value | String | 灵敏度值，取值为1-100，1表示灵敏度最低 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/detect/config/set' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K69690868' \
--header 'channelNo: 1' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'type=4' \
--data-urlencode 'value=100'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功"
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码，200表示操作成功 |
| msg | String | 返回消息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
