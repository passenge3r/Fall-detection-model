## 视频编码格式切换

- 接口功能

切换设备编码格式，校验的能力集：support\_video\_encode\_switch\_disable 为0 表示支持。是否支持托管及子账号：支持，权限为Config，设备通道级鉴权。

- 请求地址

`https://open.ys7.com/api/v3/device/video/encodeType`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | accessToken | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | localIndex | String | 资源（通道）号，非必选，默认为1 | N |
| body | encodeType | String | 编码格式 H264 / H265 | Y |
| body | streamType | Int | 码流类型 1. 主码流 2.子码流 | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/video/encodeType' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'encodeType=H265' \
--data-urlencode 'streamType=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    }
}
```
