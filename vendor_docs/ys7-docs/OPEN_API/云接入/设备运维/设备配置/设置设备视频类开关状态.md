## 设置设备视频类开关状态

- 接口功能

   设置设备视频类开关状态，支持托管及子账号，校验权限为Config，设备级鉴权。隐私遮蔽开关设置需要设备支持support\_privacy能力集，休眠开关设置需要设备支持support\_low\_power能力集，人脸识别开锁开关设置需要设备支持support\_lock\_face\_key能力集，特写追踪开关设置需要设备支持support\_feature\_track能力集，视频水印是否展示logo开关状态查询需要设备支持support\_logo\_switch能力集。

- 请求地址

`https://open.ys7.com/api/v3/device/video/switch/status`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| body | type | Int | 开关类型，7-隐私遮蔽，21-休眠，455-人脸识别开锁，701-特写追踪，702-视频水印是否展示LOGO | Y |
| body | enable | Int | 设备开关状态，0-关闭，1-开启 | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/video/switch/status' \\
--header 'accessToken: at.xxxxx' \\
--header 'deviceSerial: L89032MK' \\
--header 'Content-Type: application/x-www-form-urlencoded' \\
--data-urlencode 'type=7' \\
--data-urlencode 'enable=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 更多信息 |
