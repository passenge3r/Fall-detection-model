## 设置设备图像降噪参数

- 接口功能

   功能：设置设备图像降噪参数，  
托管/子账号：支持，  
权限类型：设备级Config权限，该接口需要设备支持能力集：support\_image\_param

- 请求地址

`https://open.ys7.com/api/v3/device/video/image/denoising`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | deviceSerial | String | 设备序列号 | Y |
| body | mode | String | 降噪模式，枚举值[close-关闭；general-普通；advanced-专家] | Y |
| body | generalLevel | Int | 普通模式降噪等级，普通模式下必填，范围1-100 | N |
| body | spatialLevel | Int | 专家模式空域等级，专家模式下必填，范围1-100 | N |
| body | temporalLevel | Int | 专家模式时域等级，专家模式下必填，范围1-100 | N |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/video/image/denoising' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'deviceSerial=' \
--data-urlencode 'mode=close' \
--data-urlencode 'generalLevel=' \
--data-urlencode 'spatialLevel=' \
--data-urlencode 'temporalLevel='
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| code | Int | 服务响应状态码。参见错误码解释。 |
| message | String | 服务响应状态描述 |
| moreInfo | Object | 设备响应信息 |
