## 平台向设备设置各种开关量

- 接口功能

   平台向设备设置各种开关量，用于设置灯光提醒开关。

- 请求地址

`https://open.ys7.com/api/v3/device/switchStatus/set`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| query | enable | String | 开关状态，0-关闭，1-打开 | Y |
| query | type | String | 开关类型，301-灯光闪烁开关/移动侦测灯光联动，650-人形追踪检测开关 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/switchStatus/set?enable=0&type=301' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K69690868' \
--header 'Content-Type: application/x-www-form-urlencoded'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功"
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码，200表示操作成功 |
| msg | String | 返回消息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数为空 | 请求参数不能为空 |
| 10002 | accessToken过期或异常 | 令牌失效，需重新获取 |
| 20002 | 设备不存在 | 设备不存在 |
| 20007 | 设备不在线 | 设备离线 |
| 20014 | deviceSerial无效 | 设备序列号无效 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |
| 60020 | 设备不支持该信令 | 设备不支持该信令 |
