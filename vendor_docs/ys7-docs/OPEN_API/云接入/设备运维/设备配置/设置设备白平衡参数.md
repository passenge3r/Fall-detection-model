## 设置设备白平衡参数

- 接口功能

设置设备白平衡参数，托管/子账号：支持，权限类型：设备级Config权限，该接口需要设备支持能力集：support\_image\_param

- 请求地址

`https://open.ys7.com/api/v3/device/video/white/balance`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | deviceSerial | String | 设备序列号 | Y |
| body | mode | String | 白平衡模式，枚举值[auto：自动；lock：锁定；manul：手动] | Y |
| body | whiteBalanceRed | Int | 白平衡红增益，手动模式下生效且手动模式下必传，范围0-255 | N |
| body | whiteBalanceBlue | Int | 白平衡蓝增益，手动模式下生效且手动模式下必传，范围0-255 | N |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/video/white/balance' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'deviceSerial=' \
--data-urlencode 'mode=manual' \
--data-urlencode 'whiteBalanceRed=2' \
--data-urlencode 'whiteBalanceBlue=3'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码，参见错误码解释 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 设备响应信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数错误 |
| 10031 | 账号无权限访问此设备 | 账号无权限访问此设备 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |
| 500 | 服务器异常 | 服务器异常 |
| 20007 | 设备不在线 | 设备不在线 |
| 20002 | 设备不存在 | 设备不存在 |
| 20015 | 设备不支持 | 设备不支持 |
