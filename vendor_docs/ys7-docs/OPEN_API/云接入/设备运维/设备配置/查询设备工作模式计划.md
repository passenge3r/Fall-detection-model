## 查询设备工作模式计划

- 接口功能

   查询设备工作模式计划

- 请求地址

`https://open.ys7.com/api/v3/device/timing/plan/get`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| query | channelNo | Int | 通道号 | N |
| query | timingPlanType | Int | 定时计划类型，只支持17、19，默认为17 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/timing/plan/get' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K69690868'
```

- 返回数据

```
{
    "msg": "操作成功",
    "code": "200",
    "data": [
        {
            "subSerial": "K69690868",
            "subType": 0,
            "enable": 1,
            "weekPlans": [
                {
                    "weekDay": "0",
                    "timePlan": [
                        {
                            "beginTime": "08:00",
                            "endTime": "20:00",
                            "eventArg": "mode:1"
                        }
                    ]
                }
            ]
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 业务码 |
| msg | String | 描述 |
| data | Object | 返回数据列表 |
| data[].subSerial | String | 设备序列号 |
| data[].subType | Int | 设备类型 |
| data[].enable | Int | 是否启用 |
| data[].weekPlans | Object | 周计划集合 |
| data[].weekPlans[].weekDay | String | 周几 |
| data[].weekPlans[].timePlan | Object | 时间计划 |
| data[].weekPlans[].timePlan[].beginTime | String | 开始时间 |
| data[].weekPlans[].timePlan[].endTime | String | 结束时间 |
| data[].weekPlans[].timePlan[].eventArg | String | 计划事件执行参数 |
