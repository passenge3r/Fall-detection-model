## 获取监测灵敏度

- 接口功能

   查询灵敏度信息

- 请求地址

`https://open.ys7.com/api/v3/device/detect/config/get`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | channelNo | String | 通道号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/detect/config/get' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K69690868' \
--header 'channelNo: 1'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功",
    "data": [
        {
            "channel": 1,
            "type": "3",
            "value": "5"
        },
        {
            "channel": 1,
            "type": "4",
            "value": "100"
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码，200表示操作成功 |
| msg | String | 返回消息 |
| data | Array | 灵敏度配置列表 |
| data[].channel | Int | 通道号 |
| data[].type | String | 检测类型，3-PIR检测灵敏度，4-人形检测灵敏度 |
| data[].value | String | 灵敏度值，范围[1,100] |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
