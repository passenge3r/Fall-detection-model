## 播放铃声

- 接口功能

   播放铃声

- 请求地址

`https://open.ys7.com/api/v3/device/audition`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Content-Type | String | application/x-www-form-urlencoded | Y |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| query | voiceIndex | String | 语音索引，200-提醒模式嘀，201-警报模式蜂鸣警报声，202-静音 | Y |
| query | volume | String | 音量，默认为1，取值范围1-100 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/audition?voiceIndex=200&volume=50' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: K69690868' \
--header 'Content-Type: application/x-www-form-urlencoded'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功"
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码，200表示操作成功 |
| msg | String | 返回消息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数为空 | 请求参数不能为空 |
| 10002 | accessToken过期或异常 | 令牌失效，需重新获取 |
| 20002 | 设备不存在 | 设备不存在 |
| 20007 | 设备不在线 | 设备离线 |
| 20014 | deviceSerial无效 | 设备序列号无效 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |
| 60020 | 设备不支持该信令 | 设备不支持该信令 |
