## 查询高级告警侦测类型

- 接口功能

   查询高级告警侦测类型。

- 请求地址

`https://open.ys7.com/api/v3/das/device/detect/switch/get`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/das/device/detect/switch/get' \
--header 'deviceSerial: K69690868' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "msg": "操作成功",
    "code": "200",
    "data": {
        "valueInfo": {
            "type": 0
        }
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| valueInfo | Object | 值信息 |
| valueInfo.type | Int | 0-关闭 4-活动侦测 8-人形检测 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
