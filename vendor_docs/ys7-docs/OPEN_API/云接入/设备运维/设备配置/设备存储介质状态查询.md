## 设备存储介质状态查询

- 接口功能

   根据设备序列号查询设备上存储介质的状态信息

- 请求地址

`https://open.ys7.com/api/v3/device/format/status`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Query | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/device/format/status?deviceSerial=BG9859941' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "storageStatus": [
            {
                "index": "1",
                "name": "本地存储",
                "status": "0",
                "formattingRate": "0"
            },
            {
                "index": "2",
                "name": "本地存储",
                "status": "0",
                "formattingRate": "0"
            }
        ]
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应结果 |
| -code | Int | 响应状态码 |
| -message | String | 响应状态码描述 |
| -moreInfo | Object | 更多信息 |
| data | Object | 响应数据 |
| -storageStatus | Array | 存储介质信息列表 |
| --index | String | 存储介质编号 |
| --name | String | 存储介质名称 |
| --status | String | 存储介质状态，0-正常，1-介质错误可以格式化，2-未格式化，3-正在格式化，4-文件系统只读（TF卡为只读状态请初始化），5-通信异常（TF卡异常请正确安装TF卡），6-写保护（TF卡异常请及时更换），7-介质错误无法格式化（TF卡已损坏请及时更换） |
| --formattingRate | String | 格式化进度 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10031 | 子账号或开发者用户无权限 | 无操作权限 |
| 20002 | 设备不存在 | 设备未注册或已注销 |
| 20007 | 设备不在线 | 设备离线 |
| 20011 | 设备不支持或者设备异常 | 设备不支持该操作 |
| 60058 | 设备存在高风险需要确权 | 需要二次验证 |
