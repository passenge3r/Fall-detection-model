## 触发设备模块升级

- 接口功能

   升级设备模块。模块信息来源于获取设备模块升级信息的接口。支持托管及子账号，设备级，校验权限为Upgrade。

- 请求地址

`https://open.ys7.com/api/v3/device/upgrade/modules`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Body | deviceSerial | String | 设备序列号 | Y |
| Body | modules | String | 设备模块信息，多个模块信息用英文逗号,隔开 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/device/upgrade/modules' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'deviceSerial={deviceSerial}' \
--data-urlencode 'modules=CS-Y3000FVX-V100-WP-BK'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| meta.code | Integer | 错误码 |
| meta.message | String | 错误提示 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 参数错误 |
| 20007 | 设备不在线 | 设备不在线 |
| 20008 | 设备响应超时 | 设备响应超时 |
| 20002 | 设备不存在 | 设备不存在 |
| 20028 | 设备模块升级包不存在 | 设备模块升级包不存在 |
