# 获取设备模块升级状态

## 获取设备模块升级状态

- 接口功能

   用于获取设备模块升级状态及进度。支持托管及子账号，设备级，校验权限为Get。

- 请求地址

`https://open.ys7.com/api/service/device/upgrade/modules/status`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Query | deviceSerial | String | 设备序列号 | Y |
| Query | module | String | 设备模块信息，仅支持单个模块查询 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/device/upgrade/modules/status?deviceSerial={deviceSerial}&module=CS-LT70-V100-C1BCP-BK' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "process": 0,
        "status": 0
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| meta.code | Integer | 错误码 |
| meta.message | String | 错误提示 |
| data | Object | 返回数据 |
| data.process | Integer | 升级进度，取值范围【0~100】 |
| data.status | Integer | 升级状态，取值：0待升级；1开始升级；2下载中；3下载完成；4烧录中；5烧录完成；6正在重启；7升级成功；8升级失败 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 10001 | 参数错误 | 参数错误 |
| 10031 | 账号无权限访问此设备 | 账号无权限访问此设备 |
| 20002 | 设备不存在 | 设备不存在 |
