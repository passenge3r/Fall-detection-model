## 获取设备能力集

- 接口功能

   该接口用于根据设备序列号查询设备能力集。

- 请求地址

`https://open.ys7.com/api/lapp/device/capacity`

- 请求方式

`POST`

- 子账户token请求所需最小权限

   无

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Body | accessToken | String | 访问令牌，授权过程获取的access\_token | Y |
| Body | deviceSerial | String | 设备序列号，存在英文字母的设备序列号，字母需为大写 | Y |
| Body | channelNo | Int | 通道号，不传默认为1 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/device/capacity' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'deviceSerial=xxxxx' \
--data-urlencode 'channelNo=1'
```

- 返回字段

   字段含义详见 [设备能力集说明](https://open.ys7.com/help/77)。能力集说明中有的，而返回字段中没有的那些能力默认不支持。

   示例字段速查表（仅列示例 JSON 中出现的字段，全量字段以《设备能力集说明》为准）：

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 操作结果状态码，200表示成功 |
| msg | String | 操作结果描述 |
| data | Object | 设备能力集 |
| data.support\_cloud | String | 是否支持云存储（1 支持 / 0 不支持） |
| data.support\_intelligent\_track | String | 是否支持智能追踪 |

| data.support\_resolution | String | 支持的画面比例（如 16-9） |
| data.support\_talk | String | 是否支持对讲 |
| data.video\_quality\_capacity | Array<Object> | 视频清晰度能力列表 |
| data.video\_quality\_capacity[].streamType | String | 码流类型 |
| data.video\_quality\_capacity[].videoLevel | String | 清晰度等级 |
| data.video\_quality\_capacity[].resolution | String | 分辨率枚举 |
| data.video\_quality\_capacity[].videoBitRate | String | 视频码率枚举 |

| data.ptz\_close\_scene | String | 云台是否支持镜头遮蔽 |
| data.support\_preset\_alarm | String | 是否支持预置点联动报警 |
| data.support\_related\_device | String | 是否支持关联设备 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 参数为空或参数不合法 |
| 10002 | accessToken过期或异常 | 请重新获取accessToken |
| 10004 | 用户不存在 | 检查账号是否存在或已注册 |
| 10005 | appKey异常 | 检查appKey是否正确，或对应应用是否被冻结 |
| 20002 | 设备不存在 | 设备序列号输入有误或者设备未添加或者通道异常 |
| 20014 | deviceSerial不合法 | 检查设备序列号格式，字母需为大写 |
| 49999 | 数据异常 | 接口请求异常，请稍后重试或联系技术支持 |
