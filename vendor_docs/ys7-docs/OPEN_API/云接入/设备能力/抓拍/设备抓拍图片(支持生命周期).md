## 设备抓拍图片(支持生命周期)

- 接口功能

设备抓拍图片(支持生命周期)，支持托管。

- 请求地址

`https://open.ys7.com/api/service/open/capture/device/capture`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| body | accessToken | String | 萤石开放API访问令牌 | Y |
| body | deviceSerial | String | 设备序列号 | Y |
| body | channelNo | String | 设备通道号，默认1 | N |
| body | resultSpaceId | Long | 抓图业务类型的存储空间id，由空间列表查询接口获取 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/capture/device/capture' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.3dunn6xgc5ubjfs0c581ef26bzxtqgp6' \
--data-urlencode 'deviceSerial=127874148' \
--data-urlencode 'channelNo=1' \
--data-urlencode 'resultSpaceId=270328'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "picUrl": "https://opencapture.ys7.com/opst/1/open_capture/3/003vvvrhN6KwFD7QPQ1byOZlFLphKFs.jpg?Expires=1778403628&OSSAccessKeyId=LTAI5tA737AgARqFm7DvPmwS&Signature=er%2BBg%2BkFitFBBvvbFFP%2FGV3bpqM%3D",
        "fileNodeId": "kKKOwUHU"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 附加信息，通常为null |
| data | Object | 响应数据 |
| data.picUrl | String | 抓拍图片下载地址 |
| data.fileNodeId | String | 文件节点id |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 请检查请求参数是否正确 |
| 403 | 无权限 | 请检查设备权限 |
| 404 | 资源不存在 | 请检查设备序列号或空间id是否存在 |
| 500 | 服务器异常 | 服务器内部错误，请稍后重试 |
