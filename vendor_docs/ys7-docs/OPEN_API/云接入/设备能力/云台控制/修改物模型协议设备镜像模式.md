## 修改物模型协议设备镜像模式

- 接口功能

修改设备的镜像模式。   
适用型号：CS-H6c-V200-1R4WFL。  
托管或子账户token请求所需最小权限："Permission":"Config" "Resource":"dev:序列号"

- 请求地址

`https://open.ys7.com/api/v3/device/otap/prop`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | localIndex | String | 资源序号 | Y |
| header | resourceCategory | String | 资源种类，固定传Video | Y |
| header | domainIdentifier | String | 功能点领域，固定传VideoAdjustment | Y |
| header | propIdentifier | String | 功能点标识，固定传ImageFlip | Y |
| header | Content-Type | String | 请设置为application/json | Y |
| body | Body | String | JSON结构，请参考请求示例设置 enable:true-生效，false-不生效； imageFlipStyle:镜像模式，枚举值：[LEFTRIGHT-左右镜像, UPDOWN-上下镜像, CENTER-中心镜像, AUTO-自动] | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/otap/prop' \
--header 'accessToken: at.XXXXXXXXX' \
--header 'deviceSerial: XXXXX' \
--header 'localIndex: 1' \
--header 'resourceCategory: Video' \
--header 'domainIdentifier: VideoAdjustment' \
--header 'propIdentifier: ImageFlip' \
--header 'Content-Type: application/json' \
--data '{
	"enabled": true,
	"imageFlipStyle": "CENTER"
}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 服务响应信息 |
| meta.code | Int | 服务响应状态码 |
| meta.message | String | 服务响应状态描述 |
| meta.moreInfo | Object | 更多响应信息 |
| meta.moreInfo.msgDetail | String | 详细消息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 参数为空或格式不正确 |
| 10031 | 子账户或萤石用户没有权限 | 无权限操作 |
| 20007 | 设备不在线 | 设备不在线 |
| 20018 | 该用户不拥有该设备 | 该用户不拥有该设备 |
