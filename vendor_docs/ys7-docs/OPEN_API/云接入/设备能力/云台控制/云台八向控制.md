## 云台八向控制

- 接口功能

   云台控制（八向控制）。本文档仅适用于设备型号：CS-RK3-SWT1和CS-RK3-AWT1。其余型号不保证可用。支持托管和子账号。

- 请求地址

`https://open.ys7.com/api/v3/device/otap/action`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | localIndex | String | 资源描述，描述资源类型下的序号，默认填0 | Y |
| header | resourceCategory | String | 资源种类，描述资源的类型，填global | Y |
| header | domainIdentifier | String | 功能点领域，填写报备时的属性所在领域，填PTZManualCtrl | Y |
| header | actionIdentifier | String | 功能点标识，填写报备时的操作标识符，填ModifyPTZCtrl | Y |
| body | timeStamp | String | 触发时间戳，毫秒级时间戳，下发云台控制该时间戳参数需要保证递增 | N |
| body | action | String | 动作：start-开始，stop-结束 | N |
| body | control | String | 控制类型：ptz-云台 | N |
| body | command | String | 云台命令：up-上，down-下，left-左，right-右，upleft-左上，downleft-左下，upright-右上，downright-右下 | N |
| body | speed | Int | 云台控制速度，取值范围1~7，当前型号默认传1即可 | N |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/v3/device/otap/action' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: BDXXXXX' \
--header 'localIndex: 0' \
--header 'resourceCategory: global' \
--header 'domainIdentifier: PTZManualCtrl' \
--header 'actionIdentifier: ModifyPTZCtrl' \
--header 'Content-Type: application/json' \
--data-raw '{"timeStamp":"1700000000000","action":"start","control":"ptz","command":"up","speed":1}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元数据 |
| meta.code | Int | 状态码，200表示成功 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数不合法 |
| 10031 | 账号无权限访问此设备 | 当前账号无该设备操作权限 |
| 20007 | 设备不在线 | 设备离线无法响应 |
| 20018 | 该用户不拥有该设备 | 设备不属于当前用户 |
