## 查询设备预置点列表

- 接口功能

   查询用户添加的预置点信息

- 请求地址

`https://open.ys7.com/api/service/device/preset/list`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | deviceSerial | String | 设备序列号 | Y |
| query | localIndex | String | 设备通道号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/device/preset/list?deviceSerial=XXXXXXXXX&localIndex=1' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": [
        {
            "deviceSerial": "BB6164213",
            "channelNo": 1,
            "name": "预置点1",
            "index": 1
        },
        {
            "deviceSerial": "BB6164213",
            "channelNo": 1,
            "name": "预置点2",
            "index": 2
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta.code | Int | 业务码，200表示成功 |
| meta.message | String | 响应信息 |
| meta.moreInfo | String | 更多信息 |
| data[].deviceSerial | String | 设备序列号 |
| data[].channelNo | Int | 通道号 |
| data[].name | String | 预置点名称 |
| data[].index | Int | 预置点索引 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请检查请求参数是否正确 |
| 10031 | 账号无权限访问此设备 | 请确认设备是否属于当前账号 |
| 50000 | 服务异常 | 服务端异常，请稍后重试 |
| 20002 | 设备不存在 | 请确认设备序列号是否正确 |
| 20014 | 设备序列不正确 | 请确认设备序列号格式 |
| 20015 | 设备不支持 | 当前设备不支持此功能 |
