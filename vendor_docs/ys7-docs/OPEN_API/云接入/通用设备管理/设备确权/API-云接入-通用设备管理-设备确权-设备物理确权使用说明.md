# 设备 物理确权 使用说明：

**当设备需要物理确权（返回 60058 / 60085 / 60086 错误码）时，按以下步骤调用：**

1. 调用“[自动确权](https://open.ys7.com/help/664)”接口，若返回“确权成功”（200），则确权完成。不需要后续的步骤。
2. 若步骤1没有返回“确权成功”（200），提示用户保证设备离线；
3. 用户操作设备离线，并确认；
4. 循环调用“[离线确认](https://open.ys7.com/help/665)”接口：

- 1. 返回“操作成功”（200）或者连续两次返回“设备离线”（2009）：继续后续步骤；
- 2. 返回其他代码，循环调用“离线确认”接口；
- 3. 120秒超时：确权失败

5. 提示用户保证设备上线；
6. 用户操作设备上线线，并确认；
7. 循环调用“[在线确权](https://open.ys7.com/help/666)”接口：

- 1. 返回“确权成功”（200）：确权完成；
- 2. 返回其他代码，循环调用“在线确权”接口；
- 3. 180秒超时：确权失败

*注：该步骤能完成正常确权。开发者也可以根据业务实际优化*。
