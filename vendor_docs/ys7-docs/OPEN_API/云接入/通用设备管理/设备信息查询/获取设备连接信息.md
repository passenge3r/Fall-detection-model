## 获取设备连接信息

- 接口功能

   查询用户下指定设备的网络连接信息，不支持子账号和托管权限

- 请求地址

`https://open.ys7.com/api/lapp/device/connection/info`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| body | deviceSerial | String | 设备序列号,存在英文字母的设备序列号，字母需为大写 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/device/connection/info' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'deviceSerial='
```

- 返回数据

```
{
    "msg": "操作成功!",
    "code": "200",
    "data": {
        "subSerial": "FX3049123",
        "localIp": "10.65.144.111",
        "natIp": "115.236.50.1"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| subSerial | String | 设备序列号 |
| localIp | String | 设备局域网IP地址 |
| natIp | String | 设备外网地址 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 参数为空或格式不正确 |
| 10002 | accessToken异常或过期 | 重新获取accessToken |
| 10004 | 用户不存在 | 需要使用B账号 |
| 10005 | appKey异常 | appKey被冻结 |
| 20002 | 设备不存在 |  |
| 20014 | deviceSerial不合法 |  |
| 20018 | 该用户不拥有该设备 | 检查设备是否属于当前账户 |
| 49999 | 数据异常 | 接口调用异常 |
