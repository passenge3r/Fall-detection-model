## 设备备注信息查询

- 接口功能

   开发者查询B端添加工具添加的设备信息，包含设备序列号，绑定方式，绑定时间，授权连接的备注。查询条件：可通过设备序列号查询或者分页查询设备信息。适用范围：B端设备添加工具。账号类型：仅支持开发者账号使用。

- 请求地址

`https://open.ys7.com/api/service/device/add/tokenNote`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号，用于查询该设备的设备信息 | N |
| Query | id | String | 起始页索引，默认0，查询数结果不包含该数据 | N |
| Query | pageSize | Integer | 分页大小，默认10，取值范围【1~50】 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/device/add/tokenNote?id=9f83e0f0bdf44a499d5f05b8ddafef95&pageSize=10' \
--header 'accessToken: at.xxxxx'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| meta.code | Integer | 响应错误码 |
| meta.message | String | 响应错误提示 |
| meta.moreInfo | Object | 其余错误信息 |
| data | Array<Object> | 响应数据 |
| data[].id | Integer | 数据索引，最后一条数据为下一页起始页索引 |
| data[].deviceSerial | String | 设备序列号 |
| data[].note | String | 备注，授权连接的备注 |
| data[].bindTime | Integer | 绑定时间，毫秒时间戳 |
| data[].bindType | String | 绑定方式【开发者绑定，开发者使用授权绑定，安装员授权绑定】 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 400 | 请求参数异常 | 请求参数异常 |
| 404 | 设备不存在 | 设备不存在 |
| 500 | 服务异常 | 服务异常 |
