## 开发者授权列表查询

- 接口功能

   开发者查询账号下授权添加连接信息，授权添加连接用于给平台客户添加设备的入口。适用范围：B端设备添加工具。账号类型：仅支持开发者账号使用。

- 请求地址

`https://open.ys7.com/api/service/device/add/tokenUrls`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Query | id | String | 起始页索引，默认0，查询数结果不包含该数据 | N |
| Query | pageSize | Integer | 分页大小，默认10，取值范围【1~50】 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/device/add/tokenUrls?id=9f83e0f0bdf44a499d5f05b8ddafef95&pageSize=10' \
--header 'accessToken: at.xxxxx'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| meta.code | Integer | 响应错误码 |
| meta.message | String | 响应错误提示 |
| meta.moreInfo | Object | 其余错误信息 |
| data | Array<Object> | 响应数据 |
| data[].id | String | 数据索引，最后一条数据为下一页起始页索引 |
| data[].expireTime | Integer | 过期时间，毫秒时间戳 |
| data[].url | String | 授权添加连接 |
| data[].note | String | 备注 |
| data[].expired | Boolean | 是否过期 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 403 | 无权限 | accessToken请使用开发者账号 |
