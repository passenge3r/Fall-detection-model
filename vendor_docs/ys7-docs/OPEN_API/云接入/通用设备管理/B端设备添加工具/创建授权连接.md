## 创建授权连接

- 接口功能

   开发者创建授权添加设备的连接，用于给平台客户添加设备的入口。适用范围：B端设备添加工具。账号类型：仅支持开发者账号使用。

- 请求地址

`https://open.ys7.com/api/service/device/add/tokenUrl`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Header | Content-Type | String | application/json | Y |
| Body | expireTime | Integer | 过期天数，1~7天 | Y |
| Body | note | String | 备注，256字以内 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/device/add/tokenUrl' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data '{
    "expireTime": 1,
    "note": "授权给xxx添加设备"
}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "url": "https://i.ys7.com/statich5/messageH5/index.html?id=xxx&uuid=xxx&token=tk.xxx"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| meta.code | Integer | 响应错误码 |
| meta.message | String | 响应错误提示 |
| meta.moreInfo | Object | 其余错误信息 |
| data | Object | 响应数据 |
| data.url | String | 授权添加的连接 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 403 | 无权限访问 | accessToken请使用开发者账号 |
