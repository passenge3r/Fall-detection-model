## 按照设备获取告警消息列表

- 接口功能

该接口用于获取对应设备的告警消息列表。

- 请求地址

`https://open.ys7.com/api/lapp/alarm/device/list`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | Content-Type | String | application/x-www-form-urlencoded | Y |
| Body | accessToken | String | 授权过程获取的access\_token | Y |
| Body | deviceSerial | String | 设备序列号,存在英文字母的设备序列号，字母需为大写 | Y |
| Body | pageSize | Int | 分页大小，默认为10，最大为,50 | N |
| Body | pageStart | Int | 分页起始页，从0开始 | N |
| Body | startTime | Long | 告警查询开始时间，时间格式为1457420564508，精确到毫秒，默认为今日0点，最多查询当前时间起前推7天以内的数据 | N |
| Body | endTime | Long | 告警查询结束时间，时间格式为1457420771029，默认为当前时间 | N |
| Body | status | Int | 告警消息状态：2-所有，1-已读，0-未读，默认为0（未读状态） | N |
| Body | alarmType | Int | 告警类型，默认为-1（全部） | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/alarm/device/list' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'deviceSerial=427734888' \
--data-urlencode 'startTime=' \
--data-urlencode 'endTime=' \
--data-urlencode 'alarmType=-1' \
--data-urlencode 'status=2' \
--data-urlencode 'pageStart=0' \
--data-urlencode 'pageSize=3'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| page | Object | 分页信息 |
| page.total | Int | 总记录数 |
| page.page | Int | 当前页码 |
| page.size | Int | 每页记录数 |
| data | Array | 告警消息列表 |
| data.alarmId | String | 消息ID |
| data.alarmName | String | 告警源名称 |
| data.alarmType | Int | 告警类型，取值参见[告警集合](/help/981) |
| data.alarmTime | Long | 告警时间，long格式如12323452345，精确到毫秒 |
| data.channelNo | Int | 通道号 |
| data.isEncrypt | Int | 是否加密：0-不加密，1-加密 |
| data.isChecked | Int | 是否已读：0-未读，1-已读 |
| data.recState | Int | 存储类型：0-无存储，1-萤石云存储，4-sd卡存储，5-萤石云存储和sd卡存储 |
| data.preTime | Int | 预录时间：单位秒 |
| data.delayTime | Int | 延迟录像时间，单位秒 |
| data.deviceSerial | String | 设备序列号,存在英文字母的设备序列号，字母需为大写 |
| data.alarmPicUrl | String | 告警图片地址 |
| data.relationAlarms | Array | 关联的告警消息 |
| data.customerType | String | 透传设备参数类型 |
| data.customerInfo | String | 透传设备参数内容 |
| code | String | 返回码 |
| msg | String | 返回信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 参数为空或格式不正确 |
| 10002 | accessToken异常或过期 | 重新获取accessToken |
| 10005 | appKey异常 | appKey被冻结 |
| 20002 | 设备不存在 |  |
| 20014 | deviceSerial不合法 |  |
| 20018 | 该用户不拥有该设备 | 检查设备是否属于当前账户 |
| 49999 | 数据异常 | 接口调用异常 |
