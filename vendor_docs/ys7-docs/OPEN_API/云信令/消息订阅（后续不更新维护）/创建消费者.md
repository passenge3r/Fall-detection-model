## 创建消费者

- 接口功能

   开发者创建项目每个租户对应一个消息Topic，该接口用于在消费组中创建消费者，与消息通道建立连接。消息通道服务建议使用单实例单线程消费的方式。如果考虑采用分布式，建议使用规则如下：1、创建consumer、订阅及提交都必须在一个线程中；2、单个消费组consumer创建数量存在上限，达到上限后consumer创建将失败；3、单个消费组目前只会存在一个consumer可以订阅到消息。

- 请求地址

`https://open.ys7.com/api/lapp/mq/v2/consumer/{consumerName}`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | Content-Type | String | application/x-www-form-urlencoded | Y |
| Path | consumerName | String | 租户组名，名称固定为group1至group5，传入其他参数报错 | Y |
| Body | accessToken | String | 开放平台授权过程获取的访问令牌，获取方式参考接口 https://open.ys7.com/help/81 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/mq/v2/consumer/group1' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx'
```

- 返回数据

```
{
    "code": "200",
    "msg": "操作成功",
    "data": {
        "consumerId": "fab41dc1ea1043e3ad7285c96df05517"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| data | Object | 返回数据 |
| data.consumerId | String | 消费者在组中唯一标识，5分钟内未使用将自动删除，断开和消息通道的链接 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
