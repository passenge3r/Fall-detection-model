# 直播间管理

### 进入直播间管理，可以通过最上面的搜索栏输入直播间标题，选择直播状态来查询直播间。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQEmcImPOAPWDZAAIE16hD-FE084.png)

### 点击需要管理的直播间对应的 “管理” 按键，进入该直播间管理后台。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQEmcI4sSAG9RnAAFZjwNvLlY359.png)

## 基本信息

### 在 “基本信息” 栏，可以看到直播间的标题（自定义），直播间状态，开始时间等，还可以通过复制直播间地址或下载并分享二维码的形式邀请人员观看直播。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQE2cImhGAchEUAAGcZDCHbII855.png)
  

### 直播内容调取的摄像头可以自定义选择，可以点开 “选择” 按键，在 “查找摄像机” 处填入设备名称或设备序列号即可搜索摄像头。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQEmcImv2ASMd6AAEtJY8sOk4770.png)
  
![](https://resource.eziot.com/group1/M00/01/4E/CtwQEmcI45yAUCAJAAFX_WR3A1A581.png)

### 还可以自定义 “直播自动录像” 和 “时间计划” ，点击新建即可自定义直播时间计划。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQE2cI5BCAR56OAAE1YpLiUho910.png)
  
![](https://resource.eziot.com/group1/M00/01/4E/CtwQEmcI5ImAXbraAAF2wNHGLy0354.png)

### 最后点击开始直播即可。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQE2cI5VqANX8iAAFRrkw1iWY565.png)
