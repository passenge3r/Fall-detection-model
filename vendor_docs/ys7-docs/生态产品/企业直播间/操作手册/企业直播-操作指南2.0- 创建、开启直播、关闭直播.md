### **4.2、开通“视频分享”应用**

### 若家长需要通过商业智居APP进行观看直播，则需要开通该应用。

### 若公开观看不做权限设置，则不需要开通该应用。

### 该应用选择全员可见，家长需要通过该应用观看直播。
