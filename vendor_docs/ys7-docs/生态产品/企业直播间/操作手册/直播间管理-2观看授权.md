# 直播间管理

## 观看授权

### 在 “观看授权” 栏可以自定义管理即授权相关人员查看直播间，具体操作如下图：

### 如果该直播间是所有人均可观看的，直接选择 “公开观看” 即可，用户可自由进入直播间。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQE2cJ3Q6AZyqxAAC5r7wiQ5Y014.png)

如果要选择人员观看，则点击 “添加成员” 点击 “查看观看成员” 即可添加成员。
