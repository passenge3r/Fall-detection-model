# 操作指南

## 第 1 章 登录账号

### 通过浏览器打开[萤石商业智居官网](https://es.ys7.com) ，点击右上角“登录”，也可以使用“萤石商业智居”手机 APP（前往手机应用市场下载安装）扫码登录 web 管理端。

![](https://resource.eziot.com/group2/M00/00/ED/CtwQFmb5AjWAdBnAAAAqkrd3IA4781.png)

## 第 2 章 创建企业

### **2.1、首次创建企业**

### 在萤石商业智居首页登录后，在上方点击“进入控制台”，提示“创建企业”，点击开始创建。

![](https://resource.eziot.com/group2/M00/00/ED/CtwQF2b5AjiAJQo3AAAdJJg2NwU990.png)

### **2.2 、已有企业创建新企业**

### 鼠标点击控制台左侧企业名称，在下拉栏中选择“创建企业”。

![](https://resource.eziot.com/group2/M00/00/ED/CtwQFmb5AjyAdP7MAABB5qUADzw335.png)
  
![](https://resource.eziot.com/group2/M00/00/ED/CtwQF2b5Aj6ADtfXAAA01oc24i4081.png)
