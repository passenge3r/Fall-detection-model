# 直播间管理

## 直播历史

### 在 “直播历史” 栏追踪和管理直播事件，包括直播的开始和结束时间、时长、观看次数（PV）、直播状态、观看人数、页面浏览次数、是否进行了录像，以及提供相关操作选项。

![](https://resource.eziot.com/group1/M00/01/4E/CtwQEmcJ276AIM9BAADzTnCAIM8658.png)

## 观众记录

### 在 “观众记录” 栏用于记录观众的观看历史，包括观众的ID、名称、首次进入直播间的时间以及最近一次退出直播间的时间。
