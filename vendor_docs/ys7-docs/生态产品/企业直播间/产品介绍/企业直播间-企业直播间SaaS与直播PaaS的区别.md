# 企业直播间SaaS与直播PaaS的区别

为满足企业各类场景的开播与观看需求，萤石云企业直播间将相关萤石开放平台SaaS云视频监控直播底层能力整合包装，输出了一套产品独立接入的 SaaS 方案。

PaaS监控直播：
支持设备取流，提供各类SDK，让给开发者能自由接入。

SaaS监控直播：
包装完整方案，企业用户在后台控制台进行配置即可观看直播。
