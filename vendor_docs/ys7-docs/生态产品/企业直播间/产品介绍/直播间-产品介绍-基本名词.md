# 产品名词

### 下文旨在介绍您在使用萤石监控直播服务过程中可能会涉及到一些基本概念。

| 概念 | 描述 |
| --- | --- |
| 设备接入 | 设备通过萤石协议、国标28181协议等协议接入萤石开放平台，实现取流、控制等一系列能力。 |
| 推流 | 将直播内容通过网络实时传输至直播平台的过程。例如将直播内容从 OBS 等直播工具传输至企业直播的直播间。 |
| 推流地址 | 用于告知直播平台将直播内容推送到哪里的一串字符，通常由直播平台自动生成。您可以将该地址复制到 OBS 等直播工具中，从而将直播内容同步至生成该地址的直播平台。 |
| 观看页 | 观看直播的页面，专门为观看视频、参与互动以及展示指定内容而设计。 |
| 观看地址 | 观众观看直播、预告、回放时所使用的地址。 |
| 直播流 | 通过互联网实时传输到观众的设备上，以供实时观看的直播内容。 |
| 开始直播 | 开始直播 |
| 观看直播 | 观看直播 |
| 录播 | 预先录制好的视频。 |
| 点播 | 观众可以自主选择何时开始、停止或继续观看的视频。与直播不同，观众可以自由选择观看进度。预告和回放均属于点播视频。 |
| 回放 | 直播结束后生成的直播录像。可被上架到观看页供观众观看。 |
| 直播状态 | 直播具有以下几种状态。 直播中：可观看直播的状态。 预告：如上传预告片可观看预告片，如未上传预告片可查看直播封面的状态。 回放：可观看回放的状态。 已结束：直播结束但未上架回放的状态。 |
| 直播封面 | 在直播间处于预告状态且未上传预告片时，以及直播间处于已结束状态时，播放器上显示的图片。 |
| OBS | Open Broadcaster Software，一款免费开源的视频录制和直播软件，支持 Windows、macOS 和 Linux 操作系统。 |
| 页面嵌入 | 将直播间嵌入到您自己的页面，从而为观众提供更加便捷的观看体验，观众无需离开您自己的页面即可观看直播内容。例如，将直播间嵌入到电商网站页面，观众可以直接在商品页面上观看直播，既方便了观看，又方便了商品选购，从而有助于提升观众的购买意愿和体验。 |
| iframe 嵌入 | 页面嵌入的一种方式，用于将直播间的功能模块嵌入到您自己页面的任意位置。 |
| H5 | 移动端网页。 |
| H.264 和 H.265 | 视频编解码器的标准，用于压缩视频文件，使其在网络传输或存储时更加方便和节省空间。H.264 是目前市面上最主流的视频编码方式，而 H.265 比 H.264 更高效，可以在相同的网络带宽下传输更高质量的视频，并节省更多流量。 |
| 直播时间 | 直播间内设置的开播时间。该时间可能与实际开播时间不同，但如果设置了自动开播，则会按照该直播时间自动开始轮播或拉流直播。 |
| 互动工具 | 开启直播后，可以通过文字、抽奖等方式与客户进行互动。 |
| 人气 | 在观看页展示的观看人数，可能与实际观看人数不同。 |
| 系数 | 用于衡量实际观看人数对人气值影响程度的因子。观看页每新增或减少一个实际观看人数，会按照配置的增长或消减系数计算人气值。 |
| 观看限制 | 限制直播间的访问和互动，只有通过指定方式（验证码、手机号+密码、账号等）才能进入直播间观看直播或参与直播间互动，从而有助于保障直播间内容的安全性和隐私性、维护直播环境，以及实现产品推广等目的。 |
| 直播协议 | 用于传输直播内容的协议，确保直播内容的稳定传输和观看质量。不同的直播平台和设备会采用不同的直播协议，例如企业直播的 Android 观播 SDK 、iOS 观播 SDK 以及 PC 端观播 SDK 采用的是 HTTP-FLV 协议，而 H5 观看直播 SDK（移动端）采用的是 HLS 协议。 |
| 观看并发 | 同一时间段内，您账号下所有直播间中的同时在线人数峰值之和。观看并发数越高，代表受欢迎程度越高。 |
| 转码 | 将一个媒体文件的格式转换为另一个可用格式的过程，以便在不同设备或平台上播放或编辑该文件。比如mov视频转为m3u8文件，方便在线点播。 |
| 管理员账号 | 创建萤石云直播间账户时提供的账号，具有完全的管理员权限，可以控制整个账户的资源和权限。 |
| 子账号 | 由管理员账号创建的账号，可用于管理资源，但通常权限受限。 |
| 企业 | 子账号的集合。企业可以将不同的部门或子公司划分为不同组织，实现不同组织间的直播资源隔离，从而独立管理组织下用户创建的直播资源。 |
