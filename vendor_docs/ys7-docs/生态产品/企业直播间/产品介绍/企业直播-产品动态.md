# 产品动态

### 萤石企业直播间，是为企业用户提供多种视频监控转直播服务，包括丰富多彩的集成直播页面、直播管理功能，并提供千万级并发、多节点分发的一站式IoT直播平台，满足各行各业日益增长的传统物联设备上云直播需求。

## 产品动态

### 我们不断致力于提升直播产品的质量和用户体验。以下是我们产品迭代的主要里程碑：

### **直播间功能优化**

### **版本 v1：**

- 对视频分享功能进行重大改进，支持企业直播间的服务需求。
- 新用户注册后，免费赠送1个月有效期的直播间与并发。

### **版本 v1.1：**

新增批量添加成员的功能，以提高直播间管理的效率； 用户现在可以根据网络状况轻松切换视频清晰度； 新增支持静音功能，让用户在观看直播时有更多的控制权。

### **版本 v1.2：**

引入观看权限设置功能，让用户能够更精细地控制直播间的访问权限。

### **版本 v1.3：**

升级底层播放器SDK能力，包括：支持http-flv协议，支持2-5秒延迟；支持H265编码，以提供更高质量的视频播放体验；错误提示优化等。

### **版本 v1.4：**

新增视频广场功能，为用户提供了更丰富的视频内容。

### **版本 v1.4.1：**

支持H265编码，以提供更高质量的视频播放体验。
