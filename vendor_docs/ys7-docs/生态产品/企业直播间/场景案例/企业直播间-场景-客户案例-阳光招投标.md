# 企业直播间-客户案例

### **1. 莆田某行政服务中心阳光招投标**

![](https://resource.eziot.com/group1/M00/01/4D/CtwQEmcHjnuAUwDzAArmqowIsfY222.png)
![](https://resource.eziot.com/group1/M00/01/4D/CtwQE2cHjoGAAzu_AArZtzjxlXU624.png)

### **项目背景：**

### 为响应福建省省级相关开评标监督平台要求，实现将开标室面向公众公开，评标室全程录像保存以及回放评标录像三个功能内容，实现招标过程透明化。

### **项目规模：**

### 该项目建设采用硬件+软件结合的方式，全市共计8间开标室、12间评标室最大可以满足同时10000人在线观看；开标、评标直播视频需要存储在云端半年时间；开标、评标直播视频允许相关监管人员远程回放观看。

### **2. 福建省某地行政服务中心阳光招投标项目**

![](https://resource.eziot.com/group1/M00/01/4D/CtwQEmcHjoWASBJjAAXx2GT2NuI943.png)

### **项目背景：**

### 福建某市行政服务中心为响应国家要求，根据发文通知，抓紧推进该市工程项目交易中心使用不见面开标的项目建设，旨在通过该项目能够依托电子招投标交易平台，加快部署在线投标、开标系统，实现有效降低现场投标、开标带来的人员聚集风险，同时降低企业交易成本，实现远程在线可视化的开评标过程，方便投标人员，管理人员，以及监管人员、甚至于公众人员对招标项目的监督管理此外，发改委也要求大力推进招投标行政监督电子化。按照政务信息化要求，依托电子招投标交易平台，加快部署行政监督窗口和监督工具，实现对电子招投标交易全程事中事后监管，因此，对于招标全程的录像也是要做到长时间存储，以方便时候回查。

### **项目需求：**

### 福建全省各地市招投标中心建设阳光招投标视频公开：

### 每个招投标中心大约有20个摄像机需要视频公开，视频可在招投标网站查看，可通过招投标中心的微信公众号查看等。

### **项目预期：**

### 每个地市配置一张直播卡密,一张直播卡密支持20个直播间2000并发：

### 提供直播接口给招投标中心网站，用户可直接登录网站进行视频查看，或者用户可通过招投标中心的微信公众号进行视频查看。

### **项目规模：**

### 该项目接入萤石云直播间、萤石云点播流量以及萤石云录像空间，采购一张实体卡密，满足2000人同时进行招标观看。
