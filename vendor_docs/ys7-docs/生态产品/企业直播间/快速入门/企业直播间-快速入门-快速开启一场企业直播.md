# 快速入门：快速开启一场企业直播

本文以智居直播间为例，介绍如何快速开始一场企业直播。

### 1、创建账号

在开始直播之前，您需要注册萤石智居的账号，并添加设备。
参见：[创建账号](/help/3752)

### 2、添加设备

萤石直播间主要包括摄像头直播、点播两个能力，以直播能力为例，您添加设备后，就可以直接针对摄像头开启直播。
参见：[添加设备](/help/3783)

### 3、创建、开启直播、关闭直播

参见：[创建、开启直播、关闭直播](/help/3763)

### 4、购买对应资源

充值及服务明细查询，参见：[参考手册](/help/3765)

### 5、功能列表

- 直播间管理
  直播间开启后的管理介绍，包括直播开启、关闭，设置直播间信息，设置直播计划等内容，详见：[直播间管理](/help/3767)
- 权限管理
  添加成员及授权观看，支持验证码观看、公开观看、限制App账号观看、白名单观看等，参见：[观看授权](/help/3771)
- 互动管理
  分享嵌入+互动工具，参见：参见：[参考手册](/help/3769)
