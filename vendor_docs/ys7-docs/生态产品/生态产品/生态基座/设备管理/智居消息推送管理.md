## 支持的消息类型

| 消息类型 | 消息名称 |
| --- | --- |
| ys.onoffline | 设备上下线消息 |
| ys.childdev.onoffline | 子设备上下线消息 |
| ys.userdevice.change | 设备绑定/解绑变更消息 |
| ys.alarm | 设备告警消息 |
| ys.open.isapi | ISAPI上行消息 |
| ys.iot | 物联协议消息 |
| ys.device.slaves | 通道关联关系消息 |
| ys.open.cloud | 云录制消息 |

## 消息返回格式

### ys.onoffline

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| header | Object | 设备信息 |
| -type | String | 消息类型：ys.onoffline |
| -deviceId | String | 设备序列号 |
| -channelNo | Long | 通道号 |
| -messageTime | Long | 消息时间戳 |
| body | Object | 设备上传的消息 |
| -devType | String | 设备类型 |
| -regTime | String | 设备上一次注册时间，格式： yyyy-MM-dd HH:mm:ss |
| -natIp | String | 设备外网IP |
| -msgType | String | 消息类型：OFFLINE-设备离线消息，ONLINE-设备上线消息 |
| -subSerial | String | 设备序列号 |
| -occurTime | String | 设备上线（离线）时间，格式： yyyy-MM-dd HH:mm:ss |
| -deviceName | String | 设备名称 |
| -IsCleanSession | Integer | 设备是否是快速重连，0-表示设备快速重连，1-表示非快速重连 |
| -dasId | String | das ID |

### ys.alarm

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| header | Object | 设备信息 |
| -type | String | 消息类型：ys.alarm表示设备告警消息 |
| -deviceId | String | 设备序列号 |
| -channelNo | String | 设备通道号 |
| body | Object | 设备上传的消息 |
| -alarmId | String | 消息内容 |
| -alarmTime | String | 报警时间戳 |
| -alarmType | String | 报备过的消息类型 |
| -channel | Integer | 设备通道号 |
| -channelName | String | 报警通道名称 |
| -channelType | Integer | 设备通道类型：1-视频通道 2-IO通道 |
| -checksum | String | 设备加密密码 |
| -crypt | Integer | 图片加密类型:0-不加密；1-用户加密；2-平台加密 |
| -customInfo | String | 报警自定义信息:限定为非xml且不包括“，”，长度限制：不能超过80字节 |
| -customType | String | 自定义协议类型,命名规则：设备型号\_协议标识 如：CS-A1-32W\_XX |
| -describe | String | 告警描述 |
| -devSerial | String | 设备序列号 |
| -location | String | 报警位置信息:长度不能超过80字节 |
| -pictureList | List<Object> | 告警图片数据列表 |
| --url | String | 告警图片 URL。图片可能被设备加密，是否加密可以通过 isEncrypted 参数判断，如图片已加密，需要调用客户端 SDK（ezOpenSDK） 的相关接口解密图片。 |
| --id | String | 图片 ID |
| -relationId | String | 报警关联ID,由发起联动方产生，用来表示联动的关联关系 |
| -status | Integer | 【报警协议内容】报警状态 1-开始；2-停止（状态2已经废弃） |
