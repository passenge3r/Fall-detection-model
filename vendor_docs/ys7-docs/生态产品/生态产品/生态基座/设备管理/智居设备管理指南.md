# 智居设备管理

## 设备管理接口

| 名称 | 功能描述 |
| --- | --- |
| [设备添加（萤石协议设备）](https://open.ys7.com/help/3743) | 将萤石协议设备添加至当前智居平台企业中 |
| [修改设备名称](https://open.ys7.com/help/3790) | 修改设备名称,同步更新开放平台的设备名称 |
| [修改设备归属部门](https://open.ys7.com/help/3791) | 修改设备归属部门,仅支持账号下所拥有的部门权限的变更 |
| [设备删除](https://open.ys7.com/help/3745) | 将设备从智居平台的当前企业中移除 |
| [查询设备详情](https://open.ys7.com/help/3744) | 查询账户下设备的详细信息，包含设备名称、状态、归属部门等信息 |
| [分页查询通道列表](https://open.ys7.com/help/4447) | 分页查询账户下通道列表数据，包含设备名称、状态、归属部门等信息 |
| [分页查询设备列表](https://open.ys7.com/help/3746) | 分页查询账户下设备列表数据，包含设备名称、状态、归属部门等信息 |
| [查询组织下通道列表](https://open.ys7.com/help/3793) | 滑动分页查询组织下监控设备列表，包含设备名称、状态、归属部门等信息 |
| [查询组织下设备列表](https://open.ys7.com/help/3829) | 查询组织下设备列表 |
| [更新单设备数据](https://open.ys7.com/help/3749) | 对指定的设备进行数据更新操作 |
| [开启开放平台设备同步任务](https://open.ys7.com/help/3748) | 同步企业在开放平台添加的设备数据，对未在智居平台的设备数据执行导入操作 |
| [查询设备同步任务状态](https://open.ys7.com/help/3750) | 查询企业同步任务状态情况 |
| [托管设备解除托管](https://open.ys7.com/help/3792) | 对托管设备进行托管解除，解除后该设备在智居平台中被移除 |
| [变更设备加解密状态](https://open.ys7.com/help/4352) | 支持对企业下添加的设备进行加解密状态的变更 |
| [同步设备状态](https://open.ys7.com/help/4353) | 从开放平台同步设备加解密状态，支持添加设备或托管设备 |
| [批量激活设备](https://open.ys7.com/help/4958) | 从开放平台同步设备加解密状态，支持添加设备或托管设备 |
