# 账号注册

## 账号注册相关接口

| 名称 | 功能描述 |
| --- | --- |
| [下发短信验证码](https://open.ys7.com/help/3796) | 下发验证码短信，主要用于账号注册以及重置密码操作 |
| [账号注册](https://open.ys7.com/help/3797) | 通过短信验证码进行账号注册 |
| [查看账号信息](https://open.ys7.com/help/3798) | 查询当前账号信息数据 |
| [账号密码登录](https://open.ys7.com/help/3800) | 采用账号+密码形式进行登录操作 |
| [获取行为验证码识别图片](https://open.ys7.com/help/3801) | 获取ocr文字识别图片，当账号多次登录失败后，需要通过该验证码进行登录 |
| [账号密码重置](https://open.ys7.com/help/3804) | 通过短信验证码进行密码更新操作 |
| [刷新访问令牌](https://open.ys7.com/help/3805) | 刷新当前访问令牌，用于令牌续期场景 |
| [账号登出](https://open.ys7.com/help/3806) | 账户登出，当前访问令牌被失效 |
| [下发账号注销短信验证码](https://open.ys7.com/help/4242) | 获取注销账号短信验证码 |
| [账号注销](https://open.ys7.com/help/4241) | 注销指定应用下的账号 |
| [获取小权限token](https://open.ys7.com/help/4303) | 企业成员用户获取设备取流、设备操作的小权限token |
