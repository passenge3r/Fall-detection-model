# 企业管理

## 企业管理接口

| 名称 | 功能描述 |
| --- | --- |
| [获取行政区域信息](https://open.ys7.com/help/3807) | 获取行政区域信息 |
| [创建企业](https://open.ys7.com/help/3808) | 在智居平台中创建企业 |
| [绑定开放平台账户创建企业](https://open.ys7.com/help/3809) | 使用开放平台的账户在智居平台中创建企业账户，需要获取开放平台的AppKey和appSecret 获取路径：开放平台官网-控制台-账号中心-应用信息-应用密钥 |
| [查询企业信息](https://open.ys7.com/help/3810) | 查询当前账户下的企业信息 ，内容包含企业名称、logo、区域等数据 |
| [变更企业信息](https://open.ys7.com/help/3811) | 变更当前账户下的企业信息 ，可修改企业名称、logo、区域等数据 |
| [查询企业列表](https://open.ys7.com/help/3812) | 查询当前账户所在的企业列表数据 |
| [下发切换企业验证码](https://open.ys7.com/help/3863) | 下发切换企业验证码短信，用于切换企业使用 |
| [切换企业](https://open.ys7.com/help/3813) | 从当前企业切换成另一个企业，返回数据为新企业的token ，旧token会失效 |
| [查询企业码信息](https://open.ys7.com/help/3814) | 查询当前企业码数据 |
| [重置企业码](https://open.ys7.com/help/3815) | 重置当前企业码数据 |
| [下发企业解散验证码](https://open.ys7.com/help/3816) | 下发企业解散验证码短信至创建者，用于解散企业使用 |
| [解散企业](https://open.ys7.com/help/3818) | 解散当前企业，基于验证码方式进行解散企业 |
| [下发企业转让验证码](https://open.ys7.com/help/3817) | 下发企业装让验证码短信至创建者，用于装让企业使用 |
| [转让企业](https://open.ys7.com/help/3819) | 转让当前企业，将当前企业转让至企业中的另一个员工名下 |
| [查询企业设置](https://open.ys7.com/help/3864) | 查询企业设置信息 |
| [编辑企业设置](https://open.ys7.com/help/3865) | 编辑企业设置信息 |
