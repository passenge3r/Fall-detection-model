# 智居云备份组件接入指南

## 智居云备份组件简介

> 客户的业务场景中若存在云备份的接入需求，需引入云备份组件的页面地址，并传入智居平台的token以及自己业务场景的登录入口地址

> **注**：目前云备份仅支持Web端接入，暂未支持H5页面；

云备份是针对视频监控设备研发的基于画面、视频的采集、存储和处理的系统组件，通过简单的操作，帮助开发者灵活地对监控设备画面进行存储和处理。

## 云备份组件使用注意事项

1. 空间创建存在上限，最多创建4个空间
2. 每个空间仅能创建20个备份计划
3. 设备仅能参与一个视频任务计划。即表现为在创建视频任务的备份计划选取设备时，若该设备参与了其他的视频备份计划时，此次创建会收到创建失败的提示。
4. 备份计划的开始时间设置
   - 当开始时间为今天时，会根据配置的任务执行时间点创建当前时间之后的任务，并在23点30分自动创建第二天的任务。创建即时任务时，若任务时间点距当前时间不足10分钟，生成的任务可能会执行异常。建议配置即时任务的时间点或时间段的开始时间均为10分钟之后的时间。
   - 当开始时间为非今天时，系统会在23点30分自动创建第二天的任务
5. 备份计划被暂停后，影响的是第二天及后续的任务生成，当天进行中的任务还会继续执行完
6. 当备份计划设备或时间被调整后，当天未开始的任务会被清除，已进行中的任务会被保留，但是不会在生成新的任务，系统会在23点30分根据变更的配置生成第二天的任务。
7. 备份计划删除后，任务会同步清除，但已生成的文件不会清除，可在文件库中查看

## 云备份组件接入

组件引入地址：https://es.ys7.com/cloud/backup?token=xxx&redirectUrl=xxx

| 参数名 | 参数类型 | 是否必传 | 说明 |
| --- | --- | --- | --- |
| token | string | YES | 商业智居平台访问令牌 |
| from | string | N | ISV 客户集成标识 |
| redirectUrl | string | N | 令牌失效后跳转路径，默认商业智居登录，被嵌入iframe不跳转 |
| header | int | N | 是否显示LayoutHeader,默认1，0：不显示；1：显示 |
| needWindow | number | N | 0：在当前页跳转；1：打开一个新的标签页；2-打开一个新的窗口 |

## 组件使用入门

- 云备份概览
- 空间管理
- 备份计划
- 文件库

### **云备份概览**

显示当前账户下云备份业务统计数据，包含存储空间、计划运行状况以及文件存储数据
![](https://es.ys7.com/dfs/7e8ba3a207ca42f4ac55b0b9c0b479b5.png)

### **空间管理**

自定义设置存储空间，用于存放图片和视频数据。空间管理支持设置多个存储空间，并根据应用的场景对空间设置存储期限

云备份组件开通后，会自动创建默认空间和点检空间，其中点检空间用于点检业务。此外可以自行创建存储空间，至多创建4个空间。每个空间都可用于存放图片和视频文件。
  
  
![](https://es.ys7.com/dfs/4ef7b45520c04c998ec8681973b8db8c.png)

**文件存储周期**
  
表示文件在该空间的存储时长。如设置空间的存储时长为60天时，表示文件上传到该空间后，文件仅保存60天的有效期，到期后会被清除。
文件存储周期只影响新上传的文件。当空间的已有文件时，调整文件存储周期不会影响原有文件的存储时长。

### **备份计划**

备份计划主要目的是根据选择的设备，周期性的执行设备监控画面的抓拍和视频录制操作，并将生成的文件存放至空间中。一个空间下最大只能创建20个备份计划
  
  
![](https://es.ys7.com/dfs/574636fd89ff44e4b140b838aeb37092.png)

#### **制定备份计划**

1. 配置备份计划的基本信息、任务类型、文件存储位置以及计划有效期

   ![](https://es.ys7.com/dfs/efbdb3b4225745a384ab8eedd2ff264e.png)

     
   **文件类型**  
   分为图片和视频类型，表示此任务是抓图任务和视频录制任务。  
   **所属空间**  
   表示该计划下设备生成的图片和视频文件的存储位置，文件的存储时间和空间的文件存储周期一致。  
   **备份计划日期**  
   表示该备份计划的有效期限，可选择为自定义或永久。当选择永久时，表示该计划会一直执行；当自定义时间时，开始日期表示该计划从什么时候开始执行，结束日期表示该计划从什么时候结束。
2. 配置任务执行周期，可配置为固定周期以及时间点执行两种方式

   ![](https://es.ys7.com/dfs/181143b81d974acf9d18b7d36b800467.png)

     
   **时间间隔触发**  
   支持图片和视频类型的任务。当计划为图片任务时，表示在配置的时间段内间隔多少分钟进行一次抓拍操作；当计划为视频任务时，时录制连续性的视频，配置的开始时间和结束时间分表表示为录制视频的起始时间和截至时间。  
   **时间点触发**  
   仅支持图片类型的任务。表示在具体的时间点进行设备抓拍操作，如设置了时间点为12:00,表示每天的12点会执行一次设备抓拍操作。
3. 选择设备，选择参与抓拍或录制任务的设备
     
   最多一次性选择200个设备。当创建的视频录制计划时，参与计划的设备需要进行唯一校验，每个设备仅能参与一个视频录制计划。
     

   ![](https://es.ys7.com/dfs/13b1fc3bc24f495ebbd543634c080943.png)
