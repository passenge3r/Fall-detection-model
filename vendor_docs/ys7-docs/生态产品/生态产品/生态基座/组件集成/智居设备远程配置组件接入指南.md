# 智居设备远程配置组件接入指南

## 智居设备远程配置组件简介

> 客户的业务场景中若存在设备的远程配置需求，可以通过引入远程配置组件的页面地址进行对设备的有远程管理

设备远程配置组件，可支持在控制台进行设备的远程配置或通过API进行远程设备配置项修改。免除设备配置过程需要前往设备本地的高成本。

## 前置条件

### 设备接入条件

- 账户添加的设备，非托管设备，且设备需在线
- 仅支持海康设备，NVR设备版本号需在4.2.0版本以上，IPC设备版本号需在5.6.0版本以上
- 生态企业用户需要有Config权限码

## 权限码

| 权限标识 | 描述 |
| --- | --- |
| [Config](https://open.ys7.com/help/3840) | 流量查看 |

## 组件接入

组件引入地址：https://es.ys7.com/webConfigCtrl?needWindow=0&header=1&token=xxx&redirectUrl=&deviceSerial=xxx

| 参数名 | 参数类型 | 是否必传 | 说明 |
| --- | --- | --- | --- |
| token | string | YES | 商业智居平台访问令牌 |
| deviceSerial | string | YES | 设备序列号 |
| from | string | N | ISV 客户集成标识 |
| redirectUrl | string | N | 令牌失效后跳转路径，默认商业智居登录，被嵌入iframe不跳转 |
| header | int | N | 是否显示LayoutHeader,默认1，0：不显示；1：显示 |
| needWindow | number | N | 0：在当前页跳转；1：打开一个新的标签页；2-打开一个新的窗口 |

### 接入页

通过接入地址时会直接打开设备的配置入口，然后点击立即配置按钮即可进入设备的配置管理页中，接入页如下

### 配置页

目前设备配置管理中会基于设备型号以及类型会展示不同的模块配置，一般主要有如下几个可配置模块

- 事件中心
- 存储接入
- 存储管理
- 系统配置
- 维护与安全
