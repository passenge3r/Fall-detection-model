# 国标协议设备接入组件

## 国标协议接入组件简介

> 客户的业务场景中若存在具备国标协议设备的接入需求，需引入国标协议申请页的页面地址，并传入智居平台的token以及自己业务场景的登录入口地址

> **注：** 国标协议功能仅支持企业套餐的开发者账户

> **注：** 目前国标设备license的申请仅支持Web端接入，暂不支持H5页面；

## 接口权限

| 权限标识 | 描述 |
| --- | --- |
| [Config](https://open.ys7.com/help/3840) | 设备配置权限 |

## 应用国标协议组件接入

组件引入地址：https://es.ys7.com/nationalStandard?token=xxx&redirectUrl=xxx

| 参数名 | 参数类型 | 是否必传 | 说明 |
| --- | --- | --- | --- |
| token | string | YES | 商业智居平台访问令牌 |
| from | string | N | ISV 客户集成标识 |
| redirectUrl | string | N | 令牌失效后跳转路径，默认商业智居登录，被嵌入iframe不跳转 |
| header | int | N | 是否显示LayoutHeader,默认1，0：不显示；1：显示 |
| needWindow | number | N | 0：在当前页跳转；1：打开一个新的标签页；2-打开一个新的窗口 |

## 国标license申请

1. 国标License配置页点击绑定设备按钮
![](https://es.ys7.com/dfs/9aa321b664d84fc0be359e91823902a6.png)
  
  
2. 根据设备类型选择IPC或者NVR进行License的创建
![](https://es.ys7.com/dfs/c50fd3e3bc144994a2d15acfd6c16164.png)
