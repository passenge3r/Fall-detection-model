# 人员管理接入指南

## 人员管理接口

| 名称 | 功能描述 |
| --- | --- |
| [查询成员列表](https://open.ys7.com/help/3841) | 分页查询企业成员信息列表，返回登录用户生效范围内的记录 |
| [查询组织下的成员列表](https://open.ys7.com/help/3845) | 查询指定组织下的成员信息列表，返回成员个人信息以及岗位信息 |
| [查询岗位下的成员列表](https://open.ys7.com/help/3846) | 查询指定岗位下的成员信息列表，返回登录用户生效范围内的记录 |
| [查看成员详情信息](https://open.ys7.com/help/3844) | 查询指定的企业成员信息，返回成员个人信息、所属组织以及权限生效范围 |
| [查询当前用户的岗位信息](https://open.ys7.com/help/3861) | 查询当前登录账户的岗位信息 |
| [添加成员](https://open.ys7.com/help/3825) | 通过手机号将成员添加到企业中 |
| [修改成员信息](https://open.ys7.com/help/3843) | 修改企业成员的信息，包括姓名、所属组织、角色以及权限生效范围 |
| [变更成员岗位及生效范围](https://open.ys7.com/help/3853) | 修改指定成员的岗位、生效范围 |
| [变更成员所在组织](https://open.ys7.com/help/3847) | 将指定成员从原组织变更至目标组织下 |
| [从组织下移除成员](https://open.ys7.com/help/3851) | 将指定成员从目标组织下移除，成员必须在一个组织下，否则移除失败 |
| [删除成员](https://open.ys7.com/help/3852) | 将指定成员从当前企业中移除，同步删除该成员的组织、岗位等数据 |
| [退出企业](https://open.ys7.com/help/4238) | 从已切换的企业中退出，不能退出自己拥有的企业 |

## 岗位管理

> 岗位涉及权限码数据，具体的权限码详情数据请看 [权限项页](https://test12open.ys7.com/help/3840)

| 名称 | 功能描述 |
| --- | --- |
| [添加岗位](https://open.ys7.com/help/3824) | 在企业下添加新的岗位,并赋予该岗位权限 |
| [查询岗位详情](https://open.ys7.com/help/3854) | 通过岗位编号查询岗位详情数据 |
| [查询岗位列表](https://open.ys7.com/help/3855) | 分页查询当前企业的岗位数据列表 |
| [修改岗位](https://open.ys7.com/help/3857) | 修改指定的岗位，包括岗位的基本信息以及权限点 |
| [修改岗位权限配置](https://open.ys7.com/help/3858) | 修改指定岗位的权限配置 |
| [删除岗位](https://open.ys7.com/help/3859) | 删除指定的岗位 |
