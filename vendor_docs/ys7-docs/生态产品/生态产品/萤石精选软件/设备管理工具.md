# 设备管理工具操作手册

# 1登录、创建企业

## 1.1登录

点击"设备管理工具"，进入登录页面，输入萤石开放平台的账号，密码，点击"登录按钮"，完成登录操作。
![](https://izhstatic.ys7.com/vasp-openweb/1776925578403_1.png)

## 1.2创建企业

初次使用登录后，需要进入企业注册页面，按照要求输入企业信息，填写开放平台的appkey和secret，点击"保存按钮"，完成创建企业操作。

场景选项，可以选择门店、厂区、工地等，也支持自定义。

![](https://izhstatic.ys7.com/vasp-openweb/1776925633699_2.png)

# 2.同步设备、看视频

## 2.1萤石开放平台设备同步

根据页面提示，进行全量设备同步。

**提示**：点击删除按钮，开放平台的设备数据也会删除

![](https://izhstatic.ys7.com/vasp-openweb/1776925934965_3.png)

## 2.2新增设备

**注**：新增设备以后，设备管理工具和开放平台均可查看、管理该设备；

### 2.2.1 扫码添加

当设备未配网、海康NVR 4.0版本以上的设备，只能通过扫码添加。具体如下：

首先下载"设备管理工具"的APP。

**1、未配网的萤石摄像机**

可通过APP扫描设备机身的二维码，根据提示配网、绑定。

**2、海康的摄像机或NVR录像机**

- 步骤1：通过浏览器访问摄像机IP，选择"配置→网络→高级配置→平台接入"，进入平台接入配置界面。
- 步骤2：将平台接入方式选择为"萤石云"，并勾选启用。
- 步骤3：根据系统提示信息设置验证码（标签上有验证码的设备无需设置）。

![](https://izhstatic.ys7.com/vasp-openweb/1776925974808_4.png)

获取到设备令牌后，用慧眼智巡APP扫码添加。二维码只可使用一次。

### 2.2.2在设备管理工具平台直接添加设备（序列号+验证码）

点击"添加设备按钮"，弹出"添加设备弹窗"，输入所需的设备名称、设备序列号、设备验证码，设置设备所属组织场景。

**说明**：

1. 勾选"继续添加按钮"可不关闭窗口继续添加下一个设备。
2. 添加设备前，设备必须已经配网。
   ![](https://izhstatic.ys7.com/vasp-openweb/1776926015998_5.png)

**注**：若提示"智居添加设备失败，错误码:60058,错误信息:设备存在高风险需要确权"，是因为使用了默认验证，触发了设备的保护机制。根据提示信息进行后续步骤操作即可
![](https://izhstatic.ys7.com/vasp-openweb/1776926045786_6.png)

## 2.4播放视频

### 2.4.1 视频预览

通过点击左侧"组织树"，选择需要播放视频的组织或场景，视频列表会展示对应组织或场景下视频监控。

**提示**：

1. 可通过输入项目的名称关键词搜索快速找到该项目。
2. 点击组织节点右侧"刷新按钮"可刷新该组织的最新信息和设备在线状态。
3. 点击视频列表下方的"视频显示方式按钮"可切换视频卡片/列表显示模式。
   ![](https://izhstatic.ys7.com/vasp-openweb/1776926266080_9.png)

依次点击需要进行播放的视频监控，右侧播放窗口会依照设备点击次序，依次在不同窗口播放所点击的视频。点击视频底部"暂停/播放按钮"视频将切换播放状态。

**提示**：

1. 可勾选"仅查看在线视频"，视频列表将只显示在线的监控。
2. 双击组织节点时，播放当前分屏数的视频。
3. 点击视频列表下方"刷新按钮"可刷新设备在线状态。
4. 点击视频列表下方"搜索按钮"可输入视频名称或序列号快速检索到该视频。

### ## ## 2.4.2 视频回放

参照本说明【视频预览】，播放需要查看回放的视频，在视频播放页面，点击视频顶部"录像回放按钮"（鼠标移至视频框内展示），进入该视频录像回放模式。

**提示**：

1. 回放模式需要监控中安装了内存卡。
2. 新内存卡需要初始化后，才能正常存储画面。

![](https://izhstatic.ys7.com/vasp-openweb/1776926353700_10.png)

在视频录像回放模式，拖动底部时间条，可快速跳转播放指定时间点回放。

![](https://izhstatic.ys7.com/vasp-openweb/1776926424603_11.png)

# 4.服务管理（设备激活）

## 4.1视频激活

**模块说明**：未激活的设备，不能操作，不能观看。视频广场和别的端也不显示。

**方法一：设备单个激活**

通过点击左侧功能按钮"系统"，默认进入组织架构页面，打开左侧功能栏中的"服务管理"，点击"视频激活"按钮，进入激活管理页面。选择要激活的组织或者在上方通过序列号搜索出设备。在要激活的视频通道右边打开激活开关，激活完毕。

**提示**：

1. 未激活设备可以预览3秒，确定是否是您所需激活的视频。3秒后，画面自动关闭。
2. 7天内激活的设备，不允许取消激活状态。

![](https://izhstatic.ys7.com/vasp-openweb/1776926794700_21.png)

## 4.2设备批量激活

通过点击左侧功能按钮"系统"，默认进入组织架构页面，打开左侧功能栏中的"服务管理"，点击"视频激活"按钮，进入激活管理页面。点击"导入激活视频"按钮，弹出批量新增弹窗。输入设备序列号和通道号后，点击确定按钮。程序开始自动激活，保持页面不动，直到所有设备激活关闭。

**提示**：

1. 可先下载模板，把用户信息复制到模板内后，再用Excel表格导入。
2. 7天内激活的设备，不允许取消激活状态。
3. 设备序列号通道号可在设备通道管理页面内导出。
