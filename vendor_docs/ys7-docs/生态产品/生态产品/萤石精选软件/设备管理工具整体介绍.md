# 设备管理工具整体介绍

> 设备管理工具整体介绍

> 更新时间: 2026-05-25T16:44:53.000+08:00

> 文档ID: 5188 | 来源树: 生态产品

---

1. 设备管理工具（面向萤石开发者客户），支持设备多级权限管理、组织架构管理、大屏轮巡、语音对讲、成员权限精细化管理的客户端工具。
2. 通过该管理工具，可以将成员加入企业，根据实际需要授权成员不同的权限，可实现成员查看、预览设备、添加、删除设备，通过客户端实现大屏轮巡等；该平台的数据与开放平台保持同步；
3. 客户首次使用，将赠送10设备激活、1个月的试用；在该工具上使用，需要将设备激活，才可以对设备进行配置、观看等。
4. 标准价格为：13元/设备/年，（支持设备配置、支持通过该工具进行查看预览、大屏轮巡等客户端标准功能）；
5. 如有其他需求，可联系小助手进行了解、购买。
