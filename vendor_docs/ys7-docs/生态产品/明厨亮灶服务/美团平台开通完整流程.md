# 美团平台开通完整流程

## 一、设备绑定（如果已绑定设备可跳过此步）

**操作步骤**

1. 打开萤石云视频APP
2. 点击首页的“+”号
3. 选择以下任一方式添加：

- 扫描二维码：扫描设备机身或说明书上的二维码
- 输入序列号：手动输入设备序列号

## 二、购买服务

### 购买套餐

1.“我的”--工具--应用市场--明厨亮灶模块  
2. 点击底部“服务”  
3. 选择**美团直播1年套餐（52一年）**  
4. 完成支付

### 如有卡密（购买了套餐不需要进行卡密兑换，直接进行后续步骤）

1. 点击“卡密兑换”
2. 输入32位卡密
3. 点击“确认绑定”

---

## 三、创建店铺

萤石云视频APP → 我的 → 工具 → 应用市场 → 明厨亮灶 →门店→ 创建店铺  
![](https://izhstatic.ys7.com/vasp-openweb/1778309222430_19b81d6fe3c66ddb7f49f7dc3e896eba.jpg)

### 必填信息

- **门店名称**：需与营业执照一致
- **行政区划**：选择店铺所在地区
- **统一社会信用代码**：18位

---

## 四、开通服务

1. 进入明厨亮灶模块
2. 选择已创建的店铺
3. 点击“新增设备”
4. 选择平台：**美团**→会弹出填写美团门店id

### 获取美团门店id

1. 打开美团外卖商家版APP
2. 点击右下角“我的”
3. 联系“客服小袋”
4. 输入指令“门店ID”
5. 系统返回门店ID  
   ![](https://izhstatic.ys7.com/vasp-openweb/1777518314995_9ac59b1b655b1bd9a20e2a86a5f16e88.jpg)
6. 选择要开通的设备
7. 点击“开通”

---

## 五、确认开通

1. 登录美团商家后台
2. 确认直播内容：
3. 提交确认

登陆美团外卖商机APP-我的--门店设置--明厨亮灶与环境档案，确认开通情况。

**如果在萤石云app已经开通了，但在美团依旧显示未开通，先检查一下自己在创建店铺的时候填写的美团id是否和美团客服给的id一致。**![](https://izhstatic.ys7.com/vasp-openweb/1777518448035_dbda63be-e3d0-493c-bf16-917e8eb74c41.jpg)

---

## 六、常见问题

### 加密设备无法开通

需先解密：我的 → 管理中心 → 设备管理 → 点击设备 → 设置 → 隐私设置 → 视频加密 → 关闭
