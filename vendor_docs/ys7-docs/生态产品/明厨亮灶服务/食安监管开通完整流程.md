# 食安监管开通完整流程

## 一、设备绑定（如果已绑定过可跳过此步）

**操作步骤**

1. 打开萤石云视频APP
2. 点击首页的“+”号
3. 选择以下任一方式添加：

- 扫描二维码：扫描设备机身或说明书上的二维码
- 输入序列号：手动输入设备序列号

## 二、购买服务

套餐和卡密兑换二选一

### 购买套餐

1. “我的”--工具--应用市场--明厨亮灶模块
2. 点击底部“服务”
3. 选择**食安监管1年套餐（36一年）**
4. 完成支付

### 如有卡密（购买套餐后无需进行卡密兑换）

1. 点击“卡密兑换”
2. 输入32位卡密
3. 点击“确认绑定”

## 三、创建店铺（如果已经创建过店铺可以跳过此步）

萤石云视频APP → 我的 → 工具 → 应用市场 → 明厨亮灶 → 创建店铺

### 必填信息

- **门店名称**：需与营业执照一致
- **行政区划**：选择店铺所在地区
- **统一社会信用代码**：18位

---

## 四、开通服务

1. 进入明厨亮灶模块
2. 选择已创建的店铺
3. 点击“新增设备”
4. 选择平台：**食安监管**，按实际情况填写相应弹出的信息
5. 选择要开通的设备
6. 点击“开通”

---

## 五、其他常见问题

### 加密设备无法开通

需先解密：我的 → 管理中心 → 设备管理 → 点击设备 → 设置 → 隐私设置 → 视频加密 → 关闭
