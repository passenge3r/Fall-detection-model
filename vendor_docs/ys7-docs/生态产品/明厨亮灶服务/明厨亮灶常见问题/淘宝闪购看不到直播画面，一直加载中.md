## Q：淘宝闪购看不到直播画面，一直加载中

![](https://izhstatic.ys7.com/vasp-openweb/1775718589896_%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE_9-4-2026_15913_www.yuque.com.jpeg)

A：原因是设备编码格式为H265，淘宝闪购平台不支持。

解决方法：将设备编码改为H264

---

方式一（推荐）：萤石工作室电脑端

1.登录萤石工作室

2.点击左下角“设备管理”

3.单击设备视频封面

4.在设备详情页找到“视频设置”

5.修改编码类型为 H264

---

方式二：萤石云视频APP手机端
（部分设备不支持此方式）

1.我的 → 工具 → 局域网设备预览 → 开始扫描

2.点击对应设备，输入设备验证码

3.点击右上角设置图标

4视频设置 → 编码类型 → 切换为 H264
