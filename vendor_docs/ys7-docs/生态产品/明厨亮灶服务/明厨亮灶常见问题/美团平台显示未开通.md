## Q:萤石云app显示已开通，但美团商家版后台显示未开通

A：萤石云app上填写的美团门店id与美团客服给的门店id不一致。

1.把店铺下绑定的美团设备解绑。

操作路径：店铺详情页 → 点击设备 → 取消开通
![](https://izhstatic.ys7.com/vasp-openweb/1775718131855_72e60854-3442-4c20-8846-1b570290ae91.png)

2.将店铺id更改为正确的美团门店id。
操作路径：萤石云视频APP → 我的 → 工具 → 应用市场 → 明厨亮灶 → 创建店铺 → 填写美团门店ID
![](https://izhstatic.ys7.com/vasp-openweb/1776755677477_78185042-203f-4d4f-b44c-523aca93de3e.jpg)

3.去美团商家版后台确认开通情况
