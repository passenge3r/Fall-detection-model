## Q：美团门店ID怎么获取？

A：在美团外卖商家版APP联系客服获取。

获取步骤：

1. 打开美团外卖商家版APP
2. 点击右下角“我的”
3. 联系“客服小袋”
4. 输入指令“门店ID”
5. 系统返回8位门店ID
