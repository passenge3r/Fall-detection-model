## Q：怎么修改填写的美团id？（怎么检查在萤石云填写的门店id）

A：创建店铺时填写。

操作路径：萤石云视频APP → 我的 → 工具 → 应用市场 → 明厨亮灶 → 创建店铺 → 填写美团门店ID

**注：修改美团ID时如果提示“编辑失败，当前门店下仍有开通美
团服务的设备，不能修改美团店铺!D”，先将门店下绑定的美团设备解绑，修改好ID后再重新进行绑定**
