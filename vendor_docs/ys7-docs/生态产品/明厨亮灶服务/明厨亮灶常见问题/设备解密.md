## Q：加密设备无法开通怎么办？（怎么给设备解密？）

A：需要先对设备解密，萤石云视频不支持给加密设备开通明厨亮灶。

解密步骤：

1. 我的 → 管理中心 → 设备管理
2. 点击被加密的设备
3. 点击右上角设置 → 隐私设置 → 视频加密
4. 关闭视频加密
