# 软件服务购买指南

## 购买方式

支持两种购买方式，任选其一即可：

- 线上直接购买
- 卡密兑换

---

## 方式一：线上直接购买

### 操作步骤

1. 进入明厨亮灶模块
2. 点击底部“服务”
3. 选择对应平台套餐：

### 购买说明

- 如需批量购买，可在“我的-联系我们”添加微信咨询优惠
- 一个套餐只能绑定一个设备一个店铺
- 购买套餐之后无需进行卡密兑换，直接使用套餐进行绑定开通

---

## 方式二：卡密充值

### 适用场景

已获得服务商提供的卡密

### 操作步骤

1. 进入明厨亮灶模块-我的
2. 点击“卡密兑换”
3. 输入32位卡密号码或扫描二维码
4. 点击“确认绑定”
5. 页面显示“绑定成功”即完成

### 注意事项

- 卡密为32位
- 如需增加授权，点击“继续绑定”重复流程
