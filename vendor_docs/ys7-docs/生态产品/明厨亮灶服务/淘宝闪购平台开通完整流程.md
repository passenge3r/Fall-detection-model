# 淘宝闪购平台开通完整流程

## 一、设备绑定（如果已绑定过设备可跳过此步）

**操作步骤**

1. 打开萤石云视频APP
2. 点击首页的“+”号
3. 选择以下任一方式添加：

- 扫描二维码：扫描设备机身或说明书上的二维码
- 输入序列号：手动输入设备序列号

## 二、购买服务

### 购买套餐

1. “我的”--工具--应用市场--明厨亮灶模块
2. 点击底部“服务”
3. 选择**淘宝闪购直播1年套餐（52一年）**
4. 完成支付

### 如有卡密(买了套餐不需要进行卡密兑换，直接进行后续操作）

1. 点击“卡密兑换”
2. 输入32位卡密
3. 点击“确认绑定”

---

## 三、创建店铺（如果已经创建过店铺，可以跳过此步）

萤石云视频APP → 我的 → 工具 → 应用市场 → 明厨亮灶 → 门店 → 创建店铺  
![](https://izhstatic.ys7.com/vasp-openweb/1778309222430_19b81d6fe3c66ddb7f49f7dc3e896eba.jpg)

### 必填信息

- **门店名称**：需与营业执照一致
- **行政区划**：选择店铺所在地区
- **统一社会信用代码**：18位

---

## 四、开通服务

1. 进入明厨亮灶模块
2. 选择已创建的店铺
3. 点击“新增直播设备”
4. 选择平台：**淘宝闪购**
5. 选择要开通的设备
6. 点击“开通”

---

## 五、确认开通

1. 登录淘宝闪购商家后台
2. 确认直播内容
3. 提交确认

## 

## 六、常见问题：淘宝闪购无法播放

### 现象

淘宝闪购客户端一直显示加载中，无法播放视频

![](https://izhstatic.ys7.com/vasp-openweb/1775718589896_%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE_9-4-2026_15913_www.yuque.com.jpeg)

### 原因

淘宝闪购平台**不支持H265编码**，设备编码需为H264

### 解决方法

#### 方法一：萤石工作室（电脑端）【推荐】

1. 登录萤石工作室
2. 点击左下角“设备管理”
3. 单击设备视频封面
4. 在设备详情页找到“视频设置”
5. 修改编码类型为 **H264**

#### 方法二：萤石云视频APP（手机端）

**注意：部分设备不支持此方式**

1. 打开萤石云视频APP
2. 我的 → 工具 → 局域网设备预览 → 开始扫描
3. 点击对应设备，输入设备验证码
4. 点击右上角设置图标
5. 视频设置 → 编码类型
6. 切换为 **H264**
