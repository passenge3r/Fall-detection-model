# 京东秒送平台开通完整流程

## 一、设备绑定（如果已绑定过可跳过此步）

**操作步骤**

1. 打开萤石云视频APP
2. 点击首页的“+”号
3. 选择以下任一方式添加：

- 扫描二维码：扫描设备机身或说明书上的二维码
- 输入序列号：手动输入设备序列号

## 二、购买服务

套餐和卡密兑换二选一

### 购买套餐

1. “我的”--工具--应用市场--明厨亮灶模块
2. 点击底部“服务”
3. 选择**京东直播1年套餐（52一年）**
4. 完成支付

### 如有卡密（购买套餐后无需进行卡密兑换）

1. 点击“卡密兑换”
2. 输入32位卡密
3. 点击“确认绑定”

## 三、创建店铺（如果已经创建过店铺可以跳过此步）

萤石云视频APP → 我的 → 工具 → 应用市场 → 明厨亮灶 → 创建店铺

### 必填信息

- **门店名称**：需与营业执照一致
- **行政区划**：选择店铺所在地区
- **统一社会信用代码**：18位

---

## 四、开通服务

1. 进入明厨亮灶模块
2. 选择已创建的店铺
3. 点击“新增设备”
4. 选择平台：**京东**
5. 选择要开通的设备
6. 点击“开通”

---

## 五、常见问题：京东秒送无法播放

### 现象

京东客户端一直加载中，无法播放视频

![](https://izhstatic.ys7.com/vasp-openweb/1777259321000_%E5%BE%AE%E4%BF%A1%E5%9B%BE%E7%89%87_20260427110607_158_43.png)

### 原因

京东秒送平台**不支持H265编码**，设备编码需为H264

### 解决方法

#### 方法一：萤石工作室（电脑端）【推荐】

1. 登录萤石工作室
2. 点击左下角“设备管理”
3. 单击设备视频封面
4. 在设备详情页找到“视频设置”
5. 修改编码类型为 **H264**

#### 方法二：萤石云视频APP（手机端）

**注意：部分设备不支持此方式**

1. 打开萤石云视频APP
2. 我的 → 工具 → 局域网设备预览 → 开始扫描
3. 点击对应设备，输入设备验证码
4. 点击右上角设置图标
5. 视频设置 → 编码类型
6. 切换为 **H264**
