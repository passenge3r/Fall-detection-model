# 明厨亮灶服务介绍与开通条件

## 服务简介

明厨亮灶服务通过萤石云视频APP开通，开通后可对接美团、淘宝闪购的阳光厨房服务，实时展示真实的厨房环境，让消费者买得放心、吃得安心。

## 开通前提条件

**必须满足以下条件才可开通：**

1. **设备所有权要求**：设备必须直接绑定到账号下，不能是他人分享的设备
2. **设备要求**：海康和萤石的设备都可以（4G免流量的设备除外）

## 支持的平台

- 美团外卖（阳光厨房）52一年
- 淘宝闪购（阳光厨房）52一年
- 京东闪送（阳光厨房）52一年
- 抖音即送（阳光厨房）52一年
- 市场监管管理局平台 36一年

## 开通流程概览

1. 绑定设备到萤石云视频APP
2. 创建店铺并填写信息
3. 购买软件服务（支持线上购买或卡密兑换）
4. 开通明厨亮灶服务
5. 登录对应平台确认开通
