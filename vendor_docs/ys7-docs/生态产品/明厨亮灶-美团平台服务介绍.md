# 明厨亮灶-美团平台介绍及服务开通

## 服务介绍

萤石支持美团所有商家线上开通明厨亮灶服务。

开通后，顾客通过美团APP-外卖-进入店铺点餐时，可通过明厨亮灶入口查看开通明厨亮灶服务的设备的画面。旨在向顾客展示商家重要区域（如厨房）的整体情况，如清洁度、环境卫生、厨师操作规范等，增加透明度，吸引客流。

开完成功后，一个设备可以允许顾客通过美团APP的明厨亮灶模块进行观看（最高支持10人同时在线观看），若顾客流量较大，可单独扩容并发。服务时间为1年。目前美团的明厨亮灶设备对外展示时间和商机外卖服务时间保持一致，如店铺接收外卖时间为10:00~次日2:00，那么顾客只可以在上述时间段内观看直播，其他时间无法观看。

根据美团商家类型，共分为2种情形：

## **1、品牌连锁店**

若已在美团申请品牌认证或已加盟某品牌，可联系品牌负责人进行服务开通，需要将门店设备托管至品牌账号下，由品牌方进行开通。
萤石侧的操作，可参考具体的操作手册：<https://www.yuque.com/crbvdo/uuw62i/seh62921akq7rx3f>，也可通过文章下方的官方客服进行咨询。

## **2、非品牌连锁店**

若是夫妻店或未加盟任何品牌的店铺，可通过萤石云视频APP直接线上开通。
操作教程可参考：<https://open.ys7.com/help/4464>
具体可咨询文章下方的官方客户进行了解。
