# 开放平台音视频产品概述：云直播、云广播

# 开放平台 IOT 设备音视频相关能力介绍

萤石开放平台致力于为全球开发者和企业提供安全、稳定、高效的物联网视频能力。平台基于萤石云视频服务，将复杂的视频处理技术封装为简单的 API 接口与 SDK，帮助开发者快速实现 IoT 设备的视频功能集成。

![](https://izhstatic.ys7.com/vasp-openweb/1782464516052_f7212c58-64ca-4544-a607-681ac9d69584.jfif)

其中，开放平台音视频实时分发需求，主要提供了**云直播**与**云广播**能力，重点解决视频流的单向传输与大规模分发问题。

## 1、云直播：实时直播预览、设备录像回放

**定义：** 指视频流从 IoT 设备（如摄像头）单向传输至云端，再由云端分发给终端用户观看的过程。同时，开放平台SDK还集成了设备对讲、操作等功能，支撑不同场景下的IOT硬件使用。

- **实时直播预览（Cloud Real-time Preview）：** 支持通过 API/SDK 获取设备实时视频流，实现低延迟的远程实时监控。其中，萤石云还支持多种协议（除萤石私有协议EZOPEN外，还支持通用的 HLS, FLV, RTMP协议）适配不同终端。
- **设备录像回放（Cloud Video Playback）：** 支持查询设备本地SD卡/本地NVR的录像文件，并提供按时间轴回放、倍速、下载等功能。

**主要特点**：

- **低延迟传输：** 优化传输协议，实现秒级开播，端到端延迟低至亚秒级，确保监控画面的实时性。
- **高并发支持：** 依托云端弹性扩容能力，支持单路视频流同时分发给成千上万个观众，满足大规模围观需求。
- **多终端适配：** 生成的直播链接可无缝嵌入 Web 页面、Android/iOS App、微信小程序等多种终端。

## 2、IOT云广播能力

**定义：** 在此场景下主要指**云端向设备端的单向音频/文字广播**，白话：云端喊话功能，支持单台设备、多台设备。

- **云广播服务（Cloud Broadcasting）：** 支持将语音文件或文本下发给设备，实现定时定点广播的能力

主要特点： - **音频推送：** 支持通过 API 接口向设备（如云台摄像机、智能音箱）推送预设音频文件或 TTS（文本转语音）内容。 - **应用场景：** 远程通知、警示喊话、背景音乐播放。 - **特点：** 无需建立双向对讲通道，实现一对多的设备指令下发。
