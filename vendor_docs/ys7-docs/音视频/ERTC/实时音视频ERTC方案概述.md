# 实时音视频ERTC方案概述

## 产品概述

萤石云实时音视频（Ezviz Real-Time Communication，ERTC），依托于萤石云多年的网络传输技术和音视频编解码技术，为客户提供低成本、超低延时、高可靠的音视频互动服务， 覆盖手机、桌面系统、嵌入式系统平台以及微信小程序、web网页等终端，开发者可快速接入，满足视频会议、互动直播、语音聊天、在线教育等应用场景需求。

产品详细介绍详见：[ERTC产品介绍](https://open.ys7.com/help/230)

## IoT ERTC视频通话能力说明

> 萤石ERTC终端总体分为两类：设备端、客户端（集成萤石提供的SDK）。

**设备端**

- 具备ERTC能力的萤石设备（详见[支持ERTC的设备列表](/help/4922) ）
- 不具备ERTC能力的萤石设备（一般是海康/萤石通用/经销摄像头等）

**客户端**

- 安卓端：集成萤石Android SDK
- IOS端：集成萤石IOS SDK
- Web端：集成萤石Web SDK
- 小程序端：请咨询客服提供SDK

## 快速接入

> 记录步骤2获取到的项目ID（RTC AppId），后续加入音视频房间，以及添加联系人相关场景会用到。

### **场景4：** 设备制造商接入萤石ERTC

我们针对设备开发者开放了 Linux、Android SDK等SDK开放，并允许非海康、萤石设备开发者接入，实现以上功能。

目前合作伙伴已经涵盖：智能家居（冠林、奥格、uiot等开发者），教育（亲禾等开发者）、养老（易联等开发者）等等，咨询小助手获取方案介绍。

设备集成介绍：

- 集成基本能⼒的ezdevSDK，并上萤⽯云，实现双向⾳频，单项视频通话（如海康门禁等设备）
- 集成具备ERTC能⼒的 ezdevSDK【推荐】，实现双向⾳视频（如S10等设备）
