# 产品功能

## 产品功能

ERTC的功能主要包括基础功能、增值功能等

## 音视频通话基础功能

| 功能 | 功能说明 | 应用场景 |
| --- | --- | --- |
| 视频通话 | 音频编码：支持48kHz高清语音，支持opus、aac音频编码音频处理：  支持回升消除、声音增强、声音降噪等基础声音处理能力；  端到端延迟低于400ms  抗网络抖动超过1000ms，  抗丢包率>70% | 1对1视频通话、300人视频会议、在线问诊、视频客服、视频双录、在线理赔、门禁对讲等 |
| 语音通话 | 两人或多人语音通话，支持48KHz采样率 高音质  单个房间最多支持千人入会，最多同时32人开启麦克风 | 1对1语音通话、多人语音通话、语音会议、摄像头对讲等 |
| IOT设备入会 | 邀请萤石云平台的IPC、NVR等带摄像头、麦克风设备加入视频通话 | IoT场景：电视屏幕会议、远程问诊、门禁对讲、智慧教学、网络广播对讲等 |
| 云端混流转码 | 使用 MCU 集群将RTC房间内各路上行音视频流按需进行混流转码，转码后输出的音视频流可旁路推流进行云端录制或实现直播观看 | 三只课堂、智慧法院、景区直播、教学直播、阳光招投标等 |
| 旁路直播 | 将转码输出的流旁路推流至云直播服务，实现直播观看功能 | 教学直播、阳光招投标、智慧法院等 |
| 云端录制 | 使用 MCU 录制集群将 TRTC 房间内各路上行音视频流按需进行单流或合流(混流）录制，并将录制下来的文件存储到开放平台云录制，保证录制过程的可靠性和实时性 | 双录、存档、合规等 |

## 增值功能

| 功能 | 功能说明 | 应用场景 |
| --- | --- | --- |
| 美颜滤镜 | 设置美白、磨皮以及滤镜效果 | 多人音视频通话、面试、互动直播等 |
| AI抠图 | 从视频中分离出人像，并叠加到背景图片或背景色上 | 多人音视频通话、面试 |
| 变声 | 变声特效可以作用于人声之上，通过声学算法对人声进行二次处理，以获得与原始声音所不同的音色 | 智慧法院、景区直播、教学直播、阳光招投标等 |
| 马赛克 | 端对视频进行人脸识别，通过算法对人脸进行模糊化处理，在交流中隐藏人脸信息 | 教学直播、阳光招投标、智慧法院等 |

## 屏幕共享

| 功能 | 功能说明 |
| --- | --- |
| 共享屏幕选择 | 获取可共享的屏幕和窗口列表（windows）  支持应用内及全系统的屏幕共享（iOS\Android） |
| 自适应帧率 | 根据屏幕内容自动调整视频的帧率，降低共享屏幕画面的码率 |
