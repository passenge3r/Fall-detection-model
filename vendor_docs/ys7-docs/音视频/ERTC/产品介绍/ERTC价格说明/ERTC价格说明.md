## 音视频时长费用

### 服务定价

萤石实时音视频ERTC 会按照当月内所有用户产生的音视频通话时长用量进行计费，把项目中当前消耗的音频时长和各个档位的视频时长分别相加，乘以对应的单价，就是当前费用，并第二天产生前一天的费用，再余额中进行体现。

说明：萤石 ERTC 费用 = 音频费用 + 视频 SD 费用 + 视频 HD 费用 + 视频 UHD 费用 + 视频 2K 费用 + 视频 2K+费用，其中每一项费用都是各自时长\*单价，例如音频费用 = 音频消耗时长 × 音频单价。

### 用量统计

对于每个用户，ERTC的计费时长均根据当前用户订阅音视频流的时长进行计算。

- 如果用户在同一时刻既订阅了音频流，也订阅了视频流，只计算视频订阅时长。
- 如果用户在同一时刻订阅了多条音频流，音频流时长不会叠加计算，只会算一路音频流时长。
- 如果用户在同一时刻订阅了多条视频流，视频流时长不会叠加计算，只会算一路视频流时长，计费单价会根据每一条视频流的分辨率之和确定计费档位。

### 计费单价

计费单价根据单个用户订阅的分辨率来计算，最终的费用是将每个用户订阅的所有视频流分辨率进行叠加。

| 媒体档位 | 规格 | 单价 |
| --- | --- | --- |
| 音频 | 标准语音规格 | 6 元/千分钟 |
| 视频 标清SD 单价 | 分辨率 ≤ 640 × 480 | 14 元/千分钟 |
| 视频 高清 HD 单价 | 640 × 480＜分辨率 ≤ 1280 × 720 | 25 元/千分钟 |
| 视频 超高清 UHD单价 | 1280 × 720＜ 分辨率 ≤ 1920 × 1080 | 60 元/千分钟 |
| 视频 2K 单价 | 1920 × 1080＜ 分辨率 ≤ 2560 × 1440 | 100 元/千分钟 |

例如，用户同时订阅三路分辨率为 640 × 480 的视频流，则该用户订阅的视频集合分辨率为 640 × 480 + 640 × 480 + 640 × 480 ，其视频用量按3个 SD 档位进行计费相加。

### 付费方式

采用余额扣费的模式进行计费，第二天会出前一天的账号计费。欠费后请及时充值付费，完成后账户会自动恢复为正常使用状态。

### 计费示例

示例一 多人语音房间

假设用户 A、B、C 三人一起在音视频通话 2.0 房间内持续停留了 1000 分钟。A、B、C 三人只进行音频通话，彼此订阅相互的音频流。

该房间的费用计算如下表所示。

收流方 订阅的用户 订阅分辨率 时长（分钟） 费用（元）
A B 音频 1000 5.9
C 音频 1000
B A 音频 1000 5.9
C 音频 1000
C A 音频 1000 5.9
B 音频 1000
用户同时订阅了多条音频流，只算一路音频流时长。所以用户 A 的 音频订阅时长为 1000 分钟。

则该房间产生的语音时长总费用为：语音时长单价 × 所有用户语音时长之和 = 5.9 元/千分钟 × (1000 分钟 + 1000 分钟 + 1000 分钟) / 1000 = 17.7 元。
