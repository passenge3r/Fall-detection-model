# ERTC：IoT设备买断计费

> 目前萤石主要是对开发者提供按设备授权进行计费，设备授权后，即可免费使用ERTC能力（取流通话能力），我们针对不同行业不同场景提供不同的定价，具体定价请咨询开放平台产品或销售。

## 计费模式介绍

| 计费模式 | 适合场景 | 查看链接 |
| --- | --- | --- |
| 按设备计费 | 与设备有关的ERTC接入计费 | 即本文档 |
| 按时长计费 | 非设备场景，视频会议/教学课堂等场景，也适用多人通话场景 | 按时长计费，详见：[计费说明](https://open.ys7.com/help/2107) |

## License 介绍

按设备license授权买断 是 萤石实时音视频ERTC 服务的一种计费模式。在 IoT 场景中，萤石通过设备 License 对单个设备进行收费，每个设备的 License 是唯一的。在 License 有效期内，不再对通话时长进行收费。

License 使用流程

### 1.License 申请

由于一般的IoT设备基本都是以Linux为主，因为ERTC提供Linux设备SDK，还需要根据设备编译工具链、芯片等进行适配，因此在申请license之前，开发者需要先跟客服申请对应Linux SDK。

如果开发者设备是安卓设备，则可以直接申请license，并用于 安卓设备授权。

### 2.License 激活

咨询客服，获取激活方法。

### 3.限制

目前开放平台提供：2并发、其他并发的计费方法，用户可以根据不同场景进行选择。

2并发：比如可视对讲-中控屏接入ERTC，需要与可视门铃、IPC等进行双方通话，则选择2并发即可，可以支持两个设备同时接入房间进行通话。

备注：

非视频通话能力，比如录制、旁路直播等能力不包括在IoT买断license费用里。详见：[ERTC计费](https://open.ys7.com/help/3802)
