# 应用场景

## IoT with ERTC

萤石ERTC广泛应用于各类物联网平台，与海康/萤石设备实现无缝对接，目前萤石设备已有超过千万用户使用过萤石ERTC相关能力。

![](https://resource.eziot.com/group2/M00/01/09/CtwQF2jaaSGAB2VxAAK3A7b6WIw570.png)

### IoT with ERTC应用场景举例

## 场景1：摄像头音视频对讲通话

智能家居观念逐步普及，智能设备成为日常生活中的看护、沟通的工具和载体；智能设备性能和音视频能力、网络带宽提升，实时音视频互动日益普及；家庭成员之间使用智能设备实现更方便的视频互动，同时云端录制，精彩时光永久保留。

![](https://resource.eziot.com/group2/M00/00/D4/CtwQF2XgVgeAYs50AAIV8ZR2tmM819.png)

ERTC支持IPC、门铃门锁、NVR、儿童手表、门禁等设备无缝对接通话，只要设备接入开放平台，即可与设备实现无缝音视频对讲与通话。

## 场景2：远程医疗

远程问诊已并不鲜见，得益于音视频技术的高速发展，跨时空医疗诊断正运用在更多场合，通过实时音视频能力，医患沟通更加顺畅，诊疗指导更为高效，在家门口药店看病+配药的体验也变成现实。如：

医师辅助购药
咳嗽、腹泻、轻微过敏等常见的问题，可通过云问诊，可以快速让医师指导患者用药，在药柜扫码购药，大大提高了看病效率。

![](https://resource.eziot.com/group2/M00/00/D4/CtwQF2XgVrqAXpsFAAC5-YprAzo294.png)

电子处方+远程问诊

治疗某些疾病所需的特殊药品，如心脑血管疾病药物，须经职业医师诊断后开出处方并在医师指导下使用。“电子处方+远程问诊”，可以在药店与医生视频连线，开具电子处方，药师审方，患者凭借处方单在药柜取药，整个过程都可以在药店内完成。

![](https://resource.eziot.com/group2/M00/00/D4/CtwQFmXgVreAReYiAAA_VSM433A050.png)

## 场景3：连锁门店

利用ERTC与IoT互通的特性，用户只需要集成一个SDK，即可实现与APP端之间的通话，也可实现与设备之间的对讲，一套系统解决，既提升了便捷性，又降低了成本。

![](https://resource.eziot.com/group2/M00/00/D4/CtwQFmXgV-iAcj_EAATkmRTNLvs154.png)

## 场景4：统一安防

4G移动设备互动
![](https://resource.eziot.com/group2/M00/00/D4/CtwQF2XgWOCARYxXAAG75CiVjPA781.png)

与执法记录仪、安全帽、手持pad设备等，ERTC能实现最快速便捷的低成本云通话方案。

应用场景：物业安防执法、园区保安互动、工地施工互动等等，这些场景下，萤石云ERTC的能力大大提升。

同时，萤石还提供了比如工地巡检组件等能力，帮助开发者快速集成。
