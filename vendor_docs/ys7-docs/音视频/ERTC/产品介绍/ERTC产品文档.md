## 产品概述

萤石云实时音视频（Ezviz Real-Time Communication，ERTC），依托于萤石云多年的网络传输技术和音视频编解码技术，为客户提供低成本、超低延时、高可靠的音视频互动服务，
覆盖手机、桌面系统、嵌入式系统平台以及微信小程序、web网页等终端，开发者可快速接入，满足视频会议、互动直播、语音聊天、在线教育等应用场景需求。

萤石ERTC基于海康威视多年物联网技术积累，在IoT音视频上提供多种高质量实时通信能力

- 物联音视频通话方案

  依靠海康威视多年物联网技术积累，提供覆盖IPC/NVR/互动屏等多硬件设备的SDK及云端API，提供Linux设备终端SDK，终端协同还支持微信小程序、web/H5网页等。
