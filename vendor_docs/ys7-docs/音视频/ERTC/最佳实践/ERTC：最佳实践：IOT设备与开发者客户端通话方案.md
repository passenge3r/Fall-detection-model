# 最佳实践：IOT屏类设备与开发者客户端之间的通话方案

> 本文档主要阐述如何将集成ERTC的IoT硬件，实现与App/Web/小程序客户端之间通话的实践

## ⼀. 背景

随着萤石S10等视频通话摄像头发布，如何实现设备端与开发者客户端之间的视频通话，开放平台提供了相关的SDK及相关API接口，帮助开发者快速实现视频通话功能。

本文档主要介绍如何将门禁、门铃、门锁、通话摄像头等设备接入开发者平台客户端的产品开发

（备注：即使设备已经支持ERTC SDK，由于设备本身物模型能力等，也有可能走不通，需要咨询客服具体设备的型号跟能力，比如RK3老版本设备由于本身能力限制，需要固件升级后方能实现toB的视频通话能力）

## 二、当前常见应用场景

①智能家居、康养等：通过S10等视频通话设备、门铃/门锁等呼叫设备，与微信进行视频通话

②教育教学：电子班牌、门禁屏等与微信进行音频、视频通话

③社区：门口机、门禁等设备与微信进行音频、视频通话

④告警设备：告警对讲设备与微信进行告警通知通话等

同时，为了更好的支撑开发者接入ERTC，针对养老、智能家居、社区等场景，萤石提供了license买断的计费模式：

<https://open.ys7.com/help/3803>

开发者可联系商务或开放平台小助手进行产品接入咨询。
