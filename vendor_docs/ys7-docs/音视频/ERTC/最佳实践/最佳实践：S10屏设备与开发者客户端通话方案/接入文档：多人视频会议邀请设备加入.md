# 接入文档：多人视频通话邀请萤石云设备加入

> 文档：该文件是介绍视频通话与萤石云摄像头之间的视频通话能力

# 背景介绍

典型案例1：多人视频通话/多人视频会议，邀请摄像头加入房间

典型案例2：开发者自有设备（如机器人/安卓屏等）与萤石摄像头视频通话

## **接入准备（默认已完成前置条件准备）**

1. 设备码流格式已切至H264编码
2. 关闭设备上的视频加密开关

> 对于不具备ERTC能力的萤石设备，需要通过开放平台接口邀请指定设备加入房间，加入房间所需要的部分参数包括strRoomId（房间号），customId（加入房间的用户唯一标识），需要开发者自己定义。appId在前置条件说明中获取，加入房间 [通话Token](https://open.ys7.com/help/1872)（原：资源token）通过开放平台接口获取

```
设备和客户端加入房间不分前后，要保证加入的是同一个房间（strRoomId），并且是同一个appId下的不同customId
```

## **加入房间流程**

1. 客户确认好此次入会所需appId，strRoomId
2. 生成设备入会所需通话Token
3. 邀请设备加入房间 [点击查看](https://open.ys7.com/help/4297) ，使用步骤2生成的通话Token
4. 生成客户端入会所需[通话Token](https://open.ys7.com/help/1872)
5. 客户端调用ERTC SDK加入房间，使用步骤4生成的[通话Token](https://open.ys7.com/help/1872)，以及定义好自己的customId （和其它入会用户不要重复）

## **离开房间流程**

1. 客户端离开房间：直接通过ERTC SDK 离开房间
2. 设备离开房间：调用开放平台接口 [点击查看](https://open.ys7.com/help/4300)
