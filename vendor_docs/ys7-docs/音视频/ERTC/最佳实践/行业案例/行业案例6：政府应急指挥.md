# 行业背景

省厅级项目，涉及景区、停车场、交通等诸多场景，应急指挥过程中还需要多个协同单位共同参与。

- 需要接入平台的终端包括：景区、停车场、交通枢纽的IPC、协同单位的华为/科达/中型会议终端、移动执法人员的移动客户端以及部分语音电话；
- 平台部署在内网，接入终端既有内网，又有互联网；
- 与融合通信平台集成，萤石易会作为其中一个模块，既要支持传统会议系统融合，又要支持云会议的SFU模式。
