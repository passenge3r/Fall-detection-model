# 行业背景

### 政策背景：

2020年3月5日印发《教育部关于加强“三个课堂”应用的指导意见》，提出到2022年全面实现“三个课堂”在广大中小学校的常态化按需应用。

### 政策痛点

- 农村薄弱学校和教学点缺少师资、开不出开不足开不好国家规定课程的问题；
- 教师教学能力不强、专业发展水平不高，需发挥名师效应，带动普通教师水平提升
- 区域、城乡、校际之间教育质量差距大，学生存在个性化发展和高质量教学的需求
