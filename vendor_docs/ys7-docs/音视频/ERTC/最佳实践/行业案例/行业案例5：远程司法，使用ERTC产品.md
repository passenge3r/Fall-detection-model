# 行业背景

基于萤石实时音视频PaaS层能力，与司法行业ISV的业务平台深度融合，组建完整的远程庭审系统。萤石提供专有云和公有云的部署方案，庭审各端集成了云会议的客户端SDK、小程序SDK、网页端组件，另外增设了RTSP网关和光闸网关，满足监控入会和安全跨网的需求。萤石提供了全覆盖的视频接入能力，让庭审涉及的各个角色都能加入线上庭审。

# 客户案例

XX公司是司法领域大型上市公司，是专业从事法院信息化解决方案研究和软件开发、信息技术服务、网络系统集成高科技产业公司，在全国与多家法院都有业务合作。

原有庭审系统以内网开庭为主，无法满足互联网接入的新需求：

- 为方便当事人，视频交互平台需要与法院小程序融合，当事人无需下载客户端直接参与庭审；
- 法院网络环境封闭，又要互联网接入，安全的跨网方案十分必要；
- 部分法院需要将庭审面向公众直播，需要平台具备互动+直播能力。

萤石提供便捷的接入方式、安全的跨网方案，与ISV的业务平台深度融合，系统效果好；

- 将线上庭审系统与庭审直播系统合二为一，灵活搭配，提高效率；
- 为周边法院的信息化建设树立了标杆，起到项目典范作用。
