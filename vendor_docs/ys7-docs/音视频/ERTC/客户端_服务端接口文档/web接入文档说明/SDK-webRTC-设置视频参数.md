# ERTC Web 设置视频参数

> 本教程基于 ERTC Web SDK 2.x 版本

本章主要介绍如何在视频通话中设置视频属性（包括分辨率、帧率和码率），开发者可以根据具体业务需求调整视频画面的清晰度和流畅度，可以不做设置，浏览器会默认去取设备真实参数。

### 设置参数

通过 `ertc.setProfile()` 来设置发布视频属性。

> 备注 1：属性更新后，需要重新发布视频才会生效,无法动态更新  
> 备注 2：属性设置对屏幕共享流同样生效

```
ertc.setProfile({
  cameraId, // 摄像头deviceId
  microphoneId, // 麦克风deviceId（重新发布音频生效）
  width, // 分辨率 宽
  height, // 分辨率 高
  frameRate, // 最大视频帧率
  bitrate, // 最大视频码率，单位：kbps
  simulcast // 是否开启大小流
})
```
