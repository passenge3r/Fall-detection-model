# ERTC Web 离开房间

> 本教程基于 ERTC Web SDK 2.x 版本

本章主要介绍如何主动退出当前 ERTC 房间，同时还会介绍在什么情况下会被动离开房间：

### 步骤 1：加入房间

可以参考文档 加入房间

### 步骤 2：退出当前房间

调用 ertc.leaveRoom() 方法退出房间，结束音视频通话。

#### 被动离开房间

除了用户主动退出房间之外，用户也有可能因为如下原因被移出房间。

1. 两个相同 userId 的用户进入相同房间，前一个进房的用户会被移出。同名用户同时进入同一房间是不允许的行为，可能会导致双方音视频通话异常，应避免出现这种情况。

ertc.on(ERTC.EVENT.ERROR, (msg) => {
