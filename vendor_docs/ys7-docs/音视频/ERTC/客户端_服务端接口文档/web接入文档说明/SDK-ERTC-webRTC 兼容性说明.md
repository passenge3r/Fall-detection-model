# 简介

​ 实时音视频是依托萤石云多年的网络传输技术和音视频编解码技术，为客户提供低成本、超低延时、高可靠的音视频互动服务，适用于视频会议、互动直播、语音聊天、在线教育等场景。详见：[产品介绍](help/230)

## Q&A

#### Q : Web SDK无法内嵌App内

A: Web SDK不支持内嵌App内。建议使用ERTC 原生iOS、Android程序SDK ：[查看](/help/1874)

#### Q : Web SDK是否支持小程序

A: Web SDK 暂不支持内嵌微信小程序、支付宝小程序。
