## 移出且禁止再加入

- 接口功能

移出且禁止再加入

是否支持托管：否

是否支持子账号：否

- 请求地址

https://open.ys7.com/api/service/rtc/conference/participant/no-entry-allowed

- 请求方式

POST

- 请求参数

| 参数名 | 类型 | 是否必选 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| accessToken | String | Y | 萤石开放API访问令牌 |  |
| appId | String | Y | 应用ID |  |
| roomId | String | Y | 会议ID |  |
| customId | String | Y | 终端ID |  |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/rtc/conference/participant/no-entry-allowed' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'appId=appId' \
--data-urlencode 'roomId=roomId' \
--data-urlencode 'customId=customId'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| -code | String | 业务响应码 |
| -message | String | 响应信息 |
| -moreInfo | Object | 更多信息 |

- 返回码

| 状态码 | 错误码 | 描述 |
| --- | --- | --- |
| 200 | 200 | 操作成功 |
| 404 | 404 | 资源不存在 |
| 500 | 500 | 服务器异常 |
| 400 | 400 | 参数错误 |
