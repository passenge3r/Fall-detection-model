## 将终端移出会议

- 接口功能

   将ERTC终端用户踢出房间，主动将ERTC终端用户从RTC房间踢出。

- 请求地址

`https://open.ys7.com/api/service/rtc/conference/participant/remove`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | roomId | String | 客户自定义房间号 | Y |
| query | customerId | String | 客户自定义终端ID | Y |
| query | appId | String | RTC应用ID | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/rtc/conference/participant/remove?roomId=xxxxx&customerId=xxxxx&appId=xxxxx' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| -code | String | 业务响应码 |
| -message | String | 响应信息 |
| -moreInfo | Object | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | HTTP状态码:200 |
| 404 | 资源不存在 | HTTP状态码:404 |
| 500 | 服务器异常 | HTTP状态码:500 |
| 400 | 参数错误 | HTTP状态码:400 |
