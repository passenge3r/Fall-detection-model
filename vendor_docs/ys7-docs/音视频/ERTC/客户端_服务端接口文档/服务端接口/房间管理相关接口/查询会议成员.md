## 查询会议成员

- 接口功能

   查询会议成员

- 请求地址

`https://open.ys7.com/api/service/rtc/conference/participants`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Query | appId | String | 应用ID | Y |
| Query | roomId | String | 房间ID | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/rtc/conference/participants?appId=your_app_id&roomId=your_room_id' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": "200",
        "message": "操作成功",
        "moreInfo": null
    },
    "data": [
        {
            "nickName": "用户A",
            "clientType": 1,
            "role": 0,
            "avatarUrl": "https://example.com/avatar.png",
            "mute": 0,
            "muteSys": 0,
            "streamMode": 1,
            "streamHead": "xxx",
            "audio": 1,
            "video": 1,
            "shareStream": 2,
            "customId": "user_001"
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | String | 状态码 |
| meta.message | String | 错误信息 |
| meta.moreInfo | Object | 更多信息 |
| data | Array<Object> | 会议成员 |
| data.nickName | String | 别名 |
| data.clientType | Int | 客户端类型：1-IOS、3-Android、111-sdpgw、117-录制 |
| data.role | Int | 用户角色，0:主持人;1:联席主持人;2:普通成员;3:设备;4:旁路 |
| data.avatarUrl | String | 头像地址 |
| data.mute | Int | 静音状态：0关闭，1开启 |
| data.muteSys | Int | 系统收音状态：0关闭，1开启 |
| data.streamMode | Int | 大小流模式：具体值以bavClient为准 |
| data.streamHead | String | 流头：具体值以bavClient为准 |
| data.audio | Int | 音频权限是否开启：1-支持，2-不支持 |
| data.video | Int | 视频权限是否开启：1-支持，2-不支持 |
| data.shareStream | Int | 共享流是否开启：1-支持，2-不支持 |
| data.customId | String | 终端ID，开发者分配 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 404 | 资源不存在 |  |
| 500 | 服务器异常 |  |
| 400 | 参数错误 |  |
