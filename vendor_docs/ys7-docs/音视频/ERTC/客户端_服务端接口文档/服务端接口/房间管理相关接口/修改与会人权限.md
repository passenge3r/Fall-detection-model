## 修改与会人权限

- 接口功能

   功能描述：修改ERTC房间内用户的权限，包括但不限于audio-音频权限、video-视频全系、shareStream-分享流权限。

   是否支持托管：否

   是否支持子账号：否

- 请求地址

`https://open.ys7.com/api/service/rtc/conference/participant/permissions/update`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | roomId | String | 会议房间号 | Y |
| body | customerId | String | 客户自定义终端ID | Y |
| body | appId | String | RTC应用ID | Y |
| body | audioPermission | Boolean | true:打开权限，false：关闭权限 | N |
| body | videoPermission | Boolean | true:打开权限，false：关闭权限 | N |
| body | shareStreamPermission | Boolean | true:打开权限，false：关闭权限 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/rtc/conference/participant/permissions/update' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'roomId=xxxxx' \
--data-urlencode 'customerId=xxxxx' \
--data-urlencode 'appId=xxxxx' \
--data-urlencode 'audioPermission=true' \
--data-urlencode 'videoPermission=true' \
--data-urlencode 'shareStreamPermission=true'
```

- 返回数据

```
{
    "meta": {
        "code": "string",
        "message": "string",
        "moreInfo": {}
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| -code | String | 业务响应码 |
| -message | String | 响应信息 |
| -moreInfo | Object | 更多信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | HTTP状态码:200 |
| 404 | 资源不存在 | HTTP状态码:404 |
| 500 | 服务器异常 | HTTP状态码:500 |
| 400 | 参数错误 | HTTP状态码:400 |
