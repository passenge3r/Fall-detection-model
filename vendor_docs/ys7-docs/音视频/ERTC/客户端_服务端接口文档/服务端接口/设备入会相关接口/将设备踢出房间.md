## 将设备踢出房间

- 接口功能

将设备踢出房间（支持资源Token认证）（已废弃，请使用[4300](https://open.ys7.com/help/4300)接口）

- 请求地址

`https://open.ys7.com/api/v3/ertc/device/kickout`

- 请求方式

`POST`

- 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| accessToken | String | Y | header | 萤石开放API访问令牌 |
| deviceSerial | String | Y | query | 设备序列号 |
| channelNo | Int | Y | query | 通道号 |
| roomId | Int | N | query | roomId未传递时，strRoomId+appId必传 |
| strRoomId | String | N | query | roomId和strRoomId不能同时为空。strRoomId和appId可以确定唯一的房间号，strRoomId不为空时将根据此外部房间号校验用户-房间对应关系。roomId和strRoomId同时存在时优先校验roomId |
| appId | String | N | query | 应用ID |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/ertc/device/kickout?deviceSerial=xxxxxx&channelNo=1&roomId=12345' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
  "meta": {
    "code": 0,
    "message": "string",
    "moreInfo": {}
  }
}
```

- 返回字段

| 字段名称 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元数据 |
| meta.code | Int | 响应code |
| meta.message | String | 响应信息 |
| meta.moreInfo | Object | 额外信息 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
