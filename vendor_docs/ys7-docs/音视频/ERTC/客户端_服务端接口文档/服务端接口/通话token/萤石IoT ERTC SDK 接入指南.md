# 萤石实时音视频ERTC：RTC token与通话Token概念说明

# 安全令牌说明

开发者云服务和开发者终端请求萤石开放平台资源都需要携带安全令牌。安全令牌是保证请求合法性和数据安全性的一种凭证。通过安全令牌，开发者也能确保其在开放平台上的操作合规、安全，并且能够对平台资源进行正常、有效的访问和使用。

原来ERTC有RTC token、RTC 小权限token、RTC 资源token等，目前已经全部废弃，全部都归入**通话Token**，因此使用RTC接入时，请尽快更新通话Token。

| **token类型** | **描述** | **token获取方法**/**获取接口** |
| --- | --- | --- |
| 通话Token（资源token） | 通话Token（资源token）由开发者云颁发给终端使用，终端可以使用此token来访问被授权的资源。 | 方法1：使用开发平台接口获取(**推荐**) [前往查看文档](https://open.ys7.com/help/4938)  方法2：使用本地java sdk （ [前往查看文档](/help/1873) ）签名颁发 |
| 资源 | 执行操作时的房间、被邀请的设备等等。上述访问过程中的目标对象都被抽象理解为资源。 | 主要用于防止终端异常操作，影响到其他未被授权的房间或会议 |

# 备注

①目前若要与设备进行音视频互动，则设备必须：

**设备需要关闭视频加密且视频流编码设置为h264**

萤石支持WebRTC的H.265方案，但是由于目前浏览器客户端支持的不多，部分客户使用后出现大量客诉，因此开发者需要通过后台咨询开通。
