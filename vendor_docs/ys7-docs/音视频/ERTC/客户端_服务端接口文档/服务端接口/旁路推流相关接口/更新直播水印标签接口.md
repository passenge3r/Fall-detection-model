## 更新直播水印标签接口

- 接口功能

   开发者用户对直播水印标签进行修改。是否支持托管：否。是否支持子账号：否

- 请求地址

`https://open.ys7.com/api/service/rtc/live/label/update`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | appId | String | RTC应用ID | Y |
| body | roomId | String | 房间号 | Y |
| body | requestId | String | 直播请求id，调用开始直播接口时返回 | Y |
| body | watermarkConfig | String | 文字水印标签配置，json格式的字符串 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/rtc/live/label/update' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'appId=xxx' \
--data-urlencode 'roomId=xxx' \
--data-urlencode 'requestId=xxx' \
--data-urlencode 'watermarkConfig={"text":"label"}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    },
    "data": {
        "requestId": "5d21f44899a14aebbbc5cabe27e8f653"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| -code | Int | 响应状态码 |
| -message | String | 响应消息 |
| -moreInfo | Object | 更多信息 |
| data | Object | 返回数据 |
| -requestId | String | 请求ID |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 404 | 资源不存在 | 资源不存在 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
