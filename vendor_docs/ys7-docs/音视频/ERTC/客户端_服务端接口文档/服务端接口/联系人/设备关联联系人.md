## 设备关联联系人

- 接口功能

   设备关联联系人，是否支持托管子账号：否

- 请求地址

`https://open.ys7.com/api/service/rtc/call/device/contact`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| body | appId | String | RTC项目ID | Y |
| body | account | String | 联系人账号 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/rtc/call/device/contact' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: BF2305302' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'appId=f66f0d7fe4e74a39b15f146eec34d03d' \
--data-urlencode 'account=13136116732'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": {}
    },
    "data": null
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 返回数据，无数据时为null |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 404 | 资源不存在 | 资源不存在 |
| 500 | 服务器异常 | 服务器内部错误 |
| 400 | 参数错误 | 请求参数不合法 |
| 412 | 前置条件不满足 | 前置条件不满足 |
