## 查询联系人列表

- 接口功能

  查询联系人列表，是否支持托管子账号：否
- 请求地址

  `https://open.ys7.com/api/service/rtc/call/contact/list`
- 请求方式

  `GET`
- 请求参数

  | 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
  | --- | --- | --- | --- | --- |
  | Header | accessToken | String | 萤石开放API访问令牌 | Y |
  | Query | account | String | 联系人账号 | N |
  | Query | appId | String | RTC项目ID | Y |
  | Query | pageStart | Int | 分页偏移，默认0 | N |
  | Query | pageSize | Int | 分页大小，默认10 | N |
- 请求示例

  ```
  curl --location --request GET 'https://open.ys7.com/api/service/rtc/call/contact/list?account=13136116732&appId=f66f0d7fe4e74a39b15f146eec34d03d&pageStart=0&pageSize=10' \\
  --header 'accessToken: at.xxxxx'
  ```
- 返回数据

  ```
  {"meta":{"code":200,"message":"操作成功","moreInfo":{}},"data":{"pageSize":2,"start":0,"totalCount":5,"result":[{"account":"13136116732","name":"appSDK-test111","avatarUrl":""},{"account":"oODN35IMsx69vtAJVLdz5LsJLnRs","name":"微信小程序测试-test","avatarUrl":""}],"totalPageCount":3,"currentPageNo":1}}
  ```
- 返回字段

  | 字段名 | 类型 | 描述 |
  | --- | --- | --- |
  | meta | Object | 响应元信息 |
  | meta.code | Int | 响应码 |
  | meta.message | String | 响应消息 |
  | meta.moreInfo | Object | 更多信息 |
  | data | Object | 返回数据 |
  | data.pageSize | Int | 每页大小 |
  | data.start | Int | 偏移量 |
  | data.totalCount | Int | 总数 |
  | data.result | Array | 结果列表 |
  | data.result[].account | String | 联系人账号 |
  | data.result[].name | String | 联系人名称 |
  | data.result[].avatarUrl | String | 头像地址 |
  | data.totalPageCount | Int | 总页数 |
  | data.currentPageNo | Int | 当前页码 |
- 返回码

  | 返回码 | 返回消息 | 描述 |
  | --- | --- | --- |
  | 200 | 操作成功 | 操作成功 |
  | 500 | 服务器异常 | 服务器异常 |
  | 400 | 参数错误 | 参数错误 |
