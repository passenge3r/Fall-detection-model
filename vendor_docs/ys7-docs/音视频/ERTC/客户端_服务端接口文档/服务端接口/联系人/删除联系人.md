## 删除联系人

- 接口功能

  删除联系人，是否支持托管子账号：否
- 请求地址

  `https://open.ys7.com/api/service/rtc/call/contact`
- 请求方式

  `DELETE`
- 请求参数

  | 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
  | --- | --- | --- | --- | --- |
  | Header | accessToken | String | 萤石开放API访问令牌 | Y |
  | Query | appId | String | RTC项目ID | Y |
  | Query | account | String | 联系人账号 | Y |
- 请求示例

  ```
  curl --location --request DELETE 'https://open.ys7.com/api/service/rtc/call/contact?appId=f66f0d7fe4e74a39b15f146eec34d03d&account=13136116732' \\
  --header 'accessToken: at.xxxxx'
  ```
- 返回数据

  ```
  {"meta":{"code":200,"message":"操作成功","moreInfo":{}},"data":null}
  ```
- 返回字段

  | 字段名 | 类型 | 描述 |
  | --- | --- | --- |
  | meta | Object | 响应元信息 |
  | meta.code | Int | 响应码 |
  | meta.message | String | 响应消息 |
  | meta.moreInfo | Object | 更多信息 |
  | data | Object | 返回数据，无数据时为null |
- 返回码

  | 返回码 | 返回消息 | 描述 |
  | --- | --- | --- |
  | 200 | 操作成功 | 操作成功 |
  | 404 | 资源不存在 | 资源不存在 |
  | 500 | 服务器异常 | 服务器异常 |
  | 400 | 参数错误 | 参数错误 |
