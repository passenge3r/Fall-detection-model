## 开始音视频实时录制V2

- 接口功能

   开始音视频实时录制V2

   不支持托管子账号

- 请求地址

`https://open.ys7.com/api/v3/open/cloud/video/v2/start/real/rec`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | Content-Type | String | application/x-www-form-urlencoded | Y |
| body | appId | String | 实时音视频项目ID | Y |
| body | roomId | String | 房间号 | Y |
| body | projectId | String | 项目ID | Y |
| body | fileId | String | 文件ID | Y |
| body | mode | Int | 云录制录制模式 | Y |
| body | recordConfig | String | 录制配置信息 | Y |
| body | watermarkConfig | String | 文字水印标签配置，json格式的字符串 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/open/cloud/video/v2/start/real/rec' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'appId=xxxxx' \
--data-urlencode 'roomId=xxxxx' \
--data-urlencode 'projectId=xxxxx' \
--data-urlencode 'fileId=xxxxx' \
--data-urlencode 'mode=1' \
--data-urlencode 'recordConfig=xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "requestId": "xxxx"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| -code | String | 响应码 |
| -msg | String | 响应信息 |
| data | Object | 响应体 |
| -requestId | String | 请求唯一标识 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | HTTP状态码:200 |
| 400 | 参数错误 | HTTP状态码:200 |
| 500 | 操作失败 | HTTP状态码:200 |
| 403 | 无限权 | HTTP状态码:200 |
