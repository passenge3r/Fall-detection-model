# 云端录制ERTC布局说明

> 在视频通话过程中，开启云录制，可将视频画面和声音录制成视频文件，保存在云端。

## RecordConfig参数配置

| 名称 | 类型 | 必填 | 描述 | 示例值及参考API |
| --- | --- | --- | --- | --- |
| mediaConfig | Object | Y | 取流配置 |  |
| - videoStreamType | int | Y | 用户画面视频流类型, 0:大流; 1:小流 |  |
| - audioStreamType | int | Y | 音频编码类型，1表示AAC/16000/mono, 2表示OPUS/48000/mono |  |
| - subUserId | Array | N | 目标录制用户的列表，Array类型。可选。为空时表示录制全部用户。成员为 user\_id(String类型) |  |
| - subScreenStream | boolean | Y | 是否订阅屏幕共享流(如果有)，如果开启订阅，此时用户选择合适的混屏布局，来保证屏幕内容效果 |  |
| - max\_idle\_time | int | N | 媒体流空闲（指无其他用户在房间中）最大时长，单位s。超过此时间，则录制会话自动结束。如果不配置则从配置服务确定该时长 |  |
| outputConfig | Object | Y | 录制输出配置 |  |
| - fileType | Array | Y | 当前只支持["mp4"] |  |
| - sliceDuration | int | N | 录制切片的最大时长，单位min, 如果未指定，则采用默认的全局时长配置。 |  |
| mixConfig | Object | N | 合流转码配置，仅当合流转码录制(mode为1)时有效 |  |
| - video | Object | N | 视频规格定义 |  |
| - - width | int | Y | 混流输出视频尺寸，宽度，像素 |  |
| - - height | int | Y | 混流输出视频尺寸，高度，像素 |  |
| - - fps | int | N | 混流视频录制帧率。默认为 15 |  |
| - - bitRate | int | N | 视频码率，kbps。默认为 1000 |  |
| - - mix\_mode | int | Y | 子画面混叠模式，0：表示使用外部指定的布局坐标，此时坐标由 layout 属性指定；其他表示使用预定义的布局模板 |  |
| - layout | Array | N | 子画面布局定义，仅当 mix\_mode 为0时有效 |  |

## 子画面混叠布局（Layout）说明

当RecordConfig中的mixConfig.video.mixMode=0时，支持通过设置各个子画面的位置、宽度、高度实现多个子画面的混叠布局。画面左上角为坐标零点(0,0)，单位为像素。

```
"layout": [ // 定义多个子画面布局
    {
        "uid": "1000000020001",         // 子画面user_id, String类型。必选
        "position": [36, 80, 320, 320]  // 子画面布局坐标, Array类型。取值为 [x,y,w,h]。(x,y)是子画面左上角坐标，w是子画面宽度，h是子画面高度。
    },
    {
        "uid": "1000000020002",
        "position": [284, 80, 320, 320]
    }
]
```
