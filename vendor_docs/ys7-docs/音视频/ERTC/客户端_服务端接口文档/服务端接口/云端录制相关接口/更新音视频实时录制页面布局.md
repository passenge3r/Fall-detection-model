## 更新音视频实时录制页面布局

- 接口功能

   功能描述：开始音视频实时录制。

   是否支持托管：否

   是否支持子帐号：否

- 请求地址

`https://open.ys7.com/api/service/rtc/record/update`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | appId | String | 开放平台应用ID | Y |
| body | roomId | String | 房间ID | Y |
| body | requestId | String | 开始云录制请求中返回的requestId | Y |
| body | recordConfig | String | 录制画面配置 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/rtc/record/update' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'appId=xxxxx' \
--data-urlencode 'roomId=xxxxx' \
--data-urlencode 'requestId=xxxxx' \
--data-urlencode 'recordConfig=xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": "string",
        "msg": "string"
    },
    "data": {
        "requestId": "string"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| -code | String | 响应码 |
| -msg | String | 响应信息 |
| data | Object | 响应体 |
| -requestId | String | 请求唯一标识 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | HTTP状态码:200 |
| 404 | 资源不存在 | HTTP状态码:404 |
| 500 | 服务器异常 | HTTP状态码:500 |
| 400 | 参数错误 | HTTP状态码:400 |
| 429 | 请求过于频繁 | HTTP状态码:429 |
