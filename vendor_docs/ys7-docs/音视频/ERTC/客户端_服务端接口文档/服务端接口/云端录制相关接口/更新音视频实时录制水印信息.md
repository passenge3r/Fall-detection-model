## 更新音视频实时录制水印信息

- 接口功能

   更新音视频实时录制水印信息。是否支持托管：否。是否支持子账号：否

- 请求地址

`https://open.ys7.com/api/service/rtc/record/water/mark/update`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | roomId | String | 房间ID | Y |
| body | requestId | String | 开始云录制请求中返回的requestId | Y |
| body | watermarkConfig | String | 录制水印配置 | Y |
| body | appId | String | 开放平台应用ID | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/rtc/record/water/mark/update' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'roomId=xxx' \
--data-urlencode 'requestId=xxx' \
--data-urlencode 'watermarkConfig={"text":"watermark"}' \
--data-urlencode 'appId=xxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "requestId": "XXX"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| -code | Int | 响应状态码 |
| -message | String | 响应消息 |
| -moreInfo | Object | 更多信息 |
| data | Object | 返回数据 |
| -requestId | String | 请求ID |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 404 | 资源不存在 | 资源不存在 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 429 | 请求过于频繁 | 请求过于频繁 |
