## 停止音视频实时录制V2

- 接口功能

   停止音视频实时录制V2

- 请求地址

`https://open.ys7.com/api/v3/open/cloud/video/v2/stop/real/rec`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | customId | String | 开发者自定义用户ID | Y |
| query | roomId | String | 房间号 | Y |
| query | recUsers | String | 需要录制的房间参与者id，以英文逗号分隔 | Y |
| query | projectId | String | 云存储项目ID | Y |
| query | fileId | String | 云存储文件名 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/v3/open/cloud/video/v2/stop/real/rec?customId=xxxxx&roomId=xxxxx&recUsers=xxxxx&projectId=xxxxx&fileId=xxxxx' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": "string",
        "msg": "string"
    },
    "data": {
        "requestId": "string"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| -code | String | 响应码 |
| -msg | String | 响应信息 |
| data | Object | 响应体 |
| -requestId | String | 请求唯一标识 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | HTTP状态码:200 |
| 400 | 参数错误 | HTTP状态码:200 |
| 500 | 操作失败 | HTTP状态码:200 |
| 403 | 无限权 | HTTP状态码:200 |
