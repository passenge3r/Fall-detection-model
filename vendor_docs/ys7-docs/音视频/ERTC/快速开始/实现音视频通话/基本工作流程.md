# 基本工作流程

## 基本流程

![](https://resource.eziot.com/group2/M00/00/CD/CtwQFmWWEQmAGKd6AAKA5lTtfLs588.png)

1. 客户端加入同一房间
2. 客户端加入房间后，可以有不同的行为
   - 用户可以接收房间内的音视频流
   - 用户都可以发布不同的媒体流：摄像头，麦克风，桌面共享

## 房间和用户管理

- 开发者通过roomId来管理房间，使用相同roomId的入会请求将进入同一个房间。开发者需要在自己的服务端为每一个房间分配一个唯一的roomId。
- 开发者通过userId来管理入会客户端,这个userId用于区分每一个入会的人员。开发者需要在服务端为每一个入会用户分配一个唯一的userId。
