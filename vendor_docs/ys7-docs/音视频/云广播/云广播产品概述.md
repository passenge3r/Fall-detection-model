# 云广播产品介绍

> 萤石云广播为您提供个性化的云端语音播报服务，支持自定义语音内容下发至设备进行实时广播或设为提示音，助力企业与机构在智慧社区、智慧工地、智慧商贸等多场景中实现智能化、标准化、自动化的语音交互体验。

## 一、核心功能介绍

### 1. 批量设备广播：一键覆盖，全域联动

通过萤石云平台，用户可轻松选择一个或多个设备（如IPC、NVR、智能广播终端等），实现跨区域、跨场景的同步语音播报。无论是商场促销、社区通知，还是工地安全提醒，均可"一键触达"，大幅提升信息传达效率，减少人工干预，实现真正意义上的"智能广域覆盖"。

### 2. 自定义语音库：打造专属语音场景

支持上传、录制、编辑个性化语音文件，灵活搭建专属语音列表，例如：

- **工地语音**：安全帽佩戴提醒、高空作业警告、施工区域警示
- **电梯语音**：乘梯安全提示、超载报警、故障安抚语
- **宣传语音**：节日促销、活动通知、品牌宣传语
- **应急语音**：消防疏散、人员聚集预警、突发情况安抚  
  语音列表可无限扩容，支持分类管理、快速检索，满足不同场景下的多样化播报需求。

### 3. 设备兼容性强：全面支持萤石生态设备

本产品深度适配海康萤石全系设备，包括IPC（网络摄像机）、NVR（网络录像机）等接入萤石云的设备。一键操作即可快速下发现有监控设备，实现"音视频"协同联动。

---

## 二、2026年全新升级功能 —— 文字转语音（TTS）

为提升语音内容制作效率，萤石云广播上线「文字转语音」功能：

![](https://izhstatic.ys7.com/vasp-openweb/1772692440786_%E5%9B%BE1.png)

- 支持输入250字以内文本，自动生成自然流畅的语音文件
- 支持多语种、多音色选择（标准女声、方言声音、机器人等）
- 生成语音可立即下发至指定设备进行广播，或保存至语音列表供后续使用
- 适用于临时通知、即兴播报、节日祝福、政策宣导等突发场景  
  该功能极大降低语音内容制作门槛，无需专业音频录制，让"文字秒变广播"，真正实现"想说就说，想播就播"。

## 三、产品核心优势

- **批量广播，高效触达**  
  无需逐台设备操作，支持跨设备、跨区域同步播报，适用于连锁门店、大型社区、工业园区等广域场景。
- **语音定制，灵活适配**  
  支持本地语音上传、实时录制、TTS生成，构建专属语音库，满足多场景个性化需求。
- **标准化播报，服务统一**  
  沉淀行业标准话术模板（如电梯故障安抚语、工地安全提醒），避免人员差异导致的服务质量波动。
- **API开放，无缝集成**  
  提供标准RESTful API接口，无需复杂对讲库即可嵌入企业自有系统（如OA、ERP），实现自动化语音调度。
- **即发即播，灵活应急**  
  支持移动端或控制台"按住说话"即时下发语音，适用于突发事件，语音不保存，安全可控。

## 四、典型应用场景

### 1. 智慧商贸连锁

- **自助娱乐场所（台球/KTV/网吧）**：自动播报"请勿喧哗""设备使用须知"等
- **门店促销**：定时播放促销语音，吸引顾客注意，提升转化率
- **异常行为提醒**：如长时间逗留、设备故障等，自动触发语音提示

### 2. 智慧社区

- 与监控、门禁、消防系统联动，实现"视频发现异常 → 自动语音提醒 → 通知物业"闭环管理
- **节假日广播**：春节祝福、垃圾分类提醒、防诈骗宣传等
- **应急指挥**：如火灾、漏水、电梯困人等场景，自动播放安抚语音，同时通知救援人员

### 3. 智慧工地

- 结合AI视频分析能力，实现“行为识别 + 语音播报”智能联动：

  未佩戴安全帽 → 自动语音提醒“请佩戴安全帽”

  人员密集区域 → 播报“请保持安全距离”

  异常跌倒/受伤 → 触发“紧急救援广播”并通知管理人员
- 极大提升工地安全管理效率，降低人为疏忽风险，保障施工安全
