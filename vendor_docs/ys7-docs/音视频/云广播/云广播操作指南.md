# 云广播操作指南

## 1. 开通服务

- 云广播为付费服务，需先购买资源包后方可使用
- 资源包费用将从开发者账户余额中扣除，有效期为12个月
  ![](https://izhstatic.ys7.com/vasp-openweb/1772784164498_%E5%9B%BE%E7%89%872.png)
  ![](https://izhstatic.ys7.com/vasp-openweb/1772784193487_%E5%9B%BE%E7%89%873.png)

## 2. 创建语音

- **支持两种方式**：
  - 上传语音文件：时长不超过60秒，文件大小不超过5MB
  - 文字合成语音：输入文本后，可选择多种音色进行合成
    ![](https://izhstatic.ys7.com/vasp-openweb/1772785496601_%E5%9B%BE%E7%89%874.png)
    ![](https://izhstatic.ys7.com/vasp-openweb/1772785621345_%E5%9B%BE%E7%89%875.png)

## 3. 创建云广播任务

- **填写设备信息**：
  - 格式为 设备序列号:通道号，例如：D8362839:2（摄像头通道号通常填1）
  - 多个设备用英文逗号分隔，如：D8362839:1, D8362840:2
- **注意事项**：
  - 单次任务最多支持50个设备批量发送
  - 设备需支持AAC音频编码，否则语音广播可能失败
  - 定时任务如需撤销，请在发送时间前操作
  - 资源包余量≤0时，任务将发送失败
    ![](https://izhstatic.ys7.com/vasp-openweb/1772785748097_%E5%9B%BE%E7%89%876.png)
