## 语音文件下发接口

- 接口功能

   语音文件下发，指定设备播放，需要设备支持能力集 support\_talk=1或3。

- 请求地址

`https://open.ys7.com/api/lapp/voice/send`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Body | accessToken | String | 访问令牌 | Y |
| Body | deviceSerial | String | 设备序列号 | Y |
| Body | channelNo | Int | 通道号，默认通道号为1 | N |
| Body | fileUrl | String | 下载音频文件的url（上传接口返回的url） | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/voice/send' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'deviceSerial=G12262381' \
--data-urlencode 'channelNo=1' \
--data-urlencode 'fileUrl=http://xxx.xxx.com/xxx.mp3'
```

- 返回数据

```
{
    "msg": "操作成功!",
    "code": "200"
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 返回码，200表示成功 |
| msg | String | 返回信息 |
