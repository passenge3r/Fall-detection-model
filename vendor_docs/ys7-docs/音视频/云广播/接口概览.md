# 接口列表

本节包含设备自定义语音与自定义提示音相关接口等。语音接口需前往云广播控制台购买资源包进行使用：https://open.ys7.com/console/cloudBroadcast.html

接口列表如下：

| 序号 | 接口功能 | 描述 |
| --- | --- | --- |
| 1 | [语音文件上传接口](#device_voice-api1) | 上传本地语音文件 |
| 2 | [语音文件查询接口](#device_voice-api2) | 查询上传的语音文件 |
| 3 | [删除已保存的语音文件接口](#device_voice-api3) | 删除语音文件 |
| 4 | [语音文件下发接口](#device_voice-api4) | 语音文件下发，指定设备播放 |
| 5 | [临时语音下发接口](#device_voice-api5) | 一次性自定义语音下发到设备，不保存到语音列表 |

- 错误码

| 返回值 | 返回信息 |
| --- | --- |
| 111001 | 语音文件格式错误 |
| 111002 | 语音文件时长不合法 |
| 111003 | 语音文件上传失败 |
| 111004 | 语音文件转换失败 |
| 111005 | 语音文件时长获取 |
| 111006 | 语音文件列表获取失败 |
| 111007 | 下发的语音文件URL不存在 |
| 111008 | 参数错误，语音文件不能为空 |
| 111009 | 参数错误，语音文件URL不能为空 |
| 111010 | 参数错误，设备序列号不能为空 |
| 111011 | 参数错误，通道号不能为空 |

其它错误码见[错误码](/help/78)
