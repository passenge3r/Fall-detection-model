## 语音文件上传接口

- 接口功能

   上传本地语音文件。

- 请求地址

`https://open.ys7.com/api/lapp/voice/upload`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Body | accessToken | String | 访问令牌 | Y |
| Body | voiceFile | MultipartFile | 语音文件，支持wav、mp3、aac格式，最大5M，最长60s | Y |
| Body | voiceName | String | 语音名称，最长50个字符 | N |
| Body | force | Boolean | 如果已存在相同voiceName的语音文件，则替换原语音文件，true表示强制替换，false表示如果存在不替换，默认为false | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/voice/upload' \
--form 'accessToken=at.xxxxx' \
--form 'voiceFile=@/path/to/voice.mp3' \
--form 'voiceName=test' \
--form 'force=false'
```

- 返回数据

```
{
    "msg": "Operation succeeded",
    "code": "200",
    "data": [
        {
            "name": "babble.wav",
            "url": "http://oss-cn-shenzhen.aliyuncs.com/voice/bbe5cc634be34a7484947d63f6361c22.aac?Expires=1583059824&OSSAccessKeyId=xxxxx&Signature=xxxxx"
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 操作码，200表示操作成功 |
| msg | String | 操作信息 |
| data | Array<Object> | 语音文件信息 |
| data[].name | String | 语音名称 |
| data[].url | String | 语音文件下载地址，有效期1天 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 无效参数 | 参数为空或格式不正确 |
| 10002 | accessToken过期或异常 | 重新获取accessToken |
| 111001 | 语音文件格式错误 |  |
| 111003 | 文件上传失败 |  |
| 111004 | 语音文件转换失败 |  |
