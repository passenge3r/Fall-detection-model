## 语音文件查询接口

- 接口功能

   查询上传的语音文件。

- 请求地址

`https://open.ys7.com/api/lapp/voice/query`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Body | accessToken | String | 访问令牌 | Y |
| Body | voiceName | String | 模糊匹配语音名称 | N |
| Body | isDefault | Boolean | 是否查询默认语音文件 | N |
| Body | queryAllStatus | Boolean | 是否查询全部状态 | N |
| Body | pageStart | Int | 分页起始页，从0开始 | N |
| Body | pageSize | Int | 分页大小，默认为10，最大为50 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/voice/query' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'voiceName=' \
--data-urlencode 'isDefault=false' \
--data-urlencode 'queryAllStatus=false' \
--data-urlencode 'pageStart=0' \
--data-urlencode 'pageSize=10'
```

- 返回数据

```
{
    "msg": "Operation succeeded",
    "code": "200",
    "data": [
        {
            "voiceName": "babble.wav",
            "fileUrl": "http://oss-cn-shenzhen.aliyuncs.com/voice/bbe5cc634be34a7484947d63f6361c22.aac?Expires=1583059824&OSSAccessKeyId=xxxxx&Signature=xxxxx",
            "duration": 60
        }
    ],
    "page": {
        "total": 1,
        "size": 10,
        "page": 0
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | String | 操作码，200表示操作成功 |
| msg | String | 操作信息 |
| data | Array<Object> | 语音文件信息 |
| data[].voiceName | String | 语音名称 |
| data[].fileUrl | String | 语音文件下载地址，有效期1天 |
| data[].duration | Int | 语音文件时长，单位秒 |
| page.total | Int | 总条数 |
| page.size | Int | 分页大小 |
| page.page | Int | 当前分页号 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10002 | accessToken过期或异常 | 重新获取accessToken |
| 10031 | 子账号或开发者用户无权限 |  |
