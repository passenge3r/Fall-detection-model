# 云直播产品概述

# 什么是萤石云直播

萤石云开放平台云直播主要是针对接入萤石云平台的设备提供视频监控取流、直播服务，提供低延时、高清晰度、高流畅、便捷接入的音视频取流服务。

**不止于直播**

萤石开放平台云直播将海康/萤石等设备上的各类直播相关能力开放出来，包括云台、对讲等等。

# 产品架构

萤石开放平台音视频产品，主要是针对接入萤石云的音视频IoT，比如摄像机、录像机、门铃门锁、门禁、网络音柱等音视频设备，萤石提供了与媒体取流相关的完整解决方案及服务，可以支撑多场景、多功能的视频监控直播及互动服务。

![](https://resource.eziot.com/group1/M00/01/8E/CtwQE2hJY2eANLLWAAM9PDz9j0k984.png)

## 物联网直播

支持海量的海康/萤石/国标设备进行取流直播与回放，及衍生的录制、截图等能力，支持多直播协议，比如萤石私有EZOPEN协议，标准直播流：hls、RTMP、HTTP-FLV，低延时萤石ERTC协议等视频码流，详见：[查看协议介绍](https://open.ys7.com/help/2821)

同时，为了开发者更方便快捷的集成，萤石提供了PC、移动端、web、H5、小程序等各种客户端SDK，帮助开发者快速入手，详见：[查看SDK集成说明](https://open.ys7.com/help/2821)

## 设备互动

除了提供基础的音视频直播能力外，开放平台通过API接口及SDK，还额外提供了音视频设备的云台、物理/电子放大、变焦、对讲等能力。

## 音视频+AI

随着互联网AI+时代的进入，开放平台音视频在集成端+云的音视频AI能力，帮助开发者快速接入音视频AI能力

# 功能说明

设备接入：可[通过萤石协议接入](https://open.ys7.com/help/2837)；也可以[通过国标接入](https://open.ys7.com/help/389)

设备接入后，萤石提供各类应用SDK及各类接口，提供实现视频直播、回放、对讲等能力的集成方案。

![](https://resource.eziot.com/group2/M00/00/E2/CtwQFmZxd6WAYbb1AAC8Wm1OyUM898.png)

与传统的视频直播供应商不同，萤石开放平台云直播在设备接入、视频取流能力、设备能力等提供详细而便捷接入的服务，具体如下

## 1.视频预览

![](https://resource.eziot.com/group2/M00/01/04/CtwQF2hJZiKAF6qeAA3rSecQRyU526.png)

视频预览：提供IoT设备的云端预览取流、多清晰度切换、加密播放等能力，提供实时预览能力

## 2.视频回放

![](https://resource.eziot.com/group2/M00/01/04/CtwQF2hJZieAZrzzAAmjeiHbHlE217.png)

视频回放：播放摄像机SD卡、录像机硬盘里的历史录像，同时也支持云端录像回放，同时录像回放能力也支持了 时间选择、多倍速选择、云存储回放、水印等能力

## 3.直播操作

![](https://resource.eziot.com/group2/M00/01/04/CtwQFmhJZiWAU9afAAmpqH5DBo4773.png)

直播操作：对预览回放中的视频进行额外操作的能力，比如加水印、多屏操作、电子放大、镜像翻转、视频水印、全屏播放等等，详细的可以参考SDK文档中心

## 4.设备控制

![](https://resource.eziot.com/group2/M00/01/04/CtwQF2hJZiuAexw2AAkhAYKSmwU149.png)

设备控制：通过海康/萤石/国标设备上报的能力集，进行IoT设备的控制

## 5.各类协议说明

![](https://resource.eziot.com/group2/M00/01/04/CtwQFmhJZimAWpaUAAHaLwhvFc4778.png)

协议说明：萤石目前核心支持 萤石协议EZOPEN，支持标准流RTMP、HTTP-FLV、HLS等协议，也支持ERTC（萤石基于WEBRTC开发）等协议。

各类协议：目前萤石提供以上协议的直播，开发者可以根据场景、业务进行选择。详细差异，可以查看：[查看协议介绍](https://open.ys7.com/help/2821)

# 场景选择

根据不同场景，利用萤石开放平台提供的不同产品，即可开发出不同的泛直播产品：

| **功能项** | **使用场景** |
| --- | --- |
| 视频监控 | 基于萤石开放平台提供的各类SDK，开发监控产品， 如：园区监控、店铺监控、明厨亮灶监控、工地监控等 |
| 视频直播 | 基于开放平台提供的直播服务，开发泛安防直播 比如景区直播、教学活动直播、企业直播等 |
