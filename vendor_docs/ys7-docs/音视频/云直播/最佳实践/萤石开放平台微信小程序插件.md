# 萤石开放平台微信小程序插件接入说明

> 小程序插件：是集成微信live-player组件，帮开发者快速集成预览、回放、对讲、云台操作等能力

## 小程序开发说明

小程序插件是对一组 js（JavaScript）接口、自定义组件或页面的封装，用于嵌入到小程序中使用。插件不能独立运行，必须嵌入在其他小程序中才能被用户使用。通俗来讲，小程序插件类似于把插件嵌入到开发者的网页中供调用，相对半屏小程序具有页面尺寸可自定义、集成更灵活等特点。

![](https://resource.eziot.com/group2/M00/01/04/CtwQFmhBcTOAMyjOAACsQnD7mLI440.png)

萤石开放平台已发布小程序、半屏小程序开发方案，为进一步满足不同行业客户的视频应用需求，已正式上线小程序插件。开发者可根据实际项目情况，选择最适合的开发方案。下图为四种开发形式的优缺点对比。

## 萤石开放平台小程序插件

无资质要求：用户使用微信小程序无需申请live\_player组件资质即可进行视频直播。

集成速度快：集成简单的代码即可实现指定设备的播放和控制。

交互体验佳：通过插件的形式插入宿主小程序内，可自定义尺寸，无萤石logo显示。

功能配置丰富：支持对设备进行对讲、云台、截屏等操作。
