# 萤石云开放平台：鸿蒙生态下的智能监控解决方案

随着华为HarmonyOS NEXT的正式发布，我们迎来了一个全新的操作系统时代。HarmonyOS NEXT以其自主研发的微内核架构，彻底摆脱了对Linux内核和AOSP代码的依赖，为用户带来了更轻量、高效和安全的系统体验。萤石云开放平台紧跟技术前沿，现已全面适配鸿蒙SDK，为开发者和用户提供了强大的直播及设备管理功能。

## 萤石云平台与HarmonyOS NEXT的完美结合

萤石云平台的鸿蒙SDK适配，不仅意味着账号对接、摄像头管理、直播预览等功能的无缝集成，更是在设备对讲、设置、控制接口等方面的深度优化，为用户提供了高效、稳定的远程音视频交互体验。

## 萤石云平台的核心功能

- **账号对接（SDK接口登录）：** 授权到萤石云平台，复用萤石云平台能力。
- **摄像头列表：** 得到对应账号下设备。
- **直播预览：** 直播预览，可设置直播分辨率。
- **查看回放：** 支持SD卡、硬盘录像机、云存储等多种回放方式。
- **设备对讲：** 对讲（包含半双工对讲和全双工对讲）
- **设备的设置功能：** 自定义设备设置接口api，满足不同场景需求。
- **设备控制接口：** 包括云台、镜头画面控制，实现精准操作。
- **WiFi配置：** 快速配置，确保设备稳定联网。
- **直播、回放边播边录：** 不错过任何精彩瞬间，同时录制备份。
- **直播、回放边播边截屏：** 关键画面，一键捕捉。
- **告警消息：** 实时推送，确保安全监控无死角。
