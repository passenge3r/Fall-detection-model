# 轻应用 UIKIT 说明

# 概念说明

萤石开放平台针对 Web 浏览器页面的视频接入需求，提供了完整的轻应用 UIKIT 解决方案。该方案主要包含 3 个 JavaScript SDK，其命名规则与底层协议强绑定，分别为：

- **EzOpen SDK：ezuikit-js**：主推方案，基于萤石私有 EzOpen 协议开发，由于该SDK开发开放较早，应用范围最广，一般若不加任何前缀后缀，默认**轻应用**或 **UIKit** 即指萤石 EzOpen SDK
- **HTTP-FLV SDK：ezuikit-flv**：基于 HTTP-FLV 标准流协议提供的 JavaScript SDK，全称萤石Web UIKit Http-FLV SDK，简称FLV SDK
- **HLS SDK：ezuikit-hls**：基于 HLS 标准流协议提供的 JavaScript SDK，全称萤石Web UIKit HLS SDK，简称HLS SDK

萤石开放平台的所有云直播SDK功能介绍详见：[云直播介绍](https://open.ys7.com/help/1744) 或者 [开放平台音视频SDK集成概览](https://open.ys7.com/help/3925)

# 三个Web SDK 差异

## Web SDK选择建议：

- **EzOpen SDK**：功能最为全面。不仅支持视频预览和回放，还支持音视频对讲、云台控制、视频录制、截图及多清晰度切换等功能，同时唯一支持视频流加密，因此开发者集成时，建议优先集成：[EzOpen SDK](https://open.ys7.com/help/4274)。

## Web SDK整体差异

|  | 主推：EzOpen SDK | HTTP-FLV SDK | HLS SDK |
| --- | --- | --- | --- |
| 适用性 | 主推：基于萤石ezopen私有协议开发，功能最全，效果最佳，支持预览、支持回放、支持可配置电脑/手机端UI，提供低代码组件，且私有协议支持视频流加密，确保设备出流安全的JavaScript SDK，延迟在1秒左右 | 适用开发者有多厂商的设备需要兼容，基于HTTP-FLV标准流协议提供的 JavaScript SDK，支持H265视频编码，视频外能力需要开发者自行处理。 | 基于HLS标准流协议提供的JavaScript SDK，试用部分手机端兼容性场景。 |
| 推荐度 | 🌟🌟🌟🌟🌟 | 🌟🌟🌟🌟 | 🌟 |
| 功能差异 | 支持功能有较大差异，可以详见下方表中内容 |  |  |
| 使用说明 | [查看文档](https://open.ys7.com/help/4274)用于说明轻应用UIKit SDK（EzOpen SDK）使用方法。 | [查看文档](https://open.ys7.com/help/1852)用于说明基于HTTP-FLV标准流协议的FLV SDK使用方法。 | [查看文档](https://open.ys7.com/help/3704)用于说明基于HLS标准流协议的HLS SDK使用方法。 |

## Web SDK 详细功能差异

| 功能模块 | 轻应用UIKit （EzOpen SDK） | HTTP-FLV SDK | HLS SDK |
| --- | --- | --- | --- |
| 实时预览 | 支持 | 支持 | 支持 |
| 云台控制 | 支持 | 不支持 | 不支持 |
| 截图/录制 | 支持 | 支持 | 支持截图，不支持录制 |
| 视频H.265 | 硬解支持，软解支持 | Web硬解支持，Web软解不支持 | 不支持硬解，仅支持软解 |
| 画面延迟 | 1秒 | 2-5秒 | 10秒以上 |
| 音频格式 | 支持AAC、G711、G722等格式 | 只支持AAC | 只支持AAC |
| 清晰度选择 | 支持 | 不支持，需API请求重新生成 FLV 链接 | 不支持，需API请求重新生成 HLS 链接 |
| 双向对讲 | 支持 | 不支持 | 不支持 |
| 本地回放 | 支持 | 支持 | 不支持 |
| 云存储/云录制回放 | 支持 | 支持 | 不支持 |
| 倍速 | 本地最大4倍速，云端最大16倍速 | 本地回放支持最大4倍速，云存储支持最大4倍速 | 不支持 |
| 回放时间轴拖动 | 支持，且支持seek拖动 | 支持，但不支持seek，拖动时间轴会断流重取 | 不支持 |
| 消息列表 | 支持 | 不支持 | 不支持 |
| 电子放大 | 支持 | 不支持 | 不支持 |
| 鱼眼/AR | web端支持软解 | 不支持 | 不支持 |
| 多目摄像机 | 单canvas显示：支持双画面 | 不支持 | 不支持 |
| 智能分析（画面中出现框框） | 支持 | 不支持 | 不支持 |
