# 微信小程序接入

在应用轻量化的趋势中，越来越多的用户选择以微信小程序作为载体进行应用服务的开发。在开发过程中，开发者经常会面临以下问题：不知道哪种开发方案更加符合自己的诉求？在开发过程中需要准备哪些额外资料？各方案之间最终呈现的效果会有什么差异？

方案介绍

|  | 小程序原生开发 | 小程序插件（推荐🌟🌟） | 小程序内嵌H5 | 半屏小程序 |
| --- | --- | --- | --- | --- |
| 优点 | 1.可自由化界面设计，根据企业需求自行定义样式，2.使用微信运行环境，性能更强。比较适合开发能力较强的客户 | 1、流程简化：无需申请视听资质（原生开发）。 2、灵活接入：通过插件形式引入，可自主布局，不受原生跳转、半屏打开限制。 3.萤石提供了基础组件，直播/本地回放/云存储/云录制都已支持，开发者可减少部分开发工作量 | 1. 支持萤石EZOPEN协议取流，延时1秒左右，延时最低；2.由于基于轻应用开发，设备控制能力等开箱即用  3. 该功能基于jssdk集成开发，延续了uikit的多项能力 | 1. 没有资质门槛。无需检验文件  2. 一行代码即可集成 |
| 缺点 | 1. 播放组件（Live-player等组件）需要企业自行认证  2. 设备操作等没有组件，开发难度较大 | 1.需开发者进行上层业务封装，工作量比半屏小程序多一点 2.不支持自定义UI样式 | 1. 限制于浏览器性能，性能消耗更大，手机可能会出现卡顿发热；2.萤石已无法提供校验文件资质，需开发者自行部署H5文件。 | 1. 暂不支持全屏 2. 不支持萤石私有协议 3. 界面可操作程度低 |
| 适用范围 | 适用于有播放组件资质 | 适用于简单快速实现视频播放 | 适用于没有组件资质，不介意性能消耗的开发者 | 适用于简单快速实现视频播放 |
| 推荐指数 | ★★★ | ★★★★★ | ★★★★ | ★★★★ |
| 开发资料 | https://github.com/Ezviz-OpenBiz/WeChat-miniApp | 开发方案：<https://open.ys7.com/help/1865> | 由于微信限制，域名已经无法新增因此无法使用uikit，请自行获取直播地址，并内嵌H5 uikit的开发参考：<https://open.ys7.com/help/4274> | 由于微信限制，半屏小程序授权若遇到卡点，新申请开发者申请时请联系小助手咨询，集成方法 <https://open.ys7.com/help/502> |
