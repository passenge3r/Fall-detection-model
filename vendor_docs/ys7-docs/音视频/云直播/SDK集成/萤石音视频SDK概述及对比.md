# 萤石音视频 SDK 概述

萤石开放平台音视频SDK 是萤石为了开发者快速接入物联网监控直播业务的软件开发工具，已为萤石云视频、海康互联等产品提供了直播的底层能力支持。在集成安防取流能力的同时，同时提供云台控制、点播播放、设备配网等能力，具有高稳定性、功能丰富、接入简单的特点。
