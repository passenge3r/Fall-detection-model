# 无插件取流巡检组件

  萤石云Web无插件取流目前主要是针对单屏的预览、回放场景，目前随着连锁、工地、监管、巡检等场景下多屏需求越来越多，开放平台目前又有了新的方案：无插件取流巡检组件，帮助开发者一键集成。

## 一、产品介绍

| **功能** | **描述** |
| --- | --- |
| 多屏预览 | 支持1/2/4/9/12/16等多屏无插件Web预览实时直播 |
| 多屏回放 | 支持多屏本地回放、云存储、云录制2.0回放 |

预览操作功能

| 预览 | 操作功能 |
| --- | --- |
| 单设备画面预览 | 对单个摄像机实时取流，查看当前单个摄像机的实时直播画面。 |
| 多设备画面预览 | 对多个摄像机同时取流，并在一个页面上展示多摄像机的实时直播画面。 |
| 云台控制 | 云台，也称PTZ，是指对摄像机进行操控，比如云台转动、物理缩放、变焦等操作，可以根据需要自动或手动调整方向和焦距，确保关键区域始终处于监控范围内。该能力需摄像头本身支持PTZ能力。 |
| 截图 | 提供截图的调用api，用户点击该按钮后可以对当前画面截图，并提供保存。 |
| 录像 | 提供录像调用api，集成后可以对当前画面进行录像，一般是某一段时长录像，并提供保存。 |
| 电子放大-按钮放大 | 电子放大：与物理缩放对应，指的是通过数字处理技术增加图像显示尺寸，而不是通过物理光学元件来实现。过度的电子放大可能会导致图像模糊等问题。 |
| 全双工对讲 | 全双工对讲，与半双工对讲对应，指的是通信系统中同时进行双向对讲的方式，它允许对讲的双方可以在同一时刻进行发送和接收语音，而不需要像半双工通信那样交替进行。 |
| 本地录像/云存储/云录制录像回放 | 查看设备本地/云存储/云录制里的录像 |
| 全屏 | 同预览功能：全屏 |
| 倍数播放（1/4/8/16/32倍数） | 针对视频可以进行多种倍速播放，云存储支持多种回放倍速，包括1/4/8/16/32倍速。 |

## 三、应用行业及场景

| 行业 | 客户案例 | 场景说明 |
| --- | --- | --- |
| 大屏监控 | 监控室 | 安防监控大屏使用 |
| 工地 | 工地监控 | 除工地视频巡检外，还可以给上级平台建立工地巡检，方便监控现场画面，并随时做出指挥 |
| 无人值守 | 值守店主端 | 值守分为客服与店主端，客服需要27屏可以集成C++SDK，但是店主端可以直接集成多屏巡检SDK，方便店主回看 |
| 驿站 | 驿站视频巡检 | 驿站现场巡检，查看是否有可疑人员或现场故障 |
