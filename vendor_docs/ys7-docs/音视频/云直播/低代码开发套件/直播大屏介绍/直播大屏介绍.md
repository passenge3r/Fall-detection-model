# 直播大屏介绍

> 在视频设备应用的海量场景中，多空间多角度覆盖已成常态，大屏直播+多屏汇聚成为行业普遍需求。一屏尽览、实时直播的服务，可以有效改善用户体验，提升管理效率。

## 产品介绍

萤石开放平台推出了直播大屏组件，该服务是基于萤石云UIKIT硬解能力、视频预加载能力打造的低代码直播多屏浏览组件。支持更多画面同步预览，支持更多设备添加，支持预加载，为多行业提供高效率、体验佳的多屏直播服务。

组件能力

**更多设备，一屏在线**

萤石全新直播大屏组件可支持12个摄像头画面同时播放，满足不同场景下对多空间实时管理的需求。

**海量终端，同时添加**

除了一屏容纳更多设备画面外，全新组件能力还支持添加设备的扩容，可实现最高100台视频设备的导入。

**支持密码设置**

针对部分场景的安全管理需求，萤石直播大屏服务可设置密码进入。设置密码后，如需查看画面，则要通过输入正确密码才能观看。

## 功能列表

| 功能 | 说明 |
| --- | --- |
| 多画面展示 | 多个画面同时取流播放。目前支持切换画面配置：支持1×1、2×2 、 3×3 、 3×4 、 4×4 、 5×5 等 |
| 添加设备 | 支持添加设备，支持添加自有、托管、国标等设备类型 |
| 设备排序 | 支持对添加设备进行排序 |
| 定时轮巡 | 支持30秒-300秒之间多个时间间隔轮巡 |

## 应用场景

萤石直播大屏组件具备无插件的特性，开发门槛低，使用场景广泛。

**场景1：展厅显示大屏**

如家装公司的展厅视频画面汇聚，以往需要安装客户端实现，现在可以直接嵌入管理后台，支持多屏画面的观看。

**场景2：云值守监控大屏**

提供网页端的云值守监控大屏，除了单屏画面数量的大幅提升，还能进行单一设备的对讲，提升客服的单一服务能力。
