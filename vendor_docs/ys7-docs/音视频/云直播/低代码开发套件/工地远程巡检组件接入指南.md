# 工地远程巡检组件接入指南

## 前提条件

在开始接入之前，您需要确认以下重要的信息：

- 您设备是否支持远程巡检能力
- 具备使用百度地图的能力

## 接入步骤

1. [步骤一: 设备接入](#%E6%AD%A5%E9%AA%A4%E4%B8%80-%E8%AE%BE%E5%A4%87%E6%8E%A5%E5%85%A5)
2. [步骤二: 申请百度地图密钥](#%E6%AD%A5%E9%AA%A4%E4%BA%8C-%E7%94%B3%E8%AF%B7%E7%99%BE%E5%BA%A6%E5%9C%B0%E5%9B%BE%E5%AF%86%E9%92%A5)
3. [步骤三: 开通权限](#%E6%AD%A5%E9%AA%A4%E4%B8%89-%E5%BC%80%E9%80%9A%E6%9D%83%E9%99%90)

## 步骤一: 设备接入

- 将您的设备接入萤石云开放平台，接入方法详见可查看 [设备云接入相关文档](https://open.ys7.com/help/1798)

## 步骤二: 申请百度地图密钥

远程巡检模板相关地图功能，使用百度地图JavaScript API实现，故三方开发者接入时需要申请百度地图密钥(ak)，百度地图秘钥申请流程可参考 [百度地图官方文档-账号和获取秘钥](https://lbsyun.baidu.com/index.php?title=jspopular3.0/guide/getkey)

## 步骤三: 开通权限

前往萤石云开放平台控制台 [云直播-轻应用](https://open.ys7.com/console/ezuikit/template.html) 开通远程巡检模板权限，获取对应远程巡检模板的代码示例，嵌入网页服务器上即可使用。如需了解更多可查看 [低代码UIKIT主题模板产品介绍](https://open.ys7.com/help/1759)
