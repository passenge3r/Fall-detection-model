# 流管理（RTMP）：流管理

视频直播提供丰富的流管理功能，包括查看在线流、历史流、禁推流及其详细信息。本文介绍直播流管理的功能及方法。

# 流列表管理

1、在新建流ID后，可以查看到流ID（也称StreamID）列表

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmg4YTGAYuriAAIOZQpIxE0002.png)

2、输入对应的流ID，可以进行搜索
![](https://resource.eziot.com/group1/M00/01/8D/CtwQE2hBQ8iAfBcqAAFdMiEqNV0558.png)

3、流列表操作：点击对应的操作可以进行查询
![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmhBQ82AASf-AAEjPZVUzMg230.png)

4、流状态：

![](https://resource.eziot.com/group1/M00/01/8D/CtwQE2g4YaGAZxZAAAAXGE8RPv4364.png)

选择筛选可以获取不同状态下的流ID

| 状态 | 功能说明 |
| --- | --- |
| 未取流 | 该流ID未启用，可能是刚创建，或者已过期 |
| 取流中 | 有用户在取流观看视频流 |
| 已禁用 | 开发者禁用该流ID，无法进行取流播放等操作 |
| 已删除 | 流ID可以删除，删除后不在列表展示，无法恢复 |

# 流监控

当前提供流监控的实时数据同步：

| 功能 | 说明 |
| --- | --- |
| 设备推流码率 | 设备推流码率受设备分辨率、变码率、主子码流影响，每5分钟更新一次 |
| 下行带宽 | 下行带宽指的是萤石云服务器到用户观看端的带宽数据，带宽数据受观看人数、观看端的清晰度等影响，每5分钟更新一次 |
| 在线人数 | 当前取流的终端数据，如果同一用户开多个取流链接也算多个人数，每5分钟更新一次 |

# 流操作：预览、删除

1、预览

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmg4Yb6AAU9lAAGG7i8rYds062.png)

功能：

1）在线预览

预览支持http-flv、HLS、RTMP三种协议（web端预览不支持RTMP）

我们提供播放地址APi接口获取，可以参考文档：获取播放地址

2）删除

删除后所有人将无法继续使用该视频流，无法再进行获取播放地址操作，也无法在线预览。删除后不可恢复。

## 禁推流管理

禁推直播流功能可帮助您在遇到鉴权推流地址暴露、用户恶意推流、业务需求情况的时候，对某路直播推流进行禁止推流的操作。

1. 输入需要禁止的流ID，或者选择对应流ID，点击**禁用**
2. 单击**查询**，查询推流历史记录
3. 禁止推流的流ID，点击启用，可以重新启用
