# RTMP推流-流管理：全球加速操作说明

> 该文档主要是介绍萤石开放平台海外RTMP推流加速产品操作说明

# 说明

若开发者对接的是萤石/海康海外设备，请勿参考该文档，海外设备需要连接海外开放平台，请参考：<https://ezsuperfans.com/portal.php?mod=view&aid=560>

# 前提

## 创建RTMP推流地址、获取播放地址

1）注册账号：[如何成为萤石开发者？](https://ezsuperfans.com/portal.php?mod=view&aid=34)

2）开通企业版套餐：由于RTMP推流方案，与开放平台设备套餐冲突，建议线下联系[小助手](https://resource.eziot.com/group1/M00/00/F3/CtwQE2VtTSuAN0y0AAAmQb_3exk350.png)开通不带设备套餐的企业版套餐。

3）了解RTMP推流功能：由于创建RTMP推流地址、获取海外播放地址的操作与普通功能一致，请阅读 [RTMP推流功能说明](https://open.ys7.com/help/4360)

# 功能操作说明

## 创建RTMP推流地址

![](https://resource.eziot.com/group1/M00/01/92/CtwQEmll7CyAJ-RvAAUZ0RX9qoI351.png)

点击创建直播流

## 选择全球区域

![](https://resource.eziot.com/group1/M00/01/92/CtwQE2ll7C6AXQ0UAAG1Nm5bi_k934.png)

选择区域，由于该区域目前限制了只有四个区域，开发者可以根据自己实际情况选择

![](https://resource.eziot.com/group1/M00/01/92/CtwQEmll7DCACP41AABUTvDkkqY009.png)

目前支持 东南亚（新加坡）、印度（孟买）、欧洲（法兰克福）3个节点

由于海外存储策略，国内的开放平台控制台无法直接使用存储，如果要使用云录制或者存储功能，请对接海外开放平台，或联系小助手

## 创建对应区域直播流

创建成功后，列表就会显示该区域的流地址，该地址可以进行推流。

![](https://resource.eziot.com/group1/M00/01/92/CtwQEmll7cqACCaEAAGPOH1Rgn0048.png)

如上，如果推流地址按钮，可以点击推流地址，查看推流相关操作。

## 推流地址

![](https://resource.eziot.com/group1/M00/01/92/CtwQEmll7DSAPfIPAAFoKDrZLu0902.png)

以印度为例，查看印度的推流地址，可以进行推流等操作。

- OBS推流：参考文档：<https://open.ys7.com/help/4362> OBS软件推流部分
- 设备推流：参考文档：<https://open.ys7.com/help/4362> 海康硬件推流部分

## 推流后预览及获取直播地址

列表点击预览，或者顶部tab切换预览地址，可以进入预览页面，预览页面可以查看当前画面或者复制预览地址

![](https://resource.eziot.com/group1/M00/01/92/CtwQE2ll7DWACUFwAAKJXoQJCno294.png)

## 查看推流记录、流管理等

此功能与国内RTMP推流基本一致，可以参考国内产品功能操作：

RTMP推流-RTMP流管理：<https://open.ys7.com/help/4361>

RTMP推流-直播推流：<https://open.ys7.com/help/4362>
