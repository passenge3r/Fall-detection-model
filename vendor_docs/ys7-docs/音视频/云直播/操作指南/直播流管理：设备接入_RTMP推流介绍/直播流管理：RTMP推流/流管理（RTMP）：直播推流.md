# 流管理（RTMP）：直播推流

如果需要进行直播推流，您可以通过OBS工具、设备推流或其他工具进行推流。通过阅读本文，您可以了解不同方式的推流方法。

## 前提条件

您已经生成推流地址。具体操作，请参见 [流管理（RTMP）：生成推流地址]

注意：

视频直播不允许同一时间向同一个推流URL进行多路推流（第二路推流会被拒绝）。

# 设备推流

海康、大华、或部分支持RTMP推流的摄像机、NVR等设备，在本地会有一个推流地址，配置后就可以向获取到的推流地址进行推流。

海康设备为例：若该设备支持RTMP推流，则可以再配置-高级配置里，选择RTMP，点击启用，将获取到的推流地址填入：

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmg4YmqAbY7XAAHglRp-d2c448.png)

设备能力校验：设备是否支持RTMP推流，需要与购买的销售、经销商确认。

备注：

1）若要使用RTMP推流协议，建议修改为H.264视频编码格式

云端不会进行编码格式的修改，虽然萤石流传输支持H.265，但是受限于播放端，目前主流设备均不支持RTMP、flv、hls的H.265的视频编码格式播放

2）设备端配置推流地址后，云端不会主动断流，需要开发者操作设备或云端停止推流进行操作，否则会一直产生流量费用。

## OBS推流

1）设置

![](https://resource.eziot.com/group1/M00/01/8D/CtwQE2g4YnuATyb0AAS9yP_PaTY390.png)

2）设置里选择推流，配置信息如下：

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmg4YoSANna9AACnJgPRE3E536.png)

| **参数** | **描述** |
| --- | --- |
| 服务 | 选择**自定义**。 |
| 服务器 | 输入已经生成的鉴权推流地址，例如：rtmp://cdnopen-push.ys7.com/c1cbc1d4e86d49a0981f54beea95280a/845740945980497920?auth\_key=1747970965-0-0-18ea59df5a95d71e1571aa11c2ff7 |
| 串流密钥 | 串流密钥为空。 |

3）在OBS主页面，点击开始推流

![](https://resource.eziot.com/group1/M00/01/8D/CtwQE2g4YpGAVf3mAAOxO2mgm2M427.png)

4）开始推流后，就可以在流管理 里查看推流历史记录

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmg4Yp2ADMgSAABH3ssrEEk832.png)

5）开始推流后，就可以在流管理 里查看并管理已推的音视频流。

详见：直播流管理（RTMP）控制台操作

## 后续操作
