## 2. 不想接入SDK进行直播流播放

如果开发者不需要摄像头提供的云台、对讲等功能，或者开发者可以自行通过API接口集成相关能力，只需要萤石提供视频预览或回放，则可以不需要集成SDK

### 前提

已经生成直播流：<https://open.ys7.com/help/4324>

已经获取播放地址：<https://open.ys7.com/help/4064> ，备注：获取播放地址请选择RTMP、HTTP-FLV、HLS等标准流协议，私有协议ezopen无法在非SDK上播放。

### 播放

1）VLC播放器：支持Windows、Mac、Linux、Android和iOS平台。可以自行搜索相关播放器

2）小程序 video组件：开发者可以集成微信小程序的video组件，并在小程序里进行hls直播流的播放

3）其他：开发者可自行寻找相关开源组件进行播放。

由于三方组件兼容性不一定有萤石提供的SDK兼容性高，若遇到相关问题，请自行排查或者寻找萤石研发协助排查。
