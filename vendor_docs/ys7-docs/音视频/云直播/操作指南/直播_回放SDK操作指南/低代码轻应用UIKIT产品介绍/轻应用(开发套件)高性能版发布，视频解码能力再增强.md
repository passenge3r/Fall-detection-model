# 轻应用UIKit(低代码开发套件)高性能版发布，视频解码能力再增强

# 关于轻应用开发套件

轻应用 UIKIT 是萤石推出的方便开发者快捷集成WEB/H5端视频解码播放能力的JS（JavaScript） SDK，自发布以来，在多场景帮助开发者快速搭建音视频应用。针对市场需求的不断变化，萤石开放平台轻应用开发套件也迎来了一次重磅升级，正式上线UIKIT高性能（硬解）版本。

# 01 解码能力说明

轻应用UIKIT PRO高性能版本，是PC端使用的无插件播放组件，包含软解、硬解播放能力集，支持常见的播放控制操作和后处理操作。与之前版本UIKIT标准版相比，主要增加了硬解能力，在多路播放及高分辨率播放上进行了重要升级。

视频编码格式能力集：

支持H264、H265、Smart264、Smart265等。

封装格式能力集：

支持PS(mpeg2)、RTP、FLV 、MP4（前置）、HIK私有封装、TS等封装格式。

音频编码格式能力集：

AAC、AACLD、ADPCM、G711(A/U)、G722\_1、G726、MP2、MP3、Opus等编码格式。

更多功能：

支持解密码流、无头开流、播放声音、快慢放、暂停恢复、帧进恢复、抓图、电子放大、降噪、重采样、兼容错误数据等。

# 03 高性能（硬解）版本应用场景

由于高性能版本无插件特性，大大提升了产品性能，未来将拓展出更广阔的应用场景，欢迎广大开发者进行集成使用。

### 场景1：展厅大屏

以前开发者进行直播页面多屏开发需要使用方安装客户端，而现在开发者基于轻应用高性能版本，能在网页端直接集成单页面20+屏幕的直播页面，实现在线无插件查看。

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmhBYRuAeUqTABIZr-3K918228.png)

### 场景2：云值守监控大屏

提供网页端的云值守监控大屏，方便进行快进回放的查看，以前只能4屏观看，而现在能支持12屏以上的屏幕同时查看，还能实现单一设备的对讲，提升客服的单一服务能力。

![](https://resource.eziot.com/group1/M00/01/8D/CtwQE2hBYTCAWlhnABaa8hedEWU391.png)

### 场景3：4K视频在线观看

海康已提供各种超高清摄像头，如鹰眼设备等，以往只能本地查看，而现在集成在萤石开放平台后，可以直接通过互联网在线实时查看超高清画面。
