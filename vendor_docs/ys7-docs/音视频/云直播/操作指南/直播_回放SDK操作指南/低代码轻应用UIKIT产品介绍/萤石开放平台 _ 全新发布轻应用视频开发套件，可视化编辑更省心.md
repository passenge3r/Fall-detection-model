# 1. 新版轻应用功能升级

萤石开放平台轻应用此次更新的主要内容分成3个部分，1）操作区功能自定义升级；2）视觉风格适配用户个性化需要；3）安防视频风格的全面升级。本次版本升级，在满足用户多种场景、多端应用、多版本需求的同时，进一步降低用户开发工作量，做到功能可视化配置。

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmhBaXmAPLU1AAJh9ntT0t4734.png)

萤石开放平台从轻应用发布起至今，致力于提升开发者简便、快速的项目开发体验。我们根据用户使用需求、视频平台共性，归纳出符合用户使用习惯、需求共性的功能，结合萤石多年音视频领域研究心得，推出9大操作功能控件、3大播放功能的自定义设置，支持用户通过简单的勾选操作，完成功能配置。实现操作区功能自定义升级，大幅度降低开发者在视频功能上的开发成本。

![](https://resource.eziot.com/group1/M00/01/8D/CtwQE2hBaaWAYyCOAAICnCb_dhQ202.png)

伴随行业发展和视频应用普及，适用于不同场景、面向不同用户、适配不同界面的各类视频监控系统都有着不同的风格需求。如何让用户既能实现功能上的便捷操作，又能满足各类自定义需求呢？全新版轻应用支持风格颜色等界面自定义。

# 2. 如何使用轻应用？

Step1：轻应用当前发布版本支持web及H5模式，对预览和回放也作出了不同版本的区分。在配置时，可以根据需求进行选择。

![](https://resource.eziot.com/group2/M00/01/04/CtwQF2hL4ieAY60MAASvdsdVcEY256.png)

Step2：轻应用控制台的配置界面可以分为两个模块，配置区和预览区。其中在配置区域可以对相关控件进行选择，对操作区的颜色以及控件颜色进行选择。

![](https://resource.eziot.com/group2/M00/01/04/CtwQF2hL4i6ALrFUAAZcZoewEIQ279.png)
