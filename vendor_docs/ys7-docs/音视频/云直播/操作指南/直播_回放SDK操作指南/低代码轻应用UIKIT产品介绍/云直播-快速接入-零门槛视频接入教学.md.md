# 快速获取浏览器播放地址

## 接入准备

1.打开[控制台-设备管理器-设备管理](https://open.ys7.com/console/device.html)

2.点击选择设备，获取ezopen协议播放地址

3.获取accesstoken：访问令牌，播放监控地址的必要参数，获取方式：[点击查看](https://open.ys7.com/help/19)

## 方案1：获取地址，该地址直接在浏览器全屏打开

**参数介绍**

https://open.ys7.com/console/jssdk/pc.html?accessToken=【at参数】&url=ezopen://open.ys7.com/【设备序列号】/【通道号、清晰度、播放类型等】.live&themeId=【UIKIT主题名称】

- accessToken：访问令牌，播放监控地址的必要参数，获取方式：[点击查看](https://open.ys7.com/help/19)
- url：监控地址，包含验证码、设备序列号、通道号、清晰度、播放类型，可以在控制台，点击设备，获取监控地址
- UIKIT主题名称：这个是轻应用的主题名称，若您只看视频，可以填写simple，其他主题介绍请参考：[uikit主题介绍](https://open.ys7.com/help/1759)
