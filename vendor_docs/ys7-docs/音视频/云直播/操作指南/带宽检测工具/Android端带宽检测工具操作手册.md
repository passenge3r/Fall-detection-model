# Android端带宽检测工具操作手册

## 为什么要进行带宽检测？

带宽检测是用来检测的上行带宽、下行带宽、丢包以及网络延迟情况的工具，可以验证实时带宽是否超出套餐额度，以及网络的速度、延迟性和稳定性。阅读本文带宽检测操作文档，您将学会如何运用带宽检测工具，了解带宽的实时情况。

适用于Android手机

## 操作说明

萤石云开放工具APP下载入口：扫一扫下方二维码可直接下载

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lM3h2Aa98_AAKU5m6Z3ps168.png)

### 步骤1：带宽检测有以下入口可以进入。

打开萤石开放工具APP，选择模拟设备带宽检测

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlM3iCASw7vAAMlnqrKaQ4226.png)

### 步骤2：根据图片指示输入账号凭证和设备序列号与通道号

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lM3iSAKR07AB8QhDf1sLc053.png)

① 请至 https://open.ys7.com/，登录控制台，进入[云直播>数据监控>带宽检测工具]或者[设备管理器>设备管理>带宽检测工具]进行获取账号凭证。

（1） 设备管理器——设备管理——带宽检测。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlOMeWATjcAAAK-6Uap4sk106.png)

（2） 云直播—数据监控—带宽检测。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lOMeeABr3xAAHPHMf3TSc597.png)

（3） 选择带宽检测临时授权的有效期，点击开始生成。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlOMemAZlBOAAHJFAXVzOY890.png)

（4） 复制下方出现的临时授权码即可。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lOMeuAIS_oAAHOQBt-Ghk587.png)

② 设备序列号在设备管理处获取，IPC多目或NVR请输入通道号，IPC单目可以不用输入，默认为1通道

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlOMe2AIDRrAAK892X741U364.png)

点击开始测速，操作成功会显示测速中

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlM3ieAC53aAAnvQB06edg608.png)

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lM3iuAeZlpAAV1GCKnWpE157.png)
