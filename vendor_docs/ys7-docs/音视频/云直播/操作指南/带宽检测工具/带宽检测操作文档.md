# 带宽检测操作文档

## 为什么要进行带宽检测？

### 带宽检测是检测设备的上行带宽、下行带宽、丢包以及网络延迟情况，可以验证设备的实时带宽是否超出套餐额度，以及网络的速度、延迟性和稳定性。阅读本文带宽检测操作文档，您将学会如何运用带宽检测工具，了解带宽的实时情况。

### **操作说明**

### **步骤1：** 带宽检测从以下入口找到

### 云直播—数据监控—带宽检测。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDi9eAB1iKAAFMjMjG-XY774.png)

### **步骤2：** 选择带宽检测临时授权的有效期，点击开始生成。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDi-qASnEnAAFX_Pi20c4859.png)

### **步骤3：** 复制下方出现的临时授权码。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDi_mAN1jzAAE5eJmPVpo789.png)

### **步骤4：** 点击[带宽检测工具链接](https://openstatic.ys7.com/ezuikit_troubleshoots/index.html?page=bandWidth)，进入带宽检测界面。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDjAqAM9vtAAFGOVh1rxQ448.png)

### **步骤5：** 点击链接下载带宽检测工具软件，安装步骤如下：

### 1. 点击带宽检测工具链接。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDjB6AToj7AAGqZ-NhvFA877.png)

### 2. 打开文件，并按操作指引安装到本地。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDjDmABjRqAAGGiJ4H2KM613.png)

### 3. 打开文件会选择“是”，然后点击“我同意此协议”，“下一步”。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDjE2ALB1NAAFY7527tbo902.png)

### 4. 根据自己的需要选择是否勾选创建快捷方式，然后点击“下一步”。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDjGCAXls0AADYdHlglvM364.png)

### 5. 点击安装。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDjHOAX0njAACXtEWtTyY392.png)

### 6. 选择自动关闭该应用程序，并点击“下一步”。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDjIKAIiO3AAC-4E_hhHM574.png)

### 7. 点击完成即“成功安装”。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDjJ2AC1HhAABlQ_uGL-k146.png)

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDjKyAEmxqAADFqbAWyjg792.png)

### 8. 此时设备重启会出现应用如下刷新，点击“是”，然后等流程结束就可以啦。

![](https://resource.eziot.com/group2/M00/01/0B/CtwQFmkLEOeAdOqqAAgvgRAaQts540.png)

### 如果选择了创建桌面快捷方式，则桌面上会出现带宽检测工具软件。

![](https://resource.eziot.com/group2/M00/01/0B/CtwQFmkLES-AV6LoAAB92XTlqt0467.png)

### **步骤6：** 回到刚刚的带宽检测界面，或者点击带宽检测工具软件后出现。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDjAqAM9vtAAFGOVh1rxQ448.png)

### **步骤7：** 在这个界面输入账号凭证、设备序列号@通道号，然后点击开始测速。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDjUKAaEvOAAG0Ez6i_dY137.png)

### **步骤8：** 测速几秒就会出现带宽检测报告结果。

![](https://resource.eziot.com/group2/M00/01/0E/CtwQF2lDjWGAfm39AAO6XIWed5Y244.png)

### **步骤9：** 检测报告展示

![](https://resource.eziot.com/group2/M00/01/0E/CtwQFmlDjXKASNq9AAHEuWK9QnA775.png)
