# 云直播-快速入门

# 1. 注册开放平台账号

使用萤石音视频服务，您需要先[注册萤石开放平台账号](https://open.ys7.com/view/register/register.html)

# 2. 开通流程

使用直播服务可以为试用版套餐（自注册日起120天内有效），但是试用版套餐目前是有限制的，请注意：

- 试用版套餐免费用户取流最多上限只能3路视频并发
- 试用版套餐免费用户取流上线不能超过1M，超过将对最后取流路数进行断流操作

3.接入设备，获取云直播地址

获取设备直播地址之前，请先保证已接入设备，购买萤石或海康设备可以前往商城、咨询客服、咨询经销门店等方式获取设备，获得设备后，请将设备接入云平台，可以参考说明书，或参考以下文档：

接入设备的流程参见：

- [通过萤石协议接入](https://open.ys7.com/help/2837)
- [通过国标接入](https://open.ys7.com/help/389)

添加设备后，获取监控直播/回放地址：

开发者可前往查看萤石提供的试用设备，获取自己想要的功能：<https://openstatic.ys7.com/ezuikit_troubleshoots/index.html?page=experienceCenter>

## 3）根据业务场景，确定直播协议

开发者可根据自己实际的使用场景，确定使用的直播协议，或者使用哪一个SDK

目前萤石开放平台主要提供以下几种取流协议：EZOPEN协议（萤石监控私有流）、HLS协议（标准流）、RTMP协议（标准流）、FLV协议（标准流），每种协议有各自的优点和缺点。

萤石ezopen协议是萤石开发的专门用于直播监控取流的协议，主要是用于：iOS/Android/Windows等原生客户端取流，或在web/H5等浏览器端取流

| - | EZOPEN协议 | HLS | RTMP | HTTP-FLV |
| --- | --- | --- | --- | --- |
| **适用性** | 适用于各类客户端接入 | 适用WEB/H5接入 | 目前只支持小程序 | 适用WEB/H5接入 |
| **出流速度** | 首次取流延时1秒 | 首次取流延时4-10秒 | 首次取流延时2-4秒 | 首次取流延时2-4秒 |
| **优势** | 取流速度快，高安全性，接入简单。需集成萤石SDK | 跨平台性好，支持网页直接（包括微信）播放 | 比HLS延时低，且支持与第三方云进行转码、录播 | 比HLS延时低，且支持与第三方云进行转码 |
| 查看介绍 | <https://open.ys7.com/help/1751> | <https://open.ys7.com/help/1752> | <https://open.ys7.com/help/1752> | <https://open.ys7.com/help/1752> |

详细协议对比及介绍，可查看文档：<https://open.ys7.com/help/2821>

开发者根据本身需求及应用场景，即可完成选型，选型后开始集成相关SDK开发
