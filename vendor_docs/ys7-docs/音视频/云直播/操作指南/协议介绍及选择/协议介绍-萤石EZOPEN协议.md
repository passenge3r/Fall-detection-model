## EZOPEN协议

## EZOPEN协议概念

EZOPEN协议是萤石专为开发者设计的针对**UIKit**使用视频资源URL的协议，目前支持视频的预览、回放等功能

## 协议功能说明

| 功能 | 说明 | 备注 |
| --- | --- | --- |
| 适用性 | 支持萤石提供的SDK接入 |  |
| 出流速度 | 1秒左右 |  |
| 延迟 | 1秒左右 |  |
| 加密 | 支持 |  |
| 倍速 | 支持 |  |
| P2P | PC、App支持，web暂不支持 |  |

## ezopen协议格式说明

详细格式如下：（中括号内为可选参数）

##### 预览：**ezopen://[验证码@]域名/序列号/通道号[.清晰度].live[?参数1=值&参数2=值]**

###### 示例：

“ezopen://open.ys7.com/`440912260`/`1`.`hd`.`live`”，可以播放序列号为“`440912260`”设备“`1通道`”“`高清`”的“`预览视频`”  
注：该清晰度选择方式仅支持8.0.5之前的版本，8.0.5及之后的版本已修改为从设备侧动态查询，不再支持“[.清晰度]”指定清晰度。

##### 回放：**ezopen://[验证码@]域名/序列号/通道号[.回放源].[rec/cloud.rec][?参数1=值&参数2=值]**

###### 示例：

“ezopen://open.ys7.com/`440912260`/1.rec`?`begin=yyyyMMddhhmmss&end=yyyyMMddhhmmss`”，可以播放序列号为“`440912260`”设备“`1通道`”从begin到end时间范围内的“`本地录像视频`”

“ezopen://open.ys7.com/`440912260`/`1`.cloud.rec`?`begin=yyyyMMddhhmmss&end=yyyyMMddhhmmss`”，可以播放序列号为“`440912260`”设备“`1通道`”从begin到end时间范围内的“`云存储录像视频`”
