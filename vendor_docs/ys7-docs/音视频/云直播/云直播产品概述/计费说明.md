# 云直播-计费说明

本文介绍萤石开放平台云直播业务的详细费用说明及费用示例。

## 计费方式

计费方式按日结算的后付费的按量计费。当您开通相关服务后，可默认根据使用量付费，每日结算。

## 计费内容

| 计费项 | 单价 |
| --- | --- |
| 视频预览回放：使用ezopen协议 | 如果SDK P2P成功，则不收费；如果P2P不成功，则根据预览回放产生的**下行**带宽或者流量进行计费，具体计费价格可以参看下表 |
| 标准流：HLS/RTMP/FLV等 | 根据预览回放产生的带宽或者流量进行计费，具体计费价格可以参看下表 |
| 对讲 | 根据对讲产生的流量或者流量计入预览回放带宽，具体计费价格可以参看下表。使用WebRTC SDK对讲则遵循ERTC产品里的计费规则。 |
| 超低延时直播 | 超低延时直播单独计费，详见超低延时直播产品计费说明 |
| 海外监控全球加速 | 海外监控，国内取流播放加速单独计费，详见监控出海子产品计费说明 |

**计费内容备注：**

1）由于标准流必须经过服务端处理后才能提供，因为无法使用P2P服务；P2P的成功率取决于当前设备与取流客户端网络、地区等多种因素，一般在60%-80%

2）P2P需要集成各端SDK，具体请参看SDK集成说明，开放平台目前相关取流SDK均不单独收费

3）智能家居、养老、小用户等场景下的设备若已经买断，则该设备产生的流量/带宽不单独计费

4） **上行带宽及下行带宽**：萤石开放平台只收取下行带宽费用，上行带宽费用不计量计费，因此每日计费是按下行带宽最高的带宽峰值计费。

## 计费价格：套餐+单独计费

萤石提供企业版套餐，开发者可以在购买后，获取一定量的接入数量及带宽使用量。

详情参考：[开放平台定价](https://open.ys7.com/cn/s/price)

1）套餐内计费：若开发者实际产生的带宽及流量在企业版套餐范围内，则按计费周期统计实际用量并从账户余额中扣除实际消费金额。

2）套餐外计费：若开发者的实际取流带宽或流量超出企业版套餐，则会产生额外的流量费用，具体如下：

| 计费项 | 单价 | 说明 |
| --- | --- | --- |
| 基础套餐费 | 参考企业版套餐使用量 | 基础套餐使用量按带宽计算 |
| 超出带宽计费1：额外带宽计费 | 1.2元/Mbps/日 | 日结后结算，超额扣费（与平台所有带宽费共同计费） |
| 超出带宽计费2：额外流量费 | 2.5元/G/日 | 仅作为使用带宽超出套餐限制时的额外带宽产生费用的计量方式（与平台所有带宽费共同计费） |

**计费价格备注：**

1）带宽费：按每日下行带宽的峰值计费。按日结预付费的计费方式。首先按照套餐内数量计费，超额部分单独按照单价计费，带宽超额分为按照超出部分带宽计费或按照超出部分产生流量计费，由**用户自行切换**（控制台-套餐管理-企业版管理，设置超出带宽计费模式）。

2）额外流量费：当日超出套餐部分时刻产生的流量总额。按日结预付费的计费方式。仅当日带宽出现超额情况且用户选择带宽超额按照流量计费时产生。

3）日结预付费：每日24：00对当日产生的费用进行结算，输出账单并对账号中余额进行扣费。

4）退费说明：本产品暂不支持退费，如果您在使用产品中遇到问题，请openteam@ezvizlife.com专业的工作人员寻求帮助。

## 计费示例

### 示例1

【计费示例一】

某个客户在全国有20家农场客户，每个客户要安装100个设备（99个ipc+1个nvr，nvr为64通道nvr，下面挂了10个ipc），都通过萤石 协议接入。根据实际的使用场景，一天同事观看的用户数量最多只有10人。所有设备的主码流设置均为1M。

某月的一天账单情况：

建议用户选择E1套餐（100路设备接入费，5M带宽，300元/月）

- 基础套餐费：300/30（假设当月30天）=10元
- 超额计费：
- - 超额设备接入费：详见设备接入费用计算
- - - 超额带宽费：
- - - 如按照超出部分产生带宽计费：(10Mbps-5Mbps)\*1.2元/Mbps/天=6元
- - - 如果按照超出部分产生流量计费（假设超出部分产生2GB流量）=2GB \* 2.5元/GB/天=5元

## 欠费说明

当您当日扣费后余额小于等于0后，账号将自动切换为个人版套餐，如果您的账户余额不足产生欠费，请及时充值，否则会影响正常的取流服务。

## 注册开放平台账号

使用云直播服务时，您需要[注册萤石开放平台账号](https://open.ys7.com/view/register/register.html)

试用版套餐：自注册日起120天内，您可以直接使用，试用版套餐含有10路接入，1M带宽，3路并发。超过120天后，需购买企业版套餐才能享有拉流直播服务。
