# 云直播-基本名词

本文旨在介绍您在使用萤石监控直播服务过程中可能会涉及到一些基本概念。

### **设备接入**

设备通过萤石协议、国标28181协议等协议接入萤石开放平台，实现取流、控制等一系列能力。

接入产品详见：[萤石开放平台云接入产品概述](https://open.ys7.com/help/658)

### **视频监控**

视频监控系统一般包括摄像、传输、控制、显示、录像五大功能。利用摄像头实现摄像功能；利用网络实现传输功能；利用云台协议实现控制功能；利用客户的手机屏幕、电脑显示器以及专业大屏显示器实现显示功能；利用SD卡、硬盘等实现存储功能，最终实现可随时通过网络预览与回放的网络监控。萤石云开放平台，把网络监控拓展到了互联网上，把存储拓展到了云存储上，将传统网络视频监控升级成互联网视频监控。

### **视频直播**

视频直播是指在远端通过网络收看到现场正在进行的音视频实况。通常是利用互联网及流媒体技术将现场视频进行再处理后生动的展现给用户，通过真实、生动的音视频及其他信息的展示，营造出强烈的现场感。视频直播注重远端重现音视频的实时性和流畅性。

#### **对讲**

对讲是指双方面对面或者通过通讯工具进行沟通。本网站中的对讲特指利用视频监控系统中的传输能力，采集现场的声音传输给监控方，同样可以将监控方的声音传递给现场，从而实现双方的语音交流。

### **回放/录像**

播放事先存放的音视频资料。回放强调播放的监控属性，主要关注音频和视频；录播强调播放的多媒体属性，除了音频和视频，往往还有标记、讲义、背景介绍、评论、弹幕等信息展示和交互。两者技术实现相似，没有实质性区别，在实际应用中没有明确的界线。

### **轻应用UIKIT**

UIKIT是开放平台针对web/H5提供的一整套视频播放SDK

萤石监控直播低代码开发aPaaS，源于海康威视安防监控20年经验的应用开发和数字化转型的实践，提供了云上低码化、支持多多场景的应用开发模式，提升了企业开发安防监控直播的效率

轻应用UIKIT包括 UIKIT ezopen私有流JS SDK、UIKIT FLV/HLS标准流JS SDK等SDK

### **标准流直播**

HLS、RTMP、HTTP-FLV等标准协议的直播回放

### **微信小程序**

提供微信小程序 SDK ，支持在移动端快速观看设备的实时和录像画面。

### **1V多 P2P**

提供App/PC SDK 支持客户在观看端集成，设备与观看端可以构建共享的 P2P 网络，达到节省观看带宽的效果。（目前web及小程序暂不支持）
