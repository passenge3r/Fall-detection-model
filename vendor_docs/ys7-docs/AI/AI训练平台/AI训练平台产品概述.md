# 萤石开放平台AI训练平台

萤石开放平台**AI训练平台**，是面向企业与开发者打造的**一站式视觉AI模型定制与部署平台**，依托萤石音视频与物联网技术底座，以低门槛、可视化、全流程化能力，帮助用户快速完成行业场景化AI模型从数据生产、模型训练、测试评估到设备落地的全链路闭环，让无算法基础的用户也能快速构建专属AI能力。

---

## 核心定位

面向**工商企业、智慧监管、智慧建筑、智慧商贸、智慧农业**等多行业，提供开箱即用的视觉AI模型训练服务，解决通用算法不贴合场景、定制开发成本高、周期长、落地难的问题。

## 核心能力

1. **全流程可视化操作**
   无需专业算法知识，通过图形化界面即可完成数据集创建、标注、版本管理、模型训练、测试与部署，操作流程标准化、步骤清晰，新用户可快速上手。
2. **多类型算法与行业适配**
   支持**混合监测、物体检测、图像单标签分类**三大主流算法类型，覆盖多行业场景需求，可按需选择行业类型与算法模型，快速匹配业务。
3. **完整的数据管理体系**
   提供训练集/测试集双维度管理，支持图片上传、在线标注、版本发布与迭代，支持数据集编辑、删除、版本继承，保障数据规范与复用。
4. **模型全生命周期管理**
   覆盖模型创建、训练、测试、评估、版本管理全流程，自动生成评估报告，直观呈现模型精度与效果，支持模型持续优化迭代。
5. **端云一体快速部署**
   训练完成的模型可直接安装至适配萤石设备，实现云端训练、端侧运行，快速将AI能力落地到真实监控与感知场景。

## 产品价值

- **降低AI落地门槛**：零算法基础也能训练专属模型，缩短开发周期。
- **提升场景适配度**：自定义数据集训练，模型精度更高、更贴合业务。
- **简化运维与部署**：一站式管理，一键部署至设备，减少集成成本。
- **支撑行业数字化**：为安防、零售、农业、建筑等场景提供可复用、可迭代的AI能力。
