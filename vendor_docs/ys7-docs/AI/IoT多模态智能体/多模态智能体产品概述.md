# IoT多模态智能体

## 产品概述

萤石IoT多模态智能体是基于萤石AIoT生态底座，融合视觉、听觉、文本、数据等多源信息的新一代智能交互核心。它打破单一模态局限，以“像人一样感知、理解、决策”为核心目标，为家庭、企业、公共空间等场景提供“看得懂、听得清、会思考、能执行”的全流程智能服务，重新定义AI与物理世界的交互边界，成为用户身边“主动响应、持续进化”的智能伙伴。

## 产品优势

依托萤石多年视觉智能与AIoT技术积累，构建“感知-融合-推理-执行”全链路技术体系：

1. **多模态全域感知，全维度数据解析**
   融合多模态大模型、CV视觉技术、ASR 语音识别、雷达传感器数据采集等核心能力，实现图像、视频、语音、文字、环境数据的同步接收、精准解析与融合处理。打造 “视觉 + 听觉 + 文本 + 环境” 四维感知网络，既能识别监控画面中的人体行为、物体特征、场景异常，也能听懂自然语言语音指令、提取文档关键信息，还能同步读取多项环境传感数据，实现多源数据的协同分析与综合决策。
2. **视觉检测能力突出，泛化适配性极强**
   基于萤石深耕多年的CV计算机视觉技术与AI大模型视觉理解能力，实现超高精度的视觉检测分析，可精准识别画面中的目标物体、人体行为、合规状态等，误报率低、检测响应快。同时具备极强的场景泛化能力，无需大量定制化开发，即可快速适配后厨、工地、商超、厂区等不同场景的视觉检测需求，支持自定义检测规则，轻松应对各类复杂视觉分析场景。
3. **聚合丰富基础服务，触发模式灵活多样**
   聚合了集成抽帧、数据采集、智能告警、设备联动等核心基础服务，且支持 3 种不同触发模式，可根据业务需求灵活配置：定时触发、事件触发、间隔触发，满足不同场景下的图像采集与分析需求，平衡检测实时性与资源消耗，适配轻量检测与高频监测等各类使用场景。
4. **低代码高效开发，全流程简易管理**
   提供可视化低代码开发与管理平台，无需复杂编码能力，即可完成智能体的全生命周期管理。支持智能体的快速新建、可视化配置、在线调试、一键发布与设备分发，同时提供知识库、工作流等模块化功能，支持拖拽式编排工作流逻辑，降低开发与使用门槛，让企业与开发者能够快速上手、高效落地，大幅缩短智能体的开发与部署周期。

## 计费

萤石 IoT 多模态智能体采用阶梯式灵活计费模式，兼顾小型场景试用与大型场景商用，具体计费规则如下：

1. **免费试用权益**：目前智能体支持免费使用 3 路，满足小型场景的基础试用需求，超出 3 路部分需人工扣费，具体费用可联系官方客服沟通确认。
2. **标准场景定价**：以1080p 高清画面、单日 12 小时运行、每 10 分钟抽 1 帧用于大模型分析的标准视觉检测场景为例，计费标准为5 元 / 月 / 路，性价比高，适配多数中小场景的商用需求。
3. **定制场景计费**：针对高频抽帧、实时视频分析、多设备大规模联动等复杂场景，计费标准需根据实际资源消耗与需求定制，具体可联系官方客户单独沟通报价。
