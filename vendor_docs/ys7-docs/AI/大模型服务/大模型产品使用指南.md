# 快速入门

## 1. 准备工作

### 1.1 注册并完成企业认证

1. 注册萤石开放平台账号
2. 完成企业实名认证

### 1.2 获取 API Key

1. 登录萤石开放平台控制台
2. 进入「大模型服务」页面，[点击链接可前往](https://open.ys7.com/console/modelService/apiKeyManage.html)
3. 点击「获取 API Key」，填写密钥名称
4. 创建成功后，复制并妥善保存 API Key

> API Key 格式示例：`ezviz-aBcDeFgHiJkLmNoPqRsT...`

### 1.3 删除/禁用API Key

进入[模型服务](https://open.ys7.com/console/modelService/apiKeyManage.html)控制台，控制台内提供禁用和删除功能

## 2. 接口说明

### 2.1 OpenAI协议

- 接口功能

调用大语言模型进行对话补全，多模态分析、支持多轮对话、流式输出、Function Calling、深度思考等能力。

- 请求地址

`https://openai.ezviz.com/v1/chat/completions`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | Authorization | String | 鉴权令牌，格式为 Bearer {API\_KEY} | Y |
| header | Content-Type | String | 固定值 application/json | Y |
| body | model | String | 模型ID，从大模型广场模型详情页获取 | Y |
| body | messages | Array | 对话消息列表，详见 Message 结构 | Y |
| body | stream | Boolean | 是否流式输出，默认false | N |
| body | temperature | Double | 采样温度，范围[0,2)，值越高越随机 | N |
| body | top\_p | Double | 核采样概率阈值，范围(0,1.0] | N |
| body | max\_tokens | Integer | 最大输出Token数，超过后截断 | N |
| body | n | Integer | 生成候选数量，默认1 | N |
| body | stop | String | 停止序列，支持字符串或数组 | N |
| body | presence\_penalty | Double | 存在惩罚，范围[-2.0,2.0] | N |
| body | frequency\_penalty | Double | 频率惩罚，范围[-2.0,2.0] | N |
| body | tools | Array | 工具定义列表，Function Calling场景 | N |
| body | tool\_choice | String | 工具选择策略，auto/none/required | N |
| body | response\_format | Object | 响应格式，如{"type":"json\_object"} | N |
| body | enable\_thinking | Boolean | 是否开启深度思考模式 | N |
| body | thinking\_budget | Integer | 思考Token预算 | N |
| body | enable\_search | Boolean | 是否开启联网搜索 | N |
| body | stream\_options | Object | 流式配置，如{"include\_usage":true} | N |

**Message 结构：**

| 字段 | 类型 | 是否必选 | 描述 |
| --- | --- | --- | --- |
| role | String | Y | 角色：system、user、assistant、tool |
| content | String/Array | Y | 消息内容，文本或多模态内容数组 |
| name | String | N | 参与者名称 |
| tool\_call\_id | String | N | 工具调用ID，role=tool时必填 |
| tool\_calls | Array | N | 工具调用列表，role=assistant时可能返回 |


| 429 | Too Many Requests | 余额不足或频率超限 |

- 流式返回格式（SSE）

流式响应以 Server-Sent Events 格式返回，每个事件包含 `event` 和 `data` 两部分：

```
event: message_start
data: {"type":"message_start","message":{"id":"msg_01...","type":"message","role":"assistant","content":[],"model":"qwen3.7-max","stop_reason":null,"usage":{"input_tokens":12,"output_tokens":0}}}

event: content_block_start
data: {"type":"content_block_start","index":0,"content_block":{"type":"text","text":""}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"春风"}}

event: content_block_delta
data: {"type":"content_block_delta","index":0,"delta":{"type":"text_delta","text":"拂面"}}

event: content_block_stop
data: {"type":"content_block_stop","index":0}

event: message_delta
data: {"type":"message_delta","delta":{"stop_reason":"end_turn"},"usage":{"output_tokens":35}}

event: message_stop
data: {"type":"message_stop"}
```

**SSE Event 类型说明：**

| Event 名称 | 描述 |
| --- | --- |
| message\_start | 消息开始，包含初始 message 对象 |
| content\_block\_start | 内容块开始 |
| content\_block\_delta | 内容块增量（文本片段） |
| content\_block\_stop | 内容块结束 |
| message\_delta | 消息级增量（stop\_reason、usage） |
| message\_stop | 消息结束 |
| ping | 心跳保活 |
| error | 错误事件 |

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| id | String | 消息唯一标识 |
| type | String | 固定值 message |
| role | String | 固定值 assistant |
| content | Array | 内容块列表，详见 Content Block 结构 |
| model | String | 实际使用的模型ID |
| stop\_reason | String | 结束原因：end\_turn / max\_tokens / tool\_use |
| stop\_sequence | String | 命中的停止序列（如有） |
| usage | Object | Token用量统计 |

**Content Block 结构（响应）：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| type | String | text 或 tool\_use |
| text | String | 文本内容（type=text时） |
| id | String | 工具调用ID（type=tool\_use时） |
| name | String | 工具名称（type=tool\_use时） |
| input | Object | 工具输入参数（type=tool\_use时） |

**Usage 结构：**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| input\_tokens | Integer | 输入消耗的Token数 |
| output\_tokens | Integer | 输出消耗的Token数 |
| cache\_creation\_input\_tokens | Integer | 缓存创建的输入Token数 |
| cache\_read\_input\_tokens | Integer | 缓存命中的输入Token数 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 400 | invalid\_request\_error | 请求参数错误/模型不支持协议 |
| 401 | authentication\_error | 鉴权失败，检查API Key |
| 403 | permission\_error | 套餐权限不足 |
| 404 | not\_found\_error | 模型不存在 |
| 429 | rate\_limit\_error | 余额不足或频率超限 |
| 500 | api\_error | 服务内部错误 |
| 529 | overloaded\_error | 上游模型过载 |
