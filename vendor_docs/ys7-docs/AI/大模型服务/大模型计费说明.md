## 3. 计费规则

### 3.1 阶梯定价说明

- 部分模型根据输入长度实行阶梯定价，输入长度越短单价越低
- 阶梯计价按所在区间的单价统一计算，不分段累加
- 输入长度以单次请求的总输入 Token 数为准

### 3.2 扣费周期

- **扣费时机**：T+1 扣费，即当日产生的用量在次日进行结算扣费
- **余额不足**：账户余额不足时，API 调用将返回 429 错误（rate\_limit\_error），充值后即可恢复使用

### 3.3 流式与非流式

流式和非流式调用的计费标准一致，均按实际产生的 Token 数量计费。
