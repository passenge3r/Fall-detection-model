# 产品简介

## 1.1 模型服务

模型服务是面向开发者的统一大模型接入平台，提供兼容 OpenAI主流协议的标准化 API 接口。开发者通过一个接入地址、一个 API Key，即可调用多家供应商的大语言模型，实现智能对话、内容生成、代码辅助、多模态理解等 AI 能力。通过此服务，开发者无需分别对接各模型厂商的 SDK 和协议，大幅降低接入成本和维护复杂度。

## 1.2 功能概览

| 功能名称 | 功能描述 |
| --- | --- |
| 统一对话接口 | 兼容 OpenAI Chat Completions 协议，支持流式与非流式响应 |
| 模型广场 | 可视化展示所有可用模型，包含价格、能力、参数等信息 |
| API Key 管理 | 支持创建、禁用、删除密钥，每账号最多 10 个 |
| 内容安全 | 敏感词检测与过滤 |

## 1.3 产品优势

- **接入简单**：兼容 OpenAI SDK，只需修改 base\_url 即可完成接入，无需额外适配开发。
- **多模型覆盖**：一个平台接入多家主流大模型（千问、豆包 等），按需选用，灵活切换。
- **按量计费**：按实际 Token 用量付费，无需预购资源包，成本可控。
- **安全合规**：内置敏感词过滤、余额校验，保障业务安全运行。
