## 运行端渲染Demo前提条件

运行DEMO有几个要求，请先行进行准备

1）必须：需要**GPU**配置：3070及以上，**CPU**配置：i5-12400及以上

2）可选：主控DEMO 可提供语音交互能力，因此若要体验数字人语音交互，请提前准备**麦克风及喇叭**。

3）建议：建议屏幕是55寸或者75寸竖屏，其他屏幕尺寸也可。
