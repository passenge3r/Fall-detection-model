# 数字人主控对接

## 什么是数字人？什么是主控

| 内容 | 内容 | 备注 |
| --- | --- | --- |
| 数字人SDK | 数字人部分，将数字人接收到的文字转化为语音，并让数字人播报 | 数字人SDK可独立对接 |
| 主控SDK | AI部分：含ASR、语音降噪、知识库等部分 | 目前只支持Windows SDK |

## 主控对接指南

1.软件包介绍

主控软件，集成了人脸识别，主动拾音，ASR以及阿里云知识库等相关功能

## 2.业务细节

1.     **注册码授权页面**：启动主控后，弹出授权页面，客户可以填充注册码，点击授权，若授权成功会有弹窗提示授权成功。若授权失败会提示失败。

2.     **调试页面**：调试页面用于调试主控SDK的功能。页面中包含识别到的人脸信息（年龄、性别、是否戴口罩等）、识别到的语音的文本信息、数字人的回答信息。数字人的状态信息。

3.     \*\*摄像头画面：\*\*在屏幕右上角会出现摄像头画面，在画面中有一个大蓝框。只要人脸出现在大蓝框中，将会被识别。识别成功后人脸会有一个小蓝框。

4.     **数字人状态**

l  **休息模式：**

1.     数字人主控启动后，初始状态为：**休息模式。**

2.     如果当前是观察状态，连续2秒钟\*\*（****serve.observationDepartureTime****）**没有出现人脸则进入**休息模式。\*\*

3.     当前是准备模式或者交互模式，连续10秒钟\*\*（****serve.executionDepartureTime****）**没有出现人脸则进入**休息模式。\*\*

l  **观察模式**：如果当前是休息模式，当画面中一出现人脸，立即进入**观察模式**。

l  **准备模式**：如果当前是观察模式，如果持续500毫秒\*\*（****serve.executionPreTime****）**一直存在人脸，则切换到**准备模式。\*\*

l  **交互模式**：如果当前是准备模式，如果接下来连续10张截图\*\*（****welcome.preFrameCount****）**都是同一张脸，则切换到**交互模式。\*\*

5.     **语音识别**：当数字人处于交互模式，开启拾音能力，并进行实时语音识别，客户说的语音可以转换成文本，用户可以不间断说多句话，数字人可以进行断句。

6.     **智能对话**：当数字人处于交互模式，打开对讲能力，针对语音识别的每个句子返回回答。

## 3.交互逻辑

1）用户走进屏幕，人脸识别到人物走进，开始进入对话模式，开始拾音

2）抓取到的声音，通过主控程序送到开放平台，通过ASR服务转成文字，客户也可以直接选择屏幕上的文字

3）开放平台通过第三方比如阿里云、科大讯飞知识库，将文字映射到对应的回答，比如客户
