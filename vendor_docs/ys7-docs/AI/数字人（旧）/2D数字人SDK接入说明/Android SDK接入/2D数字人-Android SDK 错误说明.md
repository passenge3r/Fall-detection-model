## 注意事项

1. 请勿设置 android:hardwareAccelerated="false"，关闭硬件加速之后，可能会导致视频流无法渲染;
2. sdk需要kotlin环境,请自行添加kotlin支持;
3. sdk需要AndroidX环境,请开启AndroidX后使用
4. 接入方需要自行获取及维护萤石云开放平台获取的AccessToken,确保数字人使用期间AccessToken均处于有效状态;
