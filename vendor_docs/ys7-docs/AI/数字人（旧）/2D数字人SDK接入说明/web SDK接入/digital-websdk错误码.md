# 错误码

> 本教程基于 1.x 版本

## 说明

如果返回结果中 code 值非 0，则表示调用 API 接口失败，返回示例：

```
{
"code": 10001,
"message": "accessToken 不能为空",
}
```

> 备注：  
> 1、API 调用，只会返回 API 调用错误码  
> 2、on('error')事件监听，会同时返回所有错误码类型。

## 错误码列表

### API 调用错误码

| code | 含义 | 措施 |
| --- | --- | --- |
| 10001 | accessToken 为空 | 填写正确的 accessToken |
| 10002 | accessToken 过期或异常 | 填写正确的 accessToken |
| 400101 | 代码执行异常 | 重新启动数字人，提供日志向我们反馈 |
| 400102 | 服务连接异常 | 重新启动数字人 |
| 400400 | 请求参数错误 | 检查接口传参是否填写正确 |
| 400404 | 相关应用不存在、用户 session 不存在 | 检查对应 token、appid、uid 是否正确 |
| 400412 | 用户无可用会话数或会话数超过最大限制 | 检查对应 token、appid、uid 是否正确 |
| 400500 | 服务错误 | 提供日志向我们反馈 |
| 400504 | 服务错误（超时） | 提供日志向我们反馈 |

### websocket 错误码

| code | 含义 | 措施 |
| --- | --- | --- |
| 100001 | 文本参数错误 | 字段格式、长度、类型、非空约束等错误，按照要求发送文本 |
| 100008 | 超过并发限制 | 请检查已用并发数和并发数上限 |
| 100012 | 请求过于频繁 | 控制请求发送频率 |
| 100014 | 并发配额不足 | 请检查并发配额是否充足或是否在有效期内 |
| 100015 | 数智人形象已过期 | 请检查有效期 |
| 110013 | 会话已关闭 | 请确认是否在驱动已关闭的流 |
| 110014 | 会话未就绪 | 请确认是否在驱动未就绪的流 |
| 110018 | 会话不存在 | 请检查会话状态是否已关闭或者会话未创建 |
