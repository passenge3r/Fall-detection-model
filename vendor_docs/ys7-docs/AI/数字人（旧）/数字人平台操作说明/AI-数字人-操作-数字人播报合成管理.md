# 2D数字人播报

> 本文档主要介绍 2D数字人在线合成播报视频

播报数智人适用于培训、媒体等多种内容生产场景，面向传媒、资管、教育等行业提供服务，支持定制专属的播报内容。通过使用数智人播报，可以提高人效，降低成本，迁移和复制成本低，受人为的情绪和自然条件影响小，可实现无误差播报。

平台播报数智人模块能力概述：

支持2D真人视频制作，可对文本内容、主播设置、视频设置等进行编辑，可对完成制作的视频、音频进行下载。

## 一、进入

![](https://resource.eziot.com/group1/M00/01/29/CtwQE2ZoUNKAdsjiAADdZnmacRc292.png)
图 进入开放平台控制台

进入控制台（[控制台地址](https://open.ys7.com/console/virtualman.html)）=》选择AI服务=》进入数字人tab

选择数字人播报，即可开始使用

说明：
数字人目前计费禁止吹线下计费，请联系产品经理或客服进行线下试用或购买服务。

## 二、新建视频

![](https://resource.eziot.com/group1/M00/01/28/CtwQEmZoUCSAYcs-AAD8O8iRBAg742.png)
图 控制台

进入控制台，这里会显示历史的视频，您可以选择新建视频，进入视频制作页面

## 三、制作

目前仅支持文本驱动制作数字人视频

**文本驱动**
通过输入文本即可生成口型自动匹配的数智人音视频内容。在文本中插入动作/表情标签，数智人可在对应的位置做出相应的表情和动作。

3.1 选择形象

![](https://resource.eziot.com/group1/M00/01/28/CtwQE2ZoUDGAbtBzAAPRgCV4lXU413.png)
图 可以选择已购买的数字人形象

3.2 制作声音

在数字人制作页面，输入声音，并选择音色，即可试听声音效果

![](https://resource.eziot.com/group1/M00/01/29/CtwQEmZoUnOAAjWIAA3VckcVYIk771.png)
图 输入声音

![](https://resource.eziot.com/group1/M00/01/28/CtwQEmZoUECAFbzJAAClpfspRwE448.png)
图 音色选择

3.3 选择背景
![](https://resource.eziot.com/group1/M00/01/28/CtwQE2ZoUFCAMfteABL5pXf6B5k342.png)
图 可选择对应背景图片，即可完成替换

![](https://resource.eziot.com/group1/M00/01/28/CtwQEmZoUG6AHoH_ABevaJifkZc969.png)
图 也可以选择纯色背景，或选择上传自定义图片进行替换

3.4 合成：管理视频

选择适合的背景、适合的声音后，即可开始合成

合成视频后，视频会显示排队中
