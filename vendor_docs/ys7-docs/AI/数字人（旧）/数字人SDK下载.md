## 3D 数字人

说明：

端渲染与云渲染的区别：萤石数字人是运行在GPU上的，因此我们提供两种渲染模式，

一种是端渲染，意思是电脑提供GPU（比如NVIDIA 4070显卡），本地直接驱动，不需要连接服务器即可驱动，适合一次性采购硬件，永久授权；

一种是云渲染，云渲染是数字人跑在GPU 服务器上，云端通过RTC/RTMP推流到客户端，客户端只起到接收流的作用，需要实时连接网络，适合客户端没有显卡的场景，比如手机，或信发屏等芯片处理能力较弱的场景，需要购买数字人并发授权。
