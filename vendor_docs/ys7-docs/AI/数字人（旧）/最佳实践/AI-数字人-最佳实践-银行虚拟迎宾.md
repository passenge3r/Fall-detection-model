# 银行虚拟迎宾

## 一、场景描述

目前虽然各个行业比如是金融行业的客户线上化已是不争的事实，但线下服务网点仍然不会消失。在数字化转型的浪潮下，线下网点大厅正朝着“智能化、无人化”方向发展，以全新的科技理念，优化网点服务标准、质量和效率，萤石数字人一体机产品结合商显大屏、麦克风阵列、USB相机打造全新的智能屏产品，帮助线下智慧网点比如银行网点实现迎宾、导航、咨询、互动等功能，逐渐成为智慧建设的标配，同时也是部分科技创新的试点项目。

## 二、痛点&需求

### 1.     痛点

1)     客户无法及时分流，客户办理业务流程中需多次接待和引导，工作人员无法做到一对一响应。

2)     人工服务的半径有限，人工的服务半径与深度不足，需要依托多媒体提高交互和表达能力。

3)     服务经验无法自动化积累，多岗位员工服务经验无法积累形成标准化的服务体系和先进经验。

### 2.     需求

#### **2.1   丰富虚拟迎宾像建模能力，打造专属客服形象**

一是形象音色方面，提供3D人像建模方式，并通过个性化音色定制匹配不同性别、年龄和风格的虚拟迎宾形象，支撑不同场景客服形象要求。二是动作驱动方面，借助文本、语音等多种唇形驱动方式，以及表情和动作的多维度编排能力，提升虚拟迎宾拟能力，保障虚拟迎宾交互的效果与体验。三是流畅体验方面，通过双向超低延迟数据传输、低模移动端渲染等技术，满足不同网络环境下虚拟迎宾模型形象交互动态的流畅体验要求。

#### **2.2   深度融合的智能后台**

通过语音识别、手势识别、情绪识别、人脸识别等智能感知技术实现多模融合感知能力，支持语音、手势、表情等多种交互方式，实现与客户纯自然沟通。二是全面分析客户交互的多模态数据信息，通过深度神经网络融合发现各维度信息中蕴含的潜在特征，充分洞察并精准识别客户需求，打造“比你更懂你” 的金融助手深层认知智能引擎，实现虚拟迎宾智慧大脑。

## 三、系统架构

### 1. 系统架构

系统架构分为两种：公有云部署及本地化部署混合云

（1）本地化部署/混合云：主要由前端大屏设备及服务端算法服务器组成，网点端大屏内置麦克风阵列以及USB相机，主要进行语音交互、人脸识别以及虚拟迎宾形象展示，中心服务器部署ASR、NLP、TTS模块（有提供混合云能力，混合云识别效果会更优，价格更低），实现智能语音交互。

（2）公有云部署：只需交付虚拟迎宾大屏设备，通过中控服务对接公有云语音识别接口，驱动虚拟迎宾进行表情、动作展示。

### 2.     数据架构

数据结构包括两个方面：语音数据和视频数据

![](https://resource.eziot.com/group1/M00/01/28/CtwQE2ZoJMCAJUweAAH5SHAgG4E445.png)

1. 语音数据

**输入层：**

通过大屏内置麦克风阵列进行拾音、降噪以及采集语音通过网络传输到语音服务模块

**分析层：**

ASR引擎接收前端原始语音，将语音转成文本，NLP引擎模块进行文本分析、意图理解以及检索问答，TTS引擎模块将文本转成语音并驱动虚拟迎宾引擎，进行动作、表情、语音交互。

**展示层：**

大屏应用展示分析层调用的图、文、视频等素材

2. 视频数据

视频数据

**输入层：**

通过大屏内置的USB相机采集视频流

**分析层：**

大屏安装人脸识别SDK进行人脸、属性、客流分析

**展示层：**

大屏前端界面切出一个展示模式进行客流、属性、人脸数据展示
