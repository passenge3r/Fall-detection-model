# 监控中心数字值班员方案

## “数字值班员”简介

将数字人WEB SDK嵌入银行的监控中心，形成银行的“数字值班员”，集成形象定制、声音定制、智能播报、视频生成、语音识别、语音互动、场景渲染等能力，实现告警播报、平台语音导航等功能，数字人形象和嵌入示意图如下

![](https://resource.eziot.com/group1/M00/01/28/CtwQEmZoK0WAWH_eAANWz5VdmdY615.png)

## 告警播报

当银行监控平台监测到有人闯入或异常时，监控平台产生告警消息并将告警消息传至萤石开放平台，后台处理将此告警消息转换成语音，通过语音驱动促使数字人进行告警消息的播报提醒：“XX支行加钞间门超时未关闭告警”、“XX支行有人闯入”等。

## 架构示意图

![](https://resource.eziot.com/group1/M00/01/28/CtwQE2ZoK-eAWejSAAB4gFn-H6M895.png)

如图：

（1） 通过类似“小海，小海”的命令将数字人唤醒；

（2） 指令设置：提前设置好指令，例如打开1号摄像机、打开2号摄像机等；

（3） 将数字人唤醒后，对它说：打开1号摄像机，云端会将语音转换成文字；

（4） 后台会自动识别语音文字，如果和指令吻合，会将这条指令传给银行监控平台。监控平台接受指令后，1号摄像机自动开启。开启后，银行监控平台会将1号摄像机已开启的消息传回萤石开放平台；

（5） 开放平台收到1号摄像机已开启的消息后，会驱使数字人进行播报：1号摄像机已开启。
