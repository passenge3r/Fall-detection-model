# 数字人 release note

### 2024-05

1. 2D播报数字人v1.1发布，支持倍速，支持手工上传背景
2. Android 交互SDK v2.1更新，网络不佳时进行静态图片展示，错误码更新等

### 2024-04

1. 发布展厅交互方案，支持在web端实现数字人+监控效果，支持监控取流、回放等能力基本指令
2. 3D数字人支持logo自定义

### 2024-03

1. 主控底层ASR更新，语音识别效果更好，并新增兼容方言、英文等
2. 2D Android 交互SDK v2.0更新，支持WebRTC，延迟降低至1s内
3. 发布医疗行业场景2D数字人+IoT解决方案，并在上海中医院、温州附医等医院落地

### 2024-01

1. 3D数字人新增小研形象，更换衣服材质与风格
2. 3D数字人支持多达16个动作

### 2023-11

1. 3D数字人支持3070显卡，降低系统运行内存占用
2. 2D Android 交互SDK v1.0更新，支持RTMP推流

### 2023-10

1. 更新3D数字人形象，支持更换衣服、发型
2. 发布主控v1.0，支持摄像头检测、支持语音交互等

### 2023-07

1. 发布3D数字人形象小萤，支持多套客服套装等

### 2023-04

1. 发布3D数字人星石，结合语音交互，提供客服场景下交互需求
2. 数字人支持5个动作
3. 发布Windows 端渲染方案，支持在GPU3070显卡上进行数字人驱动

### 2023-01

1. 结合海康竖屏大屏硬件，发布银行迎宾场景解决方案，并陆续在农业银行、农商行、邮储银行等20余家银行落地

### 2022-10

1. 发布3D数字人星石，支持在客服场景下进行语音交互
2. 支持云端服务器渲染 Android SDK
