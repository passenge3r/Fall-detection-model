# 头肩检测算法接口（POST）

---

## 前置条件

- 开通AI算法服务reasoning，如未开通可联系客服支持
- 需联系客服手动开通该接口调用权限

## 接口URL

https://open.ys7.com/api/service/intelligence/algo/analysis/head\_shoulder\_detection

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例值 |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放API访问令牌 | at.5so0llxxx\*\*\*\*\*rv-sixaipafg |

### Body

| 名称 | 类型 | 必填 | 描述 | 说明 |
| --- | --- | --- | --- | --- |
| requestId | string | N | 请求Id | 建议使用uuid，唯一标识请求 |
| taskType | string | Y | 算法类型 | 固定值：head\_shoulder\_detection |
| dataInfo | array<object> | Y | 请求的输入数据内容 | 图片相关入参集合 |
| -modal | string | Y | 数据模态 | 固定值：image（图片） |
| -type | string | Y | 数据类型 | 固定值：url（图片URL） |
| -data | string | Y | 图片地址 | 公网可访问的图片URL |
| dataParams | array<object> | Y | 请求的输入图片信息 | 图片属性及检测区域配置 |
| -modal | string | Y | 数据模态 | 固定值：image（图片） |
| -format | string | Y | 图片格式 | 如jpg、png等 |
| -img\_width | int | Y | 图片宽度 | 单位：像素 |
| -img\_height | int | Y | 图片高度 | 单位：像素 |
| -roi\_bboxes | List[List[float]] | Y | 感兴趣区域 | 矩形，使用归一化值；外层列表为区域框数量，内层列表为单个区域框（左上、右下2点坐标，奇数x，偶数y）；最多支持8个区域框 |

## 响应

### 返回数据结构

| 名称 | 类型 | 描述 | 说明 |
| --- | --- | --- | --- |
| meta | object | 响应公共信息 | 接口调用整体状态 |
| -code | int | 服务响应状态码 | 200为成功，其他为异常 |
| -message | string | 服务响应描述 | 成功为success，异常为具体原因 |
| -moreInfo | object | 扩展信息 | 暂无数据时返回空对象 |
| -success | boolean | 调用结果 | true为成功，false为失败 |
| data | object | 接口返回业务数据 | 头肩检测结果集合 |
| -requestId | string | 请求唯一ID | 与入参requestId一致 |
| -taskType | string | 算法类型 | 固定值：head\_shoulder\_detection |
| -images | list[Object] | 图片检测结果 | 单图片为单个元素的数组 |
| --frameIdx | int | 帧索引 | 图片帧标识，固定为0 |
| --imageHeight | int | 图片实际高度 | 单位：像素（服务解析的真实高度） |
| --imageWidth | int | 图片实际宽度 | 单位：像素（服务解析的真实宽度） |
| --contentAnn | Object | 结构化检测结果 | 头肩检测核心数据 |
| ---bboxes | List[object] | 检测框集合 | 每个元素为一个头肩检测框信息 |
| ----points | list[object] | 检测框坐标 | 包含左上、右下两个点，各点含x/y归一化坐标 |
| ----care | int | 关注标识 | 固定值：1 |
| ----weight | float | 检测置信度 | 0-1之间，值越高置信度越强 |
| ----negflag | int | 否定标识 | 固定值：0 |
| ----index | int | 检测框索引 | 从0开始的自增序号 |
| ----tagInfo | Object | 检测标签信息 | 检测目标类型标识 |
| -----tag | String | 检测目标标签 | 固定值：head\_shoulder（头肩） |

### 错误码说明

| 错误码 | 错误信息 | 解决方案 |
| --- | --- | --- |
| 10001 | accessToken不能为空 | 检查请求Header中是否携带accessToken，确保参数非空 |
| 10002 | accessToken过期或异常 | 重新获取有效的accessToken，检查令牌是否过期/填写错误 |
| 60202 | 参数解析错误 | 检查请求Body的JSON格式是否合法，入参类型/必填项是否符合要求 |
| 60203 | 未开通相关服务 或 该服务仅限灰度用户使用 | 联系萤石客服开通头肩检测算法服务，确认是否在灰度白名单内 |
| 60206 | 并发数超限 | 降低接口调用并发量，或联系客服提升并发限额 |
| 60205 | 服务内部错误 | 检查入参是否合法，稍后重试；若持续报错联系萤石技术支持 |
