## 人员计数算法接口

- 接口功能

   人员计数算法接口

- 请求地址

`https://open.ys7.com/api/service/intelligence/human/counting/detect`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Body | requestId | String | 请求Id，请使用uuid | Y |
| Body | stream | Boolean | 默认false，即同步返回结果 | Y |
| Body | dataInfo | Array<Object> | 请求的输入数据内容 | Y |
| Body | dataInfo.modal | String | 数据模态：image | Y |
| Body | dataInfo.type | String | 数据类型: url,base64 | Y |
| Body | dataInfo.data | String | 数据 | Y |
| Body | confidence | Int | 置信度，范围[0,100]，为空时将使用服务端推荐的置信度（60），置信度越高，识别结果越精准，但可能存在漏报，默认不填 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/intelligence/human/counting/detect' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{
    "requestId": "1212121212121212",
    "stream": false,
    "dataInfo": [
        {
            "modal": "image",
            "type": "url",
            "data": "https://example.com/image.jpg"
        }
    ],
    "confidence": 5
}'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "number": 3
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| meta.code | Int | 响应状态码 |
| meta.message | String | 响应状态描述 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 响应数据 |
| data.number | Int | 人数 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 10002 | accessToken过期或异常 |  |
| 60203 | 未开通相关服务 |  |
| 60210 | 图片数据错误 |  |
| 500 | 服务器异常 |  |
| 429 | 请求过于频繁 |  |
