## 删除人脸集合

- 接口功能

   该接口用于提供删除人脸识别的人脸集合，需要注意人脸集合删除会将注册到此人脸集合的人脸全部注销。子账户token请求所需最小权限：无。

- 请求地址

`https://open.ys7.com/api/lapp/intelligence/face/set/delete`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Body | accessToken | String | 授权过程获取的accessToken | Y |
| Body | setTokens | String | 人脸集合的唯一标识，多个以英文逗号分割，一次最多支持 10 个 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/intelligence/face/set/delete' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'setTokens=sdfasdf'
```
