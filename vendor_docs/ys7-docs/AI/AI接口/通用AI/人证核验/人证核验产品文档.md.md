# **1. 产品简介**

## **1.1 什么是人证核验**

萤石开放平台的人证核验服务对接公安一所权威数据源，统一使用法定证件制证数据作为比对，为各行业身份信息安全提供服务。

## **1.2 功能概览**

人证核验产品包含身份证二要素认证和身份证二要素+人像核验两种模式。

| 功能名称 | 功能描述 |
| --- | --- |
| 身份证二要素认证 | 可通过输入身份证号以及对应姓名，由公安库认证，返回是否一致信息。 |
| 身份证二要素认证+人像核验 | 在比对身份证号与对应姓名是否一致外，核对人像信息是否与身份证 |

## **1.3 产品优势**

- 安全性：萤石云可信身份认证服务，采用了服务于智能终端应用的公钥体制文件，存储没有介质要求，遗失后不会造成隐私泄露，也无法单独使用进行身份认证，没有身份被盗用的风险。
- 权威性：平台统一使用法定证件制证数据作为对比源，确保信息源权威性，比对结果权威、可信。
- 法理性：身份证的应用以《居民身份证法》和各行各业条例法规为支撑，适用于全设备终端全行业的身份认证。
- 合法性：身份认证服务对接公安一所，方案是国家方案，由中央网信办立项研究，国家发改委支持建设，公安部统一组织实施，公安部第一研究所承建。

## **1.4 数据与并发**

- 物理安全：运营商骨干节点机房
- 网络能力：三大电信运营商的线路接入
- 并发能力：每秒 2 万+
- 数据数量：全国 50 亿原子数据
- 数据品种：身份证融合脱敏数据

# **5.功能详情**

集成方可根据实际场景要求，选择不同的错误接收率，对应的相似度阈值越低，通过率越高

| 错误接受率 | 接口返回相似度阈值 |
| --- | --- |
| 1%（百分之一） | 50 |
| 0.1%（千分之一） | 60 |
| 0.01%（万分之一） | 70 |
| 0.001%（十万分之一） | 80 |
| 0.0001%（百万分之一） | 90 |

平台建议使用一般选择万分之一错误率，即相似度超过 70 认为是同一人，可通过检测，特殊时期可动态调整
