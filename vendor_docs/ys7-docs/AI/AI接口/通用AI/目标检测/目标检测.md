## 目标检测

- 接口功能

   对多种物体提供AI检测功能

- 请求地址

`https://open.ys7.com/api/lapp/intelligence/reasoning/v1/image`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | accessToken | Y |
| Body | taskType | String | 固定值，为 open\_vocabulary\_object\_detection | Y |
| Body | dataInfo | String | 填写待分析的图片参数（必填）、需要被检测到的目标参数（必填，至少填写一组）。 | Y |
| Body | dataInfo[].modal | String | 数据模态的类型，待分析的图片固定为"image"，需要被检测的目标固定为"text"。 | Y |
| Body | dataInfo[].type | String | 数据类型。modal为"image"：url（大文件时使用，data中填url地址）、base64（小文件时使用，data中填写文件base64编码后的文本）。modal为"text"：raw（固定使用此值，data中填写目录"可检测的物体"中的枚举值）。 | Y |
| Body | dataInfo[].data | String | 根据"type"的值，填写待分析的数据。可被此接口检测到的目标，枚举值见"可检测的物体"。 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/lapp/intelligence/reasoning/v1/image' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'accessToken=at.xxxxx' \
--data-urlencode 'taskType=open_vocabulary_object_detection' \
--data-urlencode 'dataInfo=[
    {
        "data": "https://img1.baidu.com/it/u=188255477,1072094173&fm=253&fmt=auto&app=138&f=JPEG?w=500&h=375",
        "type": "url",
        "modal": "image"
    },
    {
        "data": "球",
        "type": "raw",
        "modal": "text"
    },
    {
        "data": "狗",
        "type": "raw",
        "modal": "text"
    }
]'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| msg | String | 响应信息 |
| code | String | 响应编码 |
| data | Object | 响应数据 |
| data.imageHeight | Integer | 图片高度 |
| data.imageWidth | Integer | 图片宽度 |
| data.contentAnn | Object | 分析结果 |
| data.contentAnn.bboxes | Array<Object> | 检测框信息，多个目标会有多个框内容 |
| data.contentAnn.bboxes[].points | Array<Object> | 坐标点集合,第一个点代表左上的坐标点，第二个代表右下的坐标点位，以此形成一个矩形区域 |
| data.contentAnn.bboxes[].points[].x | Number | x点，默认宽度为1，按比例缩放 |
| data.contentAnn.bboxes[].points[].y | Number | y点，默认高度为1，按比例缩放 |
| data.contentAnn.bboxes[].weight | Number | 检测置信度，代表算法检测出来的可信程度，最高为1 |
| data.contentAnn.bboxes[].index | Integer | 检测框编号，多个目标会有多个框内容 |
| data.contentAnn.bboxes[].tagInfo | Object | 检测框tag |
| data.contentAnn.bboxes[].tagInfo.tag | String | tag的key，参照下方可检测的物体 |
| data.contentAnn.bboxes[].tagInfo.labels | Object | 对key的描述 |
| data.contentAnn.textInfos | Object | 检测结果文字描述 |
| requestId | String | 请求id |
