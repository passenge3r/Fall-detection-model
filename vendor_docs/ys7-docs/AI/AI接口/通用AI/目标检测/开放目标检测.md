# 开放目标分析算法接口（POST）

---

## 前置条件

- 开通AI算法服务reasoning，如未开通可联系客服支持
- 需联系客服手动开通该接口调用权限

## 接口URL

https://open.ys7.com/api/service/intelligence/algo/analysis/open\_vocabulary\_object\_detection

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放API访问令牌 |  |

### body

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| requestId | string | N | 请求Id，请使用uuid |  |
| stream | boolean | Y | 必传false |  |
| dataInfo | array<object> | Y | 请求的输入数据内容 |  |
| -modal | string | Y | 数据模态：image、text |  |
| -type | string | Y | 数据类型: raw、base64、url |  |
| -data | object | Y | 当数据类型是url时，存放url路径；是base64或者raw时存放数据 |  |
| dataParams | array<object> | N | 请求的输入图片信息 |  |
| -modal | string | Y | 数据模态：image、text |  |
| -format | int | Y | 数据格式，图像默认jpg，非jpg必填，文本默认utf-8，非utf-8必填，视频默认mp4，非mp4必填，音频默认pcm，非pcm必填 |  |
| -roi\_bboxes | object | Y （text不需要此字段） | 感兴趣区域，矩形，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个感兴趣区域框，奇数位置为x坐标，偶数位置为y坐标，感兴趣区域框用2点（左上，右下）表示 |  |

### 输入文本规则

目前只支持3种任务：多类目标检测、单类（非描述）目标检测和单类（描述）目标检测。输入文本规则如下表所示，非表格中的文本输入会返回入参错误。

| 名称 | 类型 | 必填 |
| --- | --- | --- |
| 多类目标检测 | 猫，狗，人，汽车，等等 | 类别的名称必须是单个名词，类别之间必须用“，”隔开，建议使用中文 |
| 单类（非描述）目标检测 | 人 | 建议使用中文 |
| 单类（描述）目标检测 | 穿红衣服的人 | 建议使用中文 |

### 输入ROI规则

支持1个ROI设置，示例：[[0.0,0.0,1.0,1.0]]表示全图。

### 请求示例

```
--header 'accessToken: xxxxxxxxxxxxxxx' \
--header 'User-Agent: Apifox/1.0.0 (https://apifox.com)' \
--header 'Content-Type: application/json' \
--data-raw {

  "taskType": "open_vocabulary_object_detection",
  "mark": true,

      "modal": "image",

    },

    }
  ],

 {
            "modal": "image",

        }

}'
```

## 响应

### 返回数据

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| meta | object | 响应信息 |  |
| -code | int | 服务响应状态码 |  |
| -message | string | 服务响应状态描述 |  |
| -moreInfo | object | 服务响应描述 |  |
| data | object | data |  |
| -taskType | string | 算法类型，open\_vocabulary\_object\_detection |  |
| -requestId | string | 请求唯一ID |  |
| images | list[Object] | 图片结果 |  |
| contentAnn | Object | 结构化分析结果 |  |
| bboxes | List[object] | 检测数据结果 |  |
| points | list[List[float] | 检测框，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个检测框，奇数位置为x坐标，偶数位置为y坐标，检测框可以用2点（左上，右下）表示 |  |
| weight | float | 置信度 |  |
| tagInfo | Object | 标签信息 |  |
| tag | String | 汽车 |  |
| labels | List[object] | 二维字符串列表，label是key的value |  |
