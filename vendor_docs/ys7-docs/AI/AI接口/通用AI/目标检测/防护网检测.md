## 防护网检测

- 接口功能

   防护网检测

- 请求地址

`https://open.ys7.com/api/service/intelligence/algo/analysis/housefitup_protection_detection`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| body | requestId | string | 请求Id，请使用uuid | N |
| body | stream | boolean | 必传false | Y |
| body | dataInfo | array<object> | 请求的输入数据内容 | Y |
| body | -modal | string | 数据模态：image，：图片 | Y |
| body | -type | string | 数据类型: url | Y |
| body | -data | object | url地址 | Y |
| body | dataParams | array<object> | 请求的输入图片信息 | N |
| body | -modal | string | 数据模态：image，：图片 | Y |
| body | -img\_width | int | 图片宽度 | Y |
| body | -img\_height | object | 图片高度 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/intelligence/algo/analysis/housefitup_protection_detection' \
--header 'accessToken: xxxxxxxxxxxxxxx' \
--header 'User-Agent: Apifox/1.0.0 (https://apifox.com)' \
--header 'Content-Type: application/json' \
--data-raw '{
  "requestId":"20ef9933-4d16-437e-bef6-dbf50c1e2665",
  "dataInfo": [
    {
     "modal": "image",
     "type": "url",
     "data":"https://pic.nximg.cn/file/20230322/34543442_144937882107_2.jpg"
    }
  ],
  "dataParams": [
    {
      "modal": "image",
      "img_width": 960,
      "img_height": 540
    }
  ]
}'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | 响应信息 |
| -code | int | 服务响应状态码 |
| -message | string | 服务响应状态描述 |
| -moreInfo | object | 服务响应描述 |
| data | object | data |
| -taskType | string | 算法类型，housefitup\_protection\_detection |
| -requestId | string | 请求唯一ID |
| images | list[Object] | 图片结果 |
| contentAnn | Object | 结构化分析结果 |
| bboxes | List[object] | 检测数据结果 |
| points | list[List[float] | 检测框，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个检测框，奇数位置为x坐标，偶数位置为y坐标，检测框可以用2点（左上，右下）表示 |
| weight | float | 置信度 |
| tagInfo | Object | 标签信息 |
| tag | String | no\_protection(无防护)， glass\_protection(玻璃防护)， iron\_protection(铁网防护)， net\_protection(网兜防护) |
| labels | List[object] | 二维字符串列表，label是key的value |
