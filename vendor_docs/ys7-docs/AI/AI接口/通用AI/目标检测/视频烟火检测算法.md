# 提供视频烟火检测算法接口（POST）

> 分析视频中的烟火内容，并通过云信令异步推送分析结果

---

## 前置条件

- 开通云信令，云信令开通参考本文档 **算法分析结果**目录
- 开通AI算法服务reasoning，如未开通可联系客服支持

## 接口URL

https://open.ys7.com/api/service/intelligence/algo/analysis/video\_firesmoke\_detection

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放API访问令牌 |  |

### body

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| requestId | string | N | 请求Id，请使用uuid |  |
| stream | boolean | Y | 必传true |  |
| dataInfo | array<object> | Y | 请求的输入数据内容 |  |
| -modal | string | Y | 数据模态：video，：视频 |  |
| -type | string | Y | 数据类型: url |  |
| -data | object | Y | url地址,注意:视频太大会分析失败，建议在20Mb内 |  |

### 请求示例

```
curl --location 'https://open.ys7.com/api/service/intelligence/algo/analysis/video_firesmoke_detection' \
--header 'accessToken: at.9u15ez4p2rl00vko2fyxp64' \
--header 'Content-Type: application/json' \
--data '{
    "requestId": "",
    "stream": true,
    "dataInfo":  [
         {
            "modal": "video",
            "type": "url",
            "data":  "https://domain/mock.mp4"
        }
    ]
}'
```

# 算法分析结果

> 前提条件: 在消息推送控制台开通消息推送服务 [消息推送服务开通操作手册](https://open.ys7.com/help/566)，并联系客服，后台开通AI算法分析结果消息类型：ys.open.ai.resultData，算法分析结果是通过云信令消息异步推送的

## AI算法分析结果消息

- ### **header说明**

| **字段名** | **类型** | **描述** |
| --- | --- | --- |
| **header** | **Object** | **设备信息** |
| type | String | 消息类型：ys.open.ai.resultData表示AI算法分析结果消息 |
| deviceId | String | 设备序列号，UUID |
| messageId | String | 消息唯一ID |
| messageTime | Long | 消息发送时间 |

- ### **body说明**

| **名称** | **类型** | **描述** |
| --- | --- | --- |
| **body** | **Object** | **算法分析的消息** |
| code | int | 错误码 |
| msg | String | 错误提示信息 |
| requestId | String | 请求Id |
| taskType | String | 算法类型，video\_firesmoke\_detection，视频烟火检测算法 |
| images | list[Object] | 图片结果 |
| images[i].frame\_idx | Integer | 帧索引，单帧任务时，可默认为0，多帧和视频分析任务时，根据帧索引区分不同帧之间的结果 |
| images[i].image\_height | Integer | 图像高度 |
| images[i].image\_width | Integer | 图像高度 |
| images[i].contentAnn | Object | 结构化分析结果 |
| images[i].content\_ann.bboxes | list[list[float]] | 检测框，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个检测框，奇数位置为x坐标，偶数位置为y坐标，检测框可以用2点（左上，右下）表示，其他情况下默认为顺时针依次首尾相连所组成的区域，可能是四边形或者多边形 |
| images[i].content\_ann.weights | list[float] | 一维浮点型列表，对应于每个bbox检测框或分类结果的权重值，缺省状态下为1.0 |
| images[i].content\_ann.tags | list[float] | 检测框tag，比如烟火为“firesmoke”, 烟为"smoke"，火为"fire" |
| images[i].content\_ann.key | list[string] | 二维字符串列表，外层对应检测框数量，内层是tag对应属性key的数量 |
| images[i].content\_ann.labels | list[list[string]] | 二维字符串列表，label是key的value |
| images[i].content\_ann.labels\_weights | list[list[float]] | 二维浮点型列表，描述标签的置信度，默认情况下全部为1.0 |
