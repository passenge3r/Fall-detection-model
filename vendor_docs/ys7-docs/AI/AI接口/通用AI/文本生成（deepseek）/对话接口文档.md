## 对话接口

- 接口功能

   对话接口

- 请求地址

`https://open.ys7.com/api/service/open/ezviz/v1/chat/completions`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌, 萤石令牌和账号授权token有其一即可 | N |
| header | Authorization | String | Bearer 账号授权TOKEN | N |
| body | messages | Array | 对话的消息列表。 | Y |
| body | -content | String | 消息的内容 | Y |
| body | -role | String | 该消息的发起角色，其值为 user和assistant必须成对出现，user在前，assistant在后。 | Y |
| body | model | String | 使用的模型的 ID， [deepseek-v3] | N |
| body | stream | String | 流式输出，默认false | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/ezviz/v1/chat/completions' \
--header 'accessToken: at.xxxxx' \
--header 'Authorization: Bearer TOKEN' \
--header 'Content-Type: application/json' \
--data-raw '{"messages":[{"role":"user","content":"hello"}], "model":"deepseek-v3", "stream":false}'
```

- 返回数据

```
{
    "id": "930c60df-bf64-41c9-a88e-3ec75f81e00e",
    "choices": [
        {
            "finish_reason": "stop",
            "index": 0,
            "message": {
                "content": "Hello! How can I help you today?",
                "role": "assistant"
            }
        }
    ],
    "created": 1705651092,
    "model": "deepseek-v3",
    "object": "chat.completion",
    "usage": {
        "completion_tokens": null,
        "prompt_tokens": null,
        "total_tokens": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| id | String | 该对话的唯一标识符。 |
| choices | Array | choices |
| -finish\_reason | String | 完成原因。正在生成时为null，生成结束时如果由于停止token导致则为stop。 |
| -index | Int | 该 completion 在模型生成的 completion 的选择列表中的索引。 |
| -message | Object | 模型生成的 completion 消息。 |
| --content | String | 该 completion 的内容。 |
| --role | String | 生成这条消息的角色。 |
| created | Int | 创建聊天完成时的 Unix 时间戳（以秒为单位）。 |
| model | String | 生成该 completion 的模型名。 |
| object | String | 对象的类型, 其值为 chat.completion |
| usage | Object | usage |
| -completion\_tokens | Int | 模型 completion 产生的 token 数。 |
| -prompt\_tokens | Int | 用户 prompt 所包含的 token 数 |
| -total\_tokens | Int | 该请求中，所有 token 的数量（prompt + completion）。 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 400 | 参数错误 |  |
| 401 | 用户认证失败 |  |
