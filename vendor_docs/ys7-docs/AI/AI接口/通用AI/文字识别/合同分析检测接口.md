## 合同分析检测接口

- 接口功能

   合同检测分析算法接口。前置条件：开通AI算法服务reasoning，如未开通可联系客服支持；需联系客服手动开通该接口调用权限

- 请求地址

`https://open.ys7.com/api/service/intelligence/contract`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | requestId | String | 请求Id，请使用uuid | N |
| body | async | String | 必传true | Y |
| body | taskType | String | 智能任务类型：contract\_electronicization：合同电子化 contract\_info\_extraction：合同信息提取 | Y |
| body | dataInfo | Array | 请求的输入数据内容 | Y |
| body | -modal | String | 数据模态：document：文件，支持docx、doc、pdf；image：图片，格式支持jpg、jpeg、png、bmp | Y |
| body | -type | String | 数据类型: url：大文件时使用；base64：小文件时使用 | Y |
| body | -data | Object | url地址或base64编码文本 | Y |
| body | dataParams | Array | 请求的输入图片信息 | N |
| body | -modal | String | 数据模态：image：图片 document：文件 | Y |
| body | -img\_width | Int | 图片宽度 | Y |
| body | -img\_height | Int | 图片高度 | Y |
| body | -format | String | document：文件，支持docx、doc、pdf；image：图片，格式支持jpg、jpeg、png、bmp | Y |
| body | outputParams | Array | 输出参数信息 | N |
| body | -modal | String | text：文本文件 | Y |
| body | -type | String | raw | Y |
| body | -need\_key\_list | Array | 当taskType=contract\_info\_extraction时必传入，需要提取的内容名称列表，支持最大长度25 | Y |
| body | -output\_type\_range | Array | 当taskType=contract\_electronicization时可选传入，限定提取内容的范围，列表长度[1,50] | Y |
| body | --type\_name | String | 字符长度[1,128] | Y |
| body | --type\_keywords | Array | 列表长度[1,20] | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/intelligence/contract' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{ \
    "requestId": "uuid", \
    "async": true, \
    "taskType": "contract_electronicization", \
    "dataInfo": [{"modal": "image", "type": "url", "data": "https://example.com/image.png"}], \
    "dataParams": [{"modal": "image", "img_width": 1920, "img_height": 1080, "format": "png"}], \
    "outputParams": [{"modal": "text", "type": "raw", "output_type_range": [{"type_name": "买卖合同", "type_keywords": ["买卖","购买"]}]}] \
}'
```

- 返回数据

```
{
    "meta": {
        "msg": "操作成功",
        "code": "200"
    },
    "data": null
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| -code | Int | 服务响应状态码 |
| -message | String | 服务响应状态描述 |
| -moreInfo | Object | 服务响应描述 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 10002 | accessToken过期或异常 |  |
| 60202 | 参数解析错误 |  |
| 60203 | 未开通相关服务 或 该服务仅限灰度用户使用 |  |
| 60206 | 并发数超限 |  |
| 60205 | 服务内部错误 |  |
