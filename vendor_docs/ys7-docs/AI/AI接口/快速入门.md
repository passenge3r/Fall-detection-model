# 萤石云AI产品快速入门指南

## 🚀 三步快速接入

1. **服务开通**

   - 登录[开发者平台](https://open.ys7.com)
   - 完成企业实名认证（需营业执照）
   - 在「AI服务中心」开通所需服务：
     - 联系客服进行开通
2. **获取凭证**

   ```
   # 获取accessToken（有效期7天）
   curl -X POST "https://open.ys7.com/api/lapp/token/get" \
        -d "appKey=YOUR_APP_KEY" \
        -d "appSecret=YOUR_APP_SECRET"
   ```
