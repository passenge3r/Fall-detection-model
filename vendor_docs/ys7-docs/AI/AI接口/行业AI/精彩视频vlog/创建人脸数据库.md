## 创建人脸数据库

- 接口功能

   创建人脸数据库

- 请求地址

`https://open.ys7.com/api/service/open/scenic/spot/vlog/collection`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | projectId | String | 项目id，长度0-31 | Y |
| body | expireTime | String | 参考格式: 2025-12-28 23:59:59 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/scenic/spot/vlog/collection' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'projectId=' \
--data-urlencode 'expireTime='
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": "9f74b527ce5b4b9b86f324bb6dafd9fb_projectId_boyan0004"
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| -code | Int | code |
| -message | String | message |
| -moreInfo | Object | moreInfo |
| data | String | data |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 500 | 服务器异常 |  |
| 400 | 参数错误 |  |
