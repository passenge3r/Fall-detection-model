## 万鸟识别接口

- 接口功能

   万鸟识别接口

- 请求地址

`https://open.ys7.com/api/service/intelligence/algo/analysis/birds_recognition`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| body | requestId | string | 请求Id，请使用uuid | N |
| body | stream | boolean | 必传false | Y |
| body | dataInfo | array<object> | 请求的输入数据内容 | Y |
| body | -modal | string | 数据模态：image，：图片 | Y |
| body | -type | string | 数据类型: url | Y |
| body | -data | object | url地址 | Y |
| body | dataParams | array<object> | 请求的输入图片信息 | N |
| body | -modal | string | 数据模态：image，：图片 | Y |
| body | -format | string | 数据模态：jpg,jpeg,png | Y |
| body | -img\_width | int | 图片宽度 | Y |
| body | -img\_height | object | 图片高度 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/intelligence/algo/analysis/birds_recognition' \
--header 'accessToken: at.0t47cm38d1etcbdsbpfshz9a4zdvbfuy-5c1aap2ixxxbkmy-vx693hvt7' \
--header 'User-Agent: Apifox/1.0.0 (https://apifox.com)' \
--header 'Content-Type: application/json' \
--data-raw '{
  "taskType": "birds_detection",
  "dataInfo": [
     {
      "data": "https://xxx",
      "type": "url",
      "modal": "image"
    }
  ],
  "dataParams": [
		{
			"modal": "image",
            "format":"png",
			"img_width": 960,
			"img_height": 540
		}
	]
}'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | 响应信息 |
| -code | int | 服务响应状态码 |
| -message | string | 服务响应状态描述 |
| -moreInfo | object | 服务响应描述 |
| data | object | data |
| -taskType | string | 算法类型，birds\_recognition |
| -requestId | string | 请求唯一ID |
| images | list[Object] | 图片结果 |
| contentAnn | Object | 结构化分析结果 |
| bboxes | List[object] | 检测数据结果 |
| points | list[List[float] | 检测框，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个检测框，奇数位置为x坐标，偶数位置为y坐标，检测框可以用2点（左上，右下）表示 |
| weight | float | 置信度 |
| tagInfo | Object | 标签信息 |
| tag | String | bird，鸟 |
| labels | List[object] | 二维字符串列表，label是key的value， |
| key | String | category,种类，现在返回top5的匹配结果 |
| label | String | 鸟类名称 |
| labelWeight | float | 置信度 |
