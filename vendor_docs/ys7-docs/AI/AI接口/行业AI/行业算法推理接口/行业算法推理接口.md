# 行业算法推理接口

https://open.ys7.com/api/lapp/intelligence/reasoning/{algoId}

接口名称：行业算法推理接口

接口描述：通过不同的算法ID调用不同的算法进行分析，algoId处填写不同的行业算法id

## 请求

### 请求方式

POST

### 请求头（header）

| 名称 | value | 描述 |
| --- | --- | --- |
| content-type | application/x-www-form-urlencoded | 描述 |
| accessToken | String | 用户访问令牌 |

### 输入参数

| 名称 | 数据类型 | 描述 | 是否必须 |
| --- | --- | --- | --- |
| dataType | Int |  |  |
| image | String |  |  |

### 输出参数

| 名称 | 数据类型 | 描述 | 是否必须 |
| --- | --- | --- | --- |
| code | String | 云端部署ID | 是 |
| msg | String |  | 是 |
| data | array |  | 是 |

  

#### data字段说明

| 名称 | 数据类型 | 参数说明 |
| --- | --- | --- |
| errorcode | int | 单帧分析结果: 0-成功 |
| width | String | 帧宽度 |
| height | String | 帧高度 |
| targets | array | 单帧分析内容 |
| aitype | int | 算法类型：1-检测，2-分类 |

  

#### targets字段说明

| 名称 | 数据类型 | 参数说明 |
| --- | --- | --- |
| obj | object | 检测类推理结果 |
| properties | array | 分类、属性推理结果 |

  

#### obj字段说明

| 名称 | 数据类型 | 参数说明 |
| --- | --- | --- |
| modelID | String | 模型ID， 公有模型不暴露该字段 |
| confidence | int | 置信度：取值范围[0, 1000] |
| rect | object | 目标矩形框.取值范围[0,1]。其中，x为目标矩形框左上角横坐标，y为目标矩形框左上角纵坐标，w为目标矩形框横向长度，h为目标矩形框纵向高度。注：:x、y、w、h指的是相对坐标。x、w是指相对于图片宽度（即协议体中的width）的比例，y、h是指相对于图片高度（即协议体中的height）的比例 |
| type | Int | 目标类型 |
| tag | string | 目标类型对应的含义 |
| polygon | array | 多边形框 |

  

#### properties字段说明

| 名称 | 数据类型 | 参数说明 |
| --- | --- | --- |
| classify | object | 分类信息 |

  

#### classify字段说明

| 名称 | 数据类型 | 参数说明 |
| --- | --- | --- |
| attrType | int | 分类标签 |
| attrValue | string | 分类标签 |
| attrConf | int | 分类置信度 |

  

#### 响应码

| 响应码 | 描述 |
| --- | --- |
| 200 | 请求成功 |
| 60801 | 算法没有识别出结果 |
| 60802 | 检测成功，但没有搜索到结果 |
