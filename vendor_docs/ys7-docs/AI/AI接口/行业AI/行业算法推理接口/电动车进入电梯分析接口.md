## 电动车进入电梯分析接口

- 接口功能

   电梯进入电动车分析算法接口，用于检测图片中电动车进入电梯的情况。前置条件：需开通AI算法服务reasoning，需联系客服手动开通该接口调用权限。

- 请求地址

`https://open.ys7.com/api/service/intelligence/algo/analysis/elevator_detection`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | requestId | String | 请求Id，请使用uuid | N |
| body | stream | Boolean | 必传false | Y |
| body | dataInfo | String | 请求的输入数据内容，JSON数组格式 | Y |
| body | -modal | String | 数据模态：image，即图片 | Y |
| body | -type | String | 数据类型：url | Y |
| body | -data | String | url地址 | Y |
| body | dataParams | String | 请求的输入图片信息，JSON数组格式 | N |
| body | -modal | String | 数据模态：image，即图片 | Y |
| body | -img\_width | Int | 图片宽度 | Y |
| body | -img\_height | Int | 图片高度 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/intelligence/algo/analysis/elevator_detection' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{
  "dataInfo": [
    {
      "data": "https://example.com/image.jpg",
      "type": "url",
      "modal": "image"
    }
  ],
  "dataParams": [
    {
      "modal": "image",
      "img_width": 1280,
      "img_height": 720
    }
  ]
}'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| -code | Int | 服务响应状态码 |
| -message | String | 服务响应状态描述 |
| -moreInfo | Object | 服务响应描述 |
| data | Object | 返回数据 |
| -taskType | String | 算法类型，elevator\_detection |
| -requestId | String | 请求唯一ID |
| images | List[Object] | 图片结果 |
| contentAnn | Object | 结构化分析结果 |
| bboxes | List[Object] | 检测数据结果 |
| points | List[List[Float]] | 检测框，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个检测框，奇数位置为x坐标，偶数位置为y坐标，检测框可以用2点（左上，右下）表示 |
| weight | Float | 置信度 |
| tagInfo | Object | 标签信息 |
| tag | String | electromobile\_head，电动车进电梯 |
