## 离岗检测分析

- 接口功能

离岗分析算法接口。前置条件：开通AI算法服务reasoning，如未开通可联系客服支持；需联系客服手动开通该接口调用权限

- 请求地址

`https://open.ys7.com/api/service/intelligence/algo/analysis/leave_position_detection`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | requestId | String | 请求Id，请使用uuid | N |
| body | stream | String | 必传false | Y |
| body | dataInfo | Array | 请求的输入数据内容 | Y |
| body | -modal | String | 数据模态：image，图片 | Y |
| body | -type | String | 数据类型: url | Y |
| body | -data | Object | url地址 | Y |
| body | dataParams | Array | 请求的输入图片信息 | N |
| body | -modal | String | 数据模态：image，图片 | Y |
| body | -img\_width | Int | 图片宽度 | Y |
| body | -img\_height | Int | 图片高度 | Y |
| body | -roi\_bboxes | Array | 感兴趣区域，矩形，使用归一化值，外层列表长度表示有多少个区域框，内层一个列表表示一个感兴趣区域框，奇数位置为x坐标，偶数位置为y坐标，感兴趣区域框用2点（左上，右下）表示。最多支持8个区域框 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/intelligence/algo/analysis/leave_position_detection' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/json' \
--data-raw '{ \
  "requestId": "20ef9933-4d16-437e-bef6-dbf50c1e2665", \
  "taskType": "leave_position_detection", \
  "mark": true, \
  "dataInfo": [{"modal": "image", "type": "url", "data": "https://example.com/image.jpg"}], \
  "dataParams": [{"modal": "image", "img_width": 960, "img_height": 540, "roi_bboxes": [[0.25, 0.25, 0.75, 0.75]]}] \
}'
```

```

    "meta": {

    "data": {
        "requestId": "20ef9933-4d16-437e-bef6-dbf50c1e2665",

        "audio": null,

```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| -code | Int | 服务响应状态码 |
| -message | String | 服务响应状态描述 |
| -moreInfo | Object | 服务响应描述 |
| data | Object | data |
| -taskType | String | 算法类型，leave\_position\_detection |
| -requestId | String | 请求唯一ID |
| images | Array | 图片结果 |
| contentAnn | Object | 结构化分析结果 |
| bboxes | Array | 检测数据结果 |
| points | Array | 检测框，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个检测框，奇数位置为x坐标，偶数位置为y坐标，检测框可以用2点（左上，右下）表示 |
| weight | String | 置信度 |
| tagInfo | Object | 标签信息 |
| tag | String | person |
| labels | Array | 二维字符串列表，label是key的value |
| key | String | behavior,行为 |
| label | String | leave\_position，离岗 |
| labelWeight | String | 置信度 |
