## 查询种猪生命特征

- 接口功能

   查询种猪生命特征

- 请求地址

`https://open.ys7.com/api/service/ai/oestrus/feature`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| header | deviceSerial | string | 设备序列号 | Y |
| body | queryType | int | 查询特征类型 0：查询活动、心跳、呼吸、活动以及活动均值， 1：查询活动、心跳、呼吸、活动 2：查询活动、心跳、呼吸、活动均值 3：查询起卧 | Y |
| body | startTime | string | 查询起始时间 格式：yyyy-MM-dd HH:mi:ss 只能查询24小时数据 | Y |
| body | endTime | string | 查询结束时间 格式：yyyy-MM-dd HH:mi:ss | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/ai/oestrus/feature' \
--header 'accessToken: at.xxxxx'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | meta |
| -code | int | code |
| -message | string | message |
| -moreInfo | object | moreInfo |
| data | array<object> | data |
| -startTime | string | startTime |
| -endTime | string | endTime |
| -meanAct | number | 30秒内活动量的平均值 |
| -activity | array<number> | 活动量 |
| -heart | array<integer> | 心跳，长度为1 |
| -breath | array<integer> | 呼吸，长度为1 |
| -nanReason | array<integer> | 心跳、呼吸为空值的原因。0表示正常，1表示活动量大，2表示信号质量不好 |
| -isUp | array<integer> | 起卧，长度为1。1表示起，0表示卧 |
