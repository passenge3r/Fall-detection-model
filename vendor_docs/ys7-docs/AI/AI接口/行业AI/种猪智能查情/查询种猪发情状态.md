## 查询种猪发情状态

- 接口功能

   查询种猪发情状态

- 请求地址

`https://open.ys7.com/api/service/ai/oestrus/result`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| header | deviceSerial | String | 设备序列号 | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/ai/oestrus/result' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: BDXXXXX'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": 3
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta.code | Int | 状态码，200表示成功 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 更多信息 |
| data | Int | 发情状态值 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 404 | 资源不存在 | 请求的资源不存在 |
| 500 | 服务器异常 | 服务端内部异常 |
| 400 | 参数错误 | 请求参数不合法 |
