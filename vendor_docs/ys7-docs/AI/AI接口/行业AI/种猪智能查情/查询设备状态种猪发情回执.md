## 查询设备状态种猪发情回执

- 接口功能

   设备状态种猪发情回执

- 请求地址

`https://open.ys7.com/api/service/ai/oestrus/feedback`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| body | oestrusId | Int | 发情通知Id | Y |
| body | result | Int | 发情回执（人工确认结果），0-未发情，1-已发情 | Y |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/service/ai/oestrus/feedback' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'oestrusId=12345' \
--data-urlencode 'result=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": null
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta.code | Int | 状态码，200表示成功 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 返回数据，本接口为null |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 404 | 资源不存在 | 请求的资源不存在 |
| 500 | 服务器异常 | 服务端内部异常 |
| 400 | 参数错误 | 请求参数不合法 |
