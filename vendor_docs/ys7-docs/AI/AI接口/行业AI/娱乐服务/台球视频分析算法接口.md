# 提供台球视频分析算法接口（POST）

> 分析台球视频中的进球内容，并通过云信令异步推送分析结果

---

## 前置条件

- 开通云信令，云信令开通参考本文档 **算法分析结果**目录
- 开通AI算法服务reasoning，如未开通可联系客服支持
- 需联系客服手动开通该接口调用权限

## 接口URL

https://open.ys7.com/api/service/intelligence/algo/analysis/billiards\_video\_analysis

## 请求

### Header

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 萤石开放API访问令牌 |  |

### body

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| requestId | string | N | 请求Id，请使用uuid，若需要自定义，建议在uuid前缀或后缀附上自定义ID，requestID整体不超过32位 |  |
| stream | boolean | Y | 必传true |  |
| level | boolean | N | normal:普通版本，advance：高级版本 | 高级版需要联系客服申请权限 |
| dataInfo | array<object> | Y | 请求的输入数据内容 |  |
| -modal | string | Y | 数据模态：video，：视频 |  |
| -type | string | Y | 数据类型: url |  |
| -data | object | Y | url地址,注意:视频太大会分析失败，建议视频时长在1个小时内,且视频大小不超过2G |  |

### 请求示例

```
curl --location 'https://open.ys7.com/api/service/intelligence/algo/analysis/billiards_video_analysis' \
--header 'accessToken: at.9u15ez4p2rl00vko2fyxp64' \
--header 'Content-Type: application/json' \
--data '{
    "requestId": "",
    "stream": true,
    "level": "normal",
    "dataInfo":  [
         {
            "modal": "video",
            "type": "url",
            "data":  "https://domain/mock.mp4"
        }
    ]
}'
```

# 算法分析结果

> 前提条件: 在消息推送控制台开通消息推送服务 [消息推送服务开通操作手册](https://open.ys7.com/help/566)，并联系客服，后台开通AI算法分析结果消息类型：ys.open.ai.resultData，算法分析结果是通过云信令消息异步推送的

## AI算法分析结果消息

- ### **header说明**

| **字段名** | **类型** | **描述** |
| --- | --- | --- |
| **header** | **Object** | **设备信息** |
| type | String | 消息类型：ys.open.ai.resultData表示AI算法分析结果消息 |
| deviceId | String | 设备序列号，UUID |
| messageId | String | 消息唯一ID |
| messageTime | Long | 消息发送时间 |

- ### **body说明**

| **名称** | **类型** | **描述** |
| --- | --- | --- |
| **body** | **Object** | **算法分析的消息** |
| code | int | 错误码 |
| msg | String | 错误提示信息 |
| requestId | String | 请求Id |
| taskType | String | 算法类型，billiards\_video\_analysis，台球视频分析算法 |
| images | list[Object] | 图片结果 |
| images[i].contentAnn | Object | 结构化分析结果 |
| images[i].content\_ann.time\_period | List[List[int]] | 【begin\_time，end\_time】开始时间戳，结束时间戳，单位是毫秒，是视频的相对时间，不是绝对时间，比如5000,15000，指的是视频开始后的第5000毫秒到15000毫秒 |
| images[i].content\_ann.tags | list[string] | 检测框tag，比如normalhit：普通击球，openhit：开球击球 breakAndRun: 一杆清台 |
| images[i].content\_ann.key | List[List[String]] | consecutive\_pots: 连击key,和labels为一一对应得关系，后续可能扩展其他识别结果预留列表,advance版本会返回此字段 |
| images[i].content\_ann.labels | List[List[String]] | 3: 代表此次为3连杆进球,advance版本会返回此字段 |
