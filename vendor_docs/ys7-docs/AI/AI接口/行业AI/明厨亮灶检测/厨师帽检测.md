## 厨师帽分析算法接口（POST）

- 接口功能

   开通AI算法服务reasoning，如未开通可联系客服支持  
需联系客服手动开通该接口调用权限

- 请求地址

`https://open.ys7.com/api/service/intelligence/algo/analysis/chef_hat_detection`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| body | requestId | string | 请求Id，请使用uuid | N |
| body | stream | boolean | 必传false | Y |
| body | dataInfo | array<object> | 请求的输入数据内容 | Y |
| body | -modal | string | 数据模态：image，：图片 | Y |
| body | -type | string | 数据类型: url | Y |
| body | -data | object | url地址 | Y |
| body | dataParams | array<object> | 请求的输入图片信息 | N |
| body | -modal | string | 数据模态：image，：图片 | Y |
| body | -img\_width | int | 图片宽度 | Y |
| body | -img\_height | object | 图片高度 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/intelligence/algo/analysis/chef_hat_detection' \
--header 'accessToken: at.7dvwv74k5d6hkmu812nsnc1q2ufnxatm-70aek4sdpn-1sb3rul-swsyiu2kse' \
--header 'User-Agent: Apifox/1.0.0 (https://apifox.com)' \
--header 'Content-Type: application/json' \
--data-raw '{
  "taskType": "",
  "dataInfo": [
    {
      "data": "https://img0.baidu.com/it/u=3346538651,378996156&fm=253&fmt=auto&app=120&f=JPEG?w=800&h=800",

    }
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | 响应信息 |
| -code | int | 服务响应状态码 |
| -message | string | 服务响应状态描述 |
| -moreInfo | object | 服务响应描述 |
| data | object | data |
| -taskType | string | 算法类型，chef\_hat\_detection |
| -requestId | string | 请求唯一ID |
| images | list[Object] | 图片结果 |
| contentAnn | Object | 结构化分析结果 |
| bboxes | List[object] | 检测数据结果 |
| points | list[List[float] | 检测框，使用归一化值，外层列表长度表示有多少个检测框，内层一个列表表示一个检测框，奇数位置为x坐标，偶数位置为y坐标，检测框可以用2点（左上，右下）表示 |
| weight | float | 置信度 |
| tagInfo | Object | 标签信息 |
| tag | String | head\_shoulder，头肩 |
| labels | List[object] | 二维字符串列表，label是key的value， |
| key | String | chef\_hat,厨师帽 |
| label | String | yes，no 是否佩戴厨师帽 |
| labelWeight | float | 置信度 |
