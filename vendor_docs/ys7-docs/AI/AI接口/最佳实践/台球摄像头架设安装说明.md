# 台球摄像头架设安装说明

### 本指南旨在帮助用户正确安装摄像头，以确保台球精彩时刻采集系统能够正常工作并达到最佳效果。请按照以下要求和建议进行摄像头的安装和调整，建议安装情况见**图1**。

## 1. 摄像头图像质量要求

### **清晰可见，无遮挡：** 摄像头安装位置应确保拍摄的画面没有任何遮挡物，台球桌和球的运动轨迹应清晰可见。

### **光线条件：** 避免出现过曝（光线过亮）或过暗（光线不足）现象。建议在自然光线不足的情况下，使用均匀分布的补光灯，以保证光线均匀。

## 2. 摄像头架设高度

### **高度要求：** 摄像头应架设在距离地面3-5米的高度范围内 ，以便获得最佳视角和拍摄范围。

## 3. 台球桌面摆放要求

### **桌面竖直摆放：** 台球桌应竖直摆放，即实际桌面短边对应的X轴，桌面长边对应Y轴，示例见**图2**。

![](https://resource.eziot.com/group2/M00/01/06/CtwQF2h0vNSARAZoAB_HIV4qUnc152.png)
  
![](https://resource.eziot.com/group1/M00/01/4B/CtwQEmb4sHqAIjFUAAsjc2Ll51I283.png)

### **图2 竖直摆放方式示例**

### **角度要求：** 桌面上下边缘不宜与画面有过大的旋转角。建议桌面顶端和底端与画面水平夹角小于5度。夹角过大时会影响系统识别质量并触发提示语，程序无法正常执行，安装示例见**图3**。

![](https://resource.eziot.com/group2/M00/01/06/CtwQF2h0vM2AHf-NACFzvJgin4s791.png)
  
![](https://resource.eziot.com/group2/M00/01/07/CtwQFmh0vMmAavxhACCQCuEzRnI921.png)
![](https://resource.eziot.com/group1/M00/01/4B/CtwQE2b4sZWAEu9jAArh_rMcgMM510.png)

### **图3 桌面上下边缘不宜与画面有过大的旋转角，建议桌面顶端和底端两个球洞形成的射线与画面水平夹角小于5度**

### **画面占比要求：** 确保台球桌的顶端和底端的距离不小于画面的2/3。如果桌面在画面中所占比例过小，将会影响系统的识别效果，安装示例见图4\*\*。

### **避免画面干扰：** 同一画面内不应出现过多其他台球桌或干扰物体，以确保系统对主要台球桌的识别效果最佳。

### **视角要求：** 摄像头中心点到桌面的视角应适当大一些，不宜低于30°~45°(受画质和光线影响)。以确保整个台球桌及其四周区域均在摄像头视野范围内。合适的角度能够避免图像变形和边缘模糊，确保系统能够准确捕捉球桌上的每一个动作。安装示例见图4。

### **图4 视角要求，视角应适当大一些，不宜低于30°~45°(受画质和光线影响)**

## 4. 其他要求

### **稳定性要求：** 摄像头应稳固安装，避免在使用过程中出现抖动或移动，导致图像不稳定，影响识别效果。

### **视角调整：** 摄像头应尽量垂直对准台球桌的中心，以获取最佳识别角度。如需调整角度，请确保调整后的角度符合上述的角度要求。

### **环境要求：** 摄像头周围环境应保持整洁，避免灰尘、潮湿等对设备的损害。保持定期清洁摄像头镜头，确保图像质量。

### **避免遮挡：** 在摄像头拍摄范围内，应避免任何人员站立、经过或长时间停留在台球桌的区域，防止人遮挡桌面，影响系统对台球运动的捕捉和识别效果。

## 5. 程序运行说明

### 本系统在摄像头图像质量和台球桌摆放不符合上述要求的情况下，将会提示用户进行调整。当桌面顶端和底端两个球洞形成的射线与画面左右两侧的夹角过大，或者台球桌顶端与底端的距离小于画面的2/3时，系统将发出提示语并暂停程序执行，直到调整到符合要求的位置和角度。

### 通过正确安装和调整摄像头，您将能够充分利用本台球精彩时刻采集系统，捕捉到更高质量的台球精彩时刻视频。请按照上述指南仔细检查安装和设置，确保系统正常运行。
