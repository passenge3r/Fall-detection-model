# 教育场景---人员计数案例

## 前置工作

### **一、开通云录制**

![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnSSAbXuLAABi2pYCPX8696.png)

#### **创建存储项目文件夹**

开通服务后，进入云录制控制台，进入项目管理页面。
![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnSCAR9SUAAA8kfP_yZ8116.png)

点击右上角创建新的项目，或者选择已有项目。
![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnRqAE-z2AAB6HZPHk_M166.png)

根据业务情况填写项目信息，其中，项目编号（即projectID）将会在后续接口调用中频繁被使用，文件保存时间设置好后，项目下所有文件会使用这一存储周期，到期后会自动删除文件。点击确认后文件夹创建成功。

**注意**：项目编号（projectid）创建要求：长度必须为：1-32位；只能包括字母下划线数字；必须唯一

![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnRWAV_KeAAAYmj1DOzY591.png)

### **三、抽帧消息通知**

- #### **header说明**

| **字段名** | **类型** | **描述** |
| --- | --- | --- |
| **header** | **Object** | **任务信息** |
| type | String | 消息类型：ys.open.cloud表示云录制消息 |
| deviceId | String | videoFrameBusiness |
| channelNo | Integer | 设备通道号 |
| messageId | String | 消息唯一ID |
| messageTime | Long | 消息发送时间 |

- #### **body说明**

| **名称** | **类型** | **描述** |
| --- | --- | --- |
| **body** | **Object** | **消息体** |
| projectId | String | 项目Id |
| taskId | String | 任务id |
| deviceSerial | String | 设备序列号 |
| channel | String | 通道号 |
| fileNum | long | 任务产生文件数量 |
| totalSize | long | 任务产生文件大小 |
| errorCode | String | 返回码 |
| errrorMsg | String | 返回信息 |
| taskStatus | String | 任务状态 COMPLETE(0, "已完成"),WAITING(1, "排队中"),PROCESSING(2, "进行中"), FINISHED(3, "已结束"),EXCEPTION\_FAILED(4, "异常结束"), EXCEPTION\_PAUSE(5,"暂停中"), CANCEL(6,"已取消"), NOT\_START(7,"未开始");  状态解释： 已完成：任务正常录制完成并且过程中没发生报错 已结束：任务开始后由开发者主动结束任务 排队中：回放任务下发后由于当前服务器并发任务太高，需要排队处理 进行中：任务进行中 异常结束：任务过程中发生过异常，即使在重试后录制的内容是完整的，依然会展示异常，视频任务可以通过录像完整度字段判断录制结果是否可用。 暂停中：任务在开始后，设备出流路数达到了上限，导致无法取流，任务默认等待24小时，24小时后还未能解除设备出流限制时任务会失败并上报异常 已取消：任务未达开始时间且开发者取消了任务 未开始：任务未达开始时间 |
| messageType | String | 录制类型 回放("video\_frame"), |

### **四、人形算法消息通知**

#### AI算法分析结果消息

- #### **header说明**

| **字段名** | **类型** | **描述** |

| **名称** | **类型** | **描述** |
