# 萤石AI产品概述

萤石深耕视觉物联网领域，构建了覆盖“接口开放、模型训练、场景交互”的全栈AI产品体系，涵盖AI接口、AI训练平台、数字人AI、对话智能体、多模态智能体五大核心产品。各产品协同联动，打通“技术底座-开发赋能-场景落地”的全链路，为企业、开发者及终端用户提供便捷、高效、定制化的AI解决方案，广泛适配安防、养老、教育、商贸、文旅等千行百业，助力数字化转型与智能化升级。

## 一、AI接口

萤石AI接口是整个AI产品体系的核心入口，以标准化、轻量化的方式，向开发者开放萤石多年积累的AI核心能力，打破技术壁垒，降低AI应用开发门槛。接口覆盖视频技术、图像检测与识别、语音技术、人脸与人体识别、文字识别等多元维度，进行高精准度的智能分析与处理。

## 二、AI训练平台

萤石AI训练平台是面向开发者与企业的一站式算法开发与训练工具，聚焦行业场景定制化需求，提供从素材采集、模型训练到部署落地的全流程服务，让非专业技术人员也能快速构建高精准度的定制化算法。平台兼具灵活易用性与高效性，适配云、边、端全场景部署需求。

## 三、数字人AI

萤石AI数字人是萤石自研的新一代多模态智能交互数字人产品，依托AI实时驱动、实时渲染技术，为企业提供有形象、可交互的2D/3D数字人解决方案，丰富物联网数字人资产，提升服务温度与效率。产品深度融合A各项AI技术，实现拟人化的多模态交互，广泛应用于数字迎宾、数字营销、数智客服、视频录课等场景。

## 四、对话智能体

萤石IoT AI对话智能体是面向企业的一站式对话交互解决方案，旨在帮助企业快速构建IoT硬件与AI之间的音视频通话应用，让设备能听懂、会交流，实现全双工、实时打断、可扩展的自然交互。

## 五、多模态智能体

萤石IoT多模态智能体是基于萤石AIoT生态底座，融合视觉、听觉、文本、数据等多源信息的新一代智能交互核心。它打破单一模态局限，以“像人一样感知、理解、决策”为核心目标，为家庭、企业、公共空间等场景提供“看得懂、听得清、会思考、能执行”的全流程智能服务，重新定义AI与物理世界的交互边界，成为用户身边“主动响应、持续进化”的智能伙伴。

综上，萤石五大AI产品相互支撑、协同发力，以“AI+视觉物联网”为核心，构建了从技术开放、模型开发到场景交互的全栈能力，凭借异构算力融合、全生命周期安全防护、行业场景深耕等优势，为千行百业提供开箱即用、灵活定制的AI解决方案，推动智能技术与实体经济深度融合，开启碎片化AI场景新蓝海。
