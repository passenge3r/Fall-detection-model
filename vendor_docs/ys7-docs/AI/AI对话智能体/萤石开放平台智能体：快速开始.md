# 萤石开放平台智能体：快速开始

无论你是否有编程基础，你都可以在开放平台智能体开发平台快速搭建一个 AI 智能体。本文以一个“AI雅思口语专家”机器人为例，说明如何在开放平台搭建智能体。

# 智能体效果

和“AI雅思口语专家”机器人对话时，它可以给你：10 年教龄雅思老师的实时教学反馈、 AI 辅助口语素材整理等

![](https://resource.eziot.com/group2/M00/01/04/CtwQFmg0LP2AADPTAAL-ODvHoN0963.png)

# 搭建步骤

参考以下步骤快速搭建一个“AI雅思口语专家”。

## 步骤1：创建一个智能体

1. 注册萤石开放平台账号，并打开控制台：[萤石智能体](https://open.ys7.com/console/aiAgent/aiAgent.html)
   ![](https://izhstatic.ys7.com/vasp-openweb/1775725268655_f5f78ce8ca036ac10c1e46c2f611abe8.png)
2. 在页面上，点击创建智能体，选择[对话智能体]，
3. 输入智能体名称和功能介绍，然后上传一个头像，
4. 单击**确认**。

创建智能体后，你会直接进入智能体编排页面。你可以：

![](https://resource.eziot.com/group2/M00/01/04/CtwQF2g0MFyAKLBEAAJMDYnKTKs974.png)

- 在左侧**人设与回复逻辑**面板中描述智能体的身份和任务。
- 在中间**技能**面板为智能体配置各种扩展能力。
- 在右侧**预览与调试**面板中，实时调试智能体。

## 步骤2：选择大模型

建议选择：qwen-mmh-high-speed 模型，速度较快，交互延时较低

![](https://izhstatic.ys7.com/vasp-openweb/1775725432282_108dd43fc75d2b8d50c91d93c29c8445.png)

## 步骤3：编写提示词

配置智能体的第一步就是编写提示词，也就是智能体的**人设与回复逻辑**。智能体的**人设与回复逻辑**定义了智能体的基本人设，此人设会持续影响智能体在所有会话中的回复效果。建议在人设与回复逻辑中指定模型的角色、设计回复的语言风格、限制模型的回答范围，让对话更符合用户预期。

在智能体配置页面的**人设与回复逻辑**面板中输入提示词。例如“AI雅思专家”的提示词可以设置为：

```
# 角色
你是一个雅思口语陪练专家，能够帮助用户进行雅思口语考试的训练，并提供反馈和建议。

""""""""""""""""""""""""""""""""""""""""""""""""""""""""

## 技能：练习进度回顾

- 当用户想要回顾练习进度时，告诉用户已经回答过的话题数量、题目数量；并列出具体的话题、题目内容及题目评分。
- 回复格式：

你共回答了：<话题数量>个话题，<题目数量>条题目。

---

分别是：

- Part1: <已回答话题>
- Part2: <已回答话题>
- Part3: <已回答话题>

---

你已经回答过的题目：

1. <题目，评分>

---

你跳过的题目：

- <未作答题目>

---

请问你是想要继续练习Part1，Part2，Part3，还是进行雅思模拟考试?

### 特殊情况：用户没有回答的题目，不计入练习个数，不计入已经回答过的题目。例如用户主动要求跳过题目。

""""""""""""""""""""""""""""""""""""""""""""""""""""""""

## 限制
- 只专注于雅思口语训练相关的内容，不涉及其他考试科目。
- 在用户选择模块时，不得提供任意Evaluation。
- 输出内容中不能包括以下符号{}<>
```

## 步骤4：选择知识库

开发者可以选择设置好的知识库：

或者开发者可以去控制台进行上传知识库：<https://open.ys7.com/console/KnowledgeBaseList/KnowledgeBaseList.html>

![](https://izhstatic.ys7.com/vasp-openweb/1775725552899_2e2107b5e6500b518e6cf949283996be.png)

## 步骤5：（可选）为智能体添加技能

如果模型能力可以基本覆盖智能体的功能，则只需要为智能体编写提示词即可。但是如果你为智能体设计的功能无法仅通过模型能力完成，则需要为智能体添加技能，拓展它的能力边界。

例如文本类模型不具备理解多模态内容的能力，如果智能体使用了文本类模型，则需要绑定多模态的插件才能理解或总结 PPT、图片等多模态内容。此外，模型的训练数据是互联网上的公开数据，模型通常不具备垂直领域的专业知识，如果智能体涉及智能问答场景，你还需要为其添加专属的知识库，解决模型专业领域知识不足的问题。

![](https://resource.eziot.com/group2/M00/01/04/CtwQFmg0MFqAVhpLAAE35j0Jhqo308.png)

## 步骤5：(音色）设置音色

开发者可以根据设置音色：

支持中文、英文、东北话、台湾腔等语音音色，同时支持语音倍速等

![](https://izhstatic.ys7.com/vasp-openweb/1775725675268_ac230e5a626c75b962b840636947b52c.png)

## 步骤6：智能打断VAD

智能打断说明：智能体正在说话时，如果觉得效果不好，可以随时打断。关闭后，就必须等智能体回复完整语音后才开始拾音。

关键词打断：由于关键词配置效果需要调试，暂时未直接控制台开放，开发者可以咨询产品在后台配置。

## 步骤7（可选）：设备控制指令

开发者需要控制设备时，即可在这里配置指令，比如打开微波炉、开始加热、降低温度等，大模型理解指令后即可给设备下发对应指令，需要设备能接收。

另外，你还可以为智能体添加开场白、用户问题建议等功能，增强对话体验。例如为智能体添加一张背景图片，使对话过程更沉浸。

例如：AI雅思助手，还可以选择 音色、语速等，让老师更加真实。

![](https://resource.eziot.com/group2/M00/01/04/CtwQFmg0MLqATFdiAATP8V3R85I395.png)

# 调试智能体

配置好智能体后，就可以在**预览与调试**区域中测试智能体是否符合预期。

![](https://resource.eziot.com/group1/M00/01/8D/CtwQEmg0MWOAU-juAAI2q1vKrQE190.png)

# 发布智能体

完成调试后，单击**发布**将智能体发布到线上，发布到线上后，可以通过联系人，关联相关硬件设备。
