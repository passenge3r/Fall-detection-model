# 萤石开放平台智能体：接入说明

# 一、对接方案

```
萤石云提供Http接口和控制台配置智能体，提供设备关联方式
```

该接口主要是将管理智能体，关联设备联系人等操作

# 二、接入指南

## 2.1 步骤1

**前提:**

> - 注册萤石云开放平台，链接:https://open.ys7.com/cn/s/index,获取AK、SK等关键接口对接配置信息
> - 设备支持联系人功能，已有设备有S10,S20,RK3等设备型号

## 2.2 步骤2

## 1）体验Demo

参考文档：<https://open.ys7.com/help/4350>

## 2）获取设备 SDK

目前萤石提供 RTC Linux SDK，开发者提供硬件架构及编译工具链，萤石会在1周内提供。

Linux/RTOS SDK集成方法参考：<https://open.ys7.com/help/4952>

App、Web SDK，直接参考ERTC SDK 集成：<https://open.ys7.com/help/1874>

### 语音芯片

萤石主要解决语音传输、云端大模型能力，设备端的语音唤醒、3A处理需要集成商自行解决。

如果集成商可以考虑集成语音芯片，萤石提供生态合作伙伴的音频芯片供应商，可以咨询产品经理获取生态合作伙伴的测试芯片，进行集成，生态合作伙伴提供：自定义语音唤醒词、端侧音频处理、语音采集处理、播放等能力。

## 3）智能体

获取SDK后，集成到硬件模组里，进行集成，接下来开始进行语音互动的开发

### 创建智能体

接口创建：[创建智能体任务](https://open.ys7.com/help/4249)

控制台创建：<https://open.ys7.com/help/4350>

### 接入说明

创建智能体后，开始接入：<https://open.ys7.com/help/4953>
