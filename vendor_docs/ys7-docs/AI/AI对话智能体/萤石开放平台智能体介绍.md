# 萤石开放平台智能体介绍

开放平台智能体是新一代 AI Agent 开发平台。在这里可以快速搭建基于大模型的各类 AI 应用，并将 AI 应用发布到萤石相关硬件上，也可以通过 API 或 SDK 将 AI 应用集成到你的业务系统中。

## 开放平台智能体能做什么？

借助开放平台智能体提供的可视化设计与编排工具，你可以通过零代码或低代码的方式，快速搭建出基于大模型的各类 AI 项目，满足个性化需求、实现商业价值。

- **智能体**：智能体是基于对话的 AI 项目，它通过对话方式接收用户的输入，由大模型自动调用插件或工作流等方式执行用户指定的业务流程，并生成最终的回复。
- **IoT+智能体**：让海康/萤石/三方硬件聪明起来：基于S10开放的英语助教、基于RK3开放的智能养老管家，基于SP4开放的智能公寓助手，都是典型的IoT+智能体应用，同时萤石开放平台还提供了SDK开放，开发者集成的很多AI玩具都可以直接实现AI玩具+智能体的应用。

## 萤石开放平台智能体支持哪些硬件？

任何集成萤石ERTC SDK的硬件都可以直接下发智能体。

如何新增硬件？可以联系小助手购买对应硬件，比如康养场景下的S10、S20，通用摄像头语音助手C6Wi，门禁场景下的SP4等设备，都具备语音智能体直接下发的能力。

## 为什么选择开放平台智能体？

- **持续更新的硬件资源**

任何接入萤石云的RTC设备，都可以一键开启智能体应用。

同时，开放平台还提供各类LinuxSDK，搭配音频对话模组，可以让你的硬件变的更聪明

- **灵活的流程设计**

开放平台智能体的工作流功能可以用来处理逻辑复杂，且有较高稳定性要求开放平台智能体务流。例如只需要通过提示词模板设置、选择不同的大模型，输入不同的语言音色，就可以搭建一个熟悉多国语言的英语助教，并能直接下发到萤石屏类设备上，一键开启英语交流。

- **标准且支持扩展的能力集**

开放平台智能体集成了丰富的插件工具，极大地拓展智能体的开放平台智能体边界。例如使用新闻插件，打造一个可以播报最新时事新闻的开放平台智能体播音员。

- **支持MCP**

模型上下文协议（Model Context Protocol, MCP）旨在搭建大模型和外部工具之间的信息传递通道。通过 MCP 协议，开发者不用为每个外部工具编写复杂的接口，同时智能体应用也能够接入海量第三方工具。
