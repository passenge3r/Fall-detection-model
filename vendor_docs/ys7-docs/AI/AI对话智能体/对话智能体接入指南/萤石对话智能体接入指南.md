# 背景介绍

典型案例1：[开发者自有设备（如机器人/安卓屏等）与萤石智能体语音对话]
![](https://resource.eziot.com/group2/M00/01/0B/CtwQFmkTReKAKwUeAAR2WSSt4a4442.png)

## **接入准备（默认已完成前置条件准备）**

1. 设备具有拾音功能，且设备音频格式为裸opus的音频数据
2. 注册萤石开发者账号
3. 开通AI服务能力
4. 开通实时音视频功能

## **加入房间流程**

1. 请求获取智能体对话房间信息，参考接口：[获取智能体对话房间信息](https://open.ys7.com/help/4951)
2. 将返回的appId,token,roomId,userId填入SDK进行加入房间
   ![](https://resource.eziot.com/group2/M00/01/0B/CtwQFmkTQYSAGl_1AAFp8cznEVc333.png)
3. 音频数据发送至房间中，同时监听SDK返回的音频数据
   ![](https://resource.eziot.com/group2/M00/01/0B/CtwQF2kTQhGAUdBoAADUs0JllA8197.png)

RTCSDK接入参考文档：[RTCSDK文档](https://open.ys7.com/help/4952)
