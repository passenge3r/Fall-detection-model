## 智能体创建

- 接口功能

   智能体应用创建

- 请求地址

`https://open.ys7.com/api/service/open/intelligent/agent/app/create`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | appType | Int | 智能体类型：1：感知智能体 默认感知智能体 | N |
| body | appName | String | 应用名称，1-32字符 | Y |
| body | appDesc | String | 应用描述，1-64字符 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/intelligent/agent/app/create' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'appType=' \
--data-urlencode 'appName=' \
--data-urlencode 'appDesc='
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "appId": "2661d7639e0e44169063d39c366ace46",
        "appVersion": "V1"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| -code | Int | code |
| -message | String | message |
| -moreInfo | Object | moreInfo |
| data | Object | data |
| -appId | String | appId |
| -appVersion | String | appVersion |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
