# Ai对话智能体：设备指令操作说明

## 概述

本文档介绍如何基于控制台与SDK，完成设备控制指令的集成

## 控制台：操作说明

### 入口

进入控制台：[萤石开放平台-南北全栈开放的全球化智能物联云平台\_Works with EZVIZ](https://open.ys7.com/console/aiAgent/aiAgent.html?activeKey=my-intelligent-agent&=) 进入对话智能体，选择智能体，如果没有则请创建

进入智能体后，点击最下面的设备控制指令

![](https://izhstatic.ys7.com/vasp-openweb/1782370029740_image_28.png)

### 新建配置

![](https://izhstatic.ys7.com/vasp-openweb/1782367374123_2026-06-24-22-34-31-image.png)

如果是第一次操作，请添加自定义指令

以烤箱为例，添加指令如下：

![](https://izhstatic.ys7.com/vasp-openweb/1782367374123_2026-06-24-22-45-45-image.png)

如图：

| 名称 | 功能说明 |
| --- | --- |
| 指令类型 | 对一大类的指令进行分类命名，比如音量控制、烤箱控制等 |
| 指令名称 | 指令名称，只支持英文数字下划线，填写该指令是与设备直接交互，请填写设备能理解的指令 暂不支持物模型指令 |
| 指令说明 | 指令的备注，该备注请填写清楚，大模型需要理解该指令名称，如果觉得有多个需要理解，可以用分号填写多个指令说明 |
| 参数 | 支持设置多个参数，例如具体的调节数值；提供示例有助于模型理解参数的具体意义，下发更准确。 |
|  |  |

编辑后，勾选后即可

![](https://izhstatic.ys7.com/vasp-openweb/1782367374123_2026-06-24-22-48-03-image.png)

勾选后，即可在对话中调用（备注：要发布后才能正式生效）

### 指令示意

![](https://izhstatic.ys7.com/vasp-openweb/1782367374123_2026-06-24-22-48-59-image.png)

当配置指令后，当语音下发对应指令后，设备需要在消息透传里对接对应指令，即可完成指令生效操作。

## 设备Linux SDK接收报文指令

如果开发者对接的是Linux SDK，则还需要在SDK里接收对应的报文指令

请参考文档接收该指令：<https://open.ys7.com/help/5273>
