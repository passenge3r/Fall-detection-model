## 获取智能体对话信息接口

- 接口功能

   获取智能体对话信息，用于建立智能体实时对话

- 请求地址

`https://open.ys7.com/api/service/open/sts/bridge/dialog/room/call`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | appId | String | ERTC应用Id | Y |
| body | agentAppId | String | 智能体应用Id | Y |
| body | bizType | String | 业务类型 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/sts/bridge/dialog/room/call' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'appId=xxxxx' \
--data-urlencode 'agentAppId=xxxxx' \
--data-urlencode 'bizType=xxxxx'
```

- 返回数据

```
{
    "data": {
        "roomId": "room_xxxxx",
        "token": "tk.xxxxx",
        "userId": "user_xxxxx"
    },
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta.code | Int | 业务码，200表示成功 |
| meta.message | String | 响应信息 |
| meta.moreInfo | Object | 更多信息 |
| data.roomId | String | 对话房间ID |
| data.token | String | 通话Token |
| data.userId | String | 用户ID |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 500 | 服务器异常 | 服务器内部错误 |
| 400 | 参数错误 | 请检查请求参数格式 |
