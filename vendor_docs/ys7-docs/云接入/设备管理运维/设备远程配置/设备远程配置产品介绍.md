# 设备远程配置

# 1. 产品简介

## 1.1 什么是设备远程配置

### **1. 设备远程配置**

设备远程配置服务，可支持在控制台进行设备的远程配置或通过API进行远程设备配置项修改。免除设备配置过程需要前往设备本地的高成本。

## 1.2 功能概览

| 功能名称 | 功能描述 |
| --- | --- |
| 设备远程配置（增强版） | 需要设备支持远程配置（代理HTTP）能力。 |
| 设备远程配置 | 需要设备支持ISAPI能力。 |

## 1.3 产品优势

- 操作便捷：通过云端远程连接设备进行配置调整，无需人员到场即可进行远程设备调试；

## 1.4 设备支持

- 设备状态：在线
- 萤石协议接入的海康IPC（5.6.0版本以上）和海康NVR（4.2.0版本以上）
- 不支持国标协议接入和托管的设备，如需使用，请联系小助手咨询
  ![](https://resource.eziot.com/group2/M00/01/07/CtwQFmiILNSAKI4gAAECg15bddI516.png)

# 2. 产品定价

## 2.1 计费方式

本服务无单独计费。

## 2.2 使用限制

如果您为试用版账户（P套餐），则账号下设备支持使用设备数受P套餐限制（最多控制10台设备，超过时页面会报错），进行设备远程调试设备需要为当前支持使用的设备之一。
如果您为企业版账户，则无相关限制。
