# 设备远程配置

# 1. 前置条件

设备要求：

1. 设备绑定在当前账号下
2. 当前设备状态：在线
3. 设备是通过萤石协议接入的海康IPC（5.6.0版本以上）或者海康NVR（4.2.0版本以上），不是托管设备

# 2. 使用流程

## 2.1进入设备列表，安装远程配置插件

在[萤石开放平台控制台-设备管理页面](https://open.ys7.com/console/device.html)中点击设备配置，符合要求的设备可以打开远程配置
![](https://resource.eziot.com/group1/M00/01/8F/CtwQE2iIgxGAHOIZAAHWi1lFdIk747.png)
![](https://resource.eziot.com/group1/M00/01/8F/CtwQEmiIg02AXCHYAACXAD9-oKg659.png)

## 2.2按需要配置设备

打开远程配置后与本地配置界面一致，按照实际需要使用即可。
