## 产品简介

为方便开发跟着便捷、高效管理设备，萤石开放平台提供了一系列设备运维管理工具，涵盖设备巡检、绑定、添加、调试、配置及升级等关键运维场景。

## 能力介绍

| 工具名称 | 简介 |
| --- | --- |
| [AI设备巡检](https://open.ys7.com/help/4935) | 通过自定义巡检计划，平台可自动检测设备的运行状态，包括设备离线、网络异常、视频取流异常、画面模糊以及设备移位等问题，并自动生成详尽的设备健康报告。 |
| [设备预绑定](https://open.ys7.com/help/3967) | 在设备上线前，预先到平台建立设备与账号的绑定管理。当设备上线时，自动绑定到指定账号，降低施工难度 |
| [B端添加工具](https://open.ys7.com/help/2091) | 面向项目开发与项目落地交付的全生命周期，提供开发者、安全员等多角色的设备添加方式，实现快速完成设备的配网与绑定 |
| [设备远程调试](https://open.ys7.com/help/1708) | 萤石云远程连接设备，让开发者SSH命令行远程调试设备，实现设备异常恢复、设备故障排查、设备高级配置等 |
| [设备远程配置](https://open.ys7.com/help/4126) | 远程打开海康设备的本地配置页面，进行配置修改和查看 |
| [OTA升级](https://open.ys7.com/help/1714) | 通过云端对设备固件进行远程升级 |
