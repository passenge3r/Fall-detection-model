# OTA升级

# 1. 产品定价

## 1.1 计费方式

OTA设备升级服务使用的计费方式为预付费。当您开通服务后，可根据服务用量需求，提前预购OTA服务资源。

## 1.2 计费组成

### **1.2.1计费项说明**

OTA设备升级服务计费项具体如下：

| 计费项 | 单价 | 说明 |
| --- | --- | --- |
| 激活设备license | 4元/路 | 预付费模式，需要提前购买对应资源。 设备激活数为终身计费，1路资源仅支持1个设备使用。 每台设备在激活时，消耗激活设备license数。 |
| OTA升级流量 | 2.5元/GB | 预付费模式，需要提前购买对应资源。 在设备升级过程中，对升级包下发过程消耗的升级流量。 |

## 1.3 使用限制

- 如果您为个人版账户（P套餐），则账号下设备支持使用设备数受P套餐限制，进行设备远程调试设备需要为当前支持使用的设备之一。
- 如果您为企业版账户，则无相关限制。
