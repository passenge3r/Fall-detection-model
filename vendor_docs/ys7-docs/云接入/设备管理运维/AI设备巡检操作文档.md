# AI设备巡检产品概述

## 什么是AI设备巡检

AI设备巡检是一款智能化设备管理解决方案，专为开发者量身打造。通过自定义巡检计划，平台可自动检测设备的运行状态，包括设备离线、网络异常、视频取流异常、画面模糊以及设备移位等问题，并自动生成详尽的设备健康报告。

## 产品优势

- **效率提升，成本优化：** 实现设备问题自动排查，缩短人工巡检时间，降低成本。
- **可视化管理，高效运维：** 发现问题立即推送检测报告，清晰展示设备健康状态，为维护与升级提供依据。
- **灵活适配场景：** 支持自定义巡检计划和多样化检测指标，适用于不同行业场景。

## 客户应用场景

### 1. 客户应用案例一

- **应用场景：** 某餐饮公司日常后厨监控直播，需要检查设备是否有花屏、黑屏、油污模糊、移位等异常情况。
- **痛点：** 未能及时检查到后厨直播设备异常，导致消费者投诉。
- **解决方式：** 应用AI设备巡检后，若发现异常能快速通知负责人处理，降低客诉。

### 2. 客户应用案例二

- **应用场景：** 某果园农作物监控，在农场内使用监控进行日常排查，需要检查摄像机是否正常工作、取流是否正常、是否存在遮挡、移位等问题。
- **痛点：** 每天专人检查需耗时6小时，效率低下，希望降低成本提高效率。
- **解决方式：** 对接AI设备巡检服务后，能显著降低成本，提高效率。

## 功能概览

| **功能项** | **概述** |
| --- | --- |
| **巡检计划** | 创建/触发巡检计划：创建巡检计划，设定设备范围、巡检时间；支持选择全部设备、多个巡检计划、手动触发巡检。 |
| **设备巡检指标** | 设备状态检测：包括离线、存储介质异常、取流失败、固件版本低等。 |
|  | 异常画面检测：检测遮挡、移位、花屏、模糊等异常画面，并提供包含画面截图的检测结果（一个月有效期）。 |
| **巡检报告** | 查询巡检结果：查看巡检结果概述，按设备/指标查询检测结果详情。 |
|  | 巡检报告推送：巡检结束后生成PDF检测报告并发送到指定邮箱。 |

## 计费和使用限制

- **计量方式：** 按巡检设备数收费（若一个设备提供2次巡检，按2个巡检设备计费）。
- **定价：** 按每日巡检设备数扣减，约0.068元/路/天。
- **使用限制**：一个巡检计划，每天最多执行巡检20次，如您有更高频率的巡检需求。您可以联系我们拓展

## 操作指南

1. **登录开放平台账号**

- 打开控制台——进入设备管理器——选择 AI设备巡检

- 设置每日巡检时间，最多可设置 20 个时间段进行巡检

- 选择设备：可选择全部设备或自定义设备开通 AI设备巡检
