# 预绑定使用指南

![](https://resource.eziot.com/group1/M00/01/6B/CtwQEmdrdKmAb2JlAAEPa2H080E014.png)

## 1.设备要求

通过萤石销售完成出货的萤石设备。
另外：当前版本仅支持萤石设备，且为后期添加最简单，最好使用宽带联网或者4G联网

## 2.预绑定操作流程

- 购买设备
- 联系出货的萤石销售协助申请设备序列号+验证码清单
- 在[萤石开放平台控制台-预绑定界面](/console/prebinding.html)，将需要进行预绑定的设备导入控制台，即可完成设备预绑定
- 完成预绑定，此时设备一旦通网通电即可自动与设备进行绑定

## 3.预绑定后，设备实际安装与交付流程

- 将设备通电、通网
- 后台已完成设备绑定
- 验收绑定结果
