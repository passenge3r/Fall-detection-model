# 远程设备调试

# 1. 前置条件

设备要求：

1. 设备绑定在当前账号下
2. 当前设备状态：在线
3. 设备能力要求：支持设备远程调试能力

# 2. 使用流程

## 2.1进入找到对应设备，并开启调试

在[萤石开放平台控制台-设备管理页面](https://open.ys7.com/console/device.html)中找到您需要调试的设备，并点击“设备调试”按钮进入设备调试页面（如设不支持远程调试，按钮置灰）。
![](https://resource.eziot.com/group2/M00/00/A7/CtwQF2TR96CARanvAAMztJhdUPY043.png)

## 2.2确认开启设备调试

![](https://resource.eziot.com/group2/M00/00/A7/CtwQFmTR97qANPHGAAMPmEMs76Q328.png)

## 2.3开启调试服务

开启“设备调试服务”，需要输入设备的本地用户名与密码，进行开启。
![](https://resource.eziot.com/group2/M00/00/A7/CtwQF2TR99eAMGk3AACDhiNMvy8439.png)
![](https://resource.eziot.com/group2/M00/00/A7/CtwQFmTR9_CASf1jAAC0xr9z514451.png)

成功后，“设备调试服务”状态变更为：已开启；“是否登录设备”状态变更为已开启，即可开始使用。
![](https://resource.eziot.com/group2/M00/00/A7/CtwQF2TR-AaAH6HdAADYxhsUfhY985.png)

如“是否登录设备”未成功，可点击“手动登录”重新连接。
![](https://resource.eziot.com/group2/M00/00/A7/CtwQFmTR-BiALJ3nAACSAQCYQ_E771.png)

完成后，请及时点击“手动关闭”按钮，关闭服务连接，避免后续设备因连接过多导致的问题。（每次开启会在30min后自动关闭）
![](https://resource.eziot.com/group2/M00/00/A7/CtwQF2TR-CqAdEAiAADYxhsUfhY370.png)
