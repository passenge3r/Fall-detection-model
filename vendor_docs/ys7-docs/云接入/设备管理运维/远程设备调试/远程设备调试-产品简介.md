# 远程设备调试

# 1. 产品简介

## 1.1 什么是设备远程调试

### **1. 设备远程调试**

设备远程调试服务是面向设备异常恢复、设备故障排查、设备高级配置等场景，通过SSH反向代理，实现SSH命令行调试，与设备进行远程的信息获取、设备调试。通过此项服务，可获取设备较高权限（直接通过命令行进行设备的调试），且需要对设备指令有较高了解度，因此，建议可搭配远程控制等功能，协调专业设备支持人员进行。

### **1.2 功能概览**

| 功能名称 | 功能描述 |
| --- | --- |
| 设备远程调试 | 支持通过SSH反向代理，实现SSH命令行调试。（需设备支持此能力） |

### **1.3 产品优势**

- **操作便捷**：通过云端远程开始代理，无需人员到场即可进行远程设备调试；
- **调试能力强**：通过命令行实现设备调试，可更灵活实现多种场景下的设备故障排查、设备配置调整、设备信息获取等功能。可覆盖更多设备运维场景。
