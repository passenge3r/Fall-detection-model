# 1.产品简介

## 1.1 什么是《开放平台 设备添加工具》

萤石开放平台面向开发者，在“萤石云视频APP”上提供的免开发设备添加工具。面向项目开发与项目落地交付的全生命周期，提供开发者、安全员等多角色的设备添加方式，实现快速完成设备的配网与绑定。

## 1.2 工具使用要求

您需要成为萤石开放平台的用户，拥有一个萤石开放平台的账号

## 1.3 付费说明

免费向开发者开放。

## 1.4 功能概览

开放平台设备添加工具提供开发者设备添加功能、授权安装员添加功能、查询设备添加备注等功能

| 功能名称 | 功能描述 |
| --- | --- |
| 开发者设备添加功能 | 支持开放平台用户通过该工具进行设备的配网与添加功能。支持添加萤石、海康的多种类型的设备。 |
| 授权安装员添加功能 | 支持开放平台用户通过该工具授权其余用户为自己的账号绑定设备。授权可设置有效期以及通过该授权链接添加设备的设备备注信息。通过二维码图片、授权地址URL等方式给到其余用户为自己的账号添加设备。 |
| 查询设备添加备注 | 可支持通过接口查询设备的备注信息。可根据项目生成授权链接，完成添加后，通过设备备注信息自动关联设备名称修改、设备分组等功能。 |

# 2.操作指南

## 2.1 设备添加工具入口

萤石云视频APP-我的-常用工具-萤石开放平台。

（Android版本6.13.2.24.01.09版本以上；iOS版本6.13.2.24.01.09）

![](https://resource.eziot.com/group1/M00/01/00/CtwQEmW3qNWAce87AAATG0i6ay0743.png)

## 2.2 作为开发者，如何为自己的账号绑定设备？

- **Step 1** ：打开萤石云视频APP，登录账号（开发者自己的账号）
- **Step 2** ：进入“萤石云视频APP-我的-工具-应用市场”工具中的**设备绑定**入口。

![](https://resource.eziot.com/group1/M00/01/8E/CtwQE2h4mwWAVMV9AAb5LOEF2CE454.jpg)
![](https://resource.eziot.com/group1/M00/01/8E/CtwQE2h4nGyAc4MsAAU7DZ4lc20851.jpg)

- **Step 3** ： 扫描设备二维码或通过设备序列号进行设备添加。

## 2.3 作为开发者，如何**授权安装员**为自己的账号绑定设备？

- **Step 1** ：打开萤石云视频APP，登录账号（开发者自己的账号）
- **Step 2** ：进入“萤石云视频APP-我的-工具-应用市场”工具中的**授权绑定**入口。

![](https://resource.eziot.com/group1/M00/01/8E/CtwQE2h4mwWAVMV9AAb5LOEF2CE454.jpg)
![](https://resource.eziot.com/group1/M00/01/8E/CtwQEmh4nLSAYV27AAyD6ail-oE648.jpg)

- **Step 3** ：选择授权有效期以及备注信息后，点击生成授权信息，即可生成授权二维码以及授权APP。

![](https://resource.eziot.com/group1/M00/01/00/CtwQE2W3oy-AcAhRAAHKg5F6AJc662.jpg)
![](https://resource.eziot.com/group1/M00/01/00/CtwQE2W3o3OAeidNAAgIFGKMkjY887.png)

- **Step 4** ：生成的信息您可以选择通过通讯工具发送给到您的安装员为您的账号绑定设备。

## 2.4 作为安装员，如何通过授权链接为他人的账号绑定设备？

- **Step 1** ：打开萤石云视频APP，登录账号（安装员自己的账号）
- **Step 2** ：通过点击链接或者扫描二维码，进入到绑定入口。

![](https://resource.eziot.com/group1/M00/01/00/CtwQEmW3pM2AX-ZcAALKD3Pmkkg115.jpg)

- **Step 3** ：通过点击”开始绑定设备“就可以开始为他人的账号绑定设备。
