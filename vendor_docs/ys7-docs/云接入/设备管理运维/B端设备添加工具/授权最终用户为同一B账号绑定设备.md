# 授权最终用户为同一B账号绑定设备

## 场景

零售连锁的场景中，零售店店主向某个“智能连锁管理平台”采购服务，其中采购内容包含设备与软件平台服务费。
“智能连锁管理平台”在萤石开放平台注册了统一账号，所有由该平台出售的设备希望绑定在该统一账号下。
设备出售时，未绑定账号，由零售店店主收到设备后，拆设备->设备配网->设备绑定->设备安装。

在开发对接的过程中，有以下几点要求：

1. 不想集成配网添加流程，希望提供可用工具。（顾虑点：设备更新迭代/设备型号更换，需要兼容多套配网方式或需要兼容多套配网提示文案，有大量的兼容迭代工作量）
2. 不希望直接将开放平台统一账号的账号密码给到零售店店主。（顾虑点：安全风险）
3. 安装完成后，希望能够快速完成设备分组，将每个店铺的设备分配到同一个组别。（顾虑点：后续数据管理的便捷性）

## 方案涉及关键信息

1. 智能连锁管理平台在开放平台注册的账号（简称B账号）：为萤石开放平台的开发者账号，在本次项目中涉及一个，开发者公司注册一个即可。用于绑定设备并进行应用开发。
2. 零售店店主的萤石账号（简称C账号）：萤石云视频的C账号信息。在本次项目中涉及多个，零售店店主在绑定设备的时候使用，一个用户注册一个。（仅用于辅助绑定设备的流程，无任何该账号与设备的关联关系）
3. 零售店店主的“智能连锁管理平台”账号（简称用户ID）：在“智能连锁管理平台”中注册产生的零售店店主账号的唯一标识。在本次项目中涉及多个，一个最终零售店店主对应一个账号。

## 服务设计

### 1. 在“智能连锁管理平台”系统中，维护零售店店主与萤石子账号的关系。

         实现目标：1个零售店店主账号对应一个B账号下的子账号

         涉及步骤：

                  a)【智能连锁管理平台服务】创建零售店店主账号

                  b)【萤石开放平台服务】在开发者账号下创建萤石子账号：<https://open.ys7.com/help/649>

                  c)【智能连锁管理平台服务】存储零售店店主账号与子账号之间1V1关联关系。

![](https://resource.eziot.com/group1/M00/01/33/CtwQE2aOYUmAJoqEAABSMIvfayk070.png)

### 2. 在“智能连锁管理平台”系统中，实现设备绑定功能（授权零售店店主绑定）

         实现目标：使得零售店店主拥有为B账号绑定设备的权力

         涉及步骤：

                  a)【智能连锁管理平台服务】在系统页面中增加“添加设备”按钮，根据点击“添加设备”按钮的零售店店主账号，获取关联萤石子账号信息。

                  b)【萤石开放平台服务】生成授权绑定URL/二维码（<https://open.ys7.com/help/2846>）。其中，根据业务需要选择授权时长；备注信息中可关联添入子账号信息。

![](https://resource.eziot.com/group1/M00/01/33/CtwQEmaOYWOATDq8AABUMvNqaRY035.png)

### 3. 由零售店店主操作进行设备配网、绑定流程。

         实现目标：实现设备的绑定

         涉及步骤：

                  a)【萤石开放平台服务】用户识别二维码/打开URL，打开萤石云视频APP，并进入被邀请绑定页面。

                  b)【萤石开放平台服务】用户进行对应设备绑定，并完成设备名称修改。此时，设备就已经绑定在了B账号下了。

![](https://resource.eziot.com/group1/M00/01/33/CtwQE2aOYbSALtimAAEQpdPuzBY746.png)

### 4. 将设备分配到对应子账号下。

         实现目标：将设备分配到对应子账号下，以完成设备的分组。

         涉及步骤：

                  a)【智能连锁管理平台服务】用户通过消息推送服务中，接收设备变更消息，会获知账号下最新绑定1台设备。

                  b)【萤石开放平台服务】可根据消息体中设备序列号的信息，通过接口（<https://open.ys7.com/help/2847>）查询。设备的备注信息，获取到设备子账号信息

                  c)【萤石开放平台服务】通过调用接口（<https://open.ys7.com/help/777>），将设备的对应权限，授权给对应子账号。

![](https://resource.eziot.com/group2/M00/00/E5/CtwQFmaQiZSAZDn-AABb6I9mTK8510.png)
