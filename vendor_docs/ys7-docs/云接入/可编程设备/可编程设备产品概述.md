# 1.概述

## 1.1 产品介绍

可编程设备开发功能，通过硬件原子能力开放和python支持，使开发者可以按需调用摄像头，麦克风，云台等硬件接口，实现画面处理，音频采集，远程控制等丰富场景。开发者也可以自行编写代码，自由定义和扩展摄像机的功能，将创意变成现实。开发者开发的应用还可以发布到应用设备市场，提供给全球各地同样使用此设备的用户使用。

## 1.2 文档目的

- 为开发者提供自定义开发摄像机功能的完整指导，涵盖设备固件升级、功能编写和发布的所有阶段，帮助开发者高效地集成摄像机功能到设备和 App 中，提升用户体验。
- 开发者可以自行编写代码下发设备，也可以使用我们提供的功能进行组合实现自己的需求。

## 1.3 适用群体

- 软件开发人员和移动应用开发人员
- 测试人员和产品发布团队

## 1.4 术语定义

- 固件：硬件设备上的核心软件，用于直接控制设备。
- App：用户在移动端使用的应用程序，用于操作摄像机功能。
- 软件包：安装在设备上的python脚本，用于控制设备固件。

# 2. 总体流程

## 2.1 开发流程说明

1. 设备固件升级以支持Python自定义脚本编写。
2. 编写python代码并集成到设备中。
3. 开发 App 页面以支持摄像机的用户交互。
4. 进行端到端功能调试。
5. 开发者发布软件包。
6. 用户安装软件包并使用功能。
