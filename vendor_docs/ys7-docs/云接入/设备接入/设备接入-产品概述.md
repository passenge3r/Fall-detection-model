## 产品简介

萤石云设备接入支持多品牌、多协议设备统一接入萤石开发者B端账号，让开发者可以在萤石一朵云上管理所有设备。

| 接入方式 | 设备类型 | 设备添加方式 |
| --- | --- | --- |
| 萤石协议 | 海康设备：IPC、NVR、门禁、音频传感等产品 萤石设备：IPC、门锁、门铃、智能屏、家居传感器等 | 1. 通过序列号、验证码添加 2. （海康设备）本地配置页启用萤石云 3.（海康设备）用户令牌绑定 |
| [GB28181协议](https://open.ys7.com/help/4115) | 三方品牌（如大华、宇视、天地伟业等）视频设备 | 在设备上配置国标参数、国标自动配置工具 |
| [设备托管](https://open.ys7.com/help/440) | 已接入萤石云 C 端 App 的设备，需要同时给B端账号访问时 | 先通过萤石云App配网添加，再托管给B账号 |

## 产品能力

不同设备可能适配不同的设备添加方式，以下是几种主流的设备添加方式。

### 01. 通过开放平台直接添加设备

针对海康、萤石设备，如果您知道设备序列号、验证码，可以直接添加设备。此能力也通过API开放给开发者自行集成。  
![](https://izhstatic.ys7.com/vasp-openweb/1772705877414_控制台添加设备.png)

### 02. 通过萤石云App添加设备

使用萤石云开放平台账号，您可以可以登录萤石云App直接扫码添加设备，这仅推荐单账号下设备数少的时候使用。  
![](https://izhstatic.ys7.com/vasp-openweb/1772705945640_App扫码添加.png)

如果设备已经添加到萤石云App的C端用户账号下了，您可以通过[设备托管](https://open.ys7.com/help/442)，将设备托管给B端平台。  
![](https://izhstatic.ys7.com/vasp-openweb/1772705979350_托管.png)

### 03. 本地配置页启用萤石云

针对海康设备，您可以访问本地配置页面，获取萤石二维码后，通过萤石云扫码添加。  
![](https://izhstatic.ys7.com/vasp-openweb/1772706009214_海康启用萤石云.png)
