# 如何选择萤石协议与国标协议？

### **1、 如何判断某个设备是否能够接入萤石开放平台？**

**大部分的音视频设备都能够接入萤石开放平台**。那么如何判断某一个设备是否支持接入萤石开放平台呢？

设备只要支持**萤石协议**或**国标协议**，即可接入开放平台。

- 如果您的设备品牌**为海康/萤石**：
- - 步骤一：您可以使用接口[“查询设备是否支持萤石协议”](https://open.ys7.com/help/652)根据型号与版本号判断设备是否支持萤石协议。如果支持萤石协议，则支持接入萤石开放平台。
- - 步骤二：如果经过步骤一的判断，您的设备不支持萤石协议，您可以联系设备客服（海康：400-800-5998；萤石：400-878-7878）咨询是否可通过设备版本升级使其支持萤石协议，或设备是否支持国标GB/T28181协议，支持即可通过国标协议接入萤石开放平台。
- 如果您的设备品牌**非海康/萤石**：
- - 步骤一：部分合作厂商的相关设备本身支持萤石协议，可以通过咨询硬件厂商，设备是否支持萤石协议。
- - 步骤二：可以通过咨询硬件厂商，设备是否支持国标GB/T28181协议，支持即可通过国标协议接入萤石开放平台。
- 如果经过以上的判断，您的设备均支持接入萤石云，那就没有其他办法了吗？如果您的是摄像头（IPC）设备，还可以尝试通过将设备本地与海康NVR直连（**需摄像头支持ONVIF协议**），通过海康NVR间接接入开放平台。

### **2、 萤石协议、国标协议，我应该选择什么协议接入设备呢？**

- 如果您的设备支持萤石协议 且 支持国标GB/T28181：在项目本身没有要求的情况下，建议您使用萤石协议进行设备接入。如果您的设备非普通安防摄像头（例如执法记录仪、AI网络摄像机等），萤石协议下可支持更加丰富的能力运用，例如电量查询、远程AI算法下发、远程AI画线等。萤石协议是针对公有云环境设计产生的私有协议，在取流、对讲、抓图、远程配置与运维上有更好的协议支持，能够支持更多的功能拓展可能。
- 如果您的设备仅支持萤石协议：不涉及选择，建议您通过萤石协议接入即可。
- 如果您的设备仅支持国标协议：同样不涉及选择，建议您通过国标协议接入即可，优先推荐国标2016版本。

### **3、 已经接在其他平台/账号下面接入了，还能再接入到我的萤石开放平台账号下吗？**

我们当前，我们假设X设备已在A账号/A平台下，现需要将X设备接入到您的萤石开放平台账号B下进行开发对接。

在不依赖设备能力/平台能力的情况下，以下几种情况可以满足您的需求：

- 如果A账号是萤石的账号（萤石云视频APP账号/萤石开放平台账号）：您可以通过设备托管服务，在不影响原有账号使用的情况下，将设备的使用权限给到B账号进行开发对接。详情可参考：<https://open.ys7.com/help/440>
- 如果A账号是萤石商业智居的账号：这种情况下，建议可以将设备解绑后绑定至您的萤石开放平台账号B下，再通过托管的方式给到在商业智居的账号A，操作方案详情可参考：<https://www.yuque.com/u2038998/qa5rn7/uu5qg3>
- 如果A账号是海康互联的账号：这种情况下，建议可以将设备解绑后绑定至您的萤石开放平台账号B下，可将萤石账号设备同步至海康互联账号进行双平台下的使用。


如果您的情况无法适配以上几种方案，您可以考虑依靠设备能力：

- 您的设备是否支持萤石协议（或者其余私有协议）与国标协议双协议共同使用：需要找到硬件厂商方面确认（海康：400-800-5998；萤石：400-878-7878）。如支持，可以通过私有协议接入A平台，再通过国标协议接入萤石开放平台B账号下。
- 您的设备是否支持双国标平台使用：需要找到硬件厂商方面确认（海康：400-800-5998；萤石：400-878-7878）。如支持，可以通过国标协议同时接入两个不同的平台/一个平台的两个不同账号。
- 您的设备如果是摄像头（IPC），可以将IPC直连进入A账号，再通过IPC接入到NVR，通过NVR接入到账号B。反之也一样可行。


如果以上情况都不可行，可以考虑使用国标级联的方案（例如与海康ISC平台对接）：

- 如果您的设备当前在平台A上，需要平台A支持国标级联上联服务（将设备从A平台级联至其他平台）。如果支持，可以通过国标级联-下联服务将设备接入到萤石开放平台B账号下。详情可参考：<https://open.ys7.com/cn/s/26>
- 如果您的设备当前在萤石开放平台的B账号下，想要接入到其余平台的账号A中，需要平台A支持国标级联下联服务（通过国标级联的方式，接入其余平台的设备）。如果支持，可以通过国标级联-上联服务，将设备通过萤石开放平台级联到A平台中。详情可参考：<https://open.ys7.com/help/1799>
