# 国标接入常见问题

# 

使用国标接入服务中遇到的常见问题解答

## 一、名词介绍

### 1、设备、项目分别是什么？

- 设备：需要对接的硬件设备，例如摄像机、录像机、门禁、执法记录仪等。
- 平台与项目：萤石开放平台作为云上平台，面向开发者提供云端服务，提供稳定的开发环境。每一个使用国标业务的用户可在开放平台申请一个项目，申请项目成功后，开放平台将依照国标协议规定，为开发者分配注册认证id，开发者可接入自己的设备，在开放平台实现音视频等云端服务。

### 2、 IPC、NVR、通道分别是什么？

- IPC指摄像机；
- NVR指录像机；
- 通道指与录像机本地连接的摄像机。

国标接入服务中，NVR的设备国标ID 11-13位固定为111，IPC和通道的设备国标ID 11-13位固定为132。

### 3、接入参数是什么？有什么用？

国标控制台“概览”页和“设备详情”页的参数均由平台为用户分配，均需要用户在设备配置页进行填写，以此完成设备在平台的注册连通，实现设备与云平台之间的对接后，才能够使用开放平台提供的云端服务。

### 4、设备在开放平台的序列号格式？

- 国标接入IPC和NVR的序列号格式为“项目编号:设备国标ID”；
- 通道设备的序列号格式为“项目编号:通道所属NVR的设备国标ID:该通道的视频通道编码ID”。

国标控制台[“设备列表”](https://open.ys7.com/console/nationalStandard.html)可直接查看每台设备的“设备序列号”。

### 5、设备接入数如何计算？

申请1个摄像头/录像机/通道 接入开放平台需要的参数，即算1个接入数（无论是否绑定成功）。

注意，NVR本身也算一个设备接入数。例如，3个摄像头通道通过1个录像机接入萤石云，总共算4个设备接入数。

## 二、接入环节常见问题

### **1、 注册设备前获取运营商的服务注册IP地址产生ping不通的问题？（如下图所示）**

![](http://resource.eziot.com/group2/M00/00/5E/CtwQFmC55WWAbK3eAABWlyA0nm8506.png)

红色框中的地址就是您的网络注册地址，端口号为6800。蓝框中的请求超时产生原因是由于服务端是禁止ping的，做这一步的操作主要目的是为了拿到对应的注册地址。

### **2、 如何判断设备是否支持国标协议？**

设备是否支持国标协议需要联系**设备售后**确认。

如果摄像机设备不支持萤石协议或国标协议，只能通过海康NVR间接接入（需设备支持ONVIF协议）。

详细判断方式可参考：<https://open.ys7.com/help/1798>

### **3、 配置设备参数后，设备状态一直显示“未接入”？**

设备接入未成功，可能是参数配置遗漏或错误，也可能是网络和防火墙限制等原因导致，具体可参考[接入指南](https://open.ys7.com/help/1783)“五.常见问题”进行自助排查。

### **4、 SIP服务器地址使用域名和使用IP地址有什么区别？**

建议您最好可以使用域名，目前海康、大华、宇视最近几年的设备都已支持域名方式，如果使用的是IP地址，假设您对应的宽带网络运营商发生机房故障，您的设备也会受到对应时长的影响。使用域名在后期便于平台做异地多活、自动灾备，有效规避上述问题，更好的保障服务可用性。

### **6、 录像机只想把一部分通道接入萤石云怎么办？**

在控制台指定NVR的通道列表页面，申请指定数量的通道设备的接入参数，并在设备配置页“视频通道编码ID”模块依次填写即可。

### **7、 控制台上的设备统计数量与实际接入数量不一致？**

控制台概览页面统计的是**昨日**的设备数量，不是当日接入的设备数量。并注意，NVR也算1个设备数（例如1个NVR下挂2个摄像头，则算接入了3个设备）。

### **8、 设备接过其他平台了，还能接萤石云吗？**

可参考：<https://open.ys7.com/help/1798>

### **9、 控制台上NVR通道状态不对/接口获取状态不对？**

设备端完成参数配置后，萤石服务端更新设备状态会有一定的延时情况（一般情况下刷新尝试几次即可）。



## 三、取流环节常见问题

### **1、 设备接入后没有显示播放地址？**

设备配置参数有误和网络有限制，都有可能造成该问题。

- [接入参数排查](https://open.ys7.com/help/1783)
- [网络指南](https://open.ys7.com/bbs/article/94)

### **2、 设备国标接入后，视频听不到声音？**

国标设备对讲目前只支持AAC和G711a的音频格式（其中hls标准流只支持aac），如果设备端更改音频格式后仍然无法听到声音则可能需要对设备音频进行**转码**，开通转码服务可联系[接入助手](https://resource.eziot.com/group2/M00/00/A6/CtwQFmTMwnCALwrfAAEFlTbxFz8656.png)。

### **3、 返回错误码4，无法进行画面预览**

确认您的直播地址中是否携带国标设备的通道编号。详情见直播地址接口：<https://open.ys7.com/help/1414>

### **4、 其他注意事项**

（1）确认设备所在网络是否有防火墙，防火墙是否开启了入口的限制？

（2）确认设备所在网络的路由期配置DHCP租期是否过短，建议按照路由器默认配置，一般是2天。

（3）确认设备是否有针对UDP协议的防doss攻击功能，如果有的话，需要把设备接入服务的IP地址或域名添加到设备白名单里，此IP地址就是 ping devgb28181.das.ys7.com 拿到的IP地址，以下是海康国标设备的配置界面。

![](https://resource.eziot.com/group2/M00/00/5E/CtwQF2C55UmAMISuAAD4Iz637cI511.png)

（4）如果以上都尝试过，无法解决的话，建议设备重启，先在设备端抓包，端口6800，联系萤石工作人员协助排查。

### **5、 视频播放卡顿**

1. 正常情况下，首次出流速度：监控模式1-3s，直播模式FLV1-3s、RTMP1-3s、HLS6-15s
2. 如您出现卡顿严重现象，请按照如下步骤进行排查：

- 检查摄像头里面的配置，查看当前摄像头推送的码流，因为摄像头是公网接入，请根据摄像头的实际网络情况选择合适码率的视频流。
- 请检查播放所在的网络带宽是否满足摄像头的码率。
- 可尝试降低码流：当同一个网络内接入的设备过多时或者摄像头所处的网络环境波动较大时，会由于网络带宽的限制导致视频卡顿，以海康设备为例，建议的参数配置，其他品牌的配置方法详询厂家。
