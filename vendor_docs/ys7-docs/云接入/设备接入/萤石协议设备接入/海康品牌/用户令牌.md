## 通过用户令牌进行设备绑定

![](https://resource.eziot.com/group1/M00/01/2D/CtwQE2Z1JvaASNGLAABi6nbZUYA805.png)

部分设备在进行设备绑定的过程中，会提供用户令牌的绑定模式。那么用户令牌应该如何获取呢？

打开萤石云APP，“我的”-“个人资料”中查看用户令牌（下载地址：下载中心 - 萤石服务中心 - 萤石官网 - EZVIZ）
