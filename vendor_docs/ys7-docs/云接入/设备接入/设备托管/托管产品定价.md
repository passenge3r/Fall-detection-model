# 产品定价

## 1.1计费方式

设备托管使用的计费方式为后付费的按量计费。当您开通服务后，可默认根据使用量付费，每日结算。托管设备产生的费用由实际使用设备的开发者账号支付。

## 1.2计费组成

开发者账户所需交付的费用为账号企业版套餐费用

其中，企业版付费的设备接入数包括，账号下原先计费数+托管设备数；带宽量包括账号下设备产生带宽+托管设备通过开发者账号取流产生带宽。（企业版套餐价格：[官网价格详情页](https://open.ys7.com/price.html)）

## 1.3计费说明

- 设备接入费：

  按照当日账号下绑定设备托管通道数量计费。按日结预付费的计费方式。首先按照套餐内数量计费，超额部分单独按照单价计费。超出的托管设备收费为2元/通道/月。
- 带宽费：

  按每日上行带宽的峰值计费。按日结预付费的计费方式。首先按照套餐内数量计费，超额部分单独按照单价计费，带宽超额分为按照超出部分带宽计费或按照超出部分产生流量计费，由用户自行选择。
- 额外流量费：

  当日超出套餐部分时刻产生的流量总额。按日结预付费的计费方式。仅当日带宽出现超额情况且用户选择带宽超额按照流量计费时产生。
- 日结预付费：

  每日24：00对当日产生的费用进行结算，输出账单并对账号中余额进行扣费。
- 退费说明：

  请发送邮件至openteam@ezvizlife.com，向专业工作人员寻求帮助。

## 1.4计费示例

有一个客户在全国有50家连锁店，每家连锁店有3个IPC摄像头，通过托管方式接入开发者账号，根据实际的使用场景，一天对这些摄像头画面巡检的人数最多3个人，一个人同一个时间点看六个设备画面。所有设备的主码流设置为1M。

某月的一天账单情况：
建议客户选择E1套餐（100台，5M带宽，300元/月）

日基础套餐费：300/30=10元

日超额设备接入费：（50\*3-100）\*2/30=3.33元

日超额带宽费用（使用1.2/Mbps/天计算）：（6-5）\*1.2 = 1.2元

当日总费用：10+3.33 +1.2= 14.53元

\*所有费用由开发者账号支付
