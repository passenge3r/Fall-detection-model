# 产品简介

## 1.1什么是设备托管

C端用户可以通过设备托管将设备的权限（预览、回放、对讲等）授权给开发者用户，用于同一设备的二次开发。在保障设备所属于C端用户的同时，满足了开发者用户同步进行二次开发的需求。
有了设备托管功能，开发者用户不仅可以同时进行多账户设备二次开发，而且可以保留 C端 用户使用萤石 APP 的全部能力，降低成本；C端用户不但可以掌握设备所属权、拥有设备的全部使用权限，更可以自主控制授权权限信息，保障隐私安全。

## 1.2应用场景

设备值守业务——

通过设备托管可以接入其他系统实现居家看护、农场巡检等多类值守场景，实现在不打扰、不影响用户正常使用视频设备，开发者又能同步进行方案开发，提升用户体验和管理效率。

连锁门店集中管理——

通过设备托管可以将各个加盟商店铺下的设备托管至总部账号下，实现多店铺设备的统一管理

## 1.3功能揽概

设备托管接入服务包含设备管理、直播监控、录像回放、抓拍、云存储管理等。
![](https://resource.eziot.com/group1/M00/01/8F/CtwQE2h5uUWANRXBAANzalbdX2k798.png)

## 1.4产品优势

不打扰用户

保留 C端用户使用萤石 APP 的全部能力，并将部分功能授权给开发者开展其他业务。

成本低

C端用户在萤石云视频移动端观看的视频流量不纳入开发者账号下的取流带宽。

定制化授权渠道

为开发者打造定制化的授权流程，让C端用户清晰了解授权对象，将授权过程透明化。

安全性高

按需托管不同功能权限，随时取消或新增授权功能，保障用户自主授权权利，保护信息安全。

功能丰富

根据开发者方案定制开发不同功能，实现多行业场景方案。

官方推荐

优质开发者方案将获得萤石云千万用户推荐机会，获取更多潜在客户。
