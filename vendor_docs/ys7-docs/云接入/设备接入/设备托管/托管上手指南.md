## 1.5 检查托管是否成功

进入托管控制台—设备列表（https://open.ys7.com/console/deviceTrusteeship.html），可以看到被托管的设备已经在列表上，且可点击直播，获取直播地址，查看设备视频画面。
设备托管成功后开发者可以对该类设备进行正常的开发，实现预览、回放、对讲等功能。

## 1.6 开发者获取授权信息

开发者通过向萤石云平台提供回调接口后，用户进行授权操作时，平台会通过以下接口
给到开发者授权信息：

- 授权码回调：

  Url:{callBackAddress}?auth\_code=value&state=customInfo
- 授权信息（设备）回调：

  Url:{callBackAddress}？opt\_type=opt&deviceSerials=deviceSerials&deviceTrustId=deviceTr
  ustId&state=customInfo

1. 在授权过程中开放平台会先将 auth\_code 以及 state 给开发者，auth\_code 有效时长为 10分钟
2. 开发者拿到 auth\_code，后通过 auth\_code 和开发者的 access\_token 请求到开放平台获取授权信息接口（获取设备授权信息）
3. 收到授权信息后，返回给开放平台服务成功：{“code”: “200”}，返回其他字符则会接口调
   用失败
4. 获取 auth\_code 这次操作返回平台成功后，平台认为该次授权成功，最后返回给用户授
   权成功
5. 授权成功后平台会再回调一次，将授权设备和用户设备授权 id- deviceTrustId 传给开发者

![](https://resource.eziot.com/group1/M00/01/8F/CtwQEmh59FSAaHX_AABObwqkpR4564.png)

## 1.7 开发者应用获取授权信息

### 1.7.1 关于托管中的 token

托管/授权关系中，开发者会同时存在 4 种 token：

1. 开发者 token：开发者自身的 token，目前暂时无法操作授权设备，仅用于调用授权设
   备控制类（包含获取授权设备列表）接口外的其他接口；
2. 授权设备刷新 token：与开发者&授权用户关系存在唯一关联，用于刷新授权设备
   token，刷新 token 目前会长久存在，刷新 token 只能通过授权回调中的 auth\_code 获
   得；
3. 授权设备 token：主要通过刷新 token 获取，在获取刷新 token 时，也会给到，用于授
   权设备的实际操作，同样与开发者&授权用户关系存在唯一关联，通过该 token 获取托
   管设备列表时，可以获取到所有跟该 token 关联的用户所授权给该开发者的设备，同
   样，该 token 所能操作的设备权限仅限于该 token 对应用户授权的设备；
4. 授权设备 ALL 权限 token：可以通过开发者 appkey 及 sercret 获取，该 token 和授权设
   备 token 用法类似，但是不与某用户、用户关系绑定，可以操作所有开发者下的授权
   设备和能够获取到所有授权设备。

### 1.7.2 授权设备的操作方式

1. 通过获取托管设备列表接口，可以获取到参数中 token 权限覆盖的授权设备
2. 使用 ezopen 播放和 sdk 播放函数播放时，操作的设备需传入有该设备操作权限的
   token，授权设备 ALL 权限 token 或该设备对应的授权设备 token
3. 当不操作授权设备时，开放平台的所有需要用到 token 的接口，均使用开发者 token 即
   可
4. 目前支持的能力：预览（不支持直播地址）、回放、告警消息（alarm）订阅、云台控
   制、子账号、抓图、探测器网关
