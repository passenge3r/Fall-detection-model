# 云接入产品概览

## 产品简介

萤石 IoT 设备接入服务帮助各类硬件设备快速接入萤石开放平台，平台提供统一的设备交互接口和云端服务，方便开发者基于接入设备进行二次开发，快速实现行业定制化应用。

## 产品优势

- 多协议统一接入管理：支持多种协议接入萤石自有和三方设备统一接入，让开发者自定义开发千行百业业务落地
- 海量设备稳定连接：亿级设备稳定运行，服务有保障
- 全球设备就进接入：全球覆盖的云服务，根据用户使用地区就进接入
- 丰富的云端服务：针对接入的设备提供直播、存储、AI、智能巡检等一系列云端服务供开发者选择，加速项目落地

## 核心能力

### 设备统一接入

萤石云支持多品牌、多协议设备统一接入萤石开发者B端账号，让开发者可以在萤石一朵云上管理所有设备。

| 接入方式 | 设备类型 | 设备添加方式 |
| --- | --- | --- |
| 萤石协议 | 海康设备：IPC、NVR、门禁、音频传感等产品 萤石设备：IPC、门锁、门铃、智能屏、家居传感器等 | 1. 通过序列号、验证码添加 2. （海康设备）本地配置页启用萤石云 3.（海康设备）用户令牌绑定 |
| GB28181协议 | 三方品牌（如大华、宇视、天地伟业等）视频设备 | 在设备上配置国标参数 |
| 设备托管 | 已接入萤石云 C 端 App 的设备，需要同时给B端账号访问时 | 先通过萤石云App配网添加，再托管给B账号 |
| 国标级联 | 下级平台：企业在本地已管理了一批设备通过级联提供给萤石 上级平台：客户将萤石云上的设备通过级联共享给上级平台 | 开放平台级联平台管理 |
