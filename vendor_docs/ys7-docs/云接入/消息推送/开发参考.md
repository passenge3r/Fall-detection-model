## 推送机制

萤石开放平台向您的业务系统推送消息后，如果业务系统接收消息成功，应及时向萤石开放平台返回 200 OK 响应码。如果业务系统超过 2 秒未返回响应，或者向平台返回非 200 的 HTTP 响应码（如 500、501 等），平台将认为消息推送失败。基于您设置的重试次数，平台将在推送失败时尝试再次推送，如果达到最大重试次数时仍未推送成功，平台将丢弃相应消息。

如果 1 分钟内推送失败率超过 50% 时，平台会将该业务系统标记为 **预降级** 状态，此状态下平台不会调整消息推送机制。注意，即使在达到最大重试次数前推送成功，在此之前的失败次数仍然会被计入推送失败率。

此后，如果连续推送成功次数大于 10 次，则该业务系统将从 **预降级** 状态 恢复成 **正常** 状态；如果该业务系统持续处于 **预降级** 状态超过 24 小时，平台则会正式将该业务系统标记为 **降级** 状态。对于标记为 **降级** 状态的业务系统，平台将随机选取 10% 的消息尝试推送，其余消息将被立即丢弃，直到连续推送成功次数大于 10 次，该业务系统才会被重置为 **正常** 状态。

## 推送消息格式

### 消息结构概览

平台推送的消息均由 Header 与 Body 两部分组成（注意并非 HTTP Request Header 与 HTTP Request Body）。示例：

```
{
	"header": ...,
	"body": ...
}
```

其中 Header 用于存放通用字段，Body 则用于存放与具体消息类型相关的业务字段。

Header 中的通用字段如下：

| 字段名称 | 数据类型 | 必选/可选 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| type | String | 必选 | 用于指示消息类型，可取值有： - ys.alarm，表示使用萤石协议接入的设备上报的告警消息。PS：部分型号的海康设备也采用萤石协议接入，请联系设备销售方确认 - ys.open.isapi，表示海康设备 ISAPI 消息 - ys.onoffline，表示设备上下线消息 - ys.device.slaves，表示 NVR 通道设备上下线消息 - ys.open.ram，表示托管设备变更消息 - ys.iot，表示三方设备（含国标接入设备）事件通知消息 - ys.shadow.change，表示三方设备属性变更消息 - ys.open.cloud，表示云录制消息 - ys.calling，表示呼叫消息 - ys.open.ai.resultData，表示 AI 算法结果通知消息 | ys.alarm |
| deviceId | String | 必选 | 设备序列号。 | 889036108 |
| channelNo | Number | 可选 | 设备通道号。为 0 时表示消息来自设备本身。 | 0 |
| messageId | String | 必选 | 用于唯一标识消息的 ID，消息接收方须在响应中返回此 ID。 | 3717e72051224ec095 |
| messageTime | Number | 必选 | 平台推送消息的时间，单位为毫秒。 | 1772700116891 |

## 消息签名与验签

一旦设置了签名密钥，平台将在推送消息前使用该密钥对消息正文（存放在 HTTP Request Body 中）施加签名，并将该签名与其他元数据附加在 HTTP Request Header 中，Header Name 为 `Signature`，接收方可使用自己持有的签名密钥验证收到的消息与签名是否匹配，从而验证消息的合法性。

以下为签名的计算方式：

1. 获取一个最新的毫秒级时间戳 Timestamp，将其转换为字符串后追加到消息正文 Message 末尾。
2. 使用密钥 Secret 计算拼接后的字符串的 HMAC-SHA1 值。

```
Signature = hmac_sha1(Secret, Message + Timestamp)
```

> 使用消息签名时，建议同时启用 HTTPS 以提高安全性。

### 示例

现有以下消息正文：

```
{
	"header": {
        "deviceId": "D98462102",
        "messageId": "5e57f239793f2b007fecb0de",
        "type": "ys.open.isapi"
    },
    "body": {
        "data": "this is an example"
    }
}
```

密钥为：

```
mysecret
```

毫秒级时间戳为：

```
1772435918362
```

根据以上签名计算规则，可得：

```
Signature = hmac_sha1("mysecret", "{\"header...is an example\"}}1772435918362")
          = "ccf4a926e5481feef0f541e7abc9e2997f9d59d2"
```

因此最终的 HTTP 请求为：

```
POST /webhook-server HTTP/1.1
Host: example.com
t: 1772435918362
message_type: ys.open.isapi
Signature: ccf4a926e5481feef0f541e7abc9e2997f9d59d2
Content-Type: application/json
Content-Length: 135

{
    "header": {
        "deviceId": "D98462102",
        "messageId": "5e57f239793f2b007fecb0de",
        "type": "ys.open.isapi"
    },
    "body": {
        "data": "this is an example"
    }
}
```

## 消息图片获取

### 萤石设备告警图片获取

部门萤石设备在产生告警时，还会将当前时刻的图片上传至平台，此时设备的告警消息中还将包含该图片的 URL 下载地址。

- 如果 URL 中的 isEncrypted 字段值为 0，则表示当前图片未被加密，您可以直接使用该 URL 下载图片；
- 如果 URL 中的 isEncrypted 字段值为 1，则表示当前图片已被设备加密，如果您已集成萤石提供的 ezOpenSDK，则可以通过 SDK 提供的接口解密图片（详见 SDK 文档）；如果您未集成 ezOpenSDK，则建议调用此 [API](https://open.ys7.com/help/56#device_switch-api2) 解除设备加密。对于托管设备，可以让设备持有者在萤石云视频 APP 中关闭该设备的视频加密。

注意：由于新老型号的萤石设备实现有所不同，在某些情况下，您可能需要在下载后手动加上后缀名 `.png` 才能打开相应图片。

### 海康设备 ISAPI 图片获取

如果有图片上传，海康设备的 ISAPI 消息中将包含该图片的 URL 地址，但该地址不可直接用于图片下载，您需要将该地址作为此 [API](https://open.ys7.com/help/1376) 的请求参数来获取最终的下载地址。注意，该 API 会返回 302 状态码，并使用响应头中的 Location 字段返回图片下载地址。
