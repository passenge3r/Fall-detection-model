## 服务开通与配置

您可以在控制台访问 **云信令 > 消息推送**，然后配置和开通消息推送服务。注意，开通服务须等待两小时生效。另外，如果您注册开发者账号使用的手机号同样注册了 **萤石云视频 APP** 的用户，在开通消息推送服务后，您在 APP 端将无法接收设备消息提醒。

> 目前关闭消息推送服务后，APP 端的消息提醒无法自动恢复，需要您联系小助手或提交工单联系运维人员手动恢复。

目前萤石开放平台支持以下配置项：

| 选项 | 必选/可选 | 描述 |
| --- | --- | --- |
| 开通消息类型 | 必选 | 选择您希望平台推送的消息类型。开通时无法变更消息类型，开通后方可修改。更改消息类型后同样须等待两小时生效。 |
| WebHook 回调地址 | 必选 | 用于接收消息的 WebHook 服务的 URL 地址，格式参考：https://example.com:8080，支持 HTTPS。 |
| 失败重试次数 | 必选 | 消息推送失败时的最大重试次数，达到最大重试次数仍未成功推送的消息就被丢弃不再尝试投递。注意：WebHook 服务超时未响应、返回 200 以外的状态码、状态码为 200 但响应格式不正确，均被视为推送失败。 |
| 回调失败联系人（邮箱） | 可选 | 因消息持续推送失败导致服务降级时平台将发送提醒邮件至此邮箱。 |
| 回调失败联系人（手机号） | 可选 | 因消息持续推送失败导致服务降级时平台将发送提醒短信至此手机号。 |
| 签名密钥 | 可选 | 最大长度为 64 字节的由英文字母、数字组成的字符串，用于对消息施加签名，接收方可通过签名验证消息是否被伪造和篡改。 |

### 消息类型

目前平台支持以下消息类型：

| 消息类型 | 说明 |
| --- | --- |
| 萤石设备告警消息 | 萤石品牌设备产生的移动侦测、人体感应等告警消息。 |
| 海康设备 ISAPI 消息 | 海康品牌设备上报的均属于 ISAPI 消息，平台将透传此类型消息。 |
| 设备上下线消息 | 设备上下线消息通知。注意：通过 NVR 接入平台的 IPC 设备的上下线消息通知将转为 NVR 通道设备上下线消息。 |
| NVR 通道设备上下线消息 | IPC 设备通过 NVR 接入平台后，在相应 NVR 通道上产生的设备上下线消息通知。 |
| 托管设备变更消息 | 托管设备状态变更通知，状态变更包括但不限于： - 设备托管/解除托管 - 设备/通道名称变更 - 布撤防状态变更 - 在线状态变化 - 云存储状态变更。 |
| 注意：仅萤石、海康品牌设备支持托管。 |  |
| 三方设备事件通知消息 | 三方设备产生的事件通知，三方设备指国标设备和 ezDevSDK 接入设备。 |
| 三方设备属性变更消息 | 三方物模型设备上报属性发生变化时的变更通知。萤石、海康品牌设备及国标设备不建议开通此消息类型。 |
| 云录制消息 | 云录制服务产生的计划创建/删除、任务开始/结束等消息。 |
| 呼叫消息 | 呼叫产生的呼叫开始/接听/挂断等消息。 |
| AI 算法结果通知消息 | 对于支持异步调用的 AI 服务（如视频烟火检测、台球视频分析等），您可以在成功发起服务调用后，通过平台推送的此消息类型异步获取算法结果。 |

### 消息使用前提

**萤石设备告警消息**

如需获取萤石设备的告警消息，设备必须处于布防状态。您可以调用此 [API](https://open.ys7.com/help/672) 查询设备当前是否处于布防状态，调用此 [API](https://open.ys7.com/help/701) 修改设备布撤防状态。

**海康设备 ISAPI 消息**

如需获取海康设备的 ISAPI 消息，必须首先完成以上前置操作：

1. 订阅设备消息，即通知设备向平台上报 ISAPI 消息，可调用此 [API](https://open.ys7.com/help/1385) 完成相应操作。
2. 开通云录制 1.0 服务并创建用于存放设备上传的 ISAPI 图片的文件夹。创建步骤如下：

   1. 登录 [萤石开放平台控制台](https://open.ys7.com/console)。
   2. 在左侧导航栏，选择 **云存储 > 云录制**，点击 **项目管理** 页签。

      ![](https://izhstatic.ys7.com/vasp-openweb/1772777850842_image-20260306140105348.png)
   3. 点击 **新建项目**，输入项目信息后，点击 **确定** 完成项目创建：

      | 选项名称 | 是否必选 | 描述 |
      | --- | --- | --- |
      | 项目名称 | 是 | 即项目文件夹名称。 |
      | 项目编号 | 是 | 由英文字母、数字或下划线组成的字符串，最大长度为 32 个字符。调用 API 时将使用此编号来唯一标识项目，因此项目之间的编号不可重复。 |
      | 文件保存模式 | 是 | 可选 标准存储 和 归档存储，标准存储模式下，文件须至少保存 7 天；归档存储模式下，文件须至少保存 60 天。 |
      | 文件保存时间 | 是 | 项目下文件的最长保存时间，到期后文件将被自动删除并释放存储空间。 |
   4. 点击创建好的项目文件夹右上角的 `...` 按钮，选择 **设为 ISAPI 项目**，完成后您将看到文件夹图标中增加了 ISAPI 标识。

      ![](https://izhstatic.ys7.com/vasp-openweb/1772777891027_image-20260306141026941.png)

      > 注意：每位用户只能设置一个 ISAPI 项目。如果已有项目文件夹被设为 ISAPI 项目，须删除该项目，才能将其他项目文件夹设为 ISAPI 项目。

**云录制消息**

云录制消息均由云录制服务产生，如计划创建/删除消息，任务开始/结束消息等。因此，如需获取云录制消息，必须首先开通云录制服务。

## 推送统计

开通消息推送服务后，您可以随时访问 **云信令 > 消息推送** 的 **概览** 标签页查看平台今日推送的消息总数，以及各类消息的分布情况。

![](https://izhstatic.ys7.com/vasp-openweb/1772777936862_image-20260306141127313.png)

切换至 **推送记录** 标签页，您则可以查看最近一个自然月内的消息推送记录，每条记录均包含消息来源、推送时间、消息类型与推送结果，以便您更高效地排查消息问题。

推送失败时，您还可以看到具体的失败原因提示，以下是可能的失败原因：

| 失败原因提示 | 说明 |
| --- | --- |
| 地址错误 | WebHook 回调地址格式错误。 |
| 非正常http状态码 | 对端未返回正确的 HTTP 状态码，消息推送服务目前仅在收到状态码为 200 的响应时认为消息推送成功。 |
| 错误的返回数据 | 对端返回的响应格式错误。 |
| messageId缺失 | 对端返回的响应后缺少 messageId 字段。 |
| 超时异常 | 对端未在 2 秒内返回响应，请检查您的 WebHook 服务。 |
| 连接异常 | 对端无法连接，请检查您的 WebHook 服务。 |
| 服务降级 | 当前消息因服务降级而被取消推送。 |
| 未知异常 | 请联系客服。 |

![](https://izhstatic.ys7.com/vasp-openweb/1772778052624_CtwQFmQRgOaAC-zeAAAnfyrCnb4957.png)

您还可以切换至 **业务统计** 标签页，查看平台的日推送消息次数统计，以及精确至设备维度的每日消息推送数量。

![](https://izhstatic.ys7.com/vasp-openweb/1772778083518_CtwQF2QRgfeAFzvaAAAvvMkDJjU255.png)

## 消息测试

当您的 WebHook 服务未能按照预期收到平台推送的消息，您可以借助消息测试功能快速排查定位存在问题的消息链路，然后进行针对性的调整。

### 前置条件

- 消息推送服务已启用。
- 一台与您的开发者账号绑定的设备。

### 注意事项

- 消息测试功能启用期间，消息不会再被推送至您此前配置的 WebHook 服务地址，因此请谨慎操作，以免影响正常业务。
- 消息测试功能启用期间，平台会默认为您开通所有消息类型以便您进行测试。在您关闭消息测试功能后，平台会自动为您 **恢复** 至原先开通的消息类型。

### 操作步骤

- 登录 [萤石开放平台控制台](https://open.ys7.com/console)。
- 在左侧导航栏，选择 **云信令 > 消息推送**，选择 **消息测试** 标签页。
- 点击 **开启消息测试**，点击二次确认弹窗中的 **确定**，即可成功开启。
- 首先，测试设备到平台之间的消息链路。尝试人为触发设备消息（如设备上下线消息、萤石品牌设备告警消息等），然后在 **消息上报平台** 页签中观察是否有新的消息记录产生。
  - 若有消息记录产生，且消息上报平台状态为 **成功**，则说明设备与平台之间的消息链路正常，可以进行下一步操作；
  - 若无消息记录产生，则说明设备与平台之间的消息链路存在异常，需要优先排查此链路，可能原因如下：
    - 消息推送服务开通后未满两小时，因此服务尚未生效。
    - 针对萤石设备告警消息，可能是设备未处于布防状态，您可以调用此 [API](https://open.ys7.com/help/55?h=%E6%92%A4%E9%98%B2#device_select-api2) 查询设备当前是否处于布防状态。
    - 针对萤石设备告警消息，可能是设备实际未触发告警，您可以联系设备持有者确认是否正确触发告警、是否正确配置告警等。
- 如果上一步测试通过，那么可以进一步测试平台到 WebHook 服务之间的消息链路。单击 **测试平台消息上报客户端** 页签，单击 **新建测试任务**，输入您期望测试的 WebHook 服务的 URL 地址，然后单击 **确定**。平台将虚构一条消息推送到您配置的 WebHook 服务，并输出对应的推送记录，可能的推送失败原因请参考 **推送统计 - 推送记录**。
