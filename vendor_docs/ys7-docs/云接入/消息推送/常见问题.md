### 收不到设备上报的告警消息

建议先检查设备是否处于布防状态，您可以使用此 [API](https://open.ys7.com/help/55?h=%E6%92%A4%E9%98%B2#device_select-api2) 查询设备布防状态。如果设备未布防，则可以使用此 [API](https://open.ys7.com/help/56?h=%E5%B8%83%E6%92%A4%E9%98%B2#device_switch-api1) 修改设备布撤防状态；如果设备已布防，则检查告警消息类型是否开通以及开通时间是否超过 2 小时。如果以上检查均没有问题，那么将较大概率是平台与您设置的 WebHook 服务之间的消息链路存在问题，可以尝试通过 **消息测试** 功能排查。

### 萤石云视频 APP 收不到设备消息提醒

开通消息推送服务后，设备消息将只会被推送给您配置 WebHook 服务。

### 能否自定义修改平台推送消息中的某些字段？

平台暂不支持此功能，您可以在接收消息后自行修改。

### 消息中的图片下载后无法打开

请检查图片下载链接中的 isEncrypt 字段，如果值为 1，则说明图片已经被设备加密，您需要调用 ezOpenSDK 的相关接口解密图片，如果您未集成 ezOpenSDK，则建议 [关闭设备加密](https://open.ys7.com/help/56#device_switch-api2)。
