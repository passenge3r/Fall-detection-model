## 概述

本章节旨在帮助您快速了解如何配置和使用萤石开放平台的消息推送服务。

## 前提条件

- 注册开发者账号
- 开通消息推送服务
- 准备一个具备公网 IP 的 Python 开发环境（用于运行 Python 脚本编写的 WebHook 服务，如您准备使用其他开发语言，可以替换为对应的开发环境，但公网 IP 是必须的）
- 一台与您的开发者账号绑定的设备。

## 搭建和运行 WebHook 服务

您可以使用以下示例代码搭建一个简易的 WebHook 服务：

```
from http.server import HTTPServer, BaseHTTPRequestHandler
import json

HOST_NAME = 'localhost'
PORT_NUMBER = 8080

class SimpleHandler(BaseHTTPRequestHandler):
    def _send_response(self, status_code: int, data: dict):
        self.send_response(status_code)
        self.end_headers()
        self.wfile.write(json.dumps(data, ensure_ascii=False).encode("utf-8"))
    
    def do_POST(self):
        content_length = int(self.headers['Content-Length'])
        raw_body = self.rfile.read(content_length)
        request_data = json.loads(raw_body.decode("utf-8"))
        sorted_json = json.dumps(request_data, ensure_ascii=False, indent=4, sort_keys=True)
        print("Received POST request with body: \n" + str(sorted_json))
        
        message_id = request_data.get("header", {}).get("messageId")
        response = {
            "messageId": message_id
        }
        self._send_response(200, response)

def run_server():
    server_address = (HOST_NAME, PORT_NUMBER)
    httpd = HTTPServer(server_address, SimpleHandler)
    print(f"服务器启动成功: http://{HOST_NAME}:{PORT_NUMBER}")
    try:
        httpd.serve_forever()
    except KeyboardInterrupt:
        print("\n服务器正在关闭...")
        httpd.server_close()

if __name__ == '__main__':
    run_server()
```

将以上代码保存为 `simple_server.py` 文件，然后在文件所在目录执行以下命令以启动服务：

```
python3 simple_server.py
```

## 开通并配置消息推送服务

### 操作步骤

- 登录 [萤石开放平台控制台](https://open.ys7.com/console)。
- 在左侧导航栏，选择 **云信令 > 消息推送**，点击 **立即开通**。
- 在 **消息推送服务开通** 对话框中，输入您的 WebHook 服务的 URL 地址，其他配置项保持默认即可，然后单击 **确定** 开通服务。

> 开通后，服务将在两小时后生效，耐心等待即可。
