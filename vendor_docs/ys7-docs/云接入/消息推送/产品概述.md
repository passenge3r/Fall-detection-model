## 什么是消息推送

萤石开放平台为开发者提供了可靠的、易集成的消息推送服务。它可以将与设备相关的告警、事件通知等各类型消息以 WebHook 方式即时地推送至外部服务，以满足绝大部分场景下的应用开发需求。

![](https://izhstatic.ys7.com/vasp-openweb/1772777580087_image-20260306094205570.png)

## 产品优势

### 支持 HTTP 协议接入

目前消息通道支持 HTTP 协议接入，采用 RESTful 风格，方便易用，快速接入，跨网络能力强。

### 性能指标卓越可靠

消息推送服务提供每秒 30 万推送处理能力，采用高可用分布式集群技术，具备高吞吐能力、可有效避免消息堆积的问题，服务稳定性经历过用户考验。

### 可靠重试策略

根据用户自定义重试次数，实现在开发者平台的的推送，不易产生漏传，有效提高推送抵达率。

### 实时推送效果展示

消息推送服务提供实时推送记录的展示，实时统计推送的抵达、状态等数据口径，并将以上数据在管理台可视化地展现出来，助力实时监控推送效果。

### 可视化调试工具快速排除故障

消息推送服务中的测试工具，可以协助用户在集成阶段快速接入服务，在问题排查阶段精准定位问题点，保证用户业务平稳进行。

## 应用场景

### 告警响应

通过将设备告警实时推送给您配置的 WebHook 服务，您可以在事件发生（如陌生人经过、人员入侵等）时及时做出响应。

### 设备联动

借助消息推送和平台提供的设备控制 API，您可以实现任意设备之间的场景联动，如收到开门事件通知时，联动 IPC 抓取图片或录像片段。

## 使用限制

- 消息推送目前为免费服务，但个人版套餐仅支持为每日前 10 台设备推送消息，如需推送更多设备的消息，须升级至企业套餐。
- 消息推送服务目前使用异步方式推送消息，因此无法为您保证消息的有序性。
- 暂不支持创建 VPC 对等连接。
- 若消息推送持续失败，将触发服务降级，详情请参考 **开发参考 - 推送机制**。
