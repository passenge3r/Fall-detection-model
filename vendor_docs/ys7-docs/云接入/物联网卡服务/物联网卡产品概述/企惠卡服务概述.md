# 企惠卡服务概述

## 什么是企惠卡

企惠卡是针对高流量需求企业用户打造的专属流量服务，聚焦海康 / 萤石设备访问萤石云场景，以**大流量、低资费**为核心优势，精准匹配企业级使用需求。

---

## 有什么优势

1. **资费更划算**：流量资费较普通卡显著降低，高性价比满足企业长期使用需求。
2. **场景更适配**：支持新增额外 IP 和域名，完美覆盖 toB 场景中设备需跨平台集成的常见需求。

---

## 套餐资费

### 年套餐

| 套餐规格 | 价格（元/年） |
| --- | --- |
| 100G/月 x 12月 | 500 |
| 300G/月 x 12月 | 1350 |
| 500G/月 x 12月 | 1900 |
| 1000G/月 x 12月 | 3400 |

### 月补充套餐

| 套餐规格 | 价格（元/30天） |
| --- | --- |
| 100G/月 30天 | 45 |
| 300G/月 30天 | 120 |
| 500G/月 30天 | 180 |
| 1000G/月 30天 | 320 |

#### 注：

1. 月补充套餐需在已开通年基础套餐的前提下购买，不可单独办理。
2. 年套餐购买后，若当前有在生效的其他年套餐，将自动顺延至现有套餐到期后生效。
3. 月补充套餐有效期与当前年套餐的本期周期保持一致。
   - **例**：当期年套餐周期为 2026年1月12日-2026年2月12日，2026年1月29日购买的月补充套餐，则有效期同步为 2026年1月12日-2026年2月12日。

---

## 使用说明

1. 未持有企惠卡的用户，需先通过企惠卡补发页面补发，添加至单卡模式下，“激活”后使用。
2. 企惠卡均为插拔卡，仅限在 `****`/萤石品牌设备上使用。
3. 企惠卡无法加入流量池，且仅可选购本产品专属套餐，无法购买普通流量套餐。
4. 企惠卡专属套餐仅允许企惠卡可选购，非企惠卡无法购买。
