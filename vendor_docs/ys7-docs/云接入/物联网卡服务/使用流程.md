# 使用流程

## （一）账号注册

### 1. 账号注册和登录

- 打开萤石开放平台官网，登录您的账号。
- 若您还没有账号，请先注册。

### 2. 创建应用信息

- 注册完毕后完善应用信息。
  - 首先，点击“立即创建”按钮。
  - 按照如下步骤填写相关信息后提交：
    1. 请填写“仅使用物联网卡服务”。
    2. 请填写“单卡模式/流量池模式”，填写完成后提交，即可完成应用创建。

---

## （二）物联网卡服务控制台概览

物联网卡服务控制台整合卡生命周期管理、流量监控、故障诊断、费用管控等全流程功能，助力用户高效管理物联网卡。

### 1. 控制台入口

1. 登录萤石开放平台控制台。
2. 在“云接入”处选择“物联网卡服务”进入服务页面。

### 2. 核心模式选择

物联网卡服务页面主包含两大核心模式，适配不同使用场景。

| 序号 | 模块 | 说明 |
| --- | --- | --- |
| ① | 流量池模式 | 支持电信、移动、联通运营商流量池，所有同运营商卡片共用一个流量池 |
| ② | 单卡模式 | 支持单卡 SIM 卡管理服务，每张卡独立使用专属流量套餐 |

> 注：若用户存在恶意使用流量池功能的行为（如宣传无限流量/终身流量等），萤石有权无责停止服务，并追究用户责任。

---

## （三）流量池模式操作指南

支持电信、移动、联通运营商流量池，提供萤石物联网卡流量池管理服务。

### ① 模块概览

| 模块名称 | 说明 |
| --- | --- |
| 剩余总流量（GB） | 包含剩余总流量、我的资源包、购买流量包等功能。 |
| 剩余量趋势 | 可视化展现流量池剩余总流量的每日变化趋势。 |
| 每日使用量 | 展示流量池每日流量消耗详情。 |
| 流量消耗排名Top100 | 日/月流量消耗榜单，可查询流量消耗前100的卡号及具体消耗情况。 |
| 模式选择 | 包含流量池/单卡模式切换及运营商选择（电信、移动、联通）。 |

### ② 流量统计模块

- 可查询近半年内某张卡在任意时间段内（最长跨度为30天）的流量消耗情况与趋势，数据精准可追溯。

### ③ 卡号管理

| 模块名称 | 说明 |
| --- | --- |
| 卡列表 | 卡号管理：支持新增/删除卡片；卡状态管理：查询卡状态、使用时间、消耗等；标签管理：编辑备注，支持按备注筛选卡号；流量使用管理：设置卡流量上限，控制使用时段。 |
| 申请列表 | 支持实体卡丢失或损坏时补发操作。 |

### ④ 服务设置

| 模块名称 | 说明 |
| --- | --- |
| 余量预警 | 支持按流量使用百分比、剩余量、资源包有效期等维度进行预警设置。 |
| 联系人设置 | 支持添加/勾选预警通知联系人，生效后可接收对应通知。 |

---

## （四）单卡模式操作指南

提供萤石物联网卡单卡管理服务。

### 1. 概览

| 模块名称 | 说明 |
| --- | --- |
| 卡列表 | 卡号管理：支持新增/删除卡片；卡状态管理：查询卡状态、运营商、使用时间、消耗等；标签管理：编辑备注，支持按备注筛选卡号；资源包管理：直接购买、管理流量资源包。 |
| 申请列表 | 支持实体卡丢失或损坏时补发操作。 |

### 2. 流量统计

- 可查询近半年内某张卡某个时间段内（最长跨度为30天）流量消耗情况与趋势。

### 3. 服务设置

| 模块名称 | 说明 |
| --- | --- |
| 余量预警 | 支持按流量使用百分比、剩余量、资源包有效期等维度进行预警设置。 |
| 联系人设置 | 支持设置多个流量预警通知联系人。 |
