# 物联网产品概述

## 物联网服务的基本概念

物联网卡服务是面向企业及行业用户的一体化物联网连接解决方案。萤石依托自主研发的卡管理平台，整合电信、移动、联通三大运营商优质资源，为用户实现物联网设备的网络连接提供稳定、安全、智能的技术支撑。服务涵盖卡生命周期管理、流量监控、故障诊断、费用管控等全流程，助力用户实现设备高效联网与数字化运营。

---

## 服务功能

萤石物联网服务包含卡管理、流量监控、流量池共享、达量断网、标签管理、余量告警等功能，为设备提供完整的物联网卡服务。

### 1. 卡管理

- 实时查看账号下卡总数、卡号、卡状态、运营商等相关信息。
- 支持自主管控卡片可用性，操作便捷高效。

### 2. 流量监控

- 单卡、流量池的流量使用、消耗情况可视化呈现。
- 支持按流量消耗数据对卡片进行排序，使用情况一目了然。

### 3. 流量池共享

- 支持多物联网卡共享同一流量资源池，实现流量高效利用。
- 大幅优化企业联网成本。

### 4. 达量断网

- 可按月、季度、半年、年度自主设置卡片流量使用上限。
- 精准控制流量消耗，避免超额浪费。

### 5. 标签管理

- 支持按不同项目为卡片添加备注，搭配批量搜索功能。
- 项目维度卡片管理更高效精准。

### 6. 余量告警

- 平台支持流量池流量快到期、剩余量达到设定阈值时自动触发短信告警（需先完成手机号配置）。
- 精准推送预警信息，确保及时知晓流量状态，避免设备断网。

- **Q：已办理年套餐的情况下，再次购买可以叠加使用吗？**

- **Q：月补充套餐的生效时间如何计算？**
  - A：月补充套餐有效期与当前年套餐的本期周期保持一致（例：当期年套餐周期为2026年1月12日-2026年2月12日， 2026年1月29日购买的月补充套餐，则有效期同步为2026年1月29日-2026年2月12日）。
