# 国标级联下联 开通流程

## 一、前提条件

请确保您的账号已购买企业版套餐，国标级联服务服务仅面向企业版账号提供。

## 二、试用申请

国标级联服务当前支持免费试用，试用时长为15天，国标级联服务开通15天内国标级联的相关使用均免费。

[试用入口](https://open.ys7.com/console/nationalStandardCascade.html)

## 1、创建下级平台

目前萤石支持的级联模式是：**信令-UDP协议、取流-TCP-passive模式**，请提前和下级沟通咨询是否支持这两种模式。（会影响到后期的级联是否成功哦！）

![](https://resource.eziot.com/group1/M00/01/6C/CtwQE2duQ-mAJYUPAAGh_T7op1Y044.png)
![](https://resource.eziot.com/group1/M00/01/6C/CtwQEmduQ-6AcYzTAAGAKnIxHs4411.png)

| 需填写项 | 备注 | 举例 |
| --- | --- | --- |
| 下级平台名称 | 下级平台的名称，由用户自定义 | 例如：杭州海康威视有限公司 |
| 下级平台级联编码 | 下级平台级联编码（由上级平台提供，以免平台间重复） | 用于给上级平台区分不同的下级平台，建议由上级平台指定，若上级没有规定，则用户可自定义填写（不与上级编码相同,11-13位为200） |
| 下级平台ip | 下级平台的注册IP | （由下级平台提供）例如：IP：000.000.00.000 |
| 下级平台端口 | 下级平台注册端口号 | （由下级平台提供）例如：7800 |
| 选择上级平台 | 选择本次接入的上级平台 |  |
| 新建上级平台 |  |  |
| 上级平台名称 | 上级平台的名称，由上级指定或用户自定义 | 例如：浙江省环保局 |
| 上级平台级联编码 | 上级平台国标级联编码 | （由上级平台提供）例如：33000000002000000001（20位数字11-13位为200） |

项目创建成功以后，可以开始为与该下级平台的关联查看相关资源配置，并进行联通测试。

## 2、获取级联资源信息

级联完成后，可点击“级联资源”查看下级平台级联资源信息
