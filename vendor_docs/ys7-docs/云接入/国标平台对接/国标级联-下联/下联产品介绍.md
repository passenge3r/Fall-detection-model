# 国标级联下联

## 一、什么是国标级联

## 1. 国标级联

级联，两个信令安全路由网关之间按照上下级关系连接，上级中心信令控制服务器通过信令安全路由网关可调用下级中心信令控制服务器所管辖的监控资源，下级中心信令控制服务器通过信令安全路由网关向上级中心信令控制服务器上传本级中心信令控制服务器所管辖的监控资源或共享上级资源。

![](https://resource.eziot.com/group1/M00/01/6C/CtwQE2duQ9eAB_aaAABH_RqgTK0695.png)

通过级联，可以通过平台与平台间的对接方式，将已经接入到自身平台的摄像头便捷化共享给第三方平台进行设备播放以及控制，实现了不同平台间的互联互通。

## 2. 萤石国标向下级联

萤石开放平台，开放自身音视频云平台能力，共享平台服务，提供作为上级平台的国标级联服务，将其余下级平台中的设备通过GB28181方式级联到萤石开放平台进行使用。通过强大的设备接入能力和高兼容性，能够提供稳定、高效的视频资源整合服务，助力实现平安城市、智慧城市的建设。注意，萤石协议接入的设备也支持国标级联。

![](https://resource.eziot.com/group1/M00/01/6C/CtwQE2duR5CACH9qAABVHMg_6Rk370.png)

## 二、功能概览

国标向下级联服务支持下级平台进行**预览回放、设备控制、设备对讲**等功能。

## 三、产品优势

- 功能丰富：支持对级联通道视频流实现抓拍、存储、AI识别等丰富的云功能。
- 专人对接：在和下级平台级联测试的过程中，由上级专业对接人员进行辅助对接，对接更省心。
- 强大的设备接入能力：萤石开放平台支持通过萤石协议、国标GB28181等协议接入设备，适配更多设备接入需要。

# 国标级联-下联 计费指南

## 1. 计费方式

国标级联接入设备使用的计费方式为后付费的按量计费。当您开通服务后，可默认根据使用量付费，每日结算。（与国标协议接入相同计费规则）

## 1.1 计费组成

### 1.1.1 计费项说明

国标级联设备接入服务计费项具体如下：

| 计费项 | 单价 | 说明 |
| --- | --- | --- |
| 设备接入费 | 2元/设备/月 | 日结后结算，基础套餐+超额扣费（与平台所有设备接入费共同计费） |
| 带宽费 | 1.2元/Mbps/日 | 日结后结算，基础套餐+超额扣费（与平台所有带宽费共同计费） |
| 额外流量费 | 2.5元/G/日 | 仅作为使用带宽超出套餐限制时的额外带宽产生费用的计量方式（与平台所有带宽费共同计费） |
| 接口调用费 | 0.1元/万次/日 | 日结后结算，基础套餐+超额扣费（与平台所有接口调用次数共同计费） |

### 1.1.2 套餐价格

详情参考：[官网价格详情页](https://open.ys7.com/cn/s/price)

### 1.1.3 超出套餐部分计费方式

- 额外设备接入费用：2元/台/月
- 超出带宽产生费用：按照扩展带宽计费（1.2元/Mbps/天）或超出部分产生流量计费（2.5元/GB）
- 额外接口费：0.1元/万次/日

## 1.2 计费说明

- 设备接入费：按照当日账号下级平台接入设备数计费。按日结预付费的计费方式。首先按照套餐内数量计费，超额部分单独按照单价计费。
- 带宽费：按每日上行带宽的峰值计费。按日结预付费的计费方式。首先按照套餐内数量计费，超额部分单独按照单价计费，带宽超额分为按照超出部分带宽计费或按照超出部分产生流量计费，由用户自行选择。
- 额外流量费：当日超出套餐部分时刻产生的流量总额。按日结预付费的计费方式。仅当日带宽出现超额情况且用户选择带宽超额按照流量计费时产生。
- 接口调用：按照账号下设备控制/账号控制等依赖接口调用总次数计费。按日结预付费的计费方式。首先按照套餐内数量计费，超额部分单独按照单价计费。
- 日结预付费：每日24:00对当日产生的费用进行结算，输出账单并对账号中余额进行扣费。

## 2. 欠费说明

## 2.1 欠费说明

当您当日扣费后余额小于等于0后，账号将自动切换为个人版套餐，如果您的账户余额不足产生欠费，请知悉：

当您的账号处于欠费状态，国标级联服务会自动停止。服务停止后您无法调用接口等服务。
