# 云抓拍产品介绍

## 1.1 什么是云抓拍

云抓拍是萤石开放平台提供的云端图像采集服务，通过抓拍和抽帧两种方式，实现对设备实时画面或历史视频流的精准图像截取，并将图片存储至云端空间。

（1）抓拍：适用于具备抓图能力的设备（如萤石/海康设备）。用户指定时间点后，系统调用设备自身的抓图能力，直接获取高质量静态图片。

（2）抽帧：针对无抓拍能力的设备（如国标设备）或需高频采集图片的场景。系统从设备视频流中按需抽取指定帧，生成图片文件。

## 1.2 功能概览

| 功能名称 | 功能描述 |
| --- | --- |
| 空间管理 | 创建独立存储空间，支持自定义空间编号（1-32位字母/数字/下划线，全局唯一）；按项目分类管理图片文件，支持批量操作（下载、移动、删除） |
| 查看详情 | 查看已创建的存储空间的详细信息；查看任务状态总体概览和单个任务详情 |
| 任务操作 | "通过文件夹或任务编号或设备编号获取文件编号；对指定文件进行查看、下载、删除等操作" |

## 1.3产品优势

**全兼容性：**
支持萤石/海康等智能设备调用设备原生抓图接口直接抓拍（具有抓图能力并在萤石平台报备），同时通过视频流动态抽帧技术兼容国标设备、NVR接入通道等无抓拍能力的设备。

**高效集中管理：**
所有抓拍/抽帧图片直存萤石开放平台，免除TF卡更换、本地服务器运维成本，支持千级任务并发执行，文件可按空间/设备/时间批量下载、删除，实现云端一体化存储。

**灵活可配置：**
空间编号为1-32位字母/数字/下划线组合，全局唯一可自定义；文件命名可自动添加设备号+时间戳，便于业务系统解析；抽帧频率自由控制，支持按秒级间隔抽帧，满足工业高频采集需求。

**状态可视化：**
实时展示8种任务状态，通过分布图快速定位异常节点；网络中断时自动重试任务，解码失败自动跳过故障帧，保障任务连续性。

**安全便捷：**
实现端到端安全防护，加密设备需验证密钥才能抓拍，空间文件读写权限隔离，支持子账号分权管理。

## 1.4应用场景

**安防应急响应**

1.联动报警输入（如周界防范），快速完成抓拍并推送至指挥中心

2.支持按报警事件ID快速检索关联抓拍图片

**工业设备巡检**

1.抽帧任务定时抓取设备状态

2.图片自动命名包含设备编号+时间戳，对接OCR识别系统

**智慧零售决策**

1.抽帧引擎每秒抓取1-2帧门店入口画面，精准统计门店客流量

2.空间按门店编号划分，总部统一分析陈列效果
