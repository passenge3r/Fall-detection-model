## 获取简单存储下载地址

- 接口功能

   获取简单存储下载地址。账号权限：不支持托管和子账号，不支持小权限

- 请求地址

`https://open.ys7.com/api/v3/open/cloud/storage/download/url/{storageId}`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | keyword | String | 关键词 | N |
| query | encryptionKey | String | 加密秘钥 | N |
| query | eventTime | String | 获取时间 | N |
| query | expireSeconds | Long | 下载链接有效期，单位秒(1-604800) | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/open/cloud/storage/download/url/{storageId}?accessToken=at.xxxxx&keyword=value&encryptionKey=value&eventTime=value&expireSeconds=value'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "url": "https://open-mediarecoder.oss-cn-hangzhou.aliyuncs.com/...",
        "encrypt": null,
        "algorithm": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| -code | Int | code |
| -message | String | message |
| -moreInfo | Object | moreInfo |
| data | Object | data |
| -url | String | url |
| -encrypt | Object | encrypt |
| -algorithm | Object | algorithm |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 404 | 资源不存在 |  |
| 400 | 参数错误 |  |
| 10002 | accessToken过期或异常 |  |
| 10001 | 无效参数 |  |
| 403 | 无权限 |  |
