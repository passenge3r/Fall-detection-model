## 模板创建

- 接口功能

   创建云存储转存模板。注意：每个账号允许的模板数量最多不超过100

- 请求地址

`https://open.ys7.com/api/service/cloud/video/template/add`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | templateName | String | 模板名称 | Y |
| body | format | String | 转封装格式（HLS/mp4） | Y |
| body | spaceId | Long | 存储空间ID | Y |
| body | keepPsStream | Int | 是否保存PS码流，0否1是，默认1 | N |
| body | segmentDuration | Int | 切片时长（秒），0表示不切分 | Y |
| body | audioFormat | String | 音频格式（AAC/default） | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/cloud/video/template/add' \\
--header 'accessToken: at.xxxxx' \\
--header 'Content-Type: application/x-www-form-urlencoded' \\
--data-urlencode 'templateName=模板名称mp4' \\
--data-urlencode 'format=mp4' \\
--data-urlencode 'spaceId=44130' \\
--data-urlencode 'keepPsStream=1' \\
--data-urlencode 'segmentDuration=1800' \\
--data-urlencode 'audioFormat=default'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "templateId": 75
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 返回数据 |
| data.templateId | Int | 创建成功的模板ID |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 10001 | 参数错误 | 请求参数不合法 |
| 10002 | accessToken过期或异常 | 令牌失效，请重新获取 |
| 10031 | 账号无权限访问此设备 | 权限不足 |
| 20002 | 设备不存在 | 设备未注册 |
| 20018 | 该用户不拥有该设备 | 设备不属于当前用户 |
