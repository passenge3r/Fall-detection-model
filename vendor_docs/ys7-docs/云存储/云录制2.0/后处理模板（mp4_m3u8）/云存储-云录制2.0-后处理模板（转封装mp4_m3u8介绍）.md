# 后处理模板（转封装mp4/m3u8介绍）

> 开发者录制云录制2.0视频时，部分场景下需要将视频转成mp4、m3u8文件，可以使用本文档进行模板操作

# 功能说明

什么是后处理模板

云录制创建任务时，默认是录制成ps文件，需要使用海康特定的SDK才能进行播放（详见：<https://open.ys7.com/help/4314>）

而后处理模板就是在录制的过程中，可以根据设置，将视频直接转成mp4或者m3u8（flv暂未开放）文件，方便用户进行小程序观看、下载等操作。

# 后处理模板操作说明

### 添加后处理模板

![](https://resource.eziot.com/group2/M00/01/05/CtwQFmhRFMeAK26hAAF1eEwPpWk100.png)

在云存储-云录制2.0里，打开模板管理，进行添加模板即可进行操作。（默认会有一个hls一个mp4的处理模板）

添加模板时，可以添加以下参数：

- 选择转封装格式，目前支持mp4跟m3u8
- 云点播存储空间（由于存储空间是分业务类型的，目前只支持存储到云点播空间内，存储后可以进行周期文件管理
- 音频格式：m3u8文件会自动将G711或其他音频格式更改为aac，mp4文件会保留原始音频格式
