## 模板查询

- 接口功能

   模板查询

- 请求地址

`https://open.ys7.com/api/service/cloud/video/template`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | templateId | Long | 模板ID | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/cloud/video/template?templateId=28' \\
--header 'Content-Type: application/x-www-form-urlencoded' \\
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "templateId": 49,
        "templateName": "HLS转封装模板",
        "templateType": "custom",
        "format": "HLS",
        "segmentDuration": 0,
        "keepPsStream": 0,
        "spaceId": 169,
        "spaceName": "Test1",
        "audioFormat": "AAC",
        "videoCodec": "",
        "extraParams": "{}",
        "createTime": "2025-06-03 19:15:33",
        "updateTime": "2025-06-04 20:24:47"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 模板数据 |
| data.templateId | Int | 模板ID |
| data.templateName | String | 模板名称 |
| data.templateType | String | 模板类型（system：系统预置；custom：自定义） |
| data.format | String | 转封装格式（HLS/mp4） |
| data.segmentDuration | Int | 切片时长（秒），0表示不切分 |
| data.keepPsStream | Int | 是否保存PS码流，0否1是，默认1 |
| data.spaceId | Int | 云点播空间ID |
| data.spaceName | String | 云点播空间名称 |
| data.audioFormat | String | 音频格式（AAC/default） |
| data.videoCodec | Object | 视频编码格式 |
| data.extraParams | String | 扩展参数 |
| data.createTime | String | 创建时间，yyyy-MM-DD HH:mm:ss |
| data.updateTime | String | 修改时间，yyyy-MM-DD HH:mm:ss |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 404 | 资源不存在 | 模板不存在 |
| 500 | 服务器异常 | 服务器内部错误 |
| 400 | 参数错误 | 请求参数不合法 |
