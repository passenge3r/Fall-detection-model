## 模板更新

- 接口功能

   模板更新

- 请求地址

`https://open.ys7.com/api/service/cloud/video/template/update`

- 请求方式

`PUT`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | templateId | Long | 模版id | Y |
| body | templateName | String | 模板名称 | Y |
| body | format | String | 转封装格式(HLS;mp4) | Y |
| body | spaceId | Long | 云点播存储空间ID | Y |
| body | segmentDuration | Int | 切片时长(秒)，0表示不切分 | Y |
| body | audioFormat | String | 音频格式(AAC) | Y |
| body | keepPsStream | Int | 是否保存PS码流(0否1是),默认1 | N |

- 请求示例

```
curl --location --request PUT 'https://open.ys7.com/api/service/cloud/video/template/update' \
--header 'accessToken: at.xxxxx' \
--header 'Content-Type: application/x-www-form-urlencoded' \
\
--data-urlencode 'templateName=mp4模板名称修改' \
--data-urlencode 'format=mp4' \
--data-urlencode 'audioFormat=default' \
--data-urlencode 'templateId=28' \
--data-urlencode 'spaceId=44130' \
--data-urlencode 'segmentDuration=1800' \
--data-urlencode 'keepPsStream=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| -code | Int | code |
| -message | String | message |
| -moreInfo | Object | moreInfo |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |

| 404 | 资源不存在 | 资源不存在 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
