# 云录制HLS录像地址使用说明

## 说明：

由于云录制2.0已经提供了后处理模板，在生成录像时，可以使用云录制2.0的后处理模板：<https://open.ys7.com/help/4383>

接口说明：在录制时，通过参数生成hls文件，但是由于该接口在生成hls时无法配置hls的音频格式、也无法根据时间自动切分hls切片，因此建议使用后处理模板：<https://open.ys7.com/help/4383>

功能基本一致。

因此该接口已**废弃**，建议开发者使用新的产品功能。

# 一、对接方案

```
萤石云提供Http接口和Webhook云信令消息异步数据回调产品，接入云录制2.0产品
```

# 二、接入指南

## 2.1 步骤1

**前提:**

> - 注册萤石云开放平台，链接:https://open.ys7.com/cn/s/index,获取AK、SK等关键接口对接配置信息
> - 进入萤石云开放平台-设备管理器接入设备，开通云信令，订阅ys.open.cloud消息

## 2.2 步骤2

使用云录制2.0中一次性录制计划，配置边录边转的开关,视频流则直接转换成HLS录像
