## 云录制2.0 hls 录像信息查询

### 接口功能

- 云录制2.0 HLS录像信息查询
- 是否支持托管：否
- 是否支持子账号：否

### 请求地址

`https://open.ys7.com/api/service/open/vod/hls/info/list`

### 请求方式

`POST`

### 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号 | Y |
| Header | localIndex | String | 通道号 | Y |
| Body | startTime | String | 开始时间，时间格式为：yyyy-MM-dd HH:mm:ss | Y |
| Body | endTime | String | 结束时间，时间格式为：yyyy-MM-dd HH:mm:ss，不允许跨48小时 | Y |
| Body | format | String | 转码后的文件格式，MP4或HLS | Y |
| Body | spaceId | Long | 空间ID，默认为主空间ID | N |
| Body | pageSize | Int | 默认50，分页大小，会返回是否有下一页及下一页的开始时间 | N |

### 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/vod/hls/info/list' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: F80655926' \
--header 'localIndex: 1' \
--data-urlencode 'startTime=2024-12-19 19:56:00' \
--data-urlencode 'endTime=2024-12-19 20:00:00' \
--data-urlencode 'format=HLS'
```
