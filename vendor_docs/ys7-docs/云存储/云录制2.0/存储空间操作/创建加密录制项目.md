## 创建加密录制项目

- 接口功能

   功能描述：创建加密录制项目  
    是否支持托管：否  
    是否支持子帐号：否

- 请求地址

`https://open.ys7.com/api/service/cloudrecord/video/space`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Body | spaceName | String | 录像空间名称，格式：仅支持中文、英文、数字、下划线，长度不超过32个字符 | Y |
| Body | expireDays | Int | 过期天数，默认7天，时间范围：0-永久保存，1~3650-过期时间，单位：天 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/cloudrecord/video/space' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'spaceName=myRecordSpace' \
--data-urlencode 'expireDays=7'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": ""
    },
    "data": {
        "spaceId": 5,
        "totalSize": 0,
        "totalTimePlan": 0,
        "totalEventPlan": 0,
        "spaceName": "myRecordSpace",
        "storageType": 1,
        "expireDays": 7,
        "primarySpace": false
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 返回体 |
| -code | Int | 返回码 |
| -message | String | 返回信息 |
| -moreInfo | String | 更多信息 |
| data | Object | 数据 |
| -spaceId | Int | 空间id |
| -totalSize | Int | 空间总大小 |
| -totalTimePlan | Int | 时间计划数量 |
| -totalEventPlan | Int | 事件计划数量 |
| -spaceName | String | 空间名称 |
| -storageType | Int | 存储类型，1：标准存储 |
| -expireDays | Int | 过期天数 |
| -primarySpace | Boolean | 是否为主空间 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 请求参数不合法 |
| 404 | 资源不存在 | 请求资源未找到 |
| 412 | 前置条件不满足 | 业务前置条件未满足 |
| 500 | 服务器异常 | 服务端内部错误 |
| 10001 | 无效参数 | 参数格式或值不正确 |
| 10002 | accessToken过期或异常 | token无效，请重新获取 |
