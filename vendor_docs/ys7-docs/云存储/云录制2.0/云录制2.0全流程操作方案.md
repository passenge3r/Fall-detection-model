# 云录制2.0全流程操作方案

## 项目背景

随着教培、会议、安防等各行业对音视频云端录制的需求日益提升，企业及机构对录制流程的标准化、规范化要求不断提高，需要一套统一的云录制平台实现从存储载体搭建、录制任务规划到录像回看下载的全流程管理，保障音视频录制、存证、复用的顺畅实施。因此云录制2.0平台需要提供从创建存储空间、制定录制计划到录像播放下载的完整操作方案，满足各场景下云端录制的全流程需求。

## 实施方案

### 前置条件

云录制2.0全流程操作开展前，需完成基础准备工作，确保各环节操作可正常执行，核心前置条件如下：

1. **账号认证**：完成萤石开放平台账号注册，并完成企业认证，云录制2.0的云存储功能仅企业账号可使用；
2. **凭证获取**：获取接口调用所需的accessToken，确保令牌有效未过期，若令牌异常需重新获取；
3. **设备对接**：待录制设备完成萤石云平台上云对接，设备处于在线正常状态；
4. **网络权限**：操作终端（电脑/移动端）网络通畅，且拥有萤石云录制2.0平台及相关接口的访问权限；

### 核心流程操作

云录制2.0的核心操作流程为创建存储空间->创建一次性录制计划->播放录像/下载录像，各环节操作需按顺序执行，具体操作说明如下：

### 第一步：创建存储空间

**功能说明**：为云录制的音视频录像提供专属云端存储载体，是创建一次性录制计划的基础前提，支持对存储空间的信息查询、属性修改、资源删除等全生命周期管理，确保录像有合规的存储载体。

**操作方式**：

- **平台端**：在萤石云开放平台云录制2.0模块，进入存储空间板块完成存储空间创建及后续管理；
- **接口端**：通过「接口文档」调用对应接口完成操作，支持接口包括：
  - [创建存储空间](https://open.ys7.com/help/1975)
  - [查询存储空间信息](https://open.ys7.com/help/2039)
  - [查询存储空间列表](https://open.ys7.com/help/2062)
  - [修改存储空间信息](https://open.ys7.com/help/2040)
  - [删除存储空间](https://open.ys7.com/help/2041)

**注意事项**：

1. 存储空间生命周期（视频存储时长）的修改只会应用于新生成的视频，已存在的视频还是按照原有的生命周期存储。

### 第二步：创建一次性录制计划

**功能说明**：基于已创建的有效存储空间，制定单次音视频录制的任务计划，是实现云端录制的核心环节。支持对录制计划的终止、详情查询、设备列表修改等操作，可灵活管理关联的录制设备，保障录制任务按需求执行。

**操作方式**：

- **平台端**：在萤石云开放平台云录制2.0模块，选择已创建的存储空间，完成一次性录制计划的创建及后续管理；
- **接口端**：通过「接口文档」调用对应接口完成操作，支持接口包括：
  - [创建一次性录制计划](https://open.ys7.com/help/2045)
  - [终止一次性录制计划](https://open.ys7.com/help/2046)
  - [查询一次性录制计划](https://open.ys7.com/help/2047)
  - [查询一次性录制计划列表](https://open.ys7.com/help/2051)
  - [查询已创建一次性录制计划的设备列表](https://open.ys7.com/help/2048)
  - [修改已创建一次性录制计划的设备列表](https://open.ys7.com/help/2050)
  - [删除一次性录制计划](https://open.ys7.com/help/2049)

**注意事项**：

1. 创建前需校验：确认存储空间有效，关联的录制设备在线、配置正常；
2. 可根据实际录制需求，在录制计划开始前灵活修改计划关联的设备列表，避免漏录、错录情况；
3. 录制过程中如需紧急停止，可通过接口执行终止一次性录制计划操作；未执行的无用计划及时删除，避免占用平台资源；

### 第三步：播放录像/下载录像

**功能说明**：录制任务完成后，对云端存储的录像进行在线播放、本地下载的终端操作，支持录像信息查询、标准MP4格式转封装，满足录像回看、存证、下载、二次编辑等各类场景需求，是云录制2.0全流程的收尾环节。

**操作方式**：

**1. 录像播放**

- **平台端**：在萤石云开放平台云录制2.0录像管理板块，查询录像信息后选择对应播放方式；
- **接口端**：通过「接口文档」调用对应接口完成操作，支持接口包括：
  - [云录制播放说明](https://open.ys7.com/help/4314)
  - [查询录像日历](https://open.ys7.com/help/2042)
  - [查询录像信息](https://open.ys7.com/help/2043)
  - [私有SDK播放](https://open.ys7.com/help/2044)
  - [标准流播放地址（RTMP）](https://open.ys7.com/help/2864)
  - [小程序插件播放](https://open.ys7.com/help/4384)

**2. 录像下载**

- **平台端**：在萤石云开放平台云录制2.0录像管理板块，按指引完成录像下载或格式转封装；
- **接口端**：通过「接口文档」调用对应接口完成操作，支持接口包括：
  - [云端录像下载指南](https://open.ys7.com/help/4145)
  - [云端录像SDK下载说明](https://open.ys7.com/help/4385)
  - [云端转封装mp4任务创建](https://open.ys7.com/help/3971)
  - [查询任务详情](https://open.ys7.com/help/3972)

**注意事项**：

1. 下载前可通过查询录像信息接口确认录像完整性，若需标准MP4格式，需先创建转封装任务并查询任务完成状态；
2. 播放/下载失败时，先检查录像资源是否存在、操作权限是否有效，再排查网络及接口参数问题。
