## 删除云录制2.0录像片段

- 接口功能

   删除云录制2.0录像片段，根据时间范围删除指定设备通道的录像

- 请求地址

`https://open.ys7.com/api/service/cloudrecord/video/infos/delete`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | localIndex | String | 设备通道号 | Y |
| body | startTime | String | 录像开始时间，格式yyyyMMddHHmmss | Y |
| body | endTime | String | 录像结束时间，格式yyyyMMddHHmmss | Y |
| body | spaceId | Long | 空间ID | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/cloudrecord/video/infos/delete' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: DS-XXXXX' \
--header 'localIndex: 1' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'startTime=20250101000000' \
--data-urlencode 'endTime=20250101010000' \
--data-urlencode 'spaceId=123456'
```

- 返回数据

```
{
    "data": {
        "videos": [
            {
                "fileId": "file_xxxxx",
                "startTime": "20250101000000",
                "stopTime": "20250101010000",
                "fileSize": 1048576
            }
        ],
        "hasNext": false
    },
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta.code | Int | 业务码，200表示成功 |
| meta.message | String | 响应信息 |
| meta.moreInfo | Object | 更多信息 |
| data.videos[].fileId | String | 文件ID |
| data.videos[].startTime | String | 开始时间 |
| data.videos[].stopTime | String | 结束时间 |
| data.videos[].fileSize | Long | 文件大小 |
| data.hasNext | Boolean | 是否还有录像未删除 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 404 | 资源不存在 | 请检查资源是否存在 |
| 500 | 服务器异常 | 服务器内部错误 |
| 400 | 参数错误 | 请检查请求参数格式 |
