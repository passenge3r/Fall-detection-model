## 获取云录制回放地址

- 接口功能

   获取云录制回放地址，支持at token、du token、da token、ra token、设备类小权限token，permission为Replay。

- 请求地址

`https://open.ys7.com/api/service/media/cloud/replay/address`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| header | deviceSerial | String | 设备序列号 | Y |
| header | localIndex | Int | 通道号，默认为1 | N |
| query | protocol | Int | 1-rtmp（默认） | N |
| query | expireTime | Int | 过期时长，单位秒，最小30秒，最大720天，默认1天 | N |
| query | startTime | String | 云录制回放开始时间，格式yyyy-MM-dd HH:mm:ss | Y |
| query | stopTime | String | 云录制回放结束时间，格式yyyy-MM-dd HH:mm:ss | Y |
| query | quality | Int | 视频清晰度，1-高清（主码流）默认、2-流畅（子码流） 该入参在云录制场景无效 | N |
| query | supportH265 | Int | 是否支持H265，0-不支持（默认），1-支持H265 | N |
| query | playbackSpeed | Float | 回放倍速：0.5， 1， 2， 3，4 | N |
| query | spaceId | Long | 云录制空间ID | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/media/cloud/replay/address?protocol=1&expireTime=86400&startTime=2020-07-27%2010:35:00&stopTime=2020-07-27%2023:59:59&quality=1&supportH265=0&playbackSpeed=1&spaceId=2025289' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: L16120197' \
--header 'localIndex: 1'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| data | Object | data |
| data.id | String | id，播放地址id |
| data.url | String | url，协议格式为：rtmp://rtmp01open.ys7.com:1935/v3/openpb/设备序列号\_通道\_主子码流?id=&rec=cloud&expire=&begin=20200727103500&end=20200727235959&spaceId=&busType=7&t=加密密文&ev=秘钥版本 |
| data.expireTime | String | expireTime，过期时间 |
| meta | Object | meta |
| meta.code | Int | code |
| meta.message | String | message |
| meta.moreInfo | Object | moreInfo |
