# 小程序播放云录制录像

## 获取云录制地址后，开发者可以使用不同工具进行播放：

1）VLC播放器：支持Windows、Mac、Linux、Android和iOS平台。可以自行搜索相关播放器

2）小程序live-player组件：开发者可以集成微信小程序的组件，并在小程序里进行RTMP直播流的播放

3）其他：开发者可自行寻找相关开源组件进行播放。

由于三方组件兼容性不一定有萤石提供的SDK兼容性高，若遇到相关问题，请自行排查或者寻找萤石研发协助排查。

## 小程序插件播放

由于小程序live-player组件是有资质要求等，因此开发者可以直接使用萤石小程序插件进行云录制的内容播放，具体接入说明：
