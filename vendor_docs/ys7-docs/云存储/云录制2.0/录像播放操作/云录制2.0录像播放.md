# 云录制2.0录像播放

## 录像播放说明

| 方案 | 场景说明 | 方案优势 | 方案劣势 |
| --- | --- | --- | --- |
| 方案1：集成SDK播放 | 大部分场景，工地、连锁、监管、农业等 与监管预览、本地回放能力保持一致 | 功能齐全，还支持私有信息 | 需集成SDK |
| 方案2：直接获取RTMP播放地址 | 台球、幼教等 获取RTMP地址后，直接在小程序live-player组件里播放 | RTMP集成即开即用，无需转封装费用，还支持H265 | 不支持seek拖动需要重新取流，拖拉效果不如转封装hls |
| 方案3：将ps转成m3u8或者mp4播放 | 台球点播、广播媒体、文旅景区等 录制文件的时候，直接转成HLS(m3u8文件)、mp4，然后获取新的文件地址直接在浏览器里播放 | hls点播效果较佳，短视频点播效果最佳 | 需转封装，有额外费用，且hls不支持H265 |

## 方案1：集成SDK

当前云录制2.0的录像默认存储是ps码流，因此开发者无法获取录像后直接播放，需要先集成开放平台SDK后，进行播放。

![](https://resource.eziot.com/group2/M00/01/03/CtwQF2gN3l2ALK5SAACqwZX1D9c262.png)

**步骤1：**

先查询云端录像空间里是否有录像：

接口1：可以先通过日历查询哪些日期有录像：<https://open.ys7.com/help/2042>

接口2：查询确定的某天，哪个时间段有录像：<https://open.ys7.com/help/2043>

确定有录像后，获取播放地址：[获取加密录像播放地址](https://open.ys7.com/help/2044)

**步骤2**：选择需要的SDK：[开放平台音视频SDK功能及概述](https://open.ys7.com/help/3925)

然后把录像地址放到SDK里进行播放（备注：各个SDK里也已经集成了云录制录像的播放方法，两种方案都可以）

**SDK接入功能及概述**

| 平台/语言 | 获取 SDK | 集成SDK |
| --- | --- | --- |
| Android SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/4177) |
| iOS SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/4102) |
| 轻应用 Web SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/4294) |
| 小程序 SDK | [获取 SDK](https://open.ys7.com/help/1865) | [集成 SDK](https://open.ys7.com/help/1865) |
| Windows SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/47) |

备注：小程序 SDK，暂时只支持小程序插件SDK播放，半屏小程序等暂不支持

## 方案2：获取RTMP标准流地址

云录制提供了将ps流转成RTMP标准流直播地址的方案，常见于小程序live-player组件播放

获取标准流播放地址url：[文档概述 · 萤石开放平台API文档](https://open.ys7.com/help/2864)

备注：该方案适用于可以申请微信小程序live-player组件的客户，如果开发者无法申请live-player组件，则可以参考 方案1 里的小程序插件方案集成。

## 方案3：转封装成m3u8或者mp4后播放

视频录制时，云录制提供了后处理模板，该模板支持将视频转成HLS/mp4，开发者可以根据自身业务场景进行选择

接口1：[云录制HLS录像地址使用说明](https://open.ys7.com/help/3970)

转成HLS后，就可以点播了。

接口2：[文档概述 · 萤石开放平台API文档](https://open.ys7.com/help/4145)

转成mp4后，就可以下载或点播了。
