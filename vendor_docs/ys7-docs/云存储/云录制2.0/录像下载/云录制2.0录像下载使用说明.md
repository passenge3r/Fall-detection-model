# 云录制2.0录像下载使用说明

## 功能说明

云录制2.0的默认录像是ps文件，如果要进行下载操作，可以使用SDK，然后点击下载，可以进行边播放边下载。

或者在录制时，直接将录像转成mp4，录制成功后就可以直接获得mp4的文件及连接了。

## 操作步骤

**方法1**：录制时转mp4

录制时，使用后处理模板，直接转成mp4，具体参考：[云点播转封装指南](https://open.ys7.com/help/4383)

如何下载：

1、可以通过[文件元数据搜索](https://open.ys7.com/help/4444)获取下载地址。

2、也可以对接webhook消息（[消息开通](https://open.ys7.com/help/566)、[云录制消息体结构](https://open.ys7.com/help/1384)），来获取转封装的文件node，然后通过[获取文件地址](https://open.ys7.com/help/4402)获取下载地址。

**方法2**：将已经录制好的云录制2.0、事件云存储录像片段转成MP4

操作步骤详细如下：

1. [云端录像转封装任务创建](https://open.ys7.com/help/3971)，将云录制2.0的录像转封装成MP4。
2. [查询任务详情](https://open.ys7.com/help/3972)，根据taskId查询任务状态。
3. [视频剪辑文件查询](https://open.ys7.com/help/3717)，根据taskId获取下载地址URL。
