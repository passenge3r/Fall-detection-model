# 云录制2.0/云点播产品介绍

> 云录制2.0是基于萤石云存储开发，为开发者提供自由式任务定制的视频存储产品。

云录制2.0是萤石云存储的子产品，萤石云存储的整体产品介绍，详见：[前往查看](/help/3842)

云录制2.0是基于萤石云存储开发，为开发者提供自由式任务定制与多格式输出能力的视频存储产品。作为EZVIZ面向垂直场景优化的新一代录制组件，它通过灵活的转封装配置（如海康PS文件原生存储）和可扩展的后处理模板（支持MP4、M3U8等格式转换），帮助开发者精准适配行业存储需求。

基于其开放式的存储架构，开发者可将视频监控、音视频通话及关键帧内容高效储存，适用于存证、算法训练等场景。例如在透明装修场景中，开发者可定制化录制关键作业视频，并通过后处理模板快速生成质检所需的MP4审核文件，显著提升抽查效率。

# 云录制2.0的概念区别

### 与云录制1.0的区别

云录制2.0与1.0来说没有大的区别，主要是针对部分行业客户需求，将转封装进行了拆分，录制的文件不再默认是mp4，而是改为海康ps文件，但是依然提供【云录制2.0后处理】模板，在录制时依然可以将录像自动转为mp4文件，同时我们也新增了转为m3u8文件的处理方式，使该产品更加灵活。

| 功能大类 | 功能列表 | 云录制1.0 | 云录制2.0 |
| --- | --- | --- | --- |
| 存储功能 | 自定义存储时间 | √ | √ |
|  | 归档存储 | √ | 支持中 |
| 录制功能 | 同时录制回放流和实时流，集合成事件录像 | X | √ |
|  | 即时录制（无需下发录制结束时间） | √ | √ |
| 播放功能 | 支持H265编码格式播放 | X | √ |
|  | 下载到本地 | √ | 需要转封装后下载 |
|  | 支持按设备查看录像 | X | √ |
| 小程序端播放 | 建议集成小程序插件 | √ | √ |
| APP端播放 | 需要集成App SDK | √ | √ |
| WEB端播放 | 需要集成UIKIT SDK | √ | √ |

### 与事件云存储的区别

事件云存储是设备行为，云端无法控制设备推什么录像、哪个时间点的录像。云录制是云端下发任务，设备执行的行为，可以根据时间、联动事件等进行录制。

### 与云点播的联动

云点播是对云录制产品的补充，云录制2.0是云端存储，而云点播产品是提供mp4/m3u8文件的云端存储，云录制2.0结合云点播的功能，可以实现：视频录制+点播加速、视频录制+视频剪辑等功能的开发。

## 产品优势

**自由定制**

通过云录制可以灵活配置海康PS原生存储+多格式后处理模板，开发者根据业务场景自由组合录制规则（如双流合成/即时截取），实现视频存储策略的深度定制。

**多端适配**

通过云录制可以原生支持H265编码播放与多格式输出，依托后处理模板一键生成MP4（存证归档）、M3U8（网页直播）等格式，无缝适配小程序/Web/APP多端播放场景。

**精准处理**

通过云录制可以基于事件触发双流录制与智能加工，在录制回放流与实时流（2025年07月31日）的同时，自动添加水印/缩略图等元素，确保关键内容精准可溯。

**高可靠性**

通过云录制可以延续分布式集群与多云备份架构，结合转封装重试机制保障海康PS文件稳定存储，为二次加工提供高容错基础。

## 应用场景

**精彩瞬间录播**

通过云录制可以精准录制台球进洞、一杆清台等高光时刻，原生存储海康PS文件并自动生成M3U8短视频，便于社交平台即时分享。
[查看方案](https://open.ys7.com/help/4315)

**考试视频存证**

通过云录制完整采集考生答题过程视频，通过后处理模板自动添加防作弊水印并转存为MP4文件，满足教育机构审计存证需求。
[查看方案](https://open.ys7.com/help/3946)

**多版本后处理**

通过云录制可以根据设置，将视频直接转成mp4或者m3u8（flv暂未开放）文件，方便用户进行小程序观看、下载等操作。
[查看方案](https://open.ys7.com/help/4383)

# 云点播

> 云点播是基于萤石云存储开发，与云录制2.0搭配一起使用的子产品

萤石云点播VOD是集音视频管理、处理和分发播放于一体的一站式解决方案，该方案脱胎于视频云录制2.0，是对云录制2.0的有效补充。无论是智慧监管、文化旅游、智慧商贸等行业，无论是宠物vlog、文旅景区、无人台球、阳光招投标、智慧车管所、康养、工地打卡等场景，都可以通过视频云录制叠加云点播产品服务实现高效的内容生产、管理和分发。
