# 云录制2.0常见错误码

> 本节内容包含云录制2.0使用过程中常见的错误码，主要内容如下：

错误码主要包括：

| 序号 | 接口功能 | 描述 |
| --- | --- | --- |
| 1 | [取流接口报错](#error_code-api1) | 云录制是设备取流录制，因此取流时会报错，主要是展示取流服务（萤石内部服务称为VTDU服务）的错误码及解决方案 |
| 2 | [服务内部接口报错](#error_code-api2) | 云录制2.0的取流服务报错，非流媒体相关的错误码 |
