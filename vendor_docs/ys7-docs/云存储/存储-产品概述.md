# 什么是视频云存储

萤石云存储产品是萤石针对视频监控设备研发的设备录像的采集、存储和处理的一体化录制组件，通过简单的操作，帮助开发者精准、灵活地对设备内容进行存储和处理。

开发者可以通过萤石协议、国标GB28181、RTMP推流、部标等快捷地将设备添加到萤石云，萤石云存储可以自动将视频监控、音视频通话以及设备图片等内容存储到云端，萤石云存储系列产品为客户提供海量视频、图片及其他非结构化数据存取与处理的云服务，具有弹性灵活、安全可靠、高性价比等优点，支持多种存储协议及多档资源类型，深度匹配各类行业场景应用。

## 产品架构

![](https://resource.eziot.com/group2/M00/01/03/CtwQF2gNkmSAO15fAAIQrs8ieRo355.png?msec=1745719921303)

- 支持多种协议接入：支持萤石协议、国标GB28181、RTMP推流、部标等协议
- 覆盖海康、萤石所有设备，IPC、NVR、门禁、手持设备等
- 提供多种标准存储协议以及多档资源类型，精细匹配应用场景需求
- 搭配数据管理、生命周期、数据处理等功能，完成数据的全生命周期管理

## 为什么选择视频云存储

- **稳定丰富的媒体服务**：提供从视频采集、媒体处理、分发播放的一站式服务，支持多场景需求，并提供丰富的SDK和API，满足多样化业务开发。
- **流畅高效的用户体验**：依托全国、全球多节点网络及供应商CDN网络，实现秒出流、低卡顿、低延迟，确保流畅稳定的播放体验。
- **可靠全面的安全保障**：提供设备加密录制、提供视频安全和保护方案。
- **可控经济的使用成本**：提供空间存储、设备存储，提供标准存储、冷存储等产品，满足监控、值守、连锁、监管、工地等多场景，灵活计费模式与高效开发工具降低运营成本。

## 产品优势

**快速录制**

API方便业务集成与二次开发，快速提取关键内容，录制任务即下即传

**精准存储**

支持事件联动录制，实现精准的内容存储

**高可靠性**

分布式集群部署与重试机制保障关键内容的提取稳定，多云备份保障内容的存储安全。

**高安全性**

提供多方音视频通话、视频预览、数据传输、数据存储等端到端安全保障机制。
