# 事件云存储录像播放说明

## 录像播放说明

| 方案 | 场景说明 | 方案优势 | 方案劣势 |
| --- | --- | --- | --- |
| 方案1：集成SDK播放 | 大部分场景，工地、连锁、监管、农业等 与监管预览、本地回放能力保持一致 | 功能齐全，还支持私有信息 | 需集成SDK |
| 方案2：将ps转成m3u8或者mp4播放 | 台球点播、广播媒体、文旅景区等 录制文件的时候，直接转成HLS(m3u8文件)、mp4，然后获取新的文件地址直接在浏览器里播放 | hls点播效果较佳，短视频点播效果最佳 | 需转封装，有额外费用，且hls不支持H265 |

## 方案1：集成SDK

当前事件云存储（云录制2.0也是一样）录像默认存储是ps码流，因此开发者无法获取录像后直接播放，需要先集成开放平台SDK后，进行播放。

![](https://resource.eziot.com/group2/M00/01/03/CtwQF2gN3l2ALK5SAACqwZX1D9c262.png)

**步骤1：**

直接通过接口获取录像地址：

接口1：按设备查看录像地址：<https://open.ys7.com/help/1414>

**步骤2**：选择需要的SDK：[开放平台音视频SDK功能及概述](https://open.ys7.com/help/3925)

然后把录像地址放到SDK里进行播放（备注：各个SDK里也已经集成了事件云存储录像的播放方法，两种方案都可以）

**SDK接入功能及概述**

| 平台/语言 | 获取 SDK | 集成SDK |
| --- | --- | --- |
| Android SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/4177) |
| iOS SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/4102) |
| 轻应用 Web SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/4294) |
| 小程序 SDK | [获取 SDK](https://open.ys7.com/help/1865) | [集成 SDK](https://open.ys7.com/help/1865) |
| Windows SDK | [获取 SDK](https://open.ys7.com/cn/s/download) | [集成 SDK](https://open.ys7.com/help/47) |

备注：小程序 SDK，暂时只支持小程序插件SDK播放，半屏小程序等暂不支持

## 方案2：获取RTMP标准流地址

云录制提供了将ps流转成RTMP标准流直播地址的方案，常见于小程序live-player组件播放

获取标准流播放地址url：<https://open.ys7.com/help/1414>

参数选择回放，选择RTMP或者FLV协议

备注：该方案需要播放RTMP的播放器，常见于微信小程序live-player组件，如果开发者无法申请live-player组件，则可以参考 方案1 里的小程序插件方案集成。

## 方案3：转封装成m3u8或者mp4后播放

由于事件云存储依赖设备，设备无法直接推mp4文件，因此云存储必须是已经生成好的录像文件进行转封装处理

接口1：使用云点播转封装接口，将已有录像转封装成MP4/HLS，详见：[云点播转封装接口](https://test12open.ezv-test.com/help/3975)

转成HLS后，就会保存到云点播文件里。

接口2：[云点播文件地址播放](https://test12open.ezv-test.com/help/4402)

转成mp4后，就可以下载或点播了。
