## 录像日历查询

- 接口功能

   查询某月份中有录像文件的日期。注意：本地录像查询，国标协议设备暂不支持

- 请求地址

`https://open.ys7.com/api/v3/open/cloud/video/exist/query/month`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 用户令牌 | Y |
| query | deviceSerial | String | 设备序列号 | Y |
| query | channelNo | Int | 通道号 | Y |
| query | recType | Int | 回放源，0-云存储和本地录像，1-云存储，2-本地录像，3-关联录像 | Y |
| query | queryMonth | String | 查询的月份，时间格式为：yyyy-MM | Y |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/v3/open/cloud/video/exist/query/month?accessToken=at.xxxxx&deviceSerial=BB9480953&channelNo=1&queryMonth=2025-05&recType=1'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": [
        {
            "recDay": "2025-05-21",
            "cloud": 1,
            "local": -1,
            "relation": -1
        },
        {
            "recDay": "2025-05-20",
            "cloud": 1,
            "local": -1,
            "relation": -1
        },
        {
            "recDay": "2025-05-19",
            "cloud": 1,
            "local": -1,
            "relation": -1
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | meta |
| -code | Int | code |
| -message | String | message |
| -moreInfo | Object | moreInfo |
| data | Array | data |
| -recDay | String | 日期 |
| -cloud | Int | 是否有云存储录像，1：有文件；0：无文件 |
| -local | Int | 是否有本地录像，1：有文件；0：无文件 |
| -relation | Int | 是否有关联录像，1：有文件；0：无文件 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 400 | 参数错误 |  |
| 404 | 入参错误 |  |
| 500 | 操作失败 |  |
| 403 | 无限权 |  |
