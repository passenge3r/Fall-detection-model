# 萤石智能AI云存储产品介绍

## 1. 产品概述

萤石智能 AI 云存储是依托萤石蓝海 AI 视觉大模型与云端存储技术打造的新一代视频数据管理与应用平台。本产品突破了传统云存储仅作为“数据仓库”的局限，通过“云 - 边 - 端”协同架构，将非结构化视频数据转化为可检索、可分析、可决策的结构化智能资产。

针对海量设备接入带来的数据压力及用户对实时决策的迫切需求，萤石智能 AI 云存储实现了从被动回看向主动预警、从人工巡检向智能决策的跨越式升级，广泛适用于家庭安防、连锁零售、工业生产及生态环保等多领域场景。

## 2. 通用云存储升级

### 2.1 传统云存储痛点

![](https://izhstatic.ys7.com/vasp-openweb/1774611304635_659c6fb5da4c0bb40884f78fcdddf7db.png)

- **数据非结构化**：视频数据难以直接用于智能分析，需额外处理才能提取有效信息。
- **检索效率低下**：缺乏高效检索功能，人工回看耗时耗力（回看时间与视频时长比例达 1:2~1:3），关键片段易遗漏。
- **价值挖掘不足**：无效片段占比高，数据未深度挖掘业务价值，难以支撑精准决策与风险预警。

### 2.2 ToB 场景需求升级

- **海量承载能力**：需应对智能摄像头、传感器等设备爆发式增长带来的数据接入压力。
- **实时决策支持**：业务端对视频数据的实时调取与智能分析需求迫切，要求系统具备快速响应能力。
- **多场景统一管理**：需兼容家庭、商铺、工厂等复杂场景，实现跨设备、跨环境的统一管控。

### 2.3 技术驱动机遇

依托大模型视觉理解能力的提升及多模态交互技术的普及，行业应用正加速落地。萤石智能 AI 云存储顺势而为，利用分布式架构实现计算与存储的灵活分配，推动人机交互向更自然、高效方向发展。

## 3. 核心产品：视觉智能体

本产品以“视觉智能体”为核心定位，具备以下关键能力：

### 3.1 核心数据处理引擎

![](https://izhstatic.ys7.com/vasp-openweb/1774611309314_af8cba43645973e9bf010aaaf4fe8e1d.png)

1. **云端实时解析**：摄像头采集视频通过高速网络实时上传云端，保障数据安全存储与随时调取。
2. **大模型深度理解**：利用 AI 大模型逐帧解析视频内容，精准识别并提取关键信息，全程无需人工干预。
3. **结构化数据输出**：自动将视频转化为人物、车辆、事件类型等结构化标签，并按时间、地点、事件类型多维度分类存储。
4. **关键要素标记**：精准提取人脸特征、车牌号码、异常行为等信息并智能标记，构建高效检索索引。
5. **金融级安全防护**：采用银行级加密技术配合多重安全防护体系，确保视频数据在传输与存储过程中的安全性，防止泄露与非法访问。

![](https://izhstatic.ys7.com/vasp-openweb/1774611315429_af38186a9935555c16074d8388fdf7bd.png)

### 3.2 核心功能模块

**（1）自然语言文搜视频**

- **对话式检索**：支持自然语言关键词输入，无需记忆文件名或时间标签，快速匹配相关视频片段。
- **精准定位**：可自动识别并标记特定目标行为，支持时间、地点、设备等多条件组合查询，大幅缩小检索范围。

![](https://izhstatic.ys7.com/vasp-openweb/1774610401878_image_22.png)
![](https://izhstatic.ys7.com/vasp-openweb/1774611324274_7dd300544bcd8ad62d5bcbc45aa87919.png)

**（2）智能总结与报告**

- **自动化摘要**：AI 自动分析视频内容，生成关键事件总结，支持任意时段录像摘要提取。
- **标准化报表**：提供每日/每周标准化报告模板，自动生成结构化报表，支持导出及邮件推送。
- **智能时间轴**：视频时间轴自动标记重要节点，每个录像片段生成简短摘要，点击即可快速定位关键片段。

![](https://izhstatic.ys7.com/vasp-openweb/1774610393255_image_20.png)

**（3）异常事件管理**

- **智能检测与高亮**：自动检测陌生人闯入、物品移动等异常事件并在事件列表中优先高亮显示。
- **自定义订阅与告警**：支持用户自定义事件触发条件，异常情况通过 APP、短信、Web 端等多渠道实时推送告警。

**（4）个性化智能体与内容创作**

- **场景适配**：支持自定义智能体及识别内容，灵活适配不同业务场景需求。
- **自动剪辑**：AI 自动剪辑关键片段（如宠物互动、家人活动等）生成每日精选 Vlog，支持一键回看与分享。
