# 云存储产品介绍

## 1. 产品概述

萤石云存储是一项基于云计算技术的录像存储服务。结合了移动物体检测、24小时连续录像、非工作时间的闲时存储，平台AI事件触发存储等先进功能，针对人货流通性大且有移动化监管需求的各类应用场景，支持事件云存储（动态触发录制）、连续云存储（24小时录制）、按时长定制等多种模式，为用户提供高效、智能且安全的云端存储解决方案。

### 详细说明：

• 智能触发存储：仅当监控画面出现人员活动、物体移动等有效变化时才会录像，避免存储大量无效视频。

• 高效存储管理：结合AI算法过滤无效变动（如光线变化、树叶晃动），仅保留有价值的事件片段。

• 适用于多种场景：如安防监控、零售分析、智能家居等，帮助用户精准记录关键事件，减少存储浪费。

## 2. 核心优势

**1. 金融级安全加密，数据零泄露风险**

• 采用传输、存储双重金融级加密技术，通过ISO安全认证，支持异常访问验证机制，确保企业数据全程防窃取、防破解。

• 每台设备独立云空间，避免因设备损坏或SD卡丢失导致数据泄露。

**2. 智能分层存储，按需优化资源**

• 事件云存储：基于AI移动检测技术，仅录制动态事件（如人形移动），高效节省存储空间与流量成本。

• 连续云存储：支持24小时不间断录制（需设备支持），适用于高安防场景，如金融、仓储、工地等。

**3. 弹性扩容与高可靠性保障**

• 存储资源池化，可线性扩展至百PB级容量；多副本容错机制，节点故障时自动恢复数据，保障业务不中断。

• 通过比对云端录像与本地录像，针对性地对缺失录像进行补录，确保录像完整度。

**4. 轻部署与高效管理**

• 支持海量设备：萤石、海康、三方厂商设备都可以支持接入与开通，支持摄像机、录像机、门禁、移动交通等多品类设备，一键开通

• 支持灵活配置：支持按数据权限、资源池或存储空间等多种方式灵活购买与使用

## 3. 事件定义详解

事件在事件云存储中的核心定义是：监控画面中出现有意义的内容变动，并被系统识别记录的视频片段。

详细说明：

**（1）什么情况下会被记录？**

• 有效变动触发：画面像素发生显著变化（如人、车移动），且符合设定的敏感度阈值。

• AI智能过滤：自动排除光线变化、树叶晃动、昆虫飞过等无效干扰。

• 可自定义事件类型：用户可选择仅存储特定事件（如仅记录人员进入，忽略宠物活动）。

**（2）事件存储逻辑**

• 单事件存储：每个独立事件（如一个人进入画面）会生成一段录像。

• 连续事件合并：如果短时间内多次触发（如人员在监控范围内走动），系统可智能合并为单段视频。

• 元数据标记：每个事件会记录时间、位置、事件类型（如“移动侦测”或“区域入侵”），便于后续检索。

**（3）典型事件示例**

| 事件类型 | 触发条件 | 适用场景 |
| --- | --- | --- |
| 移动侦测 | 画面内物体移动 | 家庭安防、仓库监控 |
| 区域入侵 | 特定区域出现人员或物体 | 周界防护、禁区监控 |
| 越线检测 | 人员或车辆跨越设定界线 | 交通监控、出入口管理 |
| 人脸识别 | 识别特定人脸并记录 | 门禁系统、VIP客户分析 |

## 4.产品优势

**• 智能云端备份**

• 支持7天至360天循环覆盖周期，企业可按需选择存储时长。

**• 分层存储策略**

• 事件存储：仅录制动态事件（如人形移动），高效节省存储空间

• 连续存储：全天候不间断录制（需购买专属套餐），适用于高安防场景

**• AI增强型数据价值挖掘**

• 结合AI算法实现多场景分析（如人车识别、异常行为检测），未来支持大模型生成个性化报告，提升安防效率。

**• 一站式运维工具**

• 支持自助开通、续费及资源使用明细查询，降低运维成本。

• 录像回放秒级加载，助力高效巡店与管理。

## 5.产品对比

### 事件云存储 vs. 连续云存储

| 功能 | 事件云存储 | 连续云存储 |
| --- | --- | --- |
| 适用场景 | 日常监控、低流量需求场景（如店铺、办公室） | 高安防场景（如银行、数据中心） |
| 存储效率 | 仅录制动态事件，节省90%+存储空间 | 全天录制，完整记录所有画面 |
| 设备兼容性 | 萤石IPC设备都支持 | 萤石只有行业设备支持 |
|  | 海康大部分NVR设备支持（单设备1-2条通道） | 海康NVR设备需要专属定制 |
|  | 国标设备有待开放 | 国标设备有待开放 |
| 成本优化 | 有多种档位的事件云存储资源包，性价比高 | 专属定制连续云存储套餐，适合刚性需求 |
