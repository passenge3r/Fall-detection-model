# AI云存储开通查询相关接口

| 文档名称 | 文档说明 | 文档地址 |
| --- | --- | --- |
| 使用账户余额给设备开通AI云存储服务 | 开通时，通过AI云存储套餐区分 | <https://open.ys7.com/help/1400> |
