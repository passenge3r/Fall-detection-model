# AI云存储：文搜操作手册

目前AI云存储已经开放了Web sdk（轻应用uikit）、小程序SDK，App sdk敬请期待。

# 一、Web SDK 集成 （推荐）

开放平台在轻应用中封装了相关AI云存储搜索接口、查询接口等，因此集成之前需要更新到最新版v9.0.0及以上版本，相关轻应用集成介绍：<https://open.ys7.com/help/4294>

集成后，即可直接体验相关功能

![](https://izhstatic.ys7.com/vasp-openweb/1774610401878_image_22.png)

## 核心功能

### 1.1 智能视频搜索

![](https://izhstatic.ys7.com/vasp-openweb/1774610387628_image_19.png)

用自然语言描述您想找的内容，AI 会自动理解并搜索匹配的录像。

例如：

- "帮我搜宝宝出现的录像"
- "帮我搜爸爸的录像"
- "帮我查一下宝宝摔倒的视频"
- "穿黑色衣服的男人"

搜索结果以视频缩略图卡片的形式展示，点击即可直接播放。当结果较多时，可以点击"查看全部"浏览完整列表。

### 1.2 智能总结

![](https://izhstatic.ys7.com/vasp-openweb/1774610393255_image_20.png)

AI 会对录像内容进行自动分析和归纳，生成当日或指定时间段的视频总结，帮助您快速了解监控区域内发生的事情，无需逐段回看。

### 1.3 快捷操作

![](https://izhstatic.ys7.com/vasp-openweb/1774610397435_image_21.png)

界面底部提供三个常用快捷按钮，一键触达核心功能：

- 找录像 — 快速进入视频搜索
- 看总结 — 查看 AI 生成的录像总结
- 看重点 — 浏览重点事件列表

### 1.4 推荐问题引导

首次打开时，界面会展示一组推荐的搜索示例，帮助您快速了解可以搜索哪些内容，点击即可直接发起搜索。

---

## 使用方式

1. 打开 AI 智能搜索助手界面
2. 在底部输入框中输入您想搜索的内容，或点击推荐问题 / 快捷按钮
3. 等待 AI 返回搜索结果
4. 点击视频缩略图即可播放对应录像

---

## 多端适配

- 在电脑端，对话窗口支持拖拽移动，方便调整位置
- 在手机端，界面会自动适配屏幕尺寸，操作体验同样流畅
- 支持全屏模式下使用，窗口会自动调整位置
