# AI云存储：操作说明文档

> 本文档主要介绍萤石云AI云存储的功能及相关操作

# 一、AI云存储产品介绍

萤石云AI云存储产品是，结合了设备移动物体检测、24H连续录像等能力，针对智能家居、智慧工地、商贸连锁等人货流通性大的各类应用场景，凭借自主研发的蓝海AI视觉大模型，拥有强大的数据处理能力和深度学习算法，不仅能够高效处理海量视频数据，更能通过智能分析实现对视频内容的深度理解和精准识别，为用户提供更加智能、便捷的服务，开启智能居家的全新未来，推动行业迈向更高的发展阶段。

详细介绍：<https://open.ys7.com/help/5124>

# 二、AI云存储开通说明

## 1）控制台余额开通

![](https://izhstatic.ys7.com/vasp-openweb/1774612301256_5493d83342113fbedcb6ab1b6cfbc0e1.png)

1. 进入控制台：云存储-Ai云存储
2. 选择对应设备，点击开通AI云存储
3. 选择对应云存储套餐、选择对应智能体
4. 授权密钥，点击付费开通

![](https://izhstatic.ys7.com/vasp-openweb/1774612417372_35e6b63ceced7ba28e38f56a072ecb02.png)

## 2）通过API接口开通

参考文档：[AI云存储开通查询相关接口](https://open.ys7.com/help/5149)

前提：设备需要支持萤石云存储

## 三、查看录像、使用

## 1）控制台查看录像

![](https://izhstatic.ys7.com/vasp-openweb/1774612540550_7bca5e4f8306ce23b4db0d4b585e3366.png)

点击查看AI录像按钮，点击Ai文搜按钮，在弹窗里输入对应想要搜索的内容，即可查找对应录像

## 2）集成SDK查看录像

参考文档：<https://open.ys7.com/help/5150>
