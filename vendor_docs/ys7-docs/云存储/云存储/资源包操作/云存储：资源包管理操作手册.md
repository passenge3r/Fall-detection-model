# 云存储：资源包管理操作手册

# 产品说明

### 什么是资源包？

开发者可以找萤石批量购买云存储套餐的资源包，购买后可以在控制台逐渐开通，既可以享受批量的价格，也可以按需开通设备的云存储套餐。

### 找谁充值

可以联系[小助手](https://resource.eziot.com/group1/M00/00/F3/CtwQE2VtTSuAN0y0AAAmQb_3exk350.png)进行开通

# 资源包数量显示

## 控制台：查看

![](https://resource.eziot.com/group2/M00/01/08/CtwQF2ikNnOAYi7OAAGjz8y8oa8171.png)

操作说明：
1）打开控制台，若开发者已购买资源包，则会在这里显示购买的资源包余量
2）根据购买时间，可以查询购买记录
3）资源包的类型说明：资源包的余量里，包括了每个云存储套餐的数量，具体云存储的套餐可以参见：[云存储套餐](https://open.ys7.com/help/4246)

## 控制台：开通

![](https://resource.eziot.com/group2/M00/01/08/CtwQF2ikPhaAQdW9AAIzNuG_-qo833.png)

操作：点击开通云存储、或者延长云存储

![](https://resource.eziot.com/group2/M00/01/08/CtwQFmikPj-AKONFAACdecz-Wlg432.png)

若用户有资源包余量（每个套餐对应的资源包都是一一对应的），则开通时，会自动抵扣资源包余量

## 接口

**查询：**

使用接口：<https://open.ys7.com/help/4428> 查询账号下的云存储套餐余量

**开通：**

使用接口：<https://open.ys7.com/help/1400> ，选择资源包余量（参数：payment）进行开通，若无余量，则会返回对应错误。请联系小助手充值。
