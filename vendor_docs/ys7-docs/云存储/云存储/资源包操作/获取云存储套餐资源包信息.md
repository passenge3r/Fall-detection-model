## 获取云存储套餐资源包信息

- 接口功能

获取云存储套餐资源包信息

- 请求地址

`https://open.ys7.com/api/service/cloud/storage/productPackage`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |

- 请求示例

```
curl --location 'https://open.ys7.com/api/service/cloud/storage/productPackage' \
--header 'accessToken: at.8z3t4ses32b6ubvk6e1sknni49qguq6i'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": ""
    },
    "data": [
            {
                "cloudProductName": "7天循环1月事件云存储套餐",
                "cloudType": "400299958", // 云存储套餐
                "amount": 10, // 资源包余量
                "serviceTime": 1,
                "serviceTimeUnit": 3,
                "storageTime": 7,
                "storageTimeUnit": 1
              }
        ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | meta |
| -code | int | code |
| -message | string | message |
| -moreInfo | string | moreInfo |
| data | array | data |
| -cloudProductName | string | 云存储套餐名称 |
| -cloudType | string | 云存储类型 |
| -amount | int | 云存储套餐数量 |
| -serviceTime | int | 云存储 服务时长 |
| -serviceTimeUnit | int | 云存储 服务时间单位 1:天 2:周 3:月 4 年 |
| -storageTime | int | 云存储 服务时间单位 1:天 2:周 3:月 4 年 |
| -storageTimeUnit | int | 云存储 存储时间单位 1:天 2:周 3:月 4 年 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 404 | 资源不存在 | 资源不存在 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 429 | 请求过于频繁 | 请求过于频繁 |
