# AI语音云存储集成使用手册

## 概述

本手册描述了AI语音云存储服务的完整集成流程。AI语音云存储在普通云存储基础上增加了语音关键词识别能力，开发者可以为设备配置关键词，系统会自动识别录像中的语音内容并匹配关键词，支持按关键词检索录像。

所有接口均需通过 `accessToken` 进行鉴权

---

## 步骤一/二：选择开通方式（二选一）

根据业务需要选择余额开通或资源包开通，两种方式任选其一。

### 方式A：余额开通 — 查询设备可开通的云存储类型

确认目标设备是否支持AI语音云存储套餐。返回结果中包含通用套餐、AI云存套餐及AI语音云存套餐，通过 `cloudType`和`cloudProductName`来区分。

接口文档：[获取设备可开通的云存储类型](https://test12open.ezv-test.com/help/1405)

**关键点**：

- 记录返回的 `cloudType`，后续开通接口需要使用
- 不同设备型号支持的套餐类型不同，需先确认设备是否支持AI语音云存类型
- 适用于使用账户余额直接开通的场景

### 方式B：资源包开通 — 获取云存储套餐资源包信息

查询可用的云存储套餐资源包信息，包括通用套餐及AI语音云存套餐的资源包详情。

接口文档：[获取云存储套餐资源包信息](https://test12open.ezv-test.com/help/4428)

**关键点**：

- 记录返回的 `cloudType`，后续开通接口需要使用
- 适用于使用已购买的资源包进行开通的场景

---

## 步骤三：开通AI语音云存储服务

根据步骤一/二选择的方式，使用账户余额或资源包为设备开通AI语音云存储服务。通过云存储套餐类型（`cloudType`）区分开通的是普通云存、AI云存还是AI语音云存。

接口文档：[使用账户余额给设备开通AI云存储服务](https://test12open.ezv-test.com/help/1400)

**关键点**：

- `cloudType` 传入步骤一/二获取的AI语音云存套餐类型
- 余额开通：`payment=1`；资源包开通：`payment=10`
- `requestId` 用于幂等控制，需保证唯一性
- 如设备已加密，可同时设置 `deviceAuthEnable=1` 并传入 `validateCode` 完成秘钥授权
- 仅开发者账号（openUserId == userId）有权限调用

---

## 步骤四：查询设备云存储信息

开通后调用此接口确认设备的云存储服务状态，通过返回的产品套餐信息可区分是否为AI语音云存储。

接口文档：[查询设备云存储信息](https://test12open.ezv-test.com/help/1404)

**关键点**：

- 建议在开通后等待几秒再查询，确保数据同步完成
- 返回信息包含服务状态、套餐类型、有效期等
- 通过套餐类型名称或能力集判断当前开通的是否为AI语音云存储

---

## 步骤五：秘钥授权（加密设备）

如果设备已加密且在开通时未进行秘钥授权，需通过此接口补充授权，否则云存储服务无法正常生成加密设备的视频。

接口文档：[秘钥授权接口](https://test12open.ezv-test.com/help/5146)

**关键点**：

- 如果设备未加密，可跳过此步骤
- 如果在步骤三开通时已设置 `deviceAuthEnable=1`，也可跳过此步骤
- 如果开通AI语音云存时，设备未加密，开通后再加密，一定要使用此接口进行授权，否则云存录像无法生成

---

## 步骤六：配置AI语音关键词

AI语音云存储的核心能力是语音关键词识别。开通服务后，需要配置关键词及匹配维度，系统才能对录像中的语音进行识别和匹配。

### 6.1 设置关键词匹配维度

配置关键词的匹配规则维度（如精确匹配、模糊匹配等）。

接口文档：[保存关键词匹配维度](https://test12open.ezv-test.com/help/5194)

### 6.2 保存关键词

添加需要识别的关键词。

接口文档：[保存关键词](https://test12open.ezv-test.com/help/5195)

### 6.3 查询关键词列表

查询当前已配置的关键词列表，用于确认或管理已有关键词。

接口文档：[查询关键词列表](https://test12open.ezv-test.com/help/5197)

### 6.4 删除关键词

删除不再需要的关键词。

接口文档：[删除关键词](https://test12open.ezv-test.com/help/5196)

**关键点**：

- 先设置匹配维度，再保存关键词
- 关键词配置后，系统会对后续录像进行语音识别和匹配
- 可随时通过查询、新增、删除接口管理关键词

---

## 步骤七：使用语音检索能力

关键词配置完成后，系统会自动对云存录像中的语音进行识别。开发者可通过以下两种方式获取匹配结果：

### 7.1 查询已命中关键词的录像

查询已经被系统识别并命中关键词的录像列表。

接口文档：[查询已命中关键词的录像](https://test12open.ezv-test.com/help/5199)

### 7.2 根据关键词检索录像

主动输入关键词进行录像检索，查找包含指定语音内容的录像。

接口文档：[根据关键词检索录像](https://test12open.ezv-test.com/help/5198)

**关键点**：

- 7.1 是被动查询：查看系统已自动匹配到的结果
- 7.2 是主动检索：按指定关键词搜索录像
- 两种方式可配合使用，满足不同业务场景

## 典型集成场景

### 场景一：首次开通AI语音云存（完整流程）

```
余额开通路径：
1. 调用"获取设备可开通的云存储类型"接口
   → 确认设备支持AI语音云存，获取对应 cloudType

资源包开通路径：
1. 调用"获取云存储套餐资源包信息"接口
   → 获取支持AI语音云存资源包套餐的 cloudType

（以上二选一，然后继续：）

2. 调用"开通AI云存储服务"接口
   → 传入 cloudType，开通AI语音云存（如设备加密，同时传入秘钥授权参数）

3. 调用"查询设备云存储信息"接口（可选）
   → 确认开通成功，验证套餐类型为AI语音云存

4. 调用"保存关键词匹配维度"接口
   → 设置匹配规则

5. 调用"保存关键词"接口
   → 添加需要识别的关键词

6. 等待系统对录像进行语音识别

7. 调用"查询已命中关键词的录像"或"根据关键词检索录像"接口
   → 获取匹配结果
```

### 场景二：已开通AI语音云存，管理关键词

```
1. 调用"查询关键词列表"接口 → 查看当前关键词
2. 调用"保存关键词"接口 → 新增关键词
3. 调用"删除关键词"接口 → 移除不需要的关键词
```

### 场景三：已开通AI语音云存，补充秘钥授权

```
1. 设备加密后，调用"秘钥授权"接口
   → Header 传入 deviceSerial 和 localIndex，完成授权
```

### 场景四：检索历史录像中的语音内容

```
1. 调用"根据关键词检索录像"接口
   → 传入目标关键词，获取包含该语音内容的录像列表
```
