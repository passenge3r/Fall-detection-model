# 非萤石设备开通事件云存储方法介绍

## 了解云存储服务

在了解如何开通云存储服务之前，我们需要了解什么是云存储。云存储是指将IPC本地录像保存到云端的产品与服务，它允许用户将数据存储在远程的服务器上。这种服务具有可扩展、高效、安全等优点。

## 设备开通云存储

### 萤石设备

目前所有萤石设备，包括摄像机、门锁、门铃、机器人等硬件都支持直接开通云存储服务。

### 海康设备

由于海康设备的固件、能力集等不一，因此需要根据不同设备进行开通云存储。

| 海康摄像机 | 海康NVR |
| --- | --- |
| 4G设备：一般海康设备能直连萤石的4G设备可以直接开通萤石云存储，若版本较老，请联系商务。 一般设备：需要设备定制，请联系商务或者联系小助手定制云存储协议，才能直接使用云存储 其他方案：可以参考使用拉流云录制，但是拉流云录制需要本地有SD卡或者NVR才能保证文件的可靠性。 | 普通设备：受限于NVR芯片能力，一般的NVR都支持开通1-2路事件云存储。 全通道开通云存储：更换NVR，购买支持全通道开通云存储的NVR设备。（备注） |
| 建议：添加商务进行定制 或 使用拉流云录制。 | 建议：只开通1-2路云存储，或更换全通道云存储设备。 备用方案：可以通过云录制进行错时备份。 |

备注：若要开通全通道云存储，目前建议购买NVR设备为：

303621604,DS-7716N-I5-V3(标配)/萤石云存储

303621602,DS-8608N-I9-V3(标配)/萤石云存储

303621603,DS-8616N-I9-V3(标配)/萤石云存储

303621600,DS-7608N-I3-V3(标配)/萤石云存储

目前支持这几款设备，分别支持4路、8路、16路开通云存储。

### 国标设备

国标设备目前只支持云录制，不支持云存储，但是可以通过更换存储桶等策略使用云录制，可以联系商务进行开通。
