## 2.1 计费方式

云录制产品计费方式为后付费的按量计费模式。当您开通云录制服务后，可默认根据使用量付费，每日结算。

按量计费： 按实际使用量\*单价的方式计费，按计费周期（日）统计实际用量并从账户余额中扣除实际消费金额。

## 2.3 欠费说明

如果您的账户余额不足产生欠费，请知悉：

当您的账号处于欠费状态，云录制服务会自动停止。服务停止后您无法创建新的云录制项目，已在进行中的项目会完成录制。云录制产生的内容存储费用仍会继续扣费，因此欠费额将会累计，且无法进行下载。

云录制服务停止后，您在7天内进行充值补足欠费后，服务会自动开启，可以继续使用。欠费超过7天，将视为您主动放弃云录制服务，您云录制服务产生的资源将被回收，录制的视频或图片等数据将被清空且不可恢复。
