## 1.1 什么是云录制

云录制是 EZVIZ 针对视频监控设备研发的设备录像的采集、存储和处理的一体化录制组件，通过简单的操作，帮助开发者精准、灵活地对设备内容进行存储和处理。

基于云录制能力，开发者可以将视频监控、音视频通话以及视频关键帧的内容储存下来， 作为存证和纠纷处理凭证，或作为企业算法训练的素材。如，透明装修场景中除了实时查看与历史片段浏览外，还可以将透明装修的关键作业视频录制下来，方便质检员抽查审核与打分。

## 1.2 应用场景

**设备告警视频录播**

- 通过云录制可以将告警消息产生的时刻对应的视频进行录制，实现告警消息和视频录制之间的联动
- [查看方案](https://open.ys7.com/help/357)

**课程存档**

- 通过云录制可以实现课程视频采集、视频处理、视频下载一站式操作，不再辗转多个平台进行处理
- [查看方案](https://open.ys7.com/help/507)

**图片采集**

- 通过云录制可以批量获取大量设备图片，实现算法素材的采集，如：工人操作图片；疫情隔离点人员违规进出图片；垃圾分类图片；装修过程等图片的采集。通过便捷的视频和图片内容的采集，不仅方便客户进行自研算法的训练，同时支持三方算法部署。
- [查看方案](https://open.ys7.com/help/369#image_storaged-api4)

## 1.3 功能概览

云录制产品包含内容采集，文件管理，任务管理，文件操作四个主要功能。

| 功能名称 | 功能描述 |
| --- | --- |
| 内容采集 | ①监控视频录制 ②定时抓图或抽取视频关键帧 ③告警图片自动存储 ④多方音视频通话录制 |
| 内容处理 | ①图片水印：支持在图片中打上图片、文字水印，并获取处理后文件的下载链接或存储在云端。  ②图片缩略图：支持对图片进行缩放，并获取处理后文件的下载链接或存储在云端  ③图片浓缩：支持对抽帧后获取的图片进行聚合，将图片拼接为视频 |
| 文件管理 | 账号下可设置多个文件夹，不同的文件分开管理 |
| 任务管理 | 支持设置定时任务，批量处理视频录制、图片抓取、图片处理等任务。 |

## 1.3 产品优势

**快速录制**

API方便业务集成与二次开发，快速提取关键内容，录制任务即下即传

**精准存储**

支持事件联动录制，实现精准的内容存储

**高可靠性**

分布式集群部署与重试机制保障关键内容的提取稳定，多云备份保障内容的存储安全。

**高安全性**

提供多方音视频通话、视频预览、数据传输、数据存储等端到端安全保障机制。
