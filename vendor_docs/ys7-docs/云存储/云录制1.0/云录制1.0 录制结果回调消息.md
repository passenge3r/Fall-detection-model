## 云录制1.0 录制结果回调消息

   前提条件：在消息推送控制台开通消息推送服务，并勾选云录制消息。云录制消息类型：ys.open.cloud。[消息推送服务开通操作手册](https://open.ys7.com/help/566)

### 云录制1.0（原mp4录制）

#### 录制任务消息

**header说明**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| type | String | 消息类型：ys.open.cloud表示云录制消息 |
| deviceId | String | 设备序列号 |
| channelNo | Int | 设备通道号 |
| messageId | String | 消息唯一ID |
| messageTime | Long | 消息发送时间 |

**body说明**

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| projectId | String | 项目Id |
| taskId | String | 任务id |
| deviceSerial | String | 设备序列号 |
| channel | String | 通道号 |
| fileNum | Long | 任务产生文件数量 |
| totalSize | Long | 任务产生文件大小 |
| errorCode | String | 返回码 |
| errrorMsg | String | 返回信息 |
| taskStatus | String | 任务状态：0-已完成，1-排队中，2-进行中，3-已结束，4-异常结束，5-暂停中，6-已取消，7-未开始 |
| messageType | String | 录制类型：video\_replay\_rec(回放)，video\_replay\_status\_chang(回放状态变化)，video\_preview\_rec(预览)，video\_preview\_status\_change(预览状态变化)，video\_instant\_rec(即时)，video\_instant\_status\_change(即时状态变化) |
| actualEndTime | String | 录制结束时间 |
