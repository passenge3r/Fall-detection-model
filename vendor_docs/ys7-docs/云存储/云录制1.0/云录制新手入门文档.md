# **1.控制台入门**

## **1.1 开通流程**

### **1.1.1 前提条件**

请确保您的账号已购买企业版套餐，由于云录制服务是后结算服务，仅面向企业版账号提供。

### **1.1.2** **操作步骤**

开通地址：<https://open.ys7.com/console/preCloudRecord.html>

页面介绍

![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnSSAbXuLAABi2pYCPX8696.png)

## **1.2 创建内容**

### **1.2.1 创建存储项目文件夹**

开通服务后，进入云录制控制台，进入项目管理页面。
![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnSCAR9SUAAA8kfP_yZ8116.png)

点击右上角创建新的项目，或者选择已有项目。
![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnRqAE-z2AAB6HZPHk_M166.png)

根据业务情况填写项目信息，其中，项目编号（即projectID）将会在后续接口调用中频繁被使用，文件保存时间设置好后，项目下所有文件会使用这一存储周期，到期后会自动删除文件。点击确认后文件夹创建成功。

**注意**：项目编号（projectid）创建要求：长度必须为：1-32位；只能包括字母下划线数字；必须唯一

![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnRWAV_KeAAAYmj1DOzY591.png)

### **1.2.2 创建 isapi 图片存储**

鼠标移动至创建好的项目文件夹，点击右上角的…可以进行查看项目详细信息、编辑信息等操作。

若需要存储isapi图片，选择「设为isapi项目」，后续账号下设备产生的isapi告警图片会自动转存至此项目文件夹。

**注意**：每位用户只能创建1个isapi存储地址

![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnRCAFcAZAAANeq0Vu48508.png)

### **1.2.3 创建任务**

**任务类型** ：回放录制、即时录制、预约录制、抓拍、抽帧

进入项目管理/任务管理页面，点击新建任务，进行任务创建。

![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnQyAZ0kqAAB_D3fedG8410.png)

![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnQeANr7IAADgqLtI-vk270.png)

**1.2.3.1 创建回放录制任务**

选择任务类型为回放录制，填写项目编号、设备序列号、通道号、录制时间。

**注意**：1.单通道设备（IPC）的通道号默认填写1，多通道设备（NVR）填写需要抓拍的通道号。2.选择回放录制的录制时间时需要先确认该时间段内设备的SD卡和云存储是否有本地录像。3.若设备为国标设备，则输入设备license并选择协议为国标协议，否则无法进行录制。4.若设备加密需要输入解密密钥，设备未加密则无需填写。5.自定义前缀文件（fileId）命名规则：长度必须为：1-32位；5只能包括字母下划线数字；同一个项目下名称不重复。

![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnQGAYwovAAAyFsoLoQY151.png)

**1.2.3.2 创建即时录制任务**

任务下发后将立即进行录制，直到主动结束任务或达到最大录制时间。

选择任务类型为即时录制，并选择对应项目编码，输入设备序列号、最大录制时间。

**注意**：1.单通道设备（IPC）的通道号默认填写1，多通道设备（NVR）填写需要抓拍的通道号。2.若设备为国标设备，则输入设备license并选择协议为国标协议，否则无法进行录制。3.若设备加密需要输入解密密钥，设备未加密则无需填写。4.最大录制时间为24小时。5.自定义前缀文件（fileId）命名规则：长度必须为：1-32位；只能包括字母下划线数字；同一个项目下名称不重复。

![](https://resource.eziot.com/group2/M00/00/92/CtwQF2QFnv6AKPBEAAAxPuerEHI422.png)

**1.2.3.3 创建预约录制任务**

选择任务类型为预约录制，并选择对应项目编码，输入设备序列号、录制时间段，若设备加密需要输入解密密钥，设备未加密则无需填写。

**注意**：1.单通道设备（IPC）的通道号默认填写1，多通道设备（NVR）填写需要抓拍的通道号。2.若设备为国标设备，则输入设备license并选择协议为国标协议，否则无法进行录制。3.若设备加密需要输入解密密钥，设备未加密则无需填写。4.自定义前缀文件（fileId）命名规则：长度必须为：1-32位；只能包括字母下划线数字；同一个项目下名称不重复。

![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnP6AesbrAAA1K_iA-8g609.png)

**1.2.3.4 创建抓拍任务**

选择任务类型为抓拍，输入项目编号、设备序列号、通道号抓拍时间点。使用图片抓拍接口前，需要先确认设备是否具备抓图能力集：support\_capture=1则设备支持抓拍，若为0则不支持抓拍。可以通过设备序列号查询设备能力集，[点击查看能力集查询接口](https://open.ys7.com/help/55#device_select-api8)。设备抓图能力有限，建议两次抓拍间隔在4秒以上。

**注意**：1.单通道设备（IPC）的通道号默认填写1，多通道设备（NVR）填写需要抓拍的通道号。2.若设备为国标设备，则输入设备license并选择协议为国标协议，否则无法进行录制。3.若设备加密需要输入解密密钥，设备未加密则无需填写。4.自定义前缀文件（fileId）命名规则：长度必须为：1-32位；只能包括字母下划线数字；同一个项目下名称不重复。

![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnPmACJMeAAAyGKl6qfU568.png)

**1.2.3.5 创建抽帧任务**

选择任务类型为抽帧，按照弹窗内容提交抽帧信息。适用于设备不具备抓拍能力、需要频繁获取设备图片等场景。

**注意**：1.单通道设备（IPC）的通道号默认填写1，多通道设备（NVR）填写需要抓拍的通道号。2.若设备为国标设备，则输入设备license并选择协议为国标协议，否则无法进行录制。3.若设备加密需要输入解密密钥，设备未加密则无需填写。4.自定义前缀文件（fileId）命名规则：长度必须为：1-32位；只能包括字母下划线数字；同一个项目下名称不重复。

**抽帧时间**：

- 时间点抽帧 ：根据时间点进行抽帧；
- 时间段抽帧：在确认的时间段内按照时间间隔进行抽帧；

**抽帧模式** ：

- 错峰抽帧：将错开取流高峰期进行抽帧，在期间进行取流不会收取取流费用，适合不需要马上获取到图片的方式
- 抽I帧模式：在需要马上获取大量图片，希望能快速获取又节省带宽时，可以选择抽I帧模式，该模式需要的解码时间更短，对带宽消耗更低。I帧是每隔1个GOP间隔出现一次，由于每台设备的GOP间隔不同，模式是根据设备的GOP间隔进行抽帧，不能自定义时间点

![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnPaARTUOAAA22g_zO3g810.png)

## **1.5 文件操作（文件查询、文件操作、文件查看）**

### **1.5.1 文件查询**

可根据文件编号、任务编号、项目编号进行文件检索。

进入文件检索页面，选择编号类型，输入相应编号查询所需文件。

![](https://resource.eziot.com/group1/M00/00/BE/CtwQEmQFnNWAKw6vAADtQrn1MaQ929.png)

### **1.5.2 文件操作**

文件存储方式分为：标准存储、归档存储

- **标准存储文件** ：可直接在操作列进行下载、移动、删除操作
- **归档存储文件** ：需先进行取回，再进行其他文件操作

注意：归档存储文件60天内不可删除，取回有效期为6天

![](https://resource.eziot.com/group1/M00/00/BE/CtwQE2QFnM-AYPgfAAExzF-mI6E435.png)
