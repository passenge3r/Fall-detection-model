# 常见错误码

本节内容包含云录制使用过程中常见的错误码，主要内容如下：

| 序号 | 接口功能 | 描述 |
| --- | --- | --- |
| 1 | [云录制接口报错](#error_code-api1) | 云录制功能接口报错 |
| 2 | [取流接口报错](#error_code-api2) | 取流过程中发生的接口报错 |

## 3.7.1 云录制接口错误码

| 错误码 | 错误描述 | 解决方案 |
| --- | --- | --- |
| 400 | 请求参数错误 | 请检查参数传递 |
| 403 | 权限问题 | 无权限操作，检查权限 |
| 404 | 资源不存在 | 检查资源是否存在 |
| 500 | 服务内部问题 | 请检查传递参数进行重试，如还是服务错误请联系客服 |
