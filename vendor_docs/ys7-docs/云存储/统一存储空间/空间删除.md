## 空间删除

- 接口功能

   空间删除。是否支持托管：否。是否支持子帐号：否。

- 请求地址

`https://open.ys7.com/api/service/open/storage/engine/space`

- 请求方式

`DELETE`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | spaceId | Long | 空间id | Y |

- 请求示例

```
curl --location --request DELETE 'https://open.ys7.com/api/service/open/storage/engine/space' \
--header 'accessToken: at.3dunn6xgc5ubjfs0c581ef26bzxtqgp6' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'spaceId=2029271'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": true
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 附加信息，通常为null |
| data | Boolean | 是否删除成功，true表示成功 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 请检查请求参数是否正确 |
| 404 | 资源不存在 | 请检查空间id是否存在 |
| 406 | 平台不支持的操作 | 该操作不被平台支持 |
| 412 | 前置条件不满足 | 请检查前置条件是否满足 |
| 500 | 服务器异常 | 服务器内部错误，请稍后重试 |
