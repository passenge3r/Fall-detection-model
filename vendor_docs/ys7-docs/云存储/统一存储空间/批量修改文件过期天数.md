## 批量修改文件过期天数

- 接口功能

   批量修改文件过期时间。托管/子账号：不支持。空间id和文件节点id业务类型需要匹配，支持： vod:云点播 云抓拍cloudCapture；设备抓图capture 这些空间id下的文件

- 请求地址

`https://open.ys7.com/api/service/open/storage/engine/file/batchExpire`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | fileNodeIds | String | 文件节点id，使用","分隔，上限50个， | Y |
| body | spaceId | Long | 空间id，由空间列表查询接口获取，将上述文件的过期天数调整为与该空间一致，上述文件节点需要和该空间是同一个业务类型 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/storage/engine/file/batchExpire' \
--header 'accessToken: at.3dunn6xgc5ubjfs0c581ef26bzxtqgp6' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'spaceId=2029091' \
--data-urlencode 'fileNodeIds=Yc28Y5u1,IxifvADk'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 附加信息，通常为null |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 请检查请求参数是否正确 |
| 404 | 资源不存在 | 请检查文件节点id或空间id是否存在 |
| 412 | 前置条件不满足 | 请检查文件节点与空间的业务类型是否一致 |
| 500 | 服务器异常 | 服务器内部错误，请稍后重试 |
