## 通用空间获取下载地址

- 接口功能

   获取下载地址。托管/子账号：不支持。

- 请求地址

`https://open.ys7.com/api/service/open/storage/engine/file/downloadurls`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | fileNodeIds | String | 文件节点id，通过逗号隔开的字符串，最多限制50个 | Y |
| query | expireSeconds | Long | 下载链接有效时长，30到604800区间范围，单位秒，默认1800 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/open/storage/engine/file/downloadurls?fileNodeIds=I7oZ7nPo%2C40TgZ4Kq' \
--header 'accessToken: at.3dunn6xgc5ubjfs0c581ef26bzxtqgp6'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "urls": {
            "I7oZ7nPo": "https://openrecord.ys7.com/...",
            "40TgZ4Kq": "https://opencapture.ys7.com/..."
        },
        "expireTime": 1778318776647
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 附加信息，通常为null |
| data | Object | 响应数据 |
| data.urls | Object | 下载地址，Map集合，key为folderNode（文件节点id），value为下载链接 |
| data.expireTime | Long | 下载链接过期时间，毫秒级时间戳 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 请检查请求参数是否正确 |
| 500 | 服务器异常 | 服务器内部错误，请稍后重试 |
| 10002 | accessToken过期或异常 | 请重新获取accessToken |
