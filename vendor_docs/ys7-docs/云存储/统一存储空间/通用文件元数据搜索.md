## 通用文件元数据搜索

- 接口功能

   文件元数据搜索。托管/子账号：不支持。搜索优先级：1、folderNodes 文件节点id列表；2、tagId传入时，startTime、endTime传入则有效，也可不传；3、spaceIds、startTime、endTime组合条件。

- 请求地址

`https://open.ys7.com/api/service/open/storage/engine/file/listById`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | spaceIds | Long | 空间id集合，spaceIds范围为1~5个，由空间列表查询接口获取 | N |
| body | startTime | String | 开始时间，格式：yyyy-MM-dd HH:mm:ss，当folderNodes有值时此参数无效 | N |
| body | endTime | String | 结束时间，格式：yyyy-MM-dd HH:mm:ss，当folderNodes有值时此参数无效 | N |
| body | folderNodes | String | 文件节点id集合，当与tagId同时传入时，tagId无效 | N |
| body | tagId | String | 标签id，可以是云点播视频剪辑的剪辑任务id、云点播转封装任务id或云抓拍的抽帧任务id | N |
| body | pageSize | Int | 每页大小，1-50，默认10 | N |
| body | lastId | String | 最后id，用于翻页，默认为空 | N |
| body | fileType | String | 文件类型：0-图片，1-视频，2-音频，3-文档，4-其他 | N |
| body | fileChildType | String | 文件子类型：00-JPG，01-PNG，02-GIF，10-MP4，13-M3U8，20-MP3 | N |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/storage/engine/file/listById' \
--header 'accessToken: at.3dunn6xgc5ubjfs0c581ef26bzxtqgp6' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'pageSize=10' \
--data-urlencode 'startTime=2026-04-11 20:42:53' \
--data-urlencode 'endTime=2026-05-08 20:42:55' \
--data-urlencode 'fileNodeIds=I7oZ7nPo,40TgZ4Kq'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应码，200表示成功 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 附加信息，通常为null |
| data | Object | 响应数据 |
| data.result | Array | 文件列表 |
| data.result[].folderNode | String | 当前节点id |
| data.result[].parentFolderNode | String | 文件夹目录父节点 |

| data.result[].orderIndex | Int | 显示排序 |

| data.result[].deviceSerial | String | 设备序列号 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 请检查请求参数是否正确 |
| 404 | 资源不存在 | 请检查空间id或文件节点id是否存在 |
| 412 | 前置条件不满足 | 请检查前置条件是否满足 |
| 500 | 服务器异常 | 服务器内部错误，请稍后重试 |
