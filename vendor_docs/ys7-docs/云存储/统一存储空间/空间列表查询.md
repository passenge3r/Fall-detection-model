## 空间列表查询

- 接口功能

   空间列表查询

- 请求地址

`https://open.ys7.com/api/service/open/storage/engine/space/listById`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 授权过程获取的access\_token | Y |
| query | startTime | String | 查询开始时间，格式yyyy-MM-dd HH:mm:ss，基于createTime筛选 | Y |
| query | endTime | String | 查询结束时间，格式yyyy-MM-dd HH:mm:ss，开始结束时间需要在30天内 | Y |
| query | lastSpaceId | Long | 上一页最后空间id，用于翻页 | N |
| query | pageSize | Int | 分页大小，默认10，范围1-50 | N |
| query | bizTypeList | String | 存储空间类型，默认为查询支持的所有空间类型的空间。可选值：vod(云点播)、record(云录制2.0)、cloudCapture(云抓拍)、capture(设备抓图) | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/open/storage/engine/space/listById?startTime=2026-04-23%2000%3A28%3A29&pageSize=10&endTime=2026-05-20%2000%3A28%3A28' \
--header 'accessToken: at.3dunn6xgc5ubjfs0c581ef26bzxtqgp6'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| spaceId | Int | 空间id |
| namespaceType | Int | 空间类型 1-普通空间 2-回收站空间 |
| spaceName | String | 空间名称 |
| storageType | Int | 空间存储类型 1-标准存储 |
| folderDirectoryId | String | 根节点文件夹id |
| totalFlow | Int | 流量大小，单位Bytes |
| totalSize | Int | 存储大小，单位Bytes |
| flowLimit | Int | 流量限制，-1表示无限制 |
| permission | Int | 权限 1-读写 2-只读 |
| expireDays | Int | 过期天数，-1表示永久 |
| createTime | String | 创建时间 |
| updateTime | String | 修改时间 |
| bizType | String | 空间业务类型，vod-云点播、record-云录制2.0、cloudCapture-云抓拍、capture-设备抓图 |
| bizTypeDesc | String | 空间业务类型描述 |
| defaultSpace | Int | 空间是否为默认空间 0-否 1-是 |
| lastId | Long | 当前页最后一条记录的空间id，用于翻页请求 |
| pageSize | Int | 当前分页大小 |
| hasNext | Boolean | 是否有下一页 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 请求成功 |
| 400 | 参数错误 | 参数为空或格式不正确 |
| 500 | 服务器异常 | 服务端内部错误，请稍后重试 |
