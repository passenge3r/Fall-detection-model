# 业务联动告警事件录制/图片抓拍

> 业务联动告警事件录制/图片抓拍

> 更新时间: 2026-05-25T16:36:51.000+08:00

> 文档ID: 357 | 来源树: 云存储

---

## 1.方案背景

为了适配自身的业务场景，开发者往往希望联动业务事件进行视频或图片的存储，作为后续内容查证的关键材料。为了使存储方案更适配联动存储的场景，针对告警视频的存储，萤石云给出以下方案。

## 2.实施方案

### 2.1设备选型

|  |  |
| --- | --- |
| 支持设备类型 | 萤石/海康设备、国标设备 |
| 设备说明 | 开发者账号下，通过萤石云可以取流的设备都可以进行视频/图片存储；  直连、托管设备都支持 |

### 2.2业务流程拆解

2.2.1 准备工作：

1. 确定触发视频录制和图片存储的业务条件，以及业务侧需要录制的事件时长。以消防场景为例，客户有三方的传感器触发告警后，可以以收到三方传感器的告警时刻作为触发条件
2. 付费成为企业版客户（若未付费可[点击开通企业版套餐](https://open.ys7.com/console/enterprise.html)）
3. 若需要录制视频，需要先创建云录制2.0存储空间：[控制台开通入口](https://open.ys7.com/console/cloudRecordV2.html)；[接口开通文档](https://open.ys7.com/help/1975)
4. 若需要抓拍图片，需要先创建云抓拍项目空间：[控制台开通入口](https://open.ys7.com/console/cloudSnapshot.html)；[接口开通文档](https://open.ys7.com/help/1362)

#### 2.2.2 获取视频/图片

- 获取视频

1. 开发者业务侧触发需要进行视频录制的事件后，自行计算需要存储的视频时间段

2. 若需要录制事件前后时间段的录像：根据接口文档[创建录像计划](https://open.ys7.com/help/2045)，将业务上需要的startTime和endTime填写完整

3. 若需要录制事件开始后的录像，根据接口文档创建即时录像计划，创建后可以立即开启录制，业务侧需要停止录像时，再通过[接口文档](https://open.ys7.com/help/2046)自行终止录像

4. 开发者需要记录每次事件对应的设备序列号和录像开始结束的时间点，以便后续进行播放

5. 播放录像：根据事件所在的设备序列号和录像开始结束的时间点，根据[接口文档](https://open.ys7.com/help/2864)进行播放

- 获取图片

1. 事件触发后，根据[接口文档](https://open.ys7.com/help/1387)获取即时画面。如果设备支持抓图能力，capturetype选择1，如果设备不支持抓图，capturetype选择2

2. 下载图片：如果是capturetype选择1，会在回调信息里面直接返回图片的下载地址；如果capturetype选择2，回调信息会返回文件ID，可根据[接口文档](https://open.ys7.com/help/1377)获取文件下载地址
