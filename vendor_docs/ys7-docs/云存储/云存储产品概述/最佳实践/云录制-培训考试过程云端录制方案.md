# 培训考试过程云端录制方案

## 项目背景

为了达成十四五规划的人才培养目标，各地人社厅纷纷出台政策，对十四五期间培训的人次做了对应的规划。
为了保证规划落实到位，各地培训机构需要有统一平台进行管理，同时对上课的内容进行记录，保证培训过程按照政策要求实施。
因此职业技能培训平台需要提供从设备接入、平台对接、培训过程存证的完整方案

## 实施方案

### **设备选型**

设备推荐：CTQ6X  
CTQ6X是根据教培场景定制的一款设备，支持语音提示SD卡未插入；定制码率；默认SD卡全天存储；除设备外，建议配备SD卡。

### **设备初始配置**

设备在上云后，为了适配考试场景，需要对配置项做一些设置。

#### **设备配置项设置**

**SD卡设置**：

- SD卡状态查询：[「接口文档」](https://open.ys7.com/help/2010)查询SD卡状态是否正常，或是否在格式化
- SD卡格式化：[「接口文档」](https://open.ys7.com/help/2011)下发SD卡格式化指令，在设备重新插拔过SD卡时，需要对SD卡进行格式化才能存储。
- 设备全天录像开关查询：[「接口文档」](https://open.ys7.com/help/712)设备出厂默认是事件存储，考试期间的录像会保存不全，因此需要设置成全天存储。
- 设备全天录像开关设置：[「接口文档」](https://open.ys7.com/help/713)

**视频设置**：设备出厂默认是变码率，会导致同样时长的录像大小不一样，不适合对终端用户统一收费标准。如果需要固定一场考试录制的录像大小，需要对码率进行设置

- 设备视频编码查询：[「接口文档」](https://open.ys7.com/help/2841)查询设备详细的编码参数，**注意**，这个接口需要设备支持，部分设备是查询不出的
- 设备视频参数设置：[「接口文档」](https://open.ys7.com/help/2297)设置设备的编码参数，**注意**，这个接口需要设备支持，部分设备只能本地局域网配置，不能通过云端接口配置
- 视频清晰度设置：[「接口文档」](https://open.ys7.com/help/2011)设置设备清晰度为标清、高清、超清等，**注意**，这个接口需要设备支持，部分设备只能本地局域网配置，不能通过云端接口配置
- 音频编码设置：[「接口文档」](https://open.ys7.com/help/2372)部分场景需要将录像转码成标准的MP4格式进行存储，这就需要设备的音频流是aac、G711格式

**其他设置**：

- 开启设备上下线通知：[「接口文档」](https://open.ys7.com/help/719)
- 远程重启设备：[「接口文档」](https://open.ys7.com/help/1532)（支持关机、重启、重置。不是所有设备都支持，开考前谨慎操作！）
- 关闭视频加密：[「接口文档」](https://open.ys7.com/help/697)

### **开考前**

需要对设备配置项、网络环境进行检查，确保考试期间的录像可以进行录制

#### **考前10分钟**：设备状态检查

- SD卡状态查询：[「接口文档」](https://open.ys7.com/help/2010)
- 设备全天录像开关查询：[「接口文档」](https://open.ys7.com/help/712)
- 设备视频编码查询：[「接口文档」](https://open.ys7.com/help/2841)
- 音频编码设置：[「接口文档」](https://open.ys7.com/help/2372)  
  若发现设备设置项有误的，可通过接口对设备进行远程设置，或告知现场维护人员进行本地操作。

#### **考前5分钟**：设备网络自检

- 发起30秒短视频录制：[「接口文档」](https://open.ys7.com/help/1381)通过短视频的录制情况自检现场的网络情况，避免考试过程中发现网络环境差的问题。

确认设备和网络没有问题后，发起预约录制任务[「接口文档」](https://open.ys7.com/help/1383)，从实时画面进行录制

### **考试中**

1. 视频录制过程中，由于现场的变动导致设备配置项发生变化了，需要查询设备状态的，可参考设备初始配置中对应的设备配置项
2. 查询实时网络状态：[「接口文档」](https://open.ys7.com/help/672)当发生网络异常导致录制失败时，可通过该接口查询设备实时的网络情况，方便指导现场维护人员进行问题的排查和处理
3. 常见错误码及解决方式（全量错误码请[点击查看](https://open.ys7.com/help/371)）

| 错误码 | 描述 | 建议解决方式 |
| --- | --- | --- |
| 6 | 视频被加密，请关闭加密功能后重新录制 | 需要让用户告知技术人员秘钥，重新发起录制时输入秘钥，或让用户在APP上关闭加密，技术人员也可以使用接口关闭[「接口文档」](https://open.ys7.com/help/697) |
| -9 | 音频编码格式错误，请更改音频格式后重新发起录制 | 云录制目前支持音频格式为：G711或者AAC，需要让用户在设备高级配置中将音频编码格式更改为G711或者AAC，或使用接口修改：[「接口文档」](https://open.ys7.com/help/2372) |
| 5405 | 取流超时，请检查设备网络 | 检查设备网络，重启设备接入萤石云，或减少同一网络下的设备并发录制任务 |
| 5404 | 设备不在线，请检查设备网络或重启设备 | 检查设备网络；重启设备接入萤石云 |
| 5416 | 设备达到并发上限，请减少该设备的录制任务或停止观看该设备的视频，保证录制任务可执行 | 减少该设备的录制任务或停止观看该设备的视频，然后重新发起录制 |

### **考试后**

发现考试视频缺失，需要补录

#### **接口URL**

`https://open.ys7.com//api/service/cloudrecord/video/retry`

**请求类型**

POST

**Header**

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| accessToken | string | Y | 用户令牌 |  |

**body**

| 名称 | 类型 | 必填 | 描述 | 示例指及参考API |
| --- | --- | --- | --- | --- |
| taskId | string | Y | 任务id |  |

**响应**

返回数据

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| meta | object | 返回体 |  |
| -code | int | 错误码 |  |
| -message | string | 错误信息 |  |
| -moreInfo | string | 额外信息 |  |

```

    "meta": {
        "code": 200,

        "moreInfo": ""
    }
```
