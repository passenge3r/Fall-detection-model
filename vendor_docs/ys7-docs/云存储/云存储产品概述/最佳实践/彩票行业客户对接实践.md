# 彩票行业客户对接实践

> 该文档主要是针对：体彩开发者客户快速对接

# 场景说明

体彩门店、福彩门店接入萤石云平台

# 场景1：全部为海康、萤石设备

## 1）多屏组件SDK对接

多屏组件的对接说明：https://open.ys7.com/help/4287

单个组件对接SDK：https://open.ys7.com/help/4274

对接文档说明：单个屏幕的UI可以配置PC live等模板，进行云台、清晰度切换、对讲等操作能力

## 2）小程序对接

插件对接：https://open.ys7.com/help/1865可以直接集成萤石的萤石小程序插件

-支持云台、对讲等能力

## API：云台

-独立的web页面里，我们已经集成了云台、变焦功能，可以直接使用，无需额外的接口对接

-如果是要额外的页面上使用云台功能，则需要直接对接云台的API接口

-云台接口：https://open.ys7.com/help/679

## APi：查看录像

说明：轻应用里已经集成了回放能力，可以使用pcRec等模板，但是如果客户要自定义，可以使用以下接口

- 查看本地、云存储最近日期是否有录像：https://open.ys7.com/help/4329 ，recType来区分：1-云存储，2-本地录像，这个可以看到近一个月的录像当天是否有录像
- 查看当天的本地录像时间点片段：https://open.ys7.com/help/3922
- 查看当天的云存储录像时间点片段接口：https://open.ys7.com/help/1422

# 场景2：混合大华等其他三方设备

多屏SDK对接

①http-flv的SDK对接文档：https://open.ys7.com/help/1812

②web对讲：

- -说明：在对接flv SDK后，点击某个设备，唤起新的内容，与某个设备进行对讲、云台操作等
- -对接SDK：https://open.ys7.com/help/4274
- -对接文档说明：可以配置PC live等模板，进行云台、清晰度切换、对讲等操作能力，参考https://open.ys7.com/help/4304

③小程序对讲：

- -说明：小程序如果中体彩自己有试听许可证，可以使用微信live-player组件，也可以直接集成萤石的萤石小程序插件
- -插件对接：https://open.ys7.com/help/1865 在点击某个设备后，直接集成萤石小程序插件
- -支持云台、对讲等能力

④云台接口：

- -独立的web页面里，我们已经集成了云台、变焦功能，可以直接使用，无需额外的接口对接
- -如果是flv的页面上使用云台功能，则需要直接对接云台的API接口
- -云台接口：https://open.ys7.com/help/679

⑤查看回放：
-如果是flv的SDK里，要查看历史录像，可以使用以下接口

- -查看本地、云存储最近日期是否有录像：https://open.ys7.com/help/4329 ，recType来区分：1-云存储，2-本地录像，这个可以看到近一个月的录像当天是否有录像
- -查看当天的本地录像时间点片段：https://open.ys7.com/help/3922
- -查看当天的云存储录像时间点片段接口：https://open.ys7.com/help/1422
- -获取到片段后，通过接口获取http-flv的视频，进行播放：https://open.ys7.com/help/1414，type选择2-本地录像回放，3-云存储录像回放，且protocol选择4-flv
