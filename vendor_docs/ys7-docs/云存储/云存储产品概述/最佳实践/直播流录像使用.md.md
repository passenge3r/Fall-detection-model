# 直播+录制+剪辑：开通短时视频录制存储+视频剪辑下载实践教程

> 该文档主要是针对：大华设备RTMP推流接入，普通网络摄像机请通过萤石协议接入

# 1.数据准备

- 新建云点播空间，或使用已有空间。（记录存储空间id，新建rtmp直播流录制 需要使用）

空间管理页面：https://open.ys7.com/console/cloudondemand.html
![空间管理页面](https://resource.eziot.com/group1/M00/01/91/CtwQE2ioH5KAHteOAAHIt2tpK6E821.png)
![空间新增页面](https://resource.eziot.com/group1/M00/01/91/CtwQEmioIiOACYu-AAJ0wz4purM535.png)

**备注** ：

空间周期：空间内的文件到该周期后会自动删除。比如客户打台球需要云端保存2天，那就新建一个2天周期的空间，到2天后录像会自动删除。

列表里会有一个默认永久周期空间，可以存储不需要删除的文件。

# 3.录制说明

- 当开发者将流推到萤石云RTMP流后，开发者可以配置 （ 参考 #2 里的接口说明 ）获取到的推流地址，进行直播推流，同时，可以开启录制功能，即可获取到录制的文件：mp4或m3u8
- 开启录制：<https://open.ys7.com/help/4433>，开发者可以根据这个接口，开启或者关闭直播流的录制功能开关
- 如果开启了录制功能，可以通过接口获取到源始录制文件id。[查看https://open.ys7.com/help/4751](https://open.ys7.com/help/4751)，通过该接口可以获取到录制的文件源文件，如果开发者录制的格式是MP4，则可以通过录制源文件的filenodeid去获取文件的在线播放地址。
- 如果用户录制的是HLS文件，由于萤石云服务端会有自动切片等功能，因此开发者可以通过：[查看接口：获取直播流（仅限HLS格式录制）-云点播文件](https://open.ys7.com/help/4757) 这个接口，通过不同的时间获取对应时间片段的播放URL

> 直播流状态变更消息体：[查看文档](https://open.ys7.com/help/4070)

# 4.录制文件管理

> 可以使用云点播空间控制台或者通过接口管理相关媒资信息

开发者可以通过以下几个接口文档，进行媒资管理和播放地址获取等功能

**媒资管理**

- 云点播文件分页查询。 [查看文档](https://open.ys7.com/help/4444)
- 通过fileNodeIds批量查询元数据。 [查看文档](https://open.ys7.com/help/4187)
- 对视频进行获取封面图。 [查看文档](https://open.ys7.com/help/4441)
- 保存视频封面图。 [查看文档](https://open.ys7.com/help/4442)
- 删除单个文件。 [查看文档](https://open.ys7.com/help/4333)
- 批量删除文件。[查看文档](https://open.ys7.com/help/4446)
- 迁移视频文件。[查看文档](https://open.ys7.com/help/4954)

**获取播放地址**

- 根据fileNodeIds查询文件播放地址。 [查看文档](https://open.ys7.com/help/4402)
