# 计费方式

存储产品支持以下的计费方式：

1. 按量付费：先使用，后付费，存储产品线下的产品**默认**都采用按量付费的模式。平台每日按照各计费项的实际用量结算费用，输出账单，适用于业务刚起步，用量经常有变化的场景。
2. 按资源包计费：各产品针对部分常用计费项支持专用的资源包。预先购买针对不同的计费项推出的优惠资源包，在费用结算时，优先从资源包抵扣用量。适用于业务用量稳定、需要大量使用该服务的场景。

每项计费内容如下：

## 资源包购买说明

### 资源包购买和生效规则

- 资源包仅支持余额购买，购买后立即生效。
- 购买同一服务的多个资源包后，资源包的用量叠加，但是服务有效时长不叠加。
    
  如，您已在使用10GB的存储资源包，在有效期剩余1个月，余量剩余5GB时又购买了新的10GB年套餐，则在这个月内，您账号下可以存储的空间是15GB，一个月后，第一个套餐过期，第二个套餐剩余时间为11个月。

### 资源包过期规则

- 资源包有效期到期后，资源包剩余用量会失效。
- 若账号中有余额，则剩余的服务用量会按照按量计费的模式进行扣费。
- 若账号变为非企业版套餐（免费的P套餐或其他非企业版套餐），所有内容保存15个自然日后进行删除，**删除后的内容无法找回**，请开发者们配置对应的欠费通知，并及时购买所需要的服务。

### 资源包超量规则

- 资源包的用量耗尽后，新产生的内容会按量计费。
- 如果您购买的是存储资源包，资源包过期前，您已经产生的存储内容依然能够保存，但新产生的内容需要按量计费。

### 资源包与账号关系

- 存储产品资源包只能基于企业版套餐使用
- 若账号变为非企业版套餐（免费的P套餐或其他非企业版套餐），即使资源包有效期未到期，所有内容保存15个自然日后会进行删除，**删除后的内容无法找回**，请开发者们配置对应的欠费通知，并及时购买所需要的服务。
