# 萤石云存储应用场景

## 视频云存储应用场景

| 场景 | 描述 | 功能优势 |
| --- | --- | --- |
| 安防监控 | 安防监控业务，本地+云端录像双备份 | 本地提供SD卡、NVR等存储介质，同时云端也提供云端录像，保证本地录像完整性，同时也提供云端录像长期保存、不被破坏 |
| 智慧工地 | 工程周期全过程备份，事后回溯安全查证，保证录像完整性 | 随着工程周期建设，本地只需要一块硬件，其余录像全部上云，并且云端长期冷存储，支出降低 |
| 智慧监管 | 政务机构，比如招投标场所、车管所等地，视频直播+云端录像保存 | 招投标场景、车管所等阳光政务场景下的云端录像多重备份，支撑录像回溯15年 |
| 文教卫 | 职业培训、文化旅游等场景，除了双备份需求外，还提供在线剪辑及安全管理的视频服务场景 | 视频点播不仅提供视频存储、视频转发和在线剪辑等功能，还提供语音、文字、视觉等多维度精准识别 |
| 连锁商贸 | 奶茶连锁、快递追溯、店铺断电云监控等，防止本地店铺断电、员工破坏造成的损失 | 云端备份无法删除、断电也能看录像，4S店、奶茶店、物流小站、外卖明厨亮灶监管等，应用场景及客户较多 |
| 智慧农业 | 摄像机图片抓拍，图片转视频，视频剪辑等业务支撑 | 设备抓拍、云端录像，叠加转码、水印等，搭配延时摄影等，同时搭配视频AI，提供云端媒资管理全方案 |
| 智能家居 | 宠物剪辑、智能家居录像、门禁设备备份等，同时提供在线剪辑及安全管理的视频服务场景 | 视频点播不仅提供视频存储、视频转发和在线剪辑等功能，还提供语音、文字、视觉等多维度精准识别 |
