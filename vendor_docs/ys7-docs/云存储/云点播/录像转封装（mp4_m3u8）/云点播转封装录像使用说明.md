# 云点播转封装录像使用说明

# 一、对接方案

```
萤石云提供Http接口和Webhook云信令消息异步数据回调产品，接入云录制2.0产品
```

该接口主要是将已生成的录像文件，比如事件云存储/云录制2.0里的原始ps录像转成mp4/m3u8，若开发者需要在录制时需要自动转成mp4/m3u8，建议使用后处理模板，查看链接地址：[前往查看](https://open.ys7.com/help/4378)。

# 二、接入指南

## 2.1 步骤1

**前提:**

> - 注册萤石云开放平台，链接:https://open.ys7.com/cn/s/index,获取AK、SK等关键接口对接配置信息
> - 进入萤石云开放平台-设备管理器接入设备，开通云信令，订阅ys.open.cloud消息
> - 设备已经开通云存储功能且产生云存储录像或者设备已经使用了云录制2.0产生过云录制录像

## 2.2 步骤2

使用云点播产品中的转封装接口，即可将云端录像转换至标准流进行浏览与播放
