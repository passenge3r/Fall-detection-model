## 云录像转封装任务创建

### 接口功能

- 云录像转封装任务创建
- 是否支持托管：不支持
- 是否支持子账号：不支持

### 请求地址

`https://open.ys7.com/api/service/open/vod/media/trans/code`

### 请求方式

`POST`

### 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号 | Y |
| Header | localIndex | String | 设备通道号 | Y |
| Body | busType | String | 1：事件云存储；7：云录制2.0录像；71：云录制HLS | Y |
| Body | format | String | 转封装格式，可以选择：HLS 或 MP4，当原始录像为HLS录像，不允许选择HLS | Y |
| Body | startTime | String | 开始时间，yyyy-MM-dd HH:mm:ss | Y |
| Body | endTime | String | 结束时间，yyyy-MM-dd HH:mm:ss，不允许超过48小时，不允许小于10秒 | Y |
| Body | validateCode | String | 设备验证码，如果视频加密，该入参需必填 | N |
| Body | spaceId | Long | 空间ID，busType为7时为必填字段，不传默认为云点播空间 | N |
| Body | resultSpaceId | Long | 输出结果的空间id，不填写时使用默认云点播vodspace | N |

### 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/vod/media/trans/code' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: BC30551' \
--header 'localIndex: 1' \
--data-urlencode 'busType=7' \
--data-urlencode 'startTime=2025-06-04 21:45:30' \
--data-urlencode 'endTime=2025-06-04 21:46:30' \
--data-urlencode 'format=HLS' \
--data-urlencode 'spaceId=44028'
```

### 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "taskId": "9c7802d2f9bf463794e2c0d"
    }
}
```

### 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元数据 |
| meta.code | Int | 状态码 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 附加信息 |
| data | Object | 业务数据 |
| data.taskId | String | 任务ID |

### 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 400 | 参数错误 | 请求参数有误 |
| 500 | 服务器异常 | 服务器内部错误 |
| 10002 | accessToken过期或异常 | 请重新获取accessToken |
