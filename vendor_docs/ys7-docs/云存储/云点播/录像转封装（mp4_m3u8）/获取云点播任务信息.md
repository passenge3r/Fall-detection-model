## 获取云点播任务信息

### 接口功能

- 查询云点播任务详情

### 请求地址

`https://open.ys7.com/api/service/open/vod/task`

### 请求方式

`GET`

### 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Query | taskId | String | 任务ID | Y |

### 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/open/vod/task?taskId=9c7802d2f9bf463794e2c0d' \
--header 'accessToken: at.xxxxx'
```

### 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "Operation succeeded",
        "moreInfo": null
    },
    "data": {
        "taskId": "",
        "projectId": "",
        "deviceSerial": "",
        "channelNo": 0,
        "taskType": 0,
        "taskSubType": 0,
        "taskStatus": 0,
        "taskDetail": "",
        "fileNum": 0,
        "totalSize": 0,
        "startTime": "",
        "endTime": "",
        "timingPoints": "",
        "progressRate": 0,
        "completeRate": 0,
        "errorCode": "",
        "errorMsg": "",
        "createTime": ""
    }
}
```

### 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元数据 |
| meta.code | Int | 状态码 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 附加信息 |
| data | Object | 业务数据 |
| data.taskId | String | 任务ID |
| data.projectId | String | 空间ID |
| data.deviceSerial | String | 设备序列号 |
| data.channelNo | Int | 通道号 |
| data.taskType | Int | 任务类型，1：视频转码 |
| data.taskSubType | Int | 任务子类型，80：PS->MP4，81：PS->HLS，82：HLS->MP4 |
| data.taskStatus | Int | 任务状态：0-已完成，1-排队中，2-进行中，3-已结束，4-异常结束，5-暂停中，6-已取消，7-未开始 |
| data.taskDetail | String | 任务详情 |
| data.fileNum | Int | 文件数量 |
| data.totalSize | Int | 总大小 |
| data.startTime | String | 开始时间 |
| data.endTime | String | 结束时间 |
| data.timingPoints | String | 时间点列表 |
| data.progressRate | Int | 进度 |
| data.completeRate | Int | 完成率 |
| data.errorCode | String | 错误码 |
| data.errorMsg | String | 错误信息 |
| data.createTime | String | 创建时间 |

### 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 400 | 参数错误 | 请求参数有误 |
| 404 | 资源不存在 | 请确认任务ID是否正确 |
| 500 | 服务器异常 | 服务器内部错误 |
