## 视频剪辑文件查询

- 接口功能

对视频剪辑合成后的文件查询

- 请求地址

`https://open.ys7.com/api/service/open/cloud/vod/task/files/{taskId}`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Path | taskId | String | path路径的任务id，1-32位长度的字符数字 | Y |
| Query | expireSeconds | Long | 下载链接有效期，单位秒，默认1800，范围[60,604800] | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/open/cloud/vod/task/files/06c449c5b9b44ffe89a48a8ed25f4c98?expireSeconds=3600' \
--header 'accessToken: at.XXXX-2obhhjayuc-13lt36l-gyirn1xtz' \
--header 'User-Agent: Apifox/1.0.0 (https://apifox.com)' \
--header 'Content-Type: application/json' \
--header 'Accept: */*' \
--header 'Host: open.ys7.com/' \
--header 'Connection: keep-alive' \
--data-raw ''
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": [
        {
            "folderNode": "r8gzkZPs",
            "fileName": "录像BD57407-1-20250402193258-20250402193759",
            "fileUrl": "https://openrecord.ys7.com/xxx.mp4",
            "coverPic": "E1/1o4/14/xxx.jpg",
            "coverPicUrl": "https://openrecord.ys7.com/xxx.jpg",
            "startTime": "2025-04-02 19:32:58",
            "stopTime": "2025-04-02 19:37:59",
            "fileSize": 19454699
        }
    ]
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元信息 |
| meta.code | Int | 响应状态码 |
| meta.message | String | 响应消息 |
| meta.moreInfo | Object | 更多信息 |
| data | Object | 响应数据 |
| data.folderNode | String | 文件ID |
| data.fileName | String | 文件名 |
| data.fileUrl | String | 文件地址 |
| data.coverPic | String | 封面图ID，和保存视频封面图配套使用 |
| data.coverPicUrl | String | 视频文件的封面图地址 |
| data.startTime | String | 开始时间，yyyy-MM-DD HH:mm:ss，转封装任务该字段有值 |
| data.endTime | String | 结束时间，yyyy-MM-DD HH:mm:ss，转封装任务该字段有值 |
| data.fileSize | Int | 文件大小，单位：字节 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 |  |
| 404 | 资源不存在 |  |
| 400 | 参数错误 |  |
