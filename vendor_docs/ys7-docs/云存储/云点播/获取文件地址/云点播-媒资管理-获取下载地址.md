## 获取文件地址（GET）

- 接口功能

描述:获取文件地址：支持播放/下载等 托管/子账号: 不支持

- 请求地址

`https://open.ys7.com/api/service/open/vod/file/downloadurl`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| query | fileNodeIds | string | 文件节点ID列表（[控制台](https://open.ys7.com/console/cloudondemand.html)选择云存储-》云点播，媒资管理取ID或[查询视频剪辑任务](https://open.ys7.com/help/3717)返回的folderNode），通过英文逗号隔开的字符串，最多限制50个 | Y |
| query | expireSeconds | long | 1到94608000（3年）区间范围，单位秒，默认1800 | N |
| query | spaceName | string | 空间名称，音视频存储空间vodSpace | N |
| query | spaceId | string | 空间ID，该入参优先级最高 | N |

- 请求示例

```
curl --location 'https://open.ys7.com/api/service/open/vod/file/downloadurl?expireSeconds=3600&fileNodeIds=j1jomEDi%2CC8PrlqSkt' \
--header 'accessToken: at.320gyv2s66ry9ggw0549qegu2apcsr2i'
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | meta |
| -code | int | code |
| -message | string | message |
| -moreInfo | object | moreInfo |
| data | array | data |
| -urls | object | 文件链接集合 |
| --j1jomEDi | string | 文件节点ID |
| -expireTime | int | 过期时间，时间戳，单位毫秒 |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
