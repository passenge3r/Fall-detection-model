# 获取云录像点播地址

## 获取云录像点播地址

### 接口功能

- 获取云录像点播地址
- 是否支持托管：不支持
- 是否支持子账号：不支持

### 请求地址

`https://open.ys7.com/api/service/open/vod/file/address/hls`

### 请求方式

`POST`

### 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| Header | accessToken | String | 萤石开放API访问令牌 | Y |
| Header | deviceSerial | String | 设备序列号 | Y |
| Header | localIndex | String | 设备通道号 | Y |
| Body | startTime | String | 开始时间，格式 yyyy-MM-dd HH:mm:ss | Y |
| Body | endTime | String | 结束时间，格式 yyyy-MM-dd HH:mm:ss | Y |
| Body | format | String | 转码后的文件格式，MP4或HLS | Y |
| Body | expireSeconds | Long | 过期时间，默认1800秒，允许的时间范围是1s-7天 | N |
| Body | spaceId | Long | 空间ID，不传默认为云点播空间 | N |

### 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/vod/file/address/hls' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--header 'accessToken: at.xxxxx' \
--header 'deviceSerial: J70807475' \
--header 'localIndex: 1' \
--data-urlencode 'startTime=2024-12-17 14:52:02' \
--data-urlencode 'endTime=2024-12-17 14:54:02' \
--data-urlencode 'format=HLS'
```

### 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": [
        {
            "startTime": "2024-12-17 14:52:02",
            "stopTime": "2024-12-17 14:54:02",
            "expireTime": "2024-12-19 10:37:45",
            "hlsAddress": "https://xxxxx",
            "format": "HLS"
        }
    ]
}
```

### 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应元数据 |
| meta.code | Int | 状态码 |
| meta.message | String | 状态描述 |
| meta.moreInfo | Object | 附加信息 |
| data | Array | 点播地址列表 |
| data[].startTime | String | 开始时间 |
| data[].stopTime | String | 结束时间 |
| data[].expireTime | String | 过期时间 |
| data[].hlsAddress | String | 播放地址 |
| data[].format | String | 文件格式，MP4或HLS |

### 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 400 | 参数错误 | 请求参数有误 |
| 500 | 服务器异常 | 服务器内部错误 |
| 10002 | accessToken过期或异常 | 请重新获取accessToken |
