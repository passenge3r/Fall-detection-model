## 批量文件列表信息查询

- 接口功能

   批量文件列表信息查询  
托管/子账号：不支持

- 请求地址

`https://open.ys7.com/api/service/open/vod/files`

- 请求方式

`GET`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | folderNodes | Array | 云点播中文件节点，上限50个文件 | N |
| query | spaceName | String | 空间名称,音视频存储空间vodSpace | N |
| query | spaceId | Long | 空间id,该入参优先级最高 | N |

- 请求示例

```
curl --location --request GET 'https://open.ys7.com/api/service/open/vod/files?folderNodes={folderNodes}&spaceName={spaceName}&spaceId={spaceId}' \
--header 'accessToken: at.xxxxx'
```
