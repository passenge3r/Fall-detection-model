## 视频进行获取封面图

- 接口功能

   描述:视频进行获取封面图
托管/子账号: 不支持

- 请求地址

`https://open.ys7.com/api/service/open/vod/cover/pic/get`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| query | fileNodeId | string | 文件节点 | Y |
| query | timePoint | long | 封面图片时间点，相对时间，单位毫秒 | N |
| query | type | int | 文件类型：1-云点播 2-云录制 | Y |
| query | projectId | string | 项目ID.2为必传 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/vod/cover/pic/get?fileNodeId=xxx&type=1&projectId=xxx' \
--header 'accessToken: at.xxxxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "taskId":  "xxx"
}
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | meta |
| meta.code | int | code |
| meta.message | string | message |
| meta.moreInfo | object | moreInfo |
| data | object | data |
| data.taskId | string | taskId |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
