## 文件元数据搜索

- 接口功能

   描述:文件元数据搜索
托管/子账号: 不支持

- 请求地址

`https://open.ys7.com/api/service/open/vod/file/listById`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| body | pageSize | int | 每页大小，1-50，默认10 | N |
| body | lastId | int | 最后id，默认0 | N |
| body | sortRule | int | 0-倒序 1-正序 默认为0-倒序 | N |
| body | fileName | string | 文件名搜索,128 | N |
| body | spaceIds | string | 空间id,支持多个空间查询，用逗号分割 | Y |
| body | fileType | string | 文件类型 0-图片 1-视频 2-音频 3-文档 4-其他 | Y |
| body | fileChildType | string | 文件类型 00-JPG，01-PNG，02-GIF 10-mp4，13：M3U8，20-mp3 | Y |
| body | startTime | string | 2024-07-16 15:43:32 | Y |
| body | endTime | string | 2024-07-16 15:43:32 | Y |
| body | folderNodes | string | 文件节点 | N |
| body | tagId | string | 标签id ，如果视频剪辑或转封装，则使用任务id；如果是云录制2.0后处理模板，则使用计划id | N |

- 请求示例

```
curl --location 'https://open.ys7.com/api/service/open/vod/file/listById' \
--header 'accessToken: at.310dt9j76fzia01t50p382aaa50b4r61' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'pageSize=10' \
--data-urlencode 'fileType=1' \
--data-urlencode 'spaceIds=3352' \
--data-urlencode 'fileChildType=10' \
--data-urlencode 'startTime=2025-07-21 00:43:32' \
--data-urlencode 'endTime=2025-07-22 15:43:32'
```
