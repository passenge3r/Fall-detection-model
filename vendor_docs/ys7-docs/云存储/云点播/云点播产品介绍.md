# 云点播产品介绍

## 什么是云点播

云点播是对云录制产品的补充，云录制2.0是ps录像云端存储，而云点播产品是提供标准文件mp4/m3u8文件的云端存储，云录制2.0结合云点播的功能，可以实现：视频录制+点播加速、视频录制+视频剪辑等功能的开发。

## 云点播

萤石云点播VOD是集音视频管理、处理和分发播放于一体的一站式解决方案，该方案脱胎于视频云录制2.0，是对云录制2.0的有效补充。无论是智慧监管、文化旅游、智慧商贸等行业，无论是宠物vlog、文旅景区、无人台球、阳光招投标、智慧车管所、康养、工地打卡等场景，都可以通过视频云录制叠加云点播产品服务实现高效的内容生产、管理和分发。

### 媒体管理 媒体处理 分发播放

支持通过云录制2.0将海量设备录像上传至云端，也支持通过控制台，将音视频文件上传至点播平台。

媒体处理提供视频转码、特效等媒体处理功能。

同时支持视频剪辑等媒体处理功能。

结合多供应商CDN网络，实现全球范围内的安全高效分发服务。支持预加载、本地缓存和端侧增强等丰富播控功能，为观众带来极致体验
