## 视频获取封面图

- 接口功能

   视频进行获取封面图。托管/子账号：不支持

- 请求地址

`https://open.ys7.com/api/service/open/vod/cover/pic/get`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| query | fileNodeId | String | type为1时填入云点播文件ID，type为2时填入云录制文件ID | Y |
| query | timePoint | Long | 封面图片时间点，相对时间，单位毫秒，默认0 | N |
| query | type | Int | 文件类型：1-云点播，2-云录制 | Y |
| query | projectId | String | 项目ID。type为2为必传，填入云录制的项目ID | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/vod/cover/pic/get' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'fileNodeId=xxx' \
--data-urlencode 'timePoint=0' \
--data-urlencode 'type=1' \
--data-urlencode 'projectId=xxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "taskId": "xxx"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| -code | Int | 响应状态码 |
| -message | String | 响应消息 |
| -moreInfo | Object | 更多信息 |
| data | Object | 返回数据 |
| -taskId | String | 任务ID |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
