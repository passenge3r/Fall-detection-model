# 云点播录像视频获取封面图功能介绍

# 一、对接方案

```
萤石云提供Http接口和Webhook云信令消息异步数据回调产品
```

# 二、接入指南

## 2.1 步骤1

**前提:**

> - 注册萤石云开放平台，链接:https://open.ys7.com/cn/s/index,获取AK、SK等关键接口对接配置信息
> - 进入萤石云开放平台-设备管理器接入设备，开通云信令，订阅ys.open.cloud消息
> - 使用过云点播产品

## 2.2 步骤2

使用云点播抽帧接口，进行录像抽帧，获取视频封面图ID,可以缓存至视频信息中

## 三、接口文档

#### 3.1 视频进行获取封面图 （POST）

接口文档：[视频进行获取封面图接口](https://open.ys7.com/help/3963)

#### 3.2 查询封面图任务详情 （GET）

接口文档： [查询封面图任务详情接口](https://open.ys7.com/help/3964)

#### 3.3 保存视频封面图至视频信息中 （POST）

接口文档：[保存视频封面图接口](https://open.ys7.com/help/3965)

#### 3.4 消息回调

- #### **header说明**

| **字段名** | **类型** | **描述** |
| --- | --- | --- |
| **header** | **Object** | **任务信息** |
| type | String | 消息类型：ys.open.cloud表示云录制消息 |
| deviceId | String | 任务id |
| channelNo | Integer | 1 |
| messageId | String | 消息唯一ID |
| messageTime | Long | 消息发送时间 |

- #### **body说明**

| **名称** | **类型** | **描述** |
| --- | --- | --- |
| **body** | **Object** | **消息体** |
| taskId | String | 任务id |
| errorCode | String | 返回码 |
| errrorMsg | String | 返回信息 |
| taskStatus | String | 任务状态 COMPLETE(0, "已完成"),WAITING(1, "排队中"),PROCESSING(2, "进行中"), FINISHED(3, "已结束"),EXCEPTION\_FAILED(4, "异常结束"), EXCEPTION\_PAUSE(5,"暂停中"), CANCEL(6,"已取消"), NOT\_START(7,"未开始");  状态解释： 已完成：任务正常录制完成并且过程中没发生报错 已结束：任务开始后由开发者主动结束任务 排队中：回放任务下发后由于当前服务器并发任务太高，需要排队处理 进行中：任务进行中 异常结束：任务过程中发生过异常，即使在重试后录制的内容是完整的，依然会展示异常，视频任务可以通过录像完整度字段判断录制结果是否可用。 暂停中：任务在开始后，设备出流路数达到了上限，导致无法取流，任务默认等待24小时，24小时后还未能解除设备出流限制时任务会失败并上报异常 已取消：任务未达开始时间且开发者取消了任务 未开始：任务未达开始时间 |
| messageType | String | 类型 视频封面图("video\_cover\_pic") |
