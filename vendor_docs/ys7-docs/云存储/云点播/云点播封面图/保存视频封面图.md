## 保存视频封面图

- 接口功能

   保存视频封面图。托管/子账号：不支持

- 请求地址

`https://open.ys7.com/api/service/open/vod/cover/pic/save`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | String | 萤石开放API访问令牌 | Y |
| body | fileNodeId | String | 云点播中的文件ID | Y |
| body | coverPicId | String | 封面图ID，为空则为重置封面。 | Y |

- 请求示例

```
curl --location --request POST 'https://open.ys7.com/api/service/open/vod/cover/pic/save' \
--header 'accessToken: at.xxxxx' \
--data-urlencode 'fileNodeId=VQoCcozl' \
--data-urlencode 'coverPicId=xxx'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "fileNodeId": "VQoCcozl"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | Object | 响应信息 |
| -code | Int | 响应状态码 |
| -message | String | 响应消息 |
| -moreInfo | Object | 更多信息 |
| data | Object | 返回数据 |
| -fileNodeId | String | 文件节点ID |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 500 | 服务器异常 | 服务器异常 |
| 400 | 参数错误 | 参数错误 |
| 10002 | accessToken过期或异常 | accessToken过期或异常 |
