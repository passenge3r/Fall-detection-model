## 云录制视频剪辑

- 接口功能

云录制视频剪辑

托管/子账号: 不支持

前置条件：开通&使用云点播控制台，最终录制文件将输出至云点播产品内

![](https://resource.eziot.com/group1/M00/01/4B/CtwQE2b4uLOAA-dvAAJAa3PO6lE479.png)

- 请求地址

`https://open.ys7.com/api/service/cloudrecord/video/convert`

- 请求方式

`POST`
