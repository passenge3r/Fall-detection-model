# 控制台上传媒资文件

> 开发者可以通过控制台、APi接口、云录制/事件云存储转封装等方式，上传文件到云点播空间里

# 上传音频、视频

### 1.进入控制台

![](https://resource.eziot.com/group2/M00/01/05/CtwQF2hSZcaAdhocAAJC-jr2n5g357.png)

打开开放平台官网：<https://open.ys7.com/console/cloudondemand.html?fileType=Picture>，打开右上角控制台，选择左侧目录，选择云存储-云点播，进入控制台

### 2.点击上传

点击右上角上传，进行上传文件

![](https://resource.eziot.com/group2/M00/01/05/CtwQFmhSZgyAPNe7AACmcb3NpvA144.png)

选择本地文件，当前支持mp4、mp3文件上传，控制台最大支持1GB文件上传

![](https://resource.eziot.com/group2/M00/01/05/CtwQF2hSZg6AEkvtAABobGq2iIw036.png)

选择文件后，可以修改文件名称，修改后，点击开始上传

### 3.上传后操作

上传成功后，视频列表有几个操作按钮：

![](https://resource.eziot.com/group2/M00/01/05/CtwQF2hSZhWADItHAAEBvnzmypk214.png)

①预览：上传成功后，点击视频标题，即可进行预览

![](https://resource.eziot.com/group2/M00/01/05/CtwQFmhSZhCAXmQfAAFgtL4wPlk998.png)

②编辑：点击右侧编辑按钮

进入编辑页面，可以修改文件名称

③修改封面图：默认会有封面图，开发者也可以手动生成，或者上传

![](https://resource.eziot.com/group2/M00/01/05/CtwQFmhSZhOAdBwbAAKJ5ugUQQE955.png)

④获取播放/下载链接

控制台可以获取，也可以通过APi接口获取

![](https://resource.eziot.com/group2/M00/01/05/CtwQF2hSZhKAJ3qsAADKLiauwYk160.png)

APi接口：<https://open.ys7.com/help/4402>

# 上传图片

### 1. 点击图片tab，切换到图片列表

![](https://resource.eziot.com/group2/M00/01/05/CtwQFmhSZheAG6dqAAFYIGI13ts560.png)

### 2.上传图片

上传的操作步骤与视频上传步骤相同，开发者可以选择上传按钮-选择图片-开始上传，进行上传

其中：图片的尺寸跟格式显示如图所示

![](https://resource.eziot.com/group2/M00/01/05/CtwQFmhSZ_-ATc6JAADLsbqfTi8204.png)

上传成功后，文件列表即可显示上传成功的图片

![](https://resource.eziot.com/group2/M00/01/05/CtwQF2hSZhmAZnVrAAEU1UCCmj8733.png)
