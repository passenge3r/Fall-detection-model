## 批量获取媒体文件上传地址

- 接口功能

   描述:获取POST表单形式的上传信息  
托管/子账号: 不支持  
  
注意：  
  
1、上传地址有效期时长：获取的上传地址有效期时长为1个小时  
  
2、上传的文件大小限制：图片和音频不超过10MB，视频不超过5GB

- 请求地址

`https://open.ys7.com/api/service/open/vod/file/upload/query`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| query | suffix | string | 尾缀，jpg;mp4;mp3等 | Y |
| query | fileNum | int | 申请数量，限制1-50 | Y |
| query | fileType | int | 文件类型：0.图片; 1.视频；2.音频 | Y |
| query | fileChildType | string | 文件子类型: 00-JPG，01-PNG，02-GIF ，06-JPEG，10-mp4，13：M3U8，20-mp3 | Y |
| query | resourceId | string | 资源ID，文件随机ID,默认8位随机传 | N |
| query | spaceId | long | 空间id，云点播空间id 不传为默认空间 | N |

- 请求示例

```
curl --location 'https://open.ys7.com/api/service/open/vod/file/upload/query?fileNum=1&fileType=1&fileChildType=10&suffix=mp4' \
--header 'accessToken: accessToken'
```
