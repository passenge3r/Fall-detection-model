## 保存或修改文件元数据

- 接口功能

   描述:媒体文件保存/更新  
托管/子账号: 不支持

- 请求地址

`https://open.ys7.com/api/service/open/vod/file/info/register`

- 请求方式

`POST`

- 请求参数

| 参数位置 | 参数名 | 类型 | 描述 | 是否必选 |
| --- | --- | --- | --- | --- |
| header | accessToken | string | 萤石开放API访问令牌 | Y |
| body | sourceUrl | string | 文件路径，字符长度不超过256 | Y |
| body | fileType | string | 文件类型，// fileType // 0: 图片 1: 视频 2: 音频 3: 文档 4: 其他 | Y |
| body | fileSize | string | 文件大小，默认：0，小数会默认取整数位，不建议传小数 | N |
| body | fileMd5 | string | 文件md5，50位数字字母 | N |
| body | duration | long | 视频时长，单位秒,默认：0，小数会默认取整数位，不建议传小数 | N |
| body | fileName | string | 文件名称： 256位名称 | Y |
| body | deviceSerial | string | 设备序列号,60位 | N |
| body | channelNo | string | 通道号 | N |
| body | fileChildType | string | 文件子类型 fileChildType必须为 10:mp4,20:mp3 | Y |
| body | uploadStatus | int | 上传状态 0:上传中 1.已完成 2.上传失败，默认:1 | N |
| body | uploadErrorCode | string | 上传错误码 | N |
| body | fileNodeId | string | 文件节点ID 限制1-32数字字母，属于修改文件节点 | N |
| body | autoCoverPic | boolean | 自动获取封面图，默认false | N |
| body | spaceName | string | 空间名称,音视频存储空间vodSpace | N |
| body | spaceId | long | 空间id,该入参优先级最高 | N |
| body | sourceType | int | 来源方式，固定传4，表示接口上传 | Y |

- 请求示例

```
curl --location 'https://open.ys7.com/api/service/open/vod/file/info/register' \
--header 'accessToken: at.60k51tqsbq22mzz44iyqqshq22t8cj62' \
--form 'sourceUrl="E1/1o4/14/c1cbc1d4e86d49a0981f54beea952801/0/PWm0w4G/N1/tqnWr8aw/01/5d2638adpng"' \
--form 'fileType="0"' \
--form 'fileName="kafka"' \
--form 'sourceType="4"' \
--form 'fileChildType="01"' \
--form 'uploadStatus="1"' \
--form 'autoCoverPic="false"'
```

- 返回数据

```
{
    "meta": {
        "code": 200,
        "message": "操作成功",
        "moreInfo": null
    },
    "data": {
        "fileNodeId": "xMKnxvrJ"
    }
}
```

- 返回字段

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| meta | object | meta |
| -code | int | code |
| -message | string | message |
| -moreInfo | object | moreInfo |
| data | object | data |
| -fileNodeId | string | fileNodeId |

- 返回码

| 返回码 | 返回消息 | 描述 |
| --- | --- | --- |
| 200 | 操作成功 | 操作成功 |
| 404 | 资源不存在 | 资源不存在 |
| 500 | 服务器异常 | 服务器异常 |
| 412 | 前置条件不满足 | 前置条件不满足 |
