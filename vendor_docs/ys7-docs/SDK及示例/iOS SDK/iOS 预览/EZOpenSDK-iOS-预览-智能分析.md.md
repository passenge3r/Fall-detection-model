# 智能分析

部分摄像机自带算法，会将画面中出现的人、车、宠物等画面进行标记，常见的是比如人形框选、车子框选等，SDK提供api开关，开发者可选择是否要将智能分析画框叠加到视频流中。api如下：

EZPlayer.h

```
/**
 * 设置打开播放库的智能分析，当前温感相机的框框使用了该智能分析数据，预览成功后调用，在播放过程中随时开关
 *
 * @param enable YES：开  NO：关
 *
 * @return 返回状态
 */
- (BOOL)setIntelAnalysis:(BOOL)enable;
```

**注意：如果设备不支持，调用该api无效。**
