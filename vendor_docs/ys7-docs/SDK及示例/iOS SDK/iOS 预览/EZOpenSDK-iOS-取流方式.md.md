# 取流方式

## SDK取流方式

EZOpenSDK支持三种取流方式，如下

- 内网直连取流：在局域网内部，客户端直接连接设备进行视频流的传输，这种方式通常不需要经过互联网，而是通过本地网络实现数据的高速传输。
- P2P取流：P2P（Peer-to-Peer）取流是一种点对点的数据传输方式。客户端和设备端之间链路能否链接成功跟客户端和设备端的网络强相关。
- 流媒体取流：通过流媒体服务器将视频内容以流的形式传输给客户端，客户端边接收边播放。

## SDK取流方式配置

SDK默认开启内网直连 & 流媒体取流方式，未开启P2P取流方式。

### 内网直连开关

EZOpenSDK.h

```
/**
 *  设置是否支持内网直连取流，默认是支持的
 *  内网直连取流可以降低转发取流的比例，当客户端和设备处于同一局域网下时，优先走内网直连
 *
 *  @param enable 内网直连是否开启
 */
+ (void)enableDirectInner:(BOOL)enable;
```

### P2P开关

取流走P2P方式 建立在客户端和设备端的链路建立成功的基础上，与两端所在的网络强相关。

P2P开关打开后，SDK会尝试建立客户端和设备端的链路，不代表取流一定会走P2P取流方式。

EZOpenSDK.h

```
/**
 *  设置是否支持P2P取流，默认是不支持的
 *  P2P取流可以降低转发取流的比例，但是在多人同时观看时对设备端的带宽要求也更高，设备端带宽不够的情况下，影响播放体验
 *  对于可能多人同时观看的场景，建议不支持
 *  对于家用监控类的场景，建议支持P2P
 *
 *  @param enable p2p是否开启
 */
+ (void)enableP2P:(BOOL)enable;
```

以下是客户端和设备端网络情况 对 p2p链路连接的 场景说明

| 客户端（手机端） | 设备端 | p2p连接 |
| --- | --- | --- |
| 家庭宽带WiFi | 家庭宽带WiFi | 基本能通 |
| 家庭宽带WiFi | 手机热点 | 概率通 |
| 4G/5G | 家庭宽带WiFi | 概率通 |
| 4G/5G | 手机热点 | 概率通 |
| 4G/5G/家庭宽带WiFi | 4G定向流量 | 不能通 |
| 4G/5G/家庭宽带WiFi | 公司类网络（防火墙环境） | 不能通 |

### 流媒体开关

**慎用！不建议设置！关闭后会严重影响取流成功率！**

EZOpenSDK.h

```
/**
 *  设置是否支持流媒体取流，默认是支持的
 *  如果禁用，只能通过内网直连方式方式进行取流；若开启了支持p2p取流，会再尝试p2p取流；关闭后会严重影响取流成功率，慎用！
 *
 *  @param enable  流媒体是否开启
 */
+ (void)enableVTDU:(BOOL)enable;
```

  

**当三种取流方式都开启的情况下，SDK取流优先顺序为：内网直连 > P2P > 流媒体**

## 查看取流方式

取流成功后，调用如下api获取本次取流的方式

EZPlayer.h

```
/**
 * 获取当前取流方式（耗时操作，需要在子线程中执行）
 *
 * @return 当前取流类型
 */
- (int)getStreamFetchType;
```

返回值对应的取流方式关系图如下

| 返回值 | 取流方式 |
| --- | --- |
| 0 | 流媒体 |
| 1 | P2P |
| 2 | 内网直连 |
| 4 | 云存储录像回放 |
