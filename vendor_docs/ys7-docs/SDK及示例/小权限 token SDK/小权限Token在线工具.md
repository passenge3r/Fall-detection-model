# 小权限 Token 在线工具

萤石开放平台提供了小权限 Token 在线生成与解析工具，可在浏览器本地完成 Token 生成与解析，无需部署 Java 环境，用于日常联调、集成排障与授权内容核查。

工具地址：[小权限 Token 在线工具](https://izhstatic.ys7.com/vasp-pkg-ys-h5-cn/OpenwebTktokenSupport/default/www/index.html#/openweb_tktoken_support/index.html)

> 安全提示：SecretKey 属于高敏感信息，本工具全程仅在浏览器本地内存中处理 SecretKey 用于本地签名计算，不会通过任何网络请求发送到服务器。建议仅在可信设备上使用本工具，使用完毕后关闭页面即可清除内存中的 SecretKey。

## 一、生成 Token

1. 打开工具地址，页面顶部切换到"Token 生成"页签。
2. 在页面上方选择 Token 类型：非设备类、设备类、取流、资源访问（RTC 通话），点击对应卡片切换到该类型的参数表单。
3. 点击"生成 Token"。若必填参数为空或格式不符合要求，会在对应字段下方以红色文字提示原因，需按提示修改后重新点击生成。
4. 生成成功后，右侧会展示 Token 字符串，点击"一键复制"即可将其复制到剪贴板，用于接口调用或客户端 SDK。
5. 如需重新配置，点击表单右上角的"清空"按钮一键清空当前类型的所有已填参数。

其中，资源访问（RTC 通话）类型支持添加多个 Action，并可通过发送音频、发送视频、屏幕共享三个勾选项自动计算 `permission` 数值，点击后一键写入所选 Action 的属性中，无需手动换算。

## 二、解析 Token

1. 切换到"Token 解析"页签，将待核查的 Token 字符串粘贴到左侧输入框。
2. 点击"解析"，右侧即展示该 Token 的类型及所有已授权的参数字段（如有效期、授权范围、自定义属性等）。
3. 若粘贴内容不是合法的小权限 Token（格式错误、字符被截断等），工具会提示具体的识别失败原因，并保留输入框中的原始内容。
4. 如需在已有 Token 基础上调整个别参数后重新生成，可点击"一键填回"将解析出的参数带回对应类型的生成表单；由于 Token 中不包含 SecretKey 原文，填回后需重新输入 SecretKey 才能再次生成。
