# 微信半屏方案介绍

基于微信官方推出的API接口，萤石开放平台推出微信半屏方案，开发者按照要求传入参数即可在开发者小程序上唤起半屏界面进行预览回放。

## 微信官方文档

- 打开半屏小程序：https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/openEmbeddedMiniProgram.html
- 半屏接口：https://developers.weixin.qq.com/miniprogram/dev/api/navigate/wx.openEmbeddedMiniProgram.html

## 支持能力

1. 支持设备预览
2. 支持设备按照参数进行回放
3. 支持H265播放
4. 支持对讲、云台、语音播报、截屏、镜像翻转、镜头遮蔽等设备操作项

## 半屏效果

[](http://resource.eziot.com/group1/M00/00/96/CtwQE2MrEu6AIV2XAALVOSZkBaw611.mp4)

## 半屏优势

- **无资质要求**：用户微信小程序无需申请 `live_player` 组件资质即可进行视频直播
- **集成快**：一行代码即可实现指定设备的播放和控制
- **交互体验佳**：通过半屏的形式进行播放，无需跳转小程序，大大提高交互体验

# 2. 接入指南

## 2.1 前提条件

1. 开发者向萤石的小程序（萤石云开放平台【appId】`wxf2b3a0262975d8c2`）申请半屏跳转（被半屏跳转的小程序需要通过来源小程序的调用申请，开发者可在小程序管理后台「设置」-「第三方设置」-「半屏小程序管理」板块发起申请，最多可以申请10个小程序）。
2. 基础库 2.23.1 以下版本，开发者需要在全局配置 `app.json` 的 `embeddedAppIdList` 字段中声明需要半屏跳转的小程序，若不配置将切换为普通的小程序跳转小程序。2.23.1 及以上版本起无需配置。
3. 当前小程序需为竖屏。
4. 被半屏跳转的小程序需为非个人主体小程序（不含小游戏）。

## 2.2 接口使用

调用微信接口 `wx.openEmbeddedMiniProgram(Object object)`，跳转至 ezplayer 页面。将参数对象转换为 JSON 字符串后，作为 `props` 参数在 URL 中传递。

```
// 构造参数对象
const props = {
  accessToken: 'at.xxxxx',                          // 必填，开放平台accessToken
  url: 'rtmp://open.ys7.com/BA7248908/1/live',      // 必填，播放url
  plugins: 'talk,voice,ptz,privacy,mirror',         // 可选，功能项
  theme: {                                           // 可选，主题配置
    showFullScreenBtn: false,
    showCapture: true,
    showBottomBar: true,
    showDatePicker: true,
    showTypeSwitch: true
  }
}

// 将参数对象转为JSON字符串并编码后，作为props参数传递
wx.openEmbeddedMiniProgram({
  appId: 'wxf2b3a0262975d8c2',
  path: '/packageJ/pages/ezplayer/ezplayer?props=' + encodeURIComponent(JSON.stringify(props)),
  envVersion: 'release'
})
```

## 参数说明（props 对象）

| 名称 | 数据类型 | 必须 | 描述 |
| --- | --- | --- | --- |
| accessToken | String | 是 | 开放平台口令，获取方式参考 [accessToken](https://open.ys7.com/help/81) |
| url | String | 是 | 播放url，规则：`rtmp://open.ys7.com/${deviceSerial}/${channelNo}/${type}/${startTime}/${endTime}`。type 取值：`live`（预览）、`local`（本地回放）、`cloud`（云存储）、`cloudRecord`（云录制）。当 type 为回放类型时 startTime 和 endTime 必填，格式为 `YYYY-MM-DD HH:mm:ss` |
| plugins | String | 否 | 功能项，取值：`talk`（对讲）、`voice`（语音播报）、`ptz`（云台）、`privacy`（隐私遮蔽）、`mirror`（镜像翻转），多个用逗号分隔 |
| theme | Object | 否 | 主题配置，控制播放器 UI 元素的显示隐藏，如 `showFullScreenBtn`（全屏按钮，半屏场景下请手动设置隐藏）、`showCapture`（截图按钮）、`showBottomBar`（底部直播/回放切换）、`showDatePicker`（日期选择）、`showTypeSwitch`（回放类型切换）等 |

更多参数详情请参考：[萤石开放平台微信小程序插件接入文档](https://open.ys7.com/help/1865)

## wx.openEmbeddedMiniProgram 接口参数

| 名称 | 数据类型 | 必须 | 描述 |
| --- | --- | --- | --- |
| appId | String | 是 | 萤石云开放平台小程序 appId，固定值 `wxf2b3a0262975d8c2` |
| path | String | 是 | 跳转路径，格式：`/packageJ/pages/ezplayer/ezplayer?props=` + encodeURIComponent(JSON.stringify(props)) |
| envVersion | String | 否 | 要打开的小程序版本，默认 `release` 即正式版 |
