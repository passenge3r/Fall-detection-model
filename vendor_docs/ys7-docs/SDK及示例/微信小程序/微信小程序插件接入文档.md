# 萤石云开放平台微信小程序插件化方案

## 一 插件介绍

本插件是萤石云开放平台基于微信小程序官方live-player组件集成，用户无需申请live-player组件权限即可引入该插件进行设备rtmp协议取流播放。

对比传统萤石云开放平台微信小程序推出的解决方案，插件化方案有以下优势：

- 🚀 **资质免审**：无需申请视听许可证，快速接入
- 🎨 **灵活布局**：支持自定义UI布局，突破半屏限制
- 🔧 **功能丰富**：
  - 多协议支持（直播/本地回放/云存储/云录制）
  - 水印配置
  - 播放控制组件定制
  - 智能时间轴管理

**适用场景**：智能安防监控、远程设备管理、历史录像追溯等微信小程序场景

## 二 插件申请

> 前置条件：需企业认证的小程序（个人主体不可用）详见[小程序插件开放范围及服务类目](https://developers.weixin.qq.com/miniprogram/introduction/plugin.html#%E5%BC%80%E6%94%BE%E8%8C%83%E5%9B%B4%E5%8F%8A%E6%9C%8D%E5%8A%A1%E7%B1%BB%E7%9B%AE)

**步骤：**

1. 登录[微信公众平台](https://mp.weixin.qq.com/)
2. 左下角小程序个人中心进入【账号设置】→【第三方设置】→【添加插件】
3. 添加插件ID：**wxf2b3a0262975d8c2**

![插件申请示意图](https://resource.eziot.com/group1/M00/00/E4/CtwQEmUP4qOAJewXAAFwGVjslrQ238.png)

## 三 插件引入

全局app.json文件

```
"plugins": {
    "ezplayer": {
        "version": "latest",
        "provider": "wxf2b3a0262975d8c2"
    }
},
```

引入插件的页面.json文件

```
.json文件
{
    "usingComponents": {
        "ezplayer": "plugin://ezplayer/ezplayer"
    }
}
```

引入插件的页面.wxml文件

```
// 以下传参仅为示例，可根据实际参数传递

<ezplayer 
    id="ezplayer"
    accessToken="at.2s5bel782cnsdm748sv5j2ke09p7mpze-54xbxtugfh-0remxt9-gmfxmtml2"
    url="rtmp://open.ys7.com/BA7248908/1/live"
    plugins="talk,voice,ptz,privacy,mirror"
    theme="{{ { showCapture: true, showBottomBar: true, showDatePicker: true, showTypeSwitch: true } }}"
    bind:handleError="handleError"
    bind:onControlEvent="onControlEvent"
/>
```

**小权限 token 场景传参示例**（1.6.1 起支持）：可用细粒度权限的临时 token 替代 accessToken，两者至少提供一个：

```
// token 结构详见 §四 props 表 · 对讲场景需同时传 appId

<ezplayer
    id="ezplayer"
    token="{{ tokenObj }}"
    appId="221ff9b46771481eb28fa893da83abaf"
    url="rtmp://open.ys7.com/BA7248908/1/live"
    plugins="talk,voice,ptz,privacy,mirror"
    bind:handleError="handleError"
    bind:onControlEvent="onControlEvent"
/>
```

### 4.1 播放url传参规则

```
rtmp://open.ys7.com/${deviceSerial}/${channelNo}/${type}/${startTime}/${endTime}
```

##### 字段详解：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| deviceSerial | String | 设备序列号 |  |
| channelNo | int | 视频通道号 |  |
| type | String | 取流类型 | live（预览）、local（本地回放）、cloud（云存储）、cloudRecord（云录制） |
| startTime | YYYY-MM-DD HH:mm:ss | 获取回放时间片段起始时间点 | 开始结束日期必须为同一天 |
| endTime | YYYY-MM-DD HH:mm:ss | 获取回放时间片段终止时间点 | 开始结束日期必须为同一天 |

#### 播放url传参示例：

| 类型 | 传参url示例 | 版本支持 |
| --- | --- | --- |
| 预览/直播 | rtmp://open.ys7.com/BA7248908/1/live |  |
| 本地回放 | rtmp://open.ys7.com/BA7248908/1/local/2023-09-15 00:00:00/2023-09-15 23:10:00 |  |
| 云存储回放 | rtmp://open.ys7.com/BA7248908/1/cloud/2023-09-15 00:00:00/2023-09-15 23:10:00 |  |
| 云录制回放 | rtmp://open.ys7.com/BA7248908/1/cloudRecord/2023-09-15 00:00:00/2023-09-15 23:10:00 | 1.0.8 |

**tips：**

- 当type为live时则会忽略startTime和endTime等回放相关参数值，当type为local、cloud、cloudRecord时，startTime和endTime为必填参数
- startTime和endTime 并不是时间轴渲染起止时间点，回放时间轴的渲染会根据用户传递的起止时间点，获取该时间段内有录像片段的时间点进行高亮展示。
- 注意：受标准流限制，无法获取标准流当前播放的准确时间，回放时间轴中展示的当前播放时间仅作为参考。
- 重要：暂未对播放url做强校验逻辑，请开发者自行保障参数正确性和完整性。

### 4.2 功能plugins传参

```
// plugin字段传递下列字符串为该插件全部功能，可根据需要自行配置

'talk,voice,capture,ptz,privacy,mirror'
```

**tips:**

- 不支持动态变更水印。
- 截图功能不支持水印，即：截图功能依赖原生liveplayer组件，因此保存的图片无水印。若希望截图有水印，需要开发者自行调用官方截图API二次开发。
- 开发者配置plugins功能项时，插件内部会调用设备能力集判断该功能是否可用，可用则会高亮展示。
- 回放只支持截图（capture）功能。
- 功能面板目前不支持样式配置。
- poster通过微信小程序官方基础组件image引入，只支持标准.png.jpg结尾的图片url，不支持本地相对路径传入插件内部。

### 4.3 错误回调说明

**错误码**

| code | msg | 含义 |
| --- | --- | --- |
| 4001 | 参数不完整 | 当type为local、cloud、cloudRecord时，startTime和endTime为必填参数 |
| 4002 | 参数不正确 |  |
| 4003 | 根据取流接口具体msg返回 | 获取预览流取流地址失败 |
| 4004 | 回调设备基本信息接口返回的msg |  |
| 4005 | 回调获取回放时间片段接口返回的msg | 获取回放时间轴失败 |
| 4006 | 暂未获取到回放片段/回调回放取流接口返回的msg | 暂未获取到回放片段/未获取到回放流地址 |
| 5001 | 接口请求失败 |  |

**Token 异常回调**（1.6.1）

Token 类异常不走 `handleError`，统一通过 `onControlEvent` 的 `tokenexpired` 事件上报，`data.code` 用来区分场景：

| code | 触发场景 | 建议处理 |
| --- | --- | --- |
| TOKEN\_EXPIRED | 后端响应 code=10002（真过期或权限异常） | 业务方调后端 refresh 接口拿到新 token，调 `player.updateToken(newToken)` 回填 |
| TOKEN\_EMPTY | 前置校验：需要的 token 分片为空（如对讲、语音广播等） | 检查 `accessToken` 或对应 `token` 分片是否传全 |
| TOKEN\_INVALID | 保留：token 格式错但非过期 | - |

`data.scope` 标识本次异常所属的 token 分片：`'video' | 'global' | 'alarm' | 'nonDeviceOps' | 'resource'`。

### 4.4 小权限 Token 生成指南

#### 概述

小权限 Token 将传统的 `accessToken`（大 token）按功能职责拆分为 5 个独立分片，各分片权限隔离、过期时间独立，遵循最小权限原则。

业务方后端使用萤石开放平台 Java SDK 生成各分片 token，前端通过 `token` 对象传给插件。SDK 对接详见 [开放平台小权限 Token 文档](https://open.ys7.com/help/4334)。

#### 前端 token 分片与 SDK 类对应关系

| 前端分片 | SDK 类 |
| --- | --- |
| `deviceToken`（video / global / alarm） | `DeviceGeneralTokenGenerator` |
| `nonDeviceOps` | `NonDeviceOpsTokenGenerator` |
| `resourceToken` | `GeneralResourceTokenGenerator` |

#### 各分片生成参数

##### deviceToken 三分片（SDK 类：`DeviceGeneralTokenGenerator`）

三个分片都用同一个 Generator，通过以下参数区分：

| 前端分片 | resourceCatagory | action | channelNo |
| --- | --- | --- | --- |
| `deviceToken.video` | `video` | `*` | `*` |
| `deviceToken.global` | `global` | `*` | `*` |
| `deviceToken.alarm` | `global` | `Get` | `*` |

**公共参数**（三者相同）：

- `deviceSerial`：设备序列号（必填）
- `expire`：过期时间，秒（自定义，如 604800 = 7 天）
- `urlPattern`：空字符串（不限制 URL）
- `terminalIP`：空字符串（不限制 IP）
- `useOnceOnly`：false（可复用）
- `appid`：空或填 AppKey（预留参数）

**alarm 与 global 的唯一区别**：`action = "Get"`（只读权限），服务端校验请求的 action 是否匹配 token 内编码的 `ac` 字段。

##### nonDeviceOps（SDK 类：`NonDeviceOpsTokenGenerator`）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `urlPattern` | `/**` | 全放开，不限制接口路径 |
| `expire` | 自定义 | 过期时间（秒） |
| `appid` | 空 | 预留参数 |
| `userId` | 空 | 预留参数 |
| `attributes` | `{}` | 不做 HTTP query 参数校验 |

##### resourceToken（SDK 类：`GeneralResourceTokenGenerator`）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `appid` | `<RTC 项目 ID>` | 从 [开放平台 RTC 项目管理](https://open.ys7.com/console/rtc/projectManage.html) 获取；前端 `ezplayer.appId` 必须传同一个值，服务端做一致性校验 |
| `expire` | 自定义 | 过期时间（秒），官方硬约束上限 604800（7 天） |
| `policy` | Action 列表 | 见下表 |

**policy 内容**：

| Action 名 | 用途 | attributes |
| --- | --- | --- |
| `ERTC_INFO` | RTC 终端入会 | `strRoomId = ""`（空=不限房间） `customId = ""`（空=不限用户） `permission = "7"`（位掩码：1=音频 + 2=视频 + 4=屏幕共享） |
| `GEN_JOIN` | 生成入会凭证 | `password = ""`（空=不限制） `customId = ""`（空=不限制） |

**注意**：attributes 的 key 长度 ≤ 10 字符、value 长度 ≤ 64 字符、单个 Action 最多 5 个 attributes（SDK 硬约束，超限抛 `IllegalArgumentException`）。

## 五 插件全局配置

通过插件实例调用 `setConfig` 方法，可设置插件的全局配置。建议在 `app.js` 的 `onLaunch` 中调用。

```
// app.js
const plugin = requirePlugin('ezplayer')

App({
  onLaunch() {
    plugin.setConfig({
      debug: true  // 开启 debug 日志，默认 true
    })
  }
})
```

#### setConfig 参数

| 参数 | 类型 | 默认值 | 描述 | 版本支持 |
| --- | --- | --- | --- | --- |
| debug | Boolean | true | 是否开启 debug 日志。开启后插件内部会在控制台输出带 `[EZPLAYER]` 前缀的调试日志，便于排查问题。 | 1.5.0 |
