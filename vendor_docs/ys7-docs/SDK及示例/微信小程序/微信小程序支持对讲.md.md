萤石云开放平台小程序（以下简称：萤石云小程序）开放了小程序音视频通话组件，在设备预览基础上为您提供设备对讲功能体验。同时，您可以基于小程序音视频通话组件进行二次开发。

# 1 对讲功能体验

1、进入萤石云小程序首页，单击 「设用设备」，进入试用设备页，单击 「自助设备」 按钮。
2、根据提示填写您的账号信息和设备信息。您可登录萤石开放平台官网 ，在 「控制台」-> 「我的账号」-> 「应用信息」 获取您的accessToken，再单击 「设备列表」 获取您的设备信息，需要您的设备支持全双工，视频编码为H264,音频编码为ACC。或者您还可以通过 HTTP接口 获取您的accessToken。

3、单击 「完成」 按钮进入设备播放页后点击设备播放按钮，播放视频。只有开启视频直播后才可进行设备对讲。
4、若您的设备支持全双工，您可点击 「对讲」，进入设备对讲模块进行对讲体验。

# 2 接入指南

## 2.1 组件介绍

萤石云小程序音视频通话组件可以帮助您通过微信小程序与设备端对讲或者其他小程序端进行音视频通话，基于音视频通话，已经应用于视频客服、电子班牌通话等。我们推出了源码，用户可直接使用并对源码进行修改。

## 2.2 前提条件

微信 App iOS 最低版本要求：7.0.9。
微信 App Android 最低版本要求：7.0.8。
小程序基础库最低版本要求：2.10.0。
开通小程序类目与推拉流标签权限（如不开通则无法正常使用）。 出于政策和合规的考虑，微信暂未放开所有小程序对实时音视频功能（即  和  标签）的支持：
小程序推拉流标签不支持个人小程序，只支持企业类小程序。
小程序推拉流标签使用权限暂时只开放给有限 类目。
符合类目要求的小程序，需要在 微信公众平台 > 开发 > 开发管理 > 接口设置 中自助开通该组件权限，如下图所示：
由于微信开发者工具不支持原生组件（即  和  标签），需要在真机上进行运行体验。

### **2.3.3 配置Demo**

1. 进入修改配置页，根据您下载的源码包。
2. 找到并打开 ./pages/multiPartCall/index/index.js 文件,设置相关参数。

- accessToken: '', // 开放平台访问令牌
- deviceSerial: '', // 设备序列号
- channelNo: '', // 通道号
  ![设置demo参数](https://resource.eziot.com/group1/M00/00/88/CtwQEmLWwWiAIx5-AABm4h9UrE4762.png)

3. 点击【开始对讲】按钮，体验设备对讲功能

### **2.3.4 编译运行**

1. 打开微信开发者工具，选择小程序，单击新建图标，选择导入项目。
2. 填写您微信小程序的 AppID，单击确定。
3. 单击预览，生成二维码，通过手机微信扫码二维码即可进入小程序。

### **2.3.5 扩展**

敬请期待萤石开放平台微信小程序音视频SDK。

- 支持 加入房间（enterRoom）
- 支持 离开房间（leave）
- 支持 发布音视频流（pushStream）
- 支持 停止发布音视频流 （stopPushStream）
- 支持 订阅远端的音视频流 （pullPeerStream）
- 支持 停止订阅远端的音视频流 （stopPullPeerStream）
- 支持 暂停发送本地音视频流 （pausePushStream）
- 支持 恢复发送本地音视频流 （resumePushStream）
- 支持 暂停接收远端音视频流 （pausePullPeerStream）
- 支持 继续接收远端音视频流 （resumePullPeerStream）
- 支持 设置监听事件，监听房间状态（onRoomInfoChange）
- 支持 更新accesstoken与rtctoken
