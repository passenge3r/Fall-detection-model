# 轻应用UIKit硬解解码性能说明、高性能集成建议

## 说明

- **8.0.0**之前的版本不支持高性能模式
- **8.2.0**及之后的版本默认启用高性能模式，若环境不支持则逐级递减，无需再手动配置
- **8.0.0~8.1.17**版本轻应用UIKIT分为两个版本，一个是浏览器单页面版本UIKIT，一个是硬解版本UIKIT PRO，该版本已不再更新维护，请开发者集成最新版本

## 一、集成说明

本文档部分性能测试是基于硬解模式，请开发者详细参考轻应用UIKit集成功能

## 二、各版本解码库支持条件

**注：**由于UIKIT PRO 解码库V3软解版本向前兼容V2.1多线程版本，因此升级高性能版本后**弃用了V2版本**解码库

| 版本 | 模式 | 是否依赖跨域隔离 | 支持的浏览器 | 开启条件及限制 | 是否支持移动端 |
| --- | --- | --- | --- | --- | --- |
| UIKIT标准版 | 单线程模式 | 否 | ChromeFireFoxEdge | / | 是 |
| ~V2~ | ~多线程模式~ | ~是~ | ~Chrome浏览器版本>V94 |  |  |
| ~ | ~浏览器开启跨域隔离~ | ~否~ |  |  |  |
| UIKIT PRO | 硬解模式 | 否 | Chrome>V94Edge>V94 | 独显N卡>GTX950 独显A卡>RX460集显>Intel HD620win10及以上操作系统 | 否 |
| 软解模式（多线程模式） | 是 | Chrome>V91Edge>V91FireFox>V107 | Chrome浏览器：开启跨域隔离向前兼容V2.1多线程版本 |  | 否 |

## 三、配置说明

#### **3.1 初始化实例预留了配置是否启用硬解模式的入口**

- 在html文件中初始化EZUIKIT实例的地方进行配置
- 若useHardDev为true，若当前电脑支持硬解模式，则优先启用硬解
- 若useHardDev为false，则忽略硬解模式，在开启跨域隔离的环境下会开启软件模式，未开启则使用V1版本
- useHardDev默认为true
