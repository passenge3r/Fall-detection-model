# uni-app（原生语言插件）音视频集成

> uni-app官网有JS SDK、App原生语言插件等多个集成插件方式，本文主要是提供原生语言插件的集成方法

# 背景说明

为了适应iOS、Android、Web（响应式）、以及各种小程序（微信/支付宝/百度/头条/飞书/QQ/快手/钉钉/淘宝）、快应用等多端泛滥的情况DCLOUD公司推出uni-app这个跨平台开发工具。

基于uni-app能够有效减少开发工作者在不同端学习成本，减少公司招聘各端研发人才的人力成本的优势，不少开发者和服务商选择用这种开发形式开发音视频应用。为了解决广大萤石开放平台开发者在uniapp音视频开发过程中无代码可参考的困扰，现推出uni-app demo，让多端开发更轻松。

# 区别

由于SDK来源、集成内容不同，萤石提供了两套Uni-app的集成方法：

①本文集成方法：基于iOS、Android 原生语言提供的Uni-app原生语言插件，该功能与iOS、Android SDK的功能保持一致，无UI等内容，具体功能列表见：[iOS SDK 功能概述](https://open.ys7.com/help/4102)

②Uni-app JS SDK集成方法：基于JS SDK的集成插件，该功能与UIKIT web SDK的功能保持一致，含轻应用的预览、回放模板UI等内容，适用于网页、小程序等集成方法，具体功能可详见：[前往查看](https://open.ys7.com/help/529)
