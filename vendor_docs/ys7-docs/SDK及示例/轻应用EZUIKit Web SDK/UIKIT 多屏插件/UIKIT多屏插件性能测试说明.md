## # 萤石开放平台轻应用插件（EZUIKitNative）性能测试

## 1. 测试概述 (Executive Summary)

### 1.1 测试目的

本次测试旨在验证 轻应用插件（[uikit插件](https://open.ys7.com/help/5068) ）版本的性能表现，重点评估其在不同机型上的兼容性、1080p视频的流畅度以及长时间播放的稳定性，记录插件后台进程的资源占用。

### 1.2 参数来源说明

- 1、CPU/GPU/内存：任务管理器->进程->单页面浏览器窗口的进程占用率（如图）

---

## 2. 测试环境 (Test Environment)

### 2.1 硬件配置

出厂配置：HP 288G9/I7-12700/H670/16G DDR4 3200/256G 2280 M.2 PCIe SSD+1TB HDD 7200PRM SATA/集成显卡/无光驱/VGA+HDMI/350W/有线键鼠/3年国内上门保修/8个USB接口/4.7Kg

| 设备类型 | 型号/CPU | 内存 (RAM) | 显卡 | 操作系统 | 屏幕分辨率 |
| --- | --- | --- | --- | --- | --- |
| 台式机 | 12th Gen Intel(R) Core(TM) i7-12700 2.10 GHz | 16.0 GB | 集显Intel(R) UHD Graphics 770 | Windows 10 | 1920x1080 |
| 台式机 | 13th Gen Intel(R) Core(TM) i7-13700 2.10 GHz | 16.0 GB | 集显Intel(R) UHD Graphics 770 | Windows 11 | 1920x1080 |
|  |  |  |  |  |  |

### 2.2 测试要求

- 视频编码格式：H.264、H.265
- 画面质量：高清（1080P或2K, 4K）
- 码率范围：101kbps - 774kbps
- 稳定性运行时长：2小时以上

---

## 3. 核心性能指标 (Key Performance Indicators)

### 3.1 进程的资源占用

测试结果：使用办公电脑测试Chrome、Edge浏览器，1080P分辨率16屏以上播放2H，部分窗口延迟1分钟左右，画面会出现轻微卡顿。

兼容性：请使用Chrome、Edge浏览器，其他浏览器暂不支持。
