# 萤石开放平台轻应用插件（EZUIKitNative）产品介绍

**⚠注意：EZUIKitNative为萤石新推出的实验性SDK，功能持续完善中，业务场景上线之前请进行充分的集成测试。**

## 一、 产品背景

随着网络摄像机技术的飞速发展，4K超高清、高码率摄像头在各类监控场景中已逐渐普及。原有的“无插件轻应用”方案基于纯浏览器环境，通过H5、Web等方式解码视频流，在满足中轻度、1-4画面视频播放时表现优异。

然而，在面对高并发、大屏展示等重度监控需求时，“无插件轻应用”方案受到了浏览器底层资源和内存机制的严格限制（如浏览器同源连接数限制、单页面内存上限等）。特别是在**多个超高清画面同时播放**的场景下，极易引发浏览器卡顿、崩溃、内存溢出以及软解码性能不足等问题。为了彻底解决高性能多路视频播放的痛点，萤石开放平台推出了**轻应用插件方案——EZUIKitNative**。

## 二、 核心区别与技术优势

轻应用插件（EZUIKitNative）是对无插件模式的强力补充与扩展升级，两者的核心区别及优势体现在以下几个方面：

- **硬件解码能力（核心区别）**：无插件模式多依赖于浏览器运行环境与CPU软解码，处理超高清、高码率视频时负担极重。而轻应用插件模式**调用了本地硬件解码视频播放器的能力**，通过GPU显卡进行硬解，大幅释放CPU压力。
- **突破多屏播放极限**：受浏览器资源限制，无插件模式通常限制最多同时初始化播放 **9个** 画面；而插件模式通过与本地插件连接通信，彻底突破浏览器限制，**最高支持 25路 视频画面同时稳定播放**。
- **平滑跟随与极佳兼容**：基于 `EZUIKitPlayer` 扩展升级，参数、功能及监听事件**100%向前兼容**。纯前端低成本集成，插件窗口可随浏览器的位置、大小、可见性自动自适应跟随，支持自由指定屏幕布局的行列数（最大 5x5 分屏）。
- **智能双模式切换**：SDK 提供“自动模式”，能根据开发者传入的设备数量智能判断：当设备数 \le 9 时自动采用无插件轻量渲染，当设备数 > 9 或强制指定时，自动唤醒并切换至高性能插件模式。

轻应用插件并非要取代无插件方案，而是作为其强有力的补充，专门针对高负载场景设计。两者的核心差异如下：

| 对比维度 | 无插件轻应用 (UIKit) | 轻应用插件方案 |
| --- | --- | --- |
| **技术架构** | 纯JavaScript组件，依赖浏览器渲染 | 引入本地原生插件，硬解码+独立渲染窗口 |
| **适用分辨率** | 1080P及以下常规清晰度 | **支持4K超高清**及更高码率流媒体 |
| **多屏并发** | 建议9路以内，过多易内存不足 | **最高支持25路**视频同时稳定播放 |
| **资源消耗** | 占用大量浏览器内存与CPU | 释放浏览器压力，利用本地硬件加速 |
| **定位** | 轻量级、跨平台、快速接入 | **高性能、重负载、专业监控** |

## 三、 产品应用场景

EZUIKitNative 完美适用于追求**多画面并发、超高清、高流畅、低延迟**的工业级与商业大屏监控场景：

### 1. 连锁商贸（集中巡店与运营大屏）

- **场景痛点**：跨区域、跨店面的连锁零售品牌或商贸集团，通常需要在一个画面中同时监视几十家门店的实时收银、客流、货架情况。
- **插件价值**：支持高达25路画面同屏展示，管理人员可通过 Web 平台直接调用本地硬件解码，实现无缝的多店轮巡与实时画面监控，彻底告别网页卡顿。

### 2. 安消监控（安全消防值守与无人巡检）

- **场景痛点**：智慧园区、工业厂区及消防重点单位的值班室，需要对关键通道、消防栓、机房等点位进行无人值守的 24 小时高密度监控。
- **插件价值**：插件模式提供极高稳定性。支持一键全屏、单画面双击放大等交互，并无缝支持截图（`capturePicture`）、录制（`stopSave`）等事件，方便值班人员在发生消防或安全告警时快速定位并留存证据。

### 3. 工地大屏（智慧工地综合管控大屏）

- **场景痛点**：建筑工地现场环境复杂、高空抛物及危险区域众多。工地调度中心的大屏系统通常需要同时渲染塔吊、基坑、出入口等多个4K超高清球机画面。
- **插件价值**：借助 GPU 硬解能力，轻松驾驭多路4K高码率视频流。支持自定义布局行列数（如 `layout: { col: 4, row: 4 }`），完美适配工地指挥中心的拼接大屏或 PC 端综合管理系统。

萤石开放平台轻应用插件，是对现有Web视频监控生态的一次重要补强。它打破了浏览器性能的枷锁，让4K超高清与多屏并发成为可能。无论是连锁商贸的精细化运营，还是安消工地的宏观指挥，轻应用插件都能为您提供最坚实的视频底座。
