# 视频巡检

视频巡检组件专为安防、工地、质量监控等场景设计，通过单页面多设备协同管理提升监控工作效率，实现全方位、无死角的可视化线上巡检。

- 设备展示：以树形结构展示指定账号下的设备、通道列表
- 批量预览/回放：同时播放多个设备画面
- 布局切换：按需调整单页画面数量、布局结构
- 轮询：手动翻页、自动定时翻页
- 播放器操作：批量操作所有播放器、单独操作某个播放器

**基于EZUIKit多屏播放能力，使用萤石提供的视频巡检组件，或通过批量创建多个播放器实例，自主实现单个页面内的多设备巡检业务功能。**

## 1、 视频巡检组件

EZUIKit内置一套巡检组件：EZUIKitInspectionUI，只需一行代码即可快速创建视频巡检模块，适合前端开发资源紧缺、对交互样式要求不高的场景。

```
new EZUIKit.EZUIKitInspectionUI(document.getElementById('player'), { list: deviceList })
```

## 2、自定义视频巡检

基于EZUIKit多屏播放能力自主实现视频巡检业务，自定义播放器布局，自由管理设备列表及播放器实例，适合具备前端研发资源且对页面交互结构要求较高的场景。

## 3、开放平台视频巡检

萤石开放平台控制台已上线视频巡检业务，由萤石基于EZUIKit多屏播放能力开发，支持开发者账号下所有绑定账号/托管账号进行视频巡检，适合无前端开发资源或是想体验视频巡检功能的场景。

**访问：萤石开放平台控制台 -> 云直播 -> 视频巡检，[立即体验](https://open.ys7.com/console/inspectionScreen.html)。**
