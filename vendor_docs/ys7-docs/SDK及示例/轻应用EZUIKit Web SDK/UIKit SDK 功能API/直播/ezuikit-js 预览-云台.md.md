# 云台

云台也称PTZ，是指对摄像机进行操控，比如云台转动、物理缩放、变焦等操作。 可以根据需要自动或手动调整方向和焦距，确保关键区域始终处于监控范围内。 该能力需摄像头本身支持PTZ能力。

## 云台控制

请先确认设备是否具备云台能力，并报备了对应功能的能力集，未报备会导致对应功能开启时报。若设备硬件确实支持PTZ，但是返回结果为不支持，可联系设备售后确认能力集报备准确性。

| 能力集 | 功能 |
| --- | --- |
| support\_ptz | 云台 |
| ptz\_left\_right | 云台左右转动 |
| ptz\_top\_bottom | 云台上下转动 |
| ptz\_45 | 云台45度角转动 |
| ptz\_focus | 变焦 |
| ptz\_zoom | 物理缩放 |

## 云台控制UI

EZUIKit官方模板提供云台控制UI模块，可以在使用官方模板pcLive时通过点击云台按钮或调用API开启。

**代码示例**

```
// 展示云台模块
player.Theme.Ptz.show();

// 隐藏云台模块
player.Theme.Ptz.hide();
```

## 云台控制接口

开放平台提供OPEN API直接控制设备云台，参考：https://open.ys7.com/help/679
