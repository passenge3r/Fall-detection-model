# 回放时间戳

录像回放过程中，获取当前播放帧的时间戳。

**代码示例**

```
// 获取秒级OSD时间戳
player.getOSDTime().then((res) => console.log(res));
```

## 注意

由于国标协议没有内置的OSD时间戳，EZUIKit会在开始回放后根据开始播放时间设置一个OSD基准时间，可能存在获取的OSD时间与画面显示的时间戳不一致的情况。
