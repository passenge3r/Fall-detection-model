# 排障工具

萤石云开放平台针对EZUIKit提供了一个排障工具平台，包括SDK初始化播放、版本切换、API功能触发、日志导出等功能，用于SDK使用过程中的问题收集与排障。

排障工具地址：[萤石开放平台-提供持续稳定的以音视频为主的全场景、多功能综合性服务](https://openstatic.ys7.com/ezuikit_troubleshoots/index.html)

## 初始化排障

- 填写ezopen播放地址、accessToken、template、对讲通道、设备环境参数，点击初始化执行SDK初始化操作，各参数内容及来源说明见输入框后方的链接。
- 初始化完成后按钮下方会展示结果，若初始化失败，可以点击查看具体原因及解决方案。

## 功能触发

排障工具提供播放、记录、画面、设备能力、对讲、状态获取相关功能API的触发按钮，点击后会使用右侧播放器实例触发相应功能。

- 触发功能会在右侧播放器上实时执行生效。
- 触发API的调用示例会同步在播放器下方的日志区域同步打印。

## 版本切换

若您使用的是历史版本的EZUIKit，排障工具提供了版本切换功能帮助您针对性进行排障。

- 右上角下拉框选择对应的EZUIKit版本。
- 若下拉列表中没有您想要的版本，可以选择其他版本，并在输入框中输入对应的版本进行切换。
- 版本号格式：X.X.X，仅支持7.7.9及之后的版本使用排障工具。

## 日志

SDK初始化及功能触发过程中的所有日志都会打印在播放器下方的日志区域。

点击导出按钮，可以导出所有日志及初始化参数，方便进行下一步问题反馈。
