# 配网常见问题

## 公共问题

### 1. SoftAP等定制设备无法配网

我们的SDK默认支持的是基线设备(热点WIFI名为EZVIZ\_序列号)。如果您的设备是定制的，前缀可能是SoftAP\_序列号或者其他，那热点验证码则为SoftAP\_验证码。

v5.17之前，iOS Demo需要在GlobalKit.m设置对应的WiFi Prefix，如SoftAP。 android Demo 需要在ApConfigWifiPresenterForFullSdk.java类中，确保deviceHotspotSSID和deviceHotspotPwd这两个参数一定要传入对应的设备热点名和设备热点密码，否则配网失败，其他同理。

**v5.17起，SDK已接入能力集support\_custom\_wifi\_prefix，可以判断定制设备的热点头，demo层已做适配。客户在使用demo的时候不需要再更改任何代码。**

### 2. AP配网的时候，故意输入一个错误的WiFi密码，设备已经语音播报错误了，SDK内部还在走轮询逻辑，要等很久才会返回 配网超时这个状态

AP配网时，SDK只是负责将WiFi信息发送给设备。

设备端：接收到WiFi信息后会关闭热点并进行联网；

SDK端：热点断开后，连接回原来的WiFi网络进入90秒轮询逻辑；
此时手机和设备没有任何的通讯联系，即使WiFi密码错误，设备已经语音播报失败，SDK也是无法感知的，只能等待设备成功连接网络且注册到平台后才能查询到设备的在线状态；或者等待SDK90秒内未查询到设备的在线状态，视为配网失败，回调配网超时消息给应用层。

### 3. 设备配网时提示“当前网络环境复杂...”，无法配网

当前设备所在环境存在过多的WiFi信号，设备未搜索到配网指定的WiFi账号，需要重新尝试配网；或者找个没有过多信号干扰的环境进行配网

## Android配网问题

### 1. AP配网弹出网络连接确认框，萤石云视频App没有

安卓Q-SDK API 29-系统版本号10.0以上，旧的强制连接wifi的api已被废弃，使用的话会失败。必须使用新的api来做网络连接，就会弹出提示需要用户确认才能进行网络连接。

萤石云视频App不弹框提示是因为国内的App target还是28，所以还能用旧的api。
EZOpenSDK是国内和海外公用的，有些用户需要将App上架到谷歌的Play Store，而Play Store最低的target sdk要求就是30，所以只能使用新的api来配网。

综上，这个是正常现象。以后国内应用商城targetsdk要求上来了，国内的萤石云视频App也会使用新的api，会出现网络连接弹框提示。

### 2. AP配网连接设备热点，不断弹框提示是否连接网络

**问题原因**：系统在wifi连接到设备的AP 热点后，大概过了30s，系统启动外网的检测机制，当发现该设备热点wifi无外网时，给该设备热点打上一个无外网的标签并且缓存到系统里面。当App调用API主动连接wifi名相同的热点时，系统读取到缓存认为这个wifi无网络，直接强行关闭弹窗，重新弹窗。

**解决方案**：手动去wifi管理页面，把缓存的相同wifi名删除掉即可。

### 3. AP配网EZOpenSDK.startAPConfigWifiWithSsid 错误码回调，每个错误码含义（105、110、111、120、15、502、505、506、507、605等）

请参考ApConfigWifiPresenterForFullSdk.java类OnError方法罗列的错误码注释，更多错误码查看EZConfigWifiErrorEnum类

105：配网参数异常  
110：仍在执行上次配网，进行下次配网前需要调用配网停止接口  
111：手机未接入目标wifi，无法检测设备是否配网成功  
120：验证码错误  
15：90秒配网超时，一般是设备要连接的wifi有问题，设备虽然连接上了wifi，但是无法注册到平台  
501：未打开定位权限，搜不到任何wifi  
502：AP配网进行中  
505：设备不支持AP配网模式，或设备未重置到AP配网模式  
506：在Android10及以上系统，使用NetworkSpecifier尝试自动连接到设备热点时，被用户主动拒绝。  
507：尝试打开wifi开关失败。  
605：手机未连接wifi，无法向设备传输配置  
705：手机音量未调到最大  
801：服务器异常  
802：网络异常

## iOS配网问题

### 1. login failed ret = %ld, error code = %ld

error code = 1：设备验证码输入错误  
error code = 7：连接设备失败；设备不在线或网络原因引起的连接超时等

### 2. Smart配网问题

- Smart配网失败是正常情况，所以现在设备都用AP配网方式了
- 苹果手机芯片可能不支持smart配网的，可以使用安卓手机去配网
