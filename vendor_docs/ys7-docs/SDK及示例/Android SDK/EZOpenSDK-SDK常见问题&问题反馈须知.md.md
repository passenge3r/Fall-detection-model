# App SDK常见问题 & 问题反馈须知

## 预览问题

### 1.设备预览失败

- 查阅[萤石开放平台SDK错误码文档](https://open.ys7.com/help/37)
- 确定是否是网络问题，切换至外网试试
- 如果demo正常，开发者自己App不正常，可能是验证码问题，setPlayVerifyCode方法打断点，检查传入的是不是明文字符串。SDK中验证码要传入明文，用户App验证码可能获取了后端加密的验证码
- 可能是服务端返回设备未加密，设备实际是加密状态，进入Demo该设备的设置页面，开启或关闭“视频图片加密”，同步下再试下

### 2.预览花屏、绿屏、卡顿

- 设备端网络不稳定或设备有问题，设备端传输过来的原始码流问题。可使用萤石云视频App对该设备预览进行对比验证。

### 3.啸叫、噪音

- 当摄像头和手机（或其他扩音设备）距离过近时，摄像头采集到的声音会被手机放大并再次传回摄像头，形成声音环路。这种循环放大的声音会导致尖锐刺耳的啸叫。测试或使用过程中，保证摄像头和手机不要离太近或在同一封闭空间中，或在预览时关闭EZPlayer播放器的声音，从而避免啸叫问题。

## 回放问题

### 1. 倍数设置失败

请使用官网最新Demo复现，在日志中搜索 setPlaybackRate failed, 找到错误码及错误原因

### 2. seek失败

请使用官网最新Demo复现，在日志中搜索 seekPlayback failed, 找到错误码及错误原因

### 3. 其他回放相关错误

查阅[萤石开放平台SDK错误码文档](https://open.ys7.com/help/37)

## 对讲问题

### 1. 对讲失败

- 查阅[萤石开放平台SDK错误码文档](https://open.ys7.com/help/37)
- 请先确认您的设备是否支持对讲。如果是IPC设备，调试区日志中搜索supportExtShort字段第2位数字，1：支持全双工 3：支持半双工 4：同时支持全双工和半双工；其他：不支持；如果是NVR设备，调试区日志中搜索supportExtShort字段第192位数字，1：支持通道对讲；其他：不支持

### 2. 安卓对讲声音比iOS小

- iOS开了AGC音效增强，声音会大点。android开了AGC会导致声音质量变差，Android声音本身就不小，所以没开AGC。

## 配网问题

- 查阅[萤石开放平台SDK 错误码文档](https://open.ys7.com/help/37)
- 查阅[萤石开放平台SDK 配网常见问题](https://open.ys7.com/help/4147)
- 使用萤石云视频App对该设备进行配网操作，如果也不能配网可能是设备故障
- 如果以上方式排查后仍未解决您的配网问题，请[创建工单](https://open.ys7.com/console/work.html)，提供Demo配网过程视频（**用另一个手机拍，不是手机配网录屏**，需要观察设备的响应提示），以及Demo配网过程的完整日志。

## 小权限tkToken问题

- 请先检测该接口或者功能使用的是哪种类型的tkToken，是不是未设置对应的tkToken。查阅[SDK初始化](https://open.ys7.com/help/4151)文档中的**小权限TKToken授权模式** 部分说明。
- 请检查tkToken生成规则，入参是否设置错误。**特别需要注意以下两个场景**：

```
1、IPC设备对讲使用的是0通道，对讲streamToken生成请使用0通道。
2、双目设备(C7/C60P/Y5000FVX门锁等设备)取流使用的是交织流0通道，取流streamToken生成请使用0通道，deviceGlobalToken和deviceVideoToken保持不变使用1通道。
```

- SDK只负责tkToken的透传，tkToken的生成和校验都不在SDK端；需提供tkToken生成规则+接口请求报文+接口响应报文，找服务端负责人排查。

## 问题反馈须知

请先按照以下步骤进行问题排查，通常能够定位并解决大部分SDK使用过程中遇到的问题。

- 访问[萤石开放平台SDK错误码文档](https://open.ys7.com/help/37) ，查看详细的错误码说明和解决方案
- 浏览页面上方整理的常见问题及对应解决方案
- 利用本页面右侧的【AI助理】功能，获取智能化的问题诊断和解决建议

  

如果上述方法仍未解决问题，请运行官网提供的[最新版本Demo工程](https://open.ys7.com/cn/s/download)，确认问题是否能够复现。

- 若无法复现，说明SDK最新版本已修复该问题，或者开发者在集成过程中存在不规范操作，建议参考Demo工程实现方式进行调整；
- 如果能复现，请[创建工单](https://open.ys7.com/console/work.html)，并提供以下必要信息：

  ```
  1.SDK平台类型：android、iOS、Harmony、或其他平台
  2.问题出现频率（必现还是偶现）
  3.问题详细描述（包括具体功能模块、操作步骤、异常现象，建议提供复现录屏）
  4.萤石Demo工程（不是您的App）从启动到问题复现的完整日志，IDE调试区域Ctrl+A, Ctrl+C复制【 注：此信息为必须提供项】
  ```

  

如对Demo不熟悉，请跳转 [Demo使用指南](https://open.ys7.com/help/4148) & 阅读SDK压缩包中的【README(集成必读).txt】
