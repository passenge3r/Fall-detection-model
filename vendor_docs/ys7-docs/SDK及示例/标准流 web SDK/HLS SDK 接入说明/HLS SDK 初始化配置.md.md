# HLS SDK 初始化配置

| option | 说明 | 类型 | 是否必填 | 默认值 | 版本 |
| --- | --- | --- | --- | --- | --- |
| id | 目标 dom 容器节点的 id | string | 是 | - | 0.1.0 |
| url | 取流地址 | string | 是 | - | 0.1.0 |
| width | 容器节点的宽 | number | 是 | - | 0.1.0 |
| height | 容器节点的高 | number | 是 | - | 0.1.0 |
| staticPath | wasm解码库资源地址 | string | 否 | / | 0.1.0 |
| autoPlay | 是否自动播放 | boolean | 否 | true | 0.1.0 |
