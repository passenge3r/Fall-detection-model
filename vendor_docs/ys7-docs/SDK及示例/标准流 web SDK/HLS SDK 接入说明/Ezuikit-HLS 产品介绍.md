# Ezuikit-HLS 产品介绍

[@ezuikit/player-hls](https://www.npmjs.com/package/@ezuikit/player-hls)是一款开源的纯H5直播流播放器，通过Emscripten将音视频解码库编译成js（wasm) 运行于浏览器之中。兼容主流浏览器，可以运行在PC、手机、微信中，无需额外安装插件。

### 功能

- 支持解码H.264视频
- 支持解码H.265视频（软解 ）
- 支持解码AAC音频
- 可创建多个播放实例
