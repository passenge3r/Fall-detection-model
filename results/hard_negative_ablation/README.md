# 困难负样本重训练消融

更新日期：2026-08-01

## 实验设计

- 路线：RTMPose + ST-GCN++；4折，每折固定训练300轮，不早停。
- 从原滑窗模型的折外预测中选择跌倒概率不低于0.8的ADL窗口，共110个。
- 每个困难窗口仅在其主体属于训练集的折中增加2份训练副本。
- 验证集、内部测试集和MCFD外部测试集均不改变；MCFD没有加入训练。

## 结果

| 数据与指标 | 原滑窗模型 | 困难负样本模型 | 变化 |
|---|---:|---:|---:|
| GMDCSA24 Accuracy | 84.56% | 83.91% | -0.65% |
| GMDCSA24 Recall | 81.34% | 87.00% | 5.66% |
| GMDCSA24 Specificity | 85.99% | 82.54% | -3.45% |
| GMDCSA24 F1 | 76.45% | 76.92% | 0.47% |
| GMDCSA24 Balanced Accuracy | 83.67% | 84.77% | 1.10% |
| MCFD固定0.5 Accuracy | 67.47% | 67.23% | -0.24% |
| MCFD固定0.5 Recall | 69.35% | 75.38% | 6.03% |
| MCFD固定0.5 Specificity | 65.74% | 59.72% | -6.02% |
| MCFD固定0.5 F1 | 67.15% | 68.81% | 1.65% |

MCFD固定阈值0.5的混淆矩阵变化：FP 74→87，
FN 61→49。困难负样本模型少漏报12段，但多误报13段。

## 结论

本轮没有达到“降低误报”的原目标，但形成了一个更偏向召回的模型：MCFD F1提高
1.65个百分点、Recall提高
6.03个百分点；与此同时Specificity下降、
FP增加，Accuracy与ROC-AUC略降。因此暂不替换当前均衡主模型，可保留为“少漏报模式”候选。

下一轮应测试较弱的过采样（1份副本），或同时加入折外困难正样本，以寻找Recall与
Specificity更平衡的工作点。阈值校准也应与训练策略分开评估。
